Towards World Simulator: Crafting Physical Commonsense-Based Benchmark for Video Generation ​

项内容
arXiv2410.05363
提交日期2024-10-07
作者Fanqing Meng, Jiaqi Liao, Xinyu Tan, Wenqi Shao, Quanfeng Lu, Kaipeng Zhang, Yu Cheng, Dianqi Li, Yu Qiao, Ping Luo
分类cs.CV（项目页：PhyGenBench）
一句话用 160 条"一 prompt 一物理定律"的干净提示构成 PhyGenBench，再用 GPT-4o 生成定制问题、按单帧/多帧/整段三级递进的 PhyGenEval 打分，把"视频违不违反物理常识"变成与人类判断高度相关的自动指标。

所属教程：物理感知视频生成

§ 1 — 研究问题与重要性 ​

Sora 之后，"T2V 模型是通向通用世界模拟器的路径"这个说法被反复提起。认知心理学的立场是，达成这个目标的基础是理解直觉物理——连婴儿都具备的那种。直觉物理强调的是渲染出的场景对人来说视觉上和交互上自然，而不是严格的数值精确。

论文用一个极简的例子把问题钉住：石头放进水里应该沉下去，而当时最强的模型做不到；飞机飞过平静水面应该有倒影，模型也常常漏掉。这类"看起来无聊"的现象，恰恰暴露了模型与人在基础物理上的鸿沟。

评估这件事当时有两个具体的缺口。基准缺口：现有 T2V benchmark（VBench、EvalCrafter、T2V-CompBench、DEVIL）测的是运动平滑度、背景一致性、空间关系、组合能力、动态特性，没有一个直接测"是否遵守物理定律"；VideoPhy 触及了动态运动的自然性，但没有简洁地覆盖基础物理定律。指标缺口：FVD 检测不出不真实运动且需要参考视频，新场景拿不到；直接用 video-based VLM 评估则受限于它们自身对物理定律的理解不足，而且这些方法本来也不是为物理评估设计的。

§ 2 — 前人工作与不足 ​

基准侧。FVD 依赖 UCF-101、Kinetics-400 这类范围受限的数据集。VBench 与 EvalCrafter 做的是多维度综合视频质量评估。T2V-CompBench 评组合生成能力，DEVIL 评动态特性。VideoPhy 最接近，它有 688 条精心筛选的简单 prompt，聚焦固-固、固-流、流-流三类材料交互，但论文指出两个具体不足：一是覆盖窄，缺少相变、基础材料属性这些常见物理定律，且没有物理定律的标注，导致 VLM 难以据此评估；二是它的 prompt 对 T2V 模型太难——论文用 64 条 prompt 做的对照显示 VideoPhy 的平均语义对齐（SA）得分只有 0.63，而 PhyGenBench 是 0.80。原因是 VideoPhy 的 prompt 一方面细节不足（"A tissue blots a tear from an eye"过于简略，而现代 T2V 模型是用更长更描述性的 caption 训练的），另一方面场景过于复杂或不可见（"The wristwatch knob winds the inner spring tightly"描述的是外部看不到的内部机构）。如果模型连语义对齐的视频都生不出来，评估其物理正确性就没有意义。

指标侧。VideoScore 从 VIDEOFEEDBACK 数据集训练自动评分模型，T2V-CompBench 用 Grid-LLaVA（均匀采 6 帧拼成图像网格）评空间关系，DEVIL 用 Gemini 1.5 Pro 对所有视频套同一套评分模板评整体自然度。论文实测这些指标在 PhyGenBench 上都泛化不过去：与人类评估相关性最高的 VideoScore 的 Spearman 也只有 0.19。案例分析给出了失败的具体形态——鸡蛋撞石头后像橡胶一样弹开，VideoScore 和 DEVIL 因为运动平滑连贯就判为物理正确；石头浮在水面，VideoPhy 判为正确；铜燃烧的火焰是红色而不是绿色，三者都发现不了，因为它们无法引入领域特定的物理常识。

§ 3 — 重建作者的思考路径 ​

第一步是承认一个约束：要自动评估物理正确性，被评估的视频首先得在语义上生成对。如果 prompt 太难导致模型连场景都生不出来，物理评估就退化成噪声。这直接决定了 benchmark 的设计方向——prompt 要简单、清晰、现象可观测，而不是越难越好。这与"benchmark 应该有区分度"的常见直觉相反，但在这个特定任务上是对的。

第二步是把物理常识组织起来。翻教科书是最直接的办法：从力学、光学、热学、材料属性四大类里挑那些被广泛认可、且能通过清晰可观测现象体现的定律。然后为每条定律手工写能明确体现该现象的 prompt。这里有一个容易踩的坑——一条 prompt 里混进多条物理定律会让评估变得模糊，连人类标注者都会犯难。所以必须强制"一条 prompt 对应一个物理现象"的一一对应。

第三步是想清楚为什么直接问 VLM"这个视频物理对不对"不работает。因为 prompt 里语义实体和物理现象混在一起，而中间结果被视频隐含地暗示。给定"汤在温度升到 100°C 以上时的延时摄影"，模型可能生成"画面里有汤但没有任何变化"——这时候 VLM 分不清是语义没对齐还是物理不对。所以第一件事是解耦：把语义对齐（SA）和物理常识对齐（PCA）分开评。

第四步是把 PCA 再拆开。物理过程有三个可被独立检验的性质：关键现象有没有出现（鸡蛋碎了没）、关键现象的顺序对不对（先接触后碎，不是先碎后接触）、整体过程自不自然。这三件事对应的视觉粒度不同——单帧、多帧、整段视频。于是三级递进的评估结构就自然出来了，每一级用最适合那个粒度的 VLM，并用 GPT-4o 根据物理定律现场生成定制问题，把领域知识注入进去。

§ 4 — 核心 Intuition ​

物理正确性之所以测不准，是因为它被当成一个整体判断丢给了 VLM，而 VLM 既不懂具体物理定律，也难以在一段视频上同时追踪"现象、顺序、自然度"。PhyGenEval 的做法是先用 LLM 把物理定律翻译成一组具体的、可用视觉问答回答的检查项，再按视觉粒度从单帧到整段逐级检验。任务难度因此被大幅降低——每一级只需要回答一个很窄的问题，而这正是当前 VLM 能做好的。

§ 5 — 具体方法与完整 Pipeline ​

以"一个鸡蛋被大力掷向石头"为例走一遍。

PhyGenBench 构建（五步）：1) 概念化，从力学、光学、热学、材料属性四大类中依教科书选出可被清晰观测的定律；2) prompt 工程，为每条定律手写初始 prompt；3) prompt 增强，加入更精确的物体与动作描述以提升生成质量，但刻意不透露预期的物理现象；4) 多样性增强，用 GPT-4o 做物体替换；5) 质量控制，人工复核 prompt 与定律的对应关系，并用当时的 T2V 模型抽检 prompt 是否足够简单到能生成语义正确的视频。最终 160 条 prompt 覆盖 27 条定律：力学 7 条（重力、浮力、固体压强、大气压强、弹性、摩擦、表面张力）40 条 prompt；光学 6 类（反射、折射、散射、色散、干涉衍射、直线传播）50 条；热学 6 种相变（凝固、熔化、液化、沸腾、凝华、升华）30 条；材料属性 5 项物理性质（颜色、硬度、溶解性、可燃性、焰色反应）加 3 项化学性质（酸性、氧化还原、脱水性）40 条。数据集共含 165 个独立物体、42 个独立动作，caption 平均长度 18.75 词；8 个模型共生成 1280 段视频。

PhyGenEval（SA + PCA）：

  • SA（语义对齐）：先用 GPT-4o 从原始 prompt 里抽出物体和动作，再让 GPT-4o 依次判断视频里物体是否出现（Q1，按完整度给 0/1/2）、指定动作是否发生（Q2，0/1）。分解成两问是为了避免模型把语义和物理混起来。
  • PCA 第一级：关键物理现象检测（单帧）。让 GPT-4o 根据 prompt 和对应物理定律生成一条检索 prompt pr​（用来定位关键帧，例如"鸡蛋刚接触石头的瞬间"）和一组物理相关问题 Q（例如"鸡蛋是否破裂"）。用 CLIPScore 类方法定位关键帧 Ii​，在其邻近 5 帧内取最优。评估器用 VQAScore。对单调过程（如随温度升高而熔化）只用"最后一帧"作为检索目标；非单调过程（如鸡蛋撞石头）同时看中间关键帧与最后一帧。
  • PCA 第二级：物理顺序验证（多帧）。GPT-4o 生成一条检索 prompt 和三个问题：q1​ 检验首帧到关键帧的顺序，q2​ 检验关键帧到末帧，q3​ 检验整体序列连贯性。评估器用 GPT-4o 或 LLaVA-Interleave（多图理解能力强）。
  • PCA 第三级：整体自然度（整段视频）。先参考 DEVIL 建立一套通用评分标准 ggen​，再用 prompt p、物理定律 l 和 ggen​ 引导 GPT-4o 为每条 prompt 生成定制评分标准 gspec​。评估器用 InternVideo2 与 GPT-4o，让它按标准从"Completely Fantastical / Clearly Unrealistic / Slightly Unrealistic / Almost Realistic"中选一项，映射为 0–3 分。
  • 汇总：三级分数各自离散化到四点量表，取平均后向下取整。为稳健起见，第二级同时用 GPT-4o 与 LLaVA-Interleave、第三级同时用 GPT-4o 与 InternVideo2，最终分数是两套方法的 ensemble。

§ 6 — 核心数学推导 ​

关键现象检测的置信分定义为：

Skey​=q∈Q∑​i−2≤j≤i+2max​(VLM(Ij​,q)+VLM(Ij​,pr​))

VLM(Ij​,q) 反映第 j 帧中物理现象是否存在，VLM(Ij​,pr​) 检验该帧是否真的匹配检索 prompt。第二项不可省略：视频可能有语义错误，鸡蛋不该在半空中就碎，所以必须确认现象出现在正确的帧上。取邻近 5 帧的 max 是为了鲁棒——鸡蛋未必在刚接触的那一帧就裂开。VLM(Ij​,q) 的具体算法沿用 ChronoMagicBench 的做法：肯定陈述的 VQAScore 除以肯定与否定陈述 VQAScore 之和。

顺序验证的两个分数：

Sbefore​=i−2≤j≤imax​(VLM(I0​,Ij​,q1​)+VLM(Ij​,pr​))

Safter​=i≤j≤i+2max​(VLM(Ij​,I−1​,q2​)+VLM(Ij​,pr​))

q3​ 评整体序列：Sall​=VLM(I0​,Ii−2:i+2​,I−1​,q3​)，总分 Sorder​=Sbefore​+Safter​+Sall​。注意两类 VLM 调用的输出性质不同：VLM(Ij​,pr​) 用 VQAScore 得到 0–1 的小数，而 VLM(I0​,Ij​,q1​) 是让 GPT-4V 或 LLaVA-Interleave 做是非问答，输出 1 或 0。判定 q1​ 正确的条件是上式取到最大值处同时满足 VLM(Ij​,pr​)>0.5——即"关键帧定位成功"与"顺序判断正确"必须同时成立。

整体自然度：Snatural​=VLM(I0:−1​,p,l,gspec​)，即把整段帧、原 prompt、物理定律、定制标准一起送进去。

离散化的设计细节透露了作者的价值判断：对非单调过程（分值域 0–3），离散化的分档是 [1,1.5,2.25]，理由是即便关键帧检索准确，只要物理现象错了（VLM(Ij​,pr​)=1 而 VLM(Ij​,q)=0）就不该给分——鸡蛋撞上石头却没碎，这种情况必须计零。

§ 7 — 实验设计与结论 ​

问题一：PhyGenEval 与人类判断一致吗？ 从 PhyGenBench 随机取 64 条 prompt，8 个 T2V 模型各生成 64 段，共 512 段视频，3 名标注者分别给语义分与物理分（0–3 整数），取平均后向上取整，再算 Kendall τ 与 Spearman ρ。PCA 上 PhyGenEval 总体 τ=0.78、ρ=0.81，四个类别分别为力学 0.72/0.75、光学 0.76/0.77、热学 0.73/0.75、材料 0.81/0.84；作为对照，最强的既有指标 VideoScore 的 Spearman 只有 0.19。SA 上 PhyGenEval τ=0.53、ρ=0.56，Grid-LLaVA 为 0.35/0.39。

问题二：当前 T2V 模型到底做得怎么样？ 评了 5 个开源模型（OpenSora V1.2、Lavie、CogVideoX 2B/5B、Vchitect 2.0）和 3 个闭源模型（Kling、Pika、Gen-3）。最好的 Gen-3 的 PCA 平均分只有 0.51。三条观察：所有模型在光学上都明显好于其他类别（作者归因于预训练数据中光学知识丰富且表现显式，Vchitect2.0 与 CogVideoX-5b 在光学上甚至能追平闭源模型）；Kling 与 Gen-3 整体明显领先，Gen-3 在材料属性上达 0.51，Kling 在热学上达 0.50；开源模型中 Vchitect2.0 与 CogVideoX 5B 表现较好且超过 Pika，Lavie 各类别都最低。定性上，力学最差——所有模型都无法正确表现玻璃球在水中下沉，OpenSora 和 Gen-3 甚至让球悬空；热学的相变几乎全错，CogVideoX 甚至让冰淇淋越融越大；材料属性上没有模型知道鸡蛋撞石头该碎，Kling 让鸡蛋像橡皮球一样弹跳。

问题三：现有的"万能解药"能解决吗？ 三项讨论实验。scaling：CogVideoX 2B→5B 平均分 0.39→0.45，静态场景（干涉衍射产生的彩色气泡、铁的氧化生锈）确有明显进步，热学的沸腾模拟也更真实，但两者都无法正确表现弹跳的足球这类简单运动动力学。prompt 改写：用 GPT 在原 prompt 后追加预期物理结果（例如加上"液体形成漂浮的球状体，随机地在空中散开移动"），CogVideoX 5B 与 Kling 都有增长，但 Kling 也只到 0.56；定性看只能解决焰色反应这类简单问题，鸡蛋破碎、石头下沉仍然无解。通用质量增强：VEnhancer 能让 Vchitect2.0 在 VBench 上大幅提升甚至超过 Kling，但在 PhyGenBench 上分数几乎不变，增强前后模型排名的 Spearman 高达 0.86。这最后一条是双向证据——既说明 PhyGenEval 对视觉质量因素稳健、专注物理正确性，也说明 VBench 排名高不代表物理理解好。

消融：三级评估缺任何一级都会掉点，只有三级同时使用才最优；第三级的两阶段策略（用 LLM 为每条 prompt 定制评分标准）优于 DEVIL 那种"所有视频套同一模板"的一阶段策略，InternVideo2 与 GPT-4o 上都成立；只用开源模型（LLaVA-Interleave + InternVideo2）的 PhyGenEval 仍能达到 0.66 的相关系数，ensemble 两套方法最佳。

§ 8 — Take-aways ​

5 句话版：PhyGenBench 用 160 条一一对应单个物理定律的清晰 prompt，覆盖力学、光学、热学、材料属性四大类共 27 条定律，刻意保持 prompt 简单以确保模型能生成语义正确的视频、从而让物理评估有意义。PhyGenEval 先用 GPT-4o 把物理定律翻译成检索 prompt 和定制问题，再按单帧（关键现象是否出现）、多帧（现象顺序是否正确）、整段（整体自然度）三级递进评估，每级配最适合的 VLM。这套指标与人类判断的 Spearman 达 0.81，而此前最好的 VideoScore 只有 0.19。评测结果显示当前 T2V 模型远未达到世界模拟器水平，最强的 Gen-3 也只有 0.51，且所有模型在光学上明显好于力学、热学与材料属性。放大模型、改写 prompt、用 VEnhancer 提升画质都无法解决动态物理现象这类核心问题。

3 句话版：评物理常识的前提是 prompt 简单到模型能生成语义正确的视频，否则评的是噪声。把"物理对不对"拆成"现象出没出现、顺序对不对、整体自不自然"三级并逐级降低 VLM 的任务难度，相关性从 0.19 跳到 0.81。VBench 排名高不代表物理理解好，两者近乎正交。

1 句话版：把物理定律用 LLM 翻译成分级的视觉问答检查项，物理常识才第一次变成可自动、可信地打分的东西。

§ 9 — 最脆弱的假设 ​

最关键的假设是：GPT-4o 依据 prompt 和给定物理定律生成的检索 prompt 与物理问题，能够正确且完整地刻画"该视频物理正确"的充要条件。整个 PCA 评估的正确性都建立在这一步文本侧的转换上——如果生成的问题问错了地方，后面三级 VLM 无论多准确，得到的都是对错误问题的正确回答。

它在实践中可能不成立的原因很具体。第一，物理定律到可观测现象的映射不是唯一的。"浮力"这条定律在不同物体、不同液体、不同初始条件下表现为完全不同的可观测事件，GPT-4o 生成的问题只能覆盖它想到的那些。第二，论文对非单调过程只检查"中间关键帧 + 最后一帧"两个点，这是一个刻意的简化；如果错误发生在这两个采样点之外（例如物体在下沉途中短暂上浮又下沉），检查会漏掉。第三，也是最根本的：这套方法能检测"预期现象是否出现"，但很难检测"不该出现的现象出现了"。GPT-4o 不会主动去问"有没有发生任何违反物理的额外事件"，因为那是一个开放式的否定判断。

论文为这个假设提供的证据是间接但有力的：0.81 的整体 Spearman 相关性，以及三级评估的逐项消融（缺任一级都掉点）说明三级设计各有贡献。缺的证据是：没有直接评估 GPT-4o 生成的问题本身的质量——例如让物理专业的标注者判断"这组问题是否足以判定该定律被遵守"，也没有报告在同一 prompt 上多次生成问题的稳定性。考虑到整条链路的正确性都压在这一步上，缺少对它的直接检验是最大的空白。另外要注意的是，这套评估依赖 GPT-4o 作为核心组件，其行为会随版本变化，而论文没有报告版本敏感性。

§ 10 — 最小复现实验 ​

一周内可做、不需要生成 1280 段视频的验证，直接针对上面那个最脆弱的假设。

  • 数据：从 PhyGenBench 公开仓库取 30 条 prompt（四类各若干），以及对应的物理定律标注。
  • 构造：用 GPT-4o 按论文描述为每条 prompt 生成检索 prompt 与物理问题；对同一条 prompt 重复生成 5 次，记录问题集合。另请 2 名有物理背景的标注者独立为每条 prompt 手写"判定该定律被遵守所需的充要检查项"。
  • 测量：三件事——(a) 5 次生成之间的问题集合一致性（用问题语义聚类后的 Jaccard 相似度）；(b) GPT-4o 问题集对人工充要检查项的覆盖率；(c) 反向覆盖率，即 GPT-4o 提出但人工认为无关的问题比例。
  • 判据：若 (a) 低（每次生成的问题差别很大）说明评估结果本身不稳定，报告的相关系数含有未量化的方差；若 (b) 明显低于 1（人工认为必需的检查项经常被漏掉）说明评估存在系统性盲区，且盲区类型可以被直接读出来（我推测最常被漏的是"不该发生的事发生了"这一类）。这个实验不需要任何视频生成，一周内完全可做。

§ 11 — 最强反例设计 ​

站在反对者立场，最有力的攻击是设计一类可预测失败的视频：每个被检查的关键帧都对、但帧与帧之间的过程物理上不可能。

论证基础在方法结构里：第一级只看关键帧邻近的 5 帧，第二级只比较首帧、关键帧、末帧三个锚点的顺序关系，第三级虽然看整段但依赖 VLM 的整体自然度判断，而论文自己的对照实验已经证明这类整体判断（DEVIL、VideoScore）恰恰是最容易被"平滑连贯但违反物理"的视频骗过的。于是存在一个明确的攻击面：只要在被采样的锚点上呈现正确状态，中间过程可以任意违反物理。

具体实验：人工构造（或用视频编辑合成）30 段"锚点正确、过程荒谬"的视频。例如鸡蛋在半空停顿三秒再继续下落，最后正确破碎；石头先浮上水面再突然下沉到底；冰块先变大再融化消失。这些视频在首帧、关键帧、末帧上全部符合预期物理现象和正确顺序。然后用 PhyGenEval 打分，并同时收集人类评分。如果 PhyGenEval 给出的分数显著高于人类评分，就证明该指标存在可被系统性利用的盲区——而且随着 T2V 模型开始针对这类 benchmark 优化，这个盲区会从理论隐患变成实际的 reward hacking 通道。论文当前的 ablation 证明了三级都有用，但没有证明三级合起来足够，这个反例正好打在充分性上。

§ 12 — Follow-up Research Idea ​

驱动局限：PhyGenEval 是"离散采样点 + 定制问答"的架构，它能验证若干个时刻的状态，但无法验证连续过程的合法性；同时它检验的是"预期现象是否出现"这一类正向命题，对"不该出现的事出现了"这一类开放式否定命题近乎失明。这两个局限是同一个根源——评估被建模成了对预设检查项的问答。

新 framing：把物理常识评估从"检查预设的关键事件"改造成"估计一条守恒量轨迹并检验其单调性/守恒性"。物理定律的很多内容不是"某时刻该发生什么"，而是"某个量在整个过程中必须满足某种关系"——机械能不增、动量守恒、熵不减、相变时温度平台。这些是关于整条轨迹的约束，且天然是否定式的（违反即失败），正好补上上述两个盲区。具体做法是从生成视频中估计出可观测的代理量（物体质心高度与速度、可见形变量、颜色对应的温度代理），构造出物理量的时间序列，然后检验该序列是否违反相应的守恒或单调约束。这样评分不再依赖 LLM 提出正确的问题，而依赖一组固定的、与 prompt 无关的物理约束——鲁棒性和可解释性都更强，而且对 §11 那类"锚点正确、过程荒谬"的视频天然免疫，因为荒谬恰恰体现在轨迹上。

可借鉴的相邻领域工具：时序逻辑（Signal Temporal Logic）为"整条信号必须满足某性质"提供了成熟的规约语言与鲁棒性度量，可直接把"机械能不增"写成可自动检验的公式；物理系统辨识里的守恒量发现方法（从轨迹自动找出近似守恒的量）可以用来处理无法直接测量的量；视频中的物理量估计可借用运动捕捉与光流领域的成熟工具。

第一个实验：只做一条约束、一类场景——自由落体与碰撞中的机械能不增。取 PhyGenBench 力学类中涉及下落与碰撞的 prompt，用现成的跟踪器从生成视频中估计物体质心的高度与速度序列，算出机械能代理量的时间曲线，用 STL 公式检验"机械能不显著增加"。评估两件事：该指标与人类物理评分的相关性，以及它在 §11 那批"锚点正确、过程荒谬"的对抗视频上的判罚率。如果单条约束的相关性就能接近 PhyGenEval 在力学类上的 0.75，同时在对抗视频上判罚率远高于 PhyGenEval，那么"轨迹级约束"就值得扩展成一整套与 prompt 无关的物理评估协议，把当前依赖 LLM 出题的架构替换掉。

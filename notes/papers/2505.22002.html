D-Fusion: Direct Preference Optimization for Aligning Diffusion Models with Visually Consistent Samples ​

项内容
arXiv2505.22002
提交日期2025-05-28（仅 v1）
作者Zijing Hu, Fengda Zhang, Kun Kuang（浙江大学计算机学院）
分类cs.CV（Accepted to ICML 2025）
一句话用 mask 引导的 self-attention fusion 把"对齐好的参考图"的语义注入"对齐差的基准图"，造出与基准图视觉高度一致、且带完整去噪轨迹的正样本，从而让 DPO 的偏好差异只落在真正想改的维度上。

所属教程：后训练与强化学习

版本与依据说明

本页依据 arxiv.org/html/2505.22002v1 全文（含附录 B–G）撰写。该条目只有 v1，元信息以 abs 页为准。

§ 1 — 研究问题与重要性 ​

文本到图像扩散模型最常被抱怨的毛病是 prompt-image misalignment：给"一只猴子吃三明治"，模型给你一只猴子，或者一个三明治，很少两样都对。业界的主流补救办法是把去噪过程重新解释成 sequential decision-making，然后套用 RL：状态是 (c,t,xt​)，动作是一次去噪，奖励是最终图与 prompt 的对齐分。其中 DPO 因为省掉了显式 reward model 而被广泛采用。

但这篇论文指出，DPO 在扩散模型上的实际收益一直很有限，原因不在算法而在数据。DPO 的训练对是从同一个 prompt 出发、用不同随机噪声采出来的两张图。不同噪声意味着两张图在结构、风格、背景上全都不一样，对齐相关的差异被淹没在一大堆对齐无关的差异里。模型看到"选左边不选右边"，无从判断到底是因为左边真的画对了三明治，还是因为左边背景更干净。作者把这个现象命名为 visual inconsistency。

这个问题值得单独拿出来解决，因为它揭示了一个方法论层面的错配：语言模型那边早就在做 token 级的细粒度纠正（把幻觉片段改掉，得到与原文语言风格一致的正样本），从而拿到 dense reward signal；扩散模型这边却还停留在"整张图对整张图"的粗粒度比较。把细粒度对照引入扩散模型的 RL 训练，是一个前人明确想做但被卡住的方向。

§ 2 — 前人工作与不足 ​

扩散模型的 RL 微调线：DDPO（Black et al.）把去噪当 MDP 用 PPO 优化，DPOK（Fan et al.）加了 KL 正则与 value function，Diffusion-DPO（Wallace et al.）则把奖励 reparameterize 进损失。这些方法都能跑通，但它们共享同一份采样数据——从不同噪声独立采出的图像池，因此共享同一个 visual inconsistency 缺陷。

语言模型的细粒度 RL 线：Kong et al.、Yu et al. 等对文本输出做 token 级的编辑或标注，把幻觉句改成事实句，正负样本语言风格一致，DPO 收到的信号非常干净。这条路在扩散模型上直接搬不过来，原因论文说得很清楚：语言模型的决策序列是 token-by-token 构造的，编辑发生在 token 层，编辑后的文本天然还是一条合法的决策序列；扩散模型的决策序列是 timestep-by-timestep 构造的，而图像编辑发生在 pixel 层。

图像编辑线：手工编辑、Imagen Editor、Imagic 都能做到"既改对齐又保视觉一致"，但它们的产出是一张没有去噪轨迹的图。RL 训练需要 {xT​,…,x0​} 这条状态序列来计算 pθ​(xt−1​∣xt​,c)，pixel 级编辑把这条序列彻底毁掉了，产物不可训练。

attention 控制线：MasaCtrl、Plug-and-Play 一类工作展示了 cross-attention map 决定布局、self-attention 决定外观迁移，其中一些确实有保留轨迹的潜力。但它们解决的是"把一张图从 prompt A 迁移到 prompt B"，而本文要的是"把一张图从'没对齐 prompt c'修到'对齐 prompt c'"，任务定义不同。作者在附录 B 报告了直接照搬这些方法的观察结果，结论是在所有层、所有 timestep 上做融合往往生成不了理想图像。

§ 3 — 重建作者的思考路径 ​

不用本文的贡献做前提，重走一遍：第一步是承认 DPO 在扩散模型上收益小这个经验事实，并追问原因。看几组训练样本就会发现，"高偏好图"和"低偏好图"之间的差异有一大半跟 prompt 无关。这自然导出假设：如果两张图只在对齐维度上不同，DPO 的信号会干净得多。

第二步是问怎么造这种图。最直白的做法是编辑：拿一张对齐差的图，把缺的物体 P 上去。但 RL 训练要的不是图，是轨迹。这就把问题从"图像编辑"转化成了"轨迹级编辑"——必须在去噪过程中动手，而不是在去噪之后。

第三步是问在去噪过程中哪个地方可以动。已有文献给了两条线索：cross-attention map 编码了"哪个像素该看 prompt 里的哪个词"，因此可以拿来定位物体该出现的区域；self-attention 的 key/value 携带外观信息，替换它们可以把一张图的外观搬到另一张图上。把两条线索拼起来：用 cross-attention 从参考图里抠出物体位置的 mask，再在这个 mask 圈定的区域里，把参考图的 self-attention K/V 注入到正在生成的新图里；mask 之外保留基准图自己的 K/V，并让新图与基准图共享初始噪声。这样生成出来的图，语义跟参考图一样对齐，其他部分跟基准图一样，而且因为整个过程就是一次正常的去噪，轨迹是天然完整的。

第四步是承认这套东西会失败：融合出来的图不一定真的更对齐。所以需要一个事后验证门槛，把失败样本挡在训练之外。

§ 4 — 核心 Intuition ​

DPO 之所以在扩散模型上不灵，是因为它比较的两张图差异太多，梯度不知道该归因给哪一处。真正需要的是一对"只差那一处"的图。而 pixel 级编辑虽然能造出这样的图，却把 RL 需要的决策序列毁掉了。D-Fusion 的关键在于：编辑不发生在图像上，而发生在 attention 里——因为 attention 操作本身就是去噪步骤的一部分，编辑完成的同时轨迹也就自动记录下来了。

§ 5 — 具体方法与完整 Pipeline ​

以 prompt "a monkey eating a sandwich" 为例，走一遍完整流程。

第 0 步 · 采样与分组。用 SD 2.1-base + DDIM（T=20，噪声权重 η=1.0，guidance scale 5.0）对该 prompt 采一批图并保留轨迹。用 CLIPScore 打分，高分图记为参考图 Ir（猴子和三明治都在），低分图记为基准图 Ib（只有猴子）。

第 1 步 · cross-attention mask 提取。在生成 Ir 的过程中，取 U-Net 第一个上采样层（SD 中分辨率 16×16）的 cross-attention maps，对所有 head 与所有 attention block 求平均，得到 Atcross​∈R16×16×∣c∣。对 prompt 中的物体 token（monkey、sandwich）各取一张 map，按逐 token 的阈值 thro​ 二值化，再用 XOR 合并成 Mt​。作者选第一个上采样层是因为已有工作发现该层的 cross-attention 对形状与结构的刻画最好；逐 token 阈值列在附录 G 的表 4–6 里，作者明确说这些阈值不需要精细调，可以用低成本方法预先定下。

第 2 步 · self-attention fusion。用与 Ib 相同的初始噪声开始去噪，生成目标图 Ia。在每一步 t，先把 Mt​ resize 到当前层分辨率得到 Mt​​，然后替换该层 self-attention 的 key/value：mask 内用参考图的 Kr,Vr，mask 外保留 Ia 自己的 Ka,Va；query 完全不动。融合只在中间层与上采样层（SD 2.1-base 的第 3–6 层）、timestep 18 到 1 这个范围里做——附录 B 说明全层全步融合反而生成不出理想图像。

第 3 步 · 采纳验证。融合会失败。作者加了一道门槛：只有当 R(x0a​,c)−R(x0b​,c)≥thrado​⋅(R(x0r​,c)−R(x0b​,c)) 成立时才采用 Ia，否则退回用 Ir 与 Ib 配对——也就是退化成 naive DPO。实验里 thrado​=1.0，即要求目标图至少追平参考图。

第 4 步 · 训练。用 (Ia,Ib) 这一对做 DPO，Ia 为高偏好、Ib 为低偏好，两条轨迹都已在手。用 LoRA 微调，AdamW，lr 1e-4，训练 batch size 1、梯度累积 320 步、inner epoch 2。用 CLIP（ViT-H-14）替代人工打分后可以做多轮 online 学习。同一套数据也接到 DDPO 与 DPOK 上：两者都改用"当前及历史全部轮次、同 prompt 下的均值与标准差"做 reward normalization，DPOK 的 value function 被这个 normalization 替代（α=0.99, β=0.01）。

实验资源：24GB 的 3090/4090，跑到 25.6k 训练数据量约需 30 小时（DPO/DDPO）或 40 小时（DPOK）。

§ 6 — 核心数学推导 ​

mask 提取。Atcross​[:,:,i] 表示每个像素对 prompt 第 i 个 token 的注意力强度。设 Oc​={o1​,…,ok​} 是物体 token 的下标集合：

Mt​=o∼Oc​⨁​[(Atcross​[:,:,o]≥thro​)?1:0]

⨁ 是 XOR。用 XOR 而非 OR，意味着被两个物体同时高度关注的像素会被排除在 mask 之外——这一点论文没有展开解释，从形式上可以推断它起到了避免"两个物体重叠区被参考图强行覆盖"的作用。

融合。∘ 为 Hadamard 积，Flatten(Mt​​) 广播到 key/value 的特征维：

Knewa​=Kr∘Flatten(Mt​​)+Ka∘(1−Flatten(Mt​​))

Vnewa​=Vr∘Flatten(Mt​​)+Va∘(1−Flatten(Mt​​))

注入 Knewa​ 让 self-attention 的注意力分配在物体区域上参照 Ir；注入 Vnewa​ 让该区域的最终特征也吸收 Ir 的外观。保留 query、保留 mask 外的 K/V、共享初始噪声，三者共同保证了与 Ib 的视觉一致。

训练目标。σ 为 sigmoid，θold​ 为更新前参数：

−E(t=1∑T​logσ[βpθold​​(xt−1a​∣xta​,c)pθ​(xt−1a​∣xta​,c)​−βpθold​​(xt−1b​∣xtb​,c)pθ​(xt−1b​∣xtb​,c)​])

值得留意的是这里逐步比较的是概率比本身而非其对数，与常见 DPO 写法不同；论文未对此作说明。

§ 7 — 实验设计与结论 ​

问题一：视觉一致的样本对真的能让 DPO 学得更好吗？ 设计是在三套 prompt 模板上跑多轮 online 微调，横轴是消耗的图像数据量，纵轴是 CLIPScore。模板分别覆盖物体行为（"a(n) [animal] [activity]"，45 种动物 × 3 种活动）、物体属性（"a(n) [color] and [material] [object]"，6 色 × 9 材质 × VRD 物体）、物体间位置关系（"the [obj1] [predicate] the [obj2]"，4 个方位词，依 VRD 标注构造）。每个模板 40 条训练 prompt、40 条测试 prompt，每个实验 3 个随机种子。结论：同等数据量下 DPO+D-Fusion 的曲线几乎总在 naive DPO 之上。

问题二：能不能用更简单的办法拿到轨迹？ 最自然的替代是对编辑好的图做 DDIM inversion 反推轨迹。消融显示这条路走不通——用 inversion 轨迹训练的模型对齐度没有可见提升。原因是 DDIM inversion 依赖 ϵθ​(xt−1​,t)=ϵθ​(xt​,t) 这个粗糙假设，重建出的图与原图有可见差异。这个消融是本文最有说服力的一块：它证明"保留轨迹"确实是个真问题，而不是作者自己立的靶子。

问题三：是不是只对 DPO 有效？ 把 D-Fusion 接到 DDPO 与 DPOK 上，两者的对齐曲线都被抬高。

问题四：泛化到没训练过的 prompt 吗？ 每个模板用未参与训练的 40 条 prompt 各采 1280 张图。CLIPScore 结果（模板 1/2/3）：SD 0.3725 / 0.3396 / 0.3213，DPO 0.3733 / 0.3407 / 0.3230，本方法 0.3758 / 0.3446 / 0.3276。方向一致但绝对增益很小，相对 naive DPO 只有 0.0025–0.0046。

问题五：人会不会同意？ 22 名从本科生到博士生的独立评分者，从 SD / DPO / 本方法三张图里挑最贴合 prompt 的一张。三个模板上本方法的偏好率都最高。论文给的是柱状图，未在正文列出具体百分比。

§ 8 — Take-aways ​

5 句话版：DPO 在扩散模型上收益有限的根因是训练对的视觉不一致，对齐相关差异被无关差异淹没。语言模型靠 token 级编辑解决了同类问题，但 pixel 级图像编辑会毁掉 RL 需要的去噪轨迹。D-Fusion 把编辑挪进 attention：用参考图的 cross-attention 抠出物体 mask，在 mask 内注入参考图的 self-attention K/V，mask 外保留基准图，并与基准图共享初始噪声。因为编辑就发生在去噪步骤内部，轨迹天然完整。三套 prompt 模板、三种 RL 算法上，训练曲线与人类偏好率都优于 naive DPO，但泛化测试的 CLIPScore 绝对增益仅千分之二到千分之五。

3 句话版：DPO 的正负样本差太多，扩散模型学不到该学的东西。D-Fusion 用 mask 引导的 self-attention 融合造出"只差对齐那一处"的样本对，并且因为编辑在 attention 层完成，去噪轨迹被完整保留。效果在多种 RL 算法上一致为正，但幅度不大。

1 句话版：把图像编辑从 pixel 层挪到 attention 层，就能同时拿到视觉一致性和 RL 可训练性。

§ 9 — 最脆弱的假设 ​

最致命的一条是：CLIPScore 既是奖励函数，又是评价指标。 训练时用 CLIP 挑参考图、用 CLIP 做采纳验证、用 CLIP 当 online 奖励；评估时又用同一个 CLIPScore 报告"对齐提升"。这条链路是闭合的，因此定量曲线与表格中的提升，无法区分"模型真的更对齐了"和"模型学会了迎合 CLIP"。如果 CLIP 对某类 prompt 存在系统性偏差（例如对方位词不敏感——模板 3 恰好全是方位词），整个训练就会朝那个偏差方向优化，而 CLIPScore 完全看不出来。

论文为这条假设提供的唯一独立证据是 22 人的偏好测试，这是必要的补丁，但样本量与报告粒度都不足以支撑主结论：正文没有给出偏好率数值、置信区间或每模板样本数。同时，泛化表里 0.0025–0.0046 的绝对差距，在 1280 张图上是否显著、方差多大，论文没有报。

一个次级但相关的风险来自 thrado​=1.0。这个设置要求融合图追平参考图的对齐分才被采纳，否则整对退回 Ir vs Ib。论文没有报告采纳率。如果采纳率其实很低（这在"融合有时失败"的自述下是可能的），那么大部分训练步实际跑的就是 naive DPO，观察到的增益也就主要来自那一小部分被采纳的样本——这与论文的叙事仍然相容，但会显著改变对方法有效性来源的判断。采纳率是本文最该报而没报的一个数。

§ 10 — 最小复现实验 ​

一周、单张 24GB 卡可以做的最小验证，目标不是复现全流程，而是打掉上面那条循环。

  1. 只取模板 1（动物 + 活动），只取 SD 2.1-base，只用 DPO 一种算法，T=20，LoRA。
  2. 先量采纳率：跑 200 条 prompt 的融合，统计在 thrado​=1.0 下有多少对被采纳。这一步不需要训练，几小时能出结果。若采纳率低于 30%，后面的结论都要重新解读。
  3. 训练三个模型：naive DPO、D-Fusion（thrado​=1.0）、D-Fusion（thrado​=0.0，即只要不比基准差就采纳）。数据量对齐到同一个 batch count。
  4. 换一把尺子评估：用没有参与训练的评测器（如 VQAScore 或一个 VLM 逐条判"图里有没有 X 在做 Y"）在 40 条测试 prompt 上打分，同时报告 CLIPScore。
  5. 判据：若 CLIPScore 涨而独立评测器不涨，则本文的增益主要是对 CLIP 的过拟合；若两者同涨，方法成立。若 thrado​=0.0 的版本反而更好，说明采纳门槛设得过严。

§ 11 — 最强反例设计 ​

站在反对者的立场，最有力的攻击是给出一个替代解释：D-Fusion 的增益可能不来自"视觉一致性"，而来自"目标图的分布更靠近模型自身高奖励区域"。

论证如下。融合图 Ia 是由当前模型自己在参考图 K/V 引导下生成的，它一定落在模型的生成流形上，且经过采纳验证后 CLIPScore 至少不低于参考图。而 naive DPO 的正样本 Ir 是从噪声独立采出的高分图，同样在流形上但没有"至少追平"这道筛选。也就是说，D-Fusion 组的正样本经过了一次额外的奖励筛选，naive DPO 组没有。两组正样本的平均奖励因此不同，训练收益的差异完全可以由这个奖励差解释，与视觉一致性无关。

对应的判决实验：构造一个 reward-matched naive DPO 对照组——从独立采样池里挑选 Ir，使其满足与 D-Fusion 采纳后完全相同的奖励分布（例如同样要求 R(Ir)−R(Ib) 落在相同区间），再训练。如果这个对照组追平了 D-Fusion，视觉一致性这条 claim 就被证伪；如果仍显著落后，视觉一致性才被确立为独立因素。这个实验成本不高，而论文没有做。

另一类可预测的失败场景：mask 提取依赖 cross-attention 能定位物体。对于抽象属性（"梦幻的"、"复古的"）、全局风格、以及否定式 prompt（"没有猫的房间"），cross-attention 上不存在一个可二值化的物体区域，Mt​ 要么全零要么乱七八糟，融合退化为噪声。论文的三套模板全是具象物体，恰好避开了这类 prompt。

§ 12 — Follow-up Research Idea ​

驱动的局限：D-Fusion 造正样本时必须先有一张对齐好的参考图。也就是说，它只能把"模型偶尔能做对"的能力放大，无法教会模型它从未做对过的事。而对齐失败最严重的恰恰是模型从来做不对的那类 prompt（三个以上物体的空间关系、精确计数）。这是一个结构性天花板，不是靠加数据能突破的。

新的 framing：把 D-Fusion 从"造样本的工具"重新理解为"对齐失败的因果定位器"。融合过程给出的 mask Mt​ 精确指出了"把哪一块换成参考图的表示，图就对齐了"。这实际上是一次干预实验：Mt​ 是使输出从"不对齐"翻转到"对齐"的最小充分区域。把每次融合都记录成 (c,失败模式,Mt​,ΔR) 的四元组，累积起来就是一张模型对齐失败的因果地图：哪些 token 在哪些层、哪些 timestep 上最容易丢失。

可借鉴的相邻领域工具：机制可解释性里的 activation patching / causal tracing——它做的就是"把某个位置的激活换成另一次运行的激活，看输出是否翻转"，与 self-attention fusion 在形式上是同一个操作。相关文献已经把这套方法用于定位语言模型里的事实知识存储位置。

第一个实验：固定 SD 2.1-base，对 500 条已知会失败的 prompt 各做一次融合，记录成功翻转所需的最小 (层集合,timestep 区间)。第一个要回答的问题是：这个最小干预集合是否跨 prompt 稳定。若稳定，说明扩散模型的对齐失败集中在少数几个可定位的计算位置，那么正确的修法不是继续做 RL 微调，而是只在那几个位置上做定向修改——这比全模型 DPO 便宜一到两个数量级，而且不会引入奖励模型过拟合。若不稳定，则说明对齐失败是弥散的，RL 确实是唯一可行路径，本文的方法也就获得了更强的正当性。无论哪个结果都有信息量。

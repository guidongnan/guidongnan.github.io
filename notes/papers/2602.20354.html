3DSPA: A 3D Semantic Point Autoencoder for Evaluating Video Realism ​

项内容
arXiv2602.20354
提交日期2026-02-23
作者Bhavik Chandna, Kelsey R. Allen
分类cs.CV
一句话把视频压成「3D 点轨迹 + DINO 语义」的固定尺寸 latent，用自编码器重建留出的查询轨迹，以 Average Jaccard 作为无需参考视频的真实感分数。

所属教程：物理感知视频生成

§ 1 — 研究问题与重要性 ​

视频生成模型进步很快，但"这段视频真实吗"至今仍主要靠人打分。人工标注贵、慢、无法跟上生成速度；构造成对真假视频集则需要精心策划、通常绑死在特定领域，而且预设了生成样本与手头的真实素材可比。两条路都不构成可规模化的通用方案。

更深一层的问题是既有自动指标把"真实"约等于"时序一致"：只要不闪烁、不跳变就算过关。作者举了两个反例——一个球无限向上弹且不减速，时序上完全平滑，物理上荒谬；一辆车拐弯时侧滑而无摩擦约束，违反的是"车该怎么动"的语义预期。这类失败要求同时推理语义与 3D 结构，而现有指标（包括作者自己组的前作 TRAJAN）都工作在 2D 特征空间里，忽略了真实物体在三维中持存、在遮挡下保持连续、服从重力惯性碰撞这些基本事实。VBench 这类大规模基准则已经被普遍刷到 90%+，区分度枯竭。

这件事的重要性直接落到下游：机器人策略如果在物理上不成立的视频 rollout 上训练，部署时不会迁移；影视场景里观众对细微的不自然运动极其敏感。一个可规模化、无需参考视频的真实感度量是这些应用的前置条件。

§ 2 — 前人工作与不足 ​

物理基准一支从 IntPhys、CLEVRER 到 Physion++、IntPhys2，以及真实世界的 InfLevel、Physics-IQ、TRAVL。这些基准衡量的是模型的物理常识（预测视频如何展开，或看模型是否对不真实视频"更惊讶"），本身不是可以对任意生成视频打分的通用指标。

视频质量评估一支，FVD 与 CLIP 系分数分别测帧质量与文图对齐，都抓不住"真实感"这个联合了语义连贯、运动一致与物理合理的复合概念。近期出现了物理感知的自动评估器与 VBench 这类大规模基准，但饱和问题严重。因此 EvalCrafter 与 VideoPhy-2 退回到人工判断以避免饱和，同时也提供各自的自动评估器（如 VideoPhy-2 AutoEval，一个在该数据集子集上微调过的 VLM）。

合成视频检测一支（D3 的二阶时序特征、TCMabNet 的时空网络）目标是二分类，不对齐人类的运动真实感判断。

最直接的前作是 TRAJAN：一个 2D 点轨迹自编码器，把支撑轨迹映射成固定尺寸的运动 latent，再重建查询轨迹，用重建质量当自动指标。论文对它的批评有两条且都很具体：一是模型完全不看视觉环境，只看轨迹本身，因此无法推理场景上下文、物体交互与遮挡；二是把运动限制在 2D 不足以评估本质发生在 3D 里的动力学。论文的图 4 给了两个佐证例子：狗走路时腿部的关节运动需要 3D 才能建模，TRAJAN 把它误判为不真实；手机缓慢消失时轨迹是平滑的，TRAJAN 因为没有物体语义而误判为真实。

§ 3 — 重建作者的思考路径 ​

从 TRAJAN 的两条失效开始倒推。它误判狗走路，是因为 2D 投影下腿的往复运动看起来杂乱；补上深度这条维度，同一段运动就变得可预测。它误判消失的手机，是因为轨迹层面根本没有"这是一部手机、手机不会凭空消失"这个信息；补上语义特征，重建时就有了额外的约束。两条失效指向同一个补丁：把 3D 与语义都塞进 latent。

第二步是自编码器为什么能当真实感指标。核心逻辑是信息瓶颈：模型被迫把一整段运动压进固定尺寸的 latent，再从中重建留出的轨迹。要做到这一点，它必须学会真实运动的规律性——什么样的轨迹是可从其他轨迹推出来的。不符合这些规律的运动就压不进去，重建误差自然升高。这条路线的一个附带好处是不需要参考视频：分数只依赖视频自身。

第三步是 3D 轨迹从哪来。训练时可以用 Kubric3D 的真值，但推理时只有 2D 视频，于是用 CoTracker3 出 2D 轨迹、VideoDepthAnything 出米制深度，把 2D 抬升到 3D。这个选择在后面成了整个方法最大的软肋。

§ 4 — 核心 Intuition ​

真实运动是可压缩的：看一半的点轨迹就能推出另一半，因为它们被同一套物理与语义规律绑在一起。把视频压进一个固定尺寸的 latent 再重建留出的轨迹，重建得好说明这段运动服从规律，重建得差说明它不服从。而要让"规律"这个概念足够强，latent 里必须同时有 3D 几何（腿在深度上怎么摆）和语义（手机不会凭空消失）——只有轨迹的 2D 形状是不够的。

§ 5 — 具体方法与完整 Pipeline ​

以 VideoPhy-2 里一段"男人用锤子砸墙"的生成视频为例：

编码。 输入是一组稠密的支撑轨迹 S={st,j​}，每条轨迹的元素是 (x,y,z,o)，o 是二值遮挡标志。对每条轨迹，把 3D 位置与时间 t 做正弦编码得到 PEt,j​，同时从对应视频帧区域采 DINOv2 特征 ft,jDINO​，两者拼接后投影到 C 通道。追加一个可学习的 readout token，在所有 token 上做自注意力，注意力掩码用 (1−ot,j​) 屏蔽被遮挡的点；注意力后只保留 readout token，得到该轨迹的 C 维描述子。跨轨迹的信息整合用 Perceiver 结构：128 个 latent token 交叉注意到所有轨迹描述子，再互相自注意，最终压成固定的 128×64 表示 ϕS​。

解码。 给定 ϕS​ 与一个查询点 (xq​,yq​,zq​,tq​)，先把 latent token 上投影，加上查询点正弦编码得到的 query readout token，做自注意力后只留 readout token，线性映射出该点在所有帧上的完整轨迹与遮挡预测。附录里提到一个细节：把朴素的线性上投影换成了带步长窗口的上采样算子，把每个 latent token 与一段时间窗 [ρt​:ρt​+128) 沿通道拼接，让解码器更容易对齐到与查询点时间相关的信息。

训练。 数据是 Kubric3D 生成的 38k 合成场景加 TAPVid-3D（主集 4569 段、minival 150 段，长度 25–300 帧）。Kubric3D 有真值 3D 位置但没有遮挡标签，作者把 3D 点投影回图像平面，与 VideoDepthAnything 的渲染深度比较，ot,j​=1[zt,j​>Dt​(xt,j​,yt,j​)+ϵ]，ϵ=10−4。每段视频的轨迹随机对半分：一半当支撑喂编码器，另一半当查询让解码器重建。优化器 AdamW，峰值学习率 10−4，10000 步 warmup 后余弦衰减，从预训练的 TRAJAN checkpoint 初始化，训 300 epoch，batch 256，DINO 全程冻结。

推理与打分。 只有 2D 视频时，先用 CoTracker3 出带遮挡的稠密 2D 轨迹，再用 VideoDepthAnything 的米制深度抬升到 3D，一半当支撑一半当查询，重建后的查询轨迹相对"伪真值"查询轨迹算 Average Jaccard，AJ 越高越真实。

§ 6 — 核心数学推导 ​

训练损失。 位置用 L1、遮挡用二元交叉熵：

Lmodel​=q,t∑​(wl1​∥pq,t​−p^​q,t​∥1​+wBCE​BCE(oq,t​,o^q,t​)),pq,t​=(xq,t​,yq,t​,zq,t​)

附录给出的权重比是 5000:10−8，也就是遮挡项几乎被完全压掉。作者的说明值得记：把两项等权衡会降低与人类真实感判断的相关性。这条经验暗示遮挡预测的准确性与真实感判别几乎无关，甚至有害——可以推断，让模型花容量去预测遮挡会挤占它用于建模运动规律的表征能力（论文只报告了现象，未给出机制解释）。

Average Jaccard。 沿用 TAPVid-3D 的定义：真正例是空间位置落在阈值 δ3D​ 内且被正确预测为可见的点，

AJ=TP+FP+FNTP​

其中假正例是"预测可见但实际被遮挡或超出阈值"的点，假负例是"实际可见但被预测为遮挡或超出阈值"的点。它同时惩罚位置误差与遮挡误判，因此比纯位置误差更严格。这里有一个必须点破的性质：AJ 衡量的是自编码器重建其自身输入轨迹的质量，而这些输入轨迹本身来自 CoTracker3 + VDA，并非真值。

遮挡感知注意力。 掩码取 (1−ot,j​)，被遮挡的点在注意力中被忽略。这不是一个复杂的机制，但它是让 latent 不被"遮挡期间轨迹跳变"污染的关键。

§ 7 — 实验设计与结论 ​

三条实验轴，逻辑递进：能不能重建、能不能抓物理违规、能不能对齐人类。

能重建吗？ 在 TAPVid-3D minival 上报 Occlusion Accuracy、3D APD 与 3D AJ。作者的立场很清楚：自编码器有信息瓶颈，不指望在跟踪上打赢专门的跟踪器，只需要"够准"。平均一栏上，3DSPA 是 AJ 14.0 / APD 19.8 / OA 85.8，与在 TAPVid-3D 上微调过的 CoTracker3+ZeroDepth（13.5 / 19.9 / 88.5）大致相当，胜过多数 2D 抬升的基线；但 SpatialTrackerV2（17.7 / 26.0 / 89.2）在三项上都明显更好，论文"consistently outperforms most baselines"的措辞是准确的，读者不应据此理解为跟踪 SOTA。

能抓物理违规吗？ IntPhys2 有 1012 段视频、253 个场景，以四元组组织（两段 possible、两段 impossible），覆盖 object permanence、immutability、spatio-temporal continuity、solidity 四类原则，固定与移动相机各一半。3DSPA 的胜率是 permanence 76.92 / 75.00、immutability 73.08 / 76.47、continuity 67.31 / 69.12、solidity 70.77 / 64.47，显著高于 GPT-4o、Qwen-VL 2.5、Gemini-1.5 Pro、Gemini-2.5 Flash、VideoMAEv2-g、Cosmos-4B、V-JEPA 2-h 等（这些大多在 50–65 区间徘徊，接近随机）。作者自己点出的意外是：增益最大的是 permanence（+10%）、immutability（+10%）与 solidity（+5%），而不是 continuity（约 −5% 到 +2%）。

消融给出的图景比标题更微妙。去掉 3D 只留 DINO 的变体在多数类别上与完整模型相当，continuity 上甚至更高（78.85 / 73.53 对 67.31 / 69.12）；而去掉 DINO 只留 3D 的变体在 solidity 上掉到 38.46 / 39.36——低于随机，也低于纯 TRAJAN。也就是说在 IntPhys2 上，语义是主要驱动力，3D 单独加入反而有害。作者诚实地写了这一点。

能对齐人类吗？ VideoPhy-2 的 physical commonsense 维度上算 Spearman 相关：VideoLlava 0.08、VideoCon 0.13、VideoScore 0.17、VideoCon-Physics 0.48、VideoPhy-2 AutoEval 0.76（这个是在该数据集子集上微调过的）；消融侧 TRAJAN 0.19、只加 DINO 0.40、只加 3D 0.50、完整 3DSPA 0.74。这组数字与 IntPhys2 的结论正好相反：这里 3D 单独的贡献（0.19→0.50）大于 DINO 单独的贡献（0.19→0.40），而两者合起来（0.74）远超各自增量之和，呈现明显的超可加性。3DSPA 在没有在该数据集上训练的前提下几乎追平了专门微调的 AutoEval，这是全文最有分量的结果。

EvalCrafter 上，因为大量视频几乎没有运动（无从判断物理真实性），作者只保留按 3D 点位移排序的前 50%，得到 1849 段。五个人工维度上的 Spearman：完整模型 0.48 / 0.58 / 0.55 / 0.60 / 0.60，明显高于 TRAJAN 的 0.28 / 0.25 / 0.24 / 0.33 / 0.23。在最后一个维度 subjective likeness 上，去掉 DINO 的变体（0.63）反而高于完整模型（0.60），"3DSPA achieves the best performance"这句概括在这一列上不成立。

成本。 单张 A100-40GB、50 帧片段、50 次平均的端到端耗时（含 CoTracker3、VDA、DINOv2 与自编码器四个阶段，串行执行）：TRAJAN 2.18 s、3DSPA 5.61 s、VideoScore 4.89 s、VideoCon 6.21 s、VideoCon-Physics 8.13 s、VideoPhy-2 AutoEval 10.67 s、VideoLLaVA 13.52 s。正文说相对 TRAJAN 约 2× 开销，按表中数字实际是 2.57×。

§ 8 — Take-aways ​

5 句话版。 真实运动是可压缩的，把一半点轨迹压进固定尺寸 latent 再重建另一半，重建质量就是一个无需参考视频的真实感分数。TRAJAN 只用 2D 轨迹的两处失效——狗腿的 3D 关节运动被误判为不真实、缓慢消失的手机因轨迹平滑被误判为真实——分别指向 3D 与语义两个缺口。补上这两者后，在 IntPhys2 上大幅超过一众 VLM 与视频基础模型，但那里的增益几乎全部来自 DINO 语义，单加 3D 在 solidity 上甚至掉到随机以下。在 VideoPhy-2 的物理常识维度上结论反转，3D 的单独贡献更大，而两者合起来呈超可加，Spearman 0.74 几乎追平在该数据集上微调过的专用评估器。遮挡损失权重被压到近乎为零，因为等权反而降低与人类判断的相关性。

3 句话版。 用自编码器的重建误差当真实感度量，避开了参考视频与人工标注两个瓶颈。3D 结构与语义特征在不同基准上的贡献比例完全不同，合成的 IntPhys2 靠语义、真实生成视频靠两者协同。整套方法的精度上限被 VideoDepthAnything 的单目深度牢牢卡住。

1 句话版。 不真实的运动压不进一个学过真实运动的瓶颈里。

§ 9 — 最脆弱的假设 ​

最致命的一条是：重建误差的高低只反映真实感，不反映跟踪难度。整个指标建立在"AJ 低 = 不真实"上，但 AJ 低还有一个完全无关的原因——这段视频本来就难跟踪。透明物体、剧烈运动、严重遮挡、杂乱背景都会让 CoTracker3 + VDA 出的伪真值轨迹变噪，进而让重建 AJ 下降，而这与视频是否物理合理毫无关系。

论文自己提供了这条混淆确实存在的直接证据：附录 B 报告 IntPhys2 的 hard 类别（真实物体、杂乱复杂背景）"在 Average Jaccard 上一致最低"。难度直接压低了 AJ。IntPhys2 的实验之所以不受影响，是因为它的四元组设计让 possible 与 impossible 共享同一批初始帧与同样的场景复杂度，比较是配对的，难度被抵消掉了。但 VideoPhy-2 与 EvalCrafter 上没有这种配对，不同视频的内容、运动幅度、遮挡程度差异巨大，此时"AJ 与人类评分相关"完全可能有一部分来自"人类也倾向于给杂乱、剧烈、跟踪困难的视频打低分"这个共同原因，而非 AJ 真的在测物理合理性。

作者在 EvalCrafter 上只取运动量前 50% 的做法，某种意义上正是在缓解这个问题（低运动视频的 AJ 虚高），但这只处理了混淆的一端。缺失的证据很明确：没有报告 AJ 与"跟踪难度代理量"（例如 CoTracker3 自身的置信度、平均遮挡比例、光流幅度）之间的相关性，也没有做偏相关分析看控制住难度后 AJ 与人类评分还剩多少相关。论文另外承认了一条相关的限制：当深度线索模糊、VideoDepthAnything 表现差时，3D 轨迹重建会不可靠并把误差传到真实感分数上——这其实是同一条假设的另一个侧面。

§ 10 — 最小复现实验 ​

不必重训模型，一周内可做的最小验证直接针对上述混淆：

  • 数据：取 EvalCrafter 中作者用的那 1849 段视频（或任意带人工评分的生成视频集）。
  • 实现：跑现成的 3DSPA（作者承诺开源权重）得到每段视频的 AJ。同时计算三个与真实性无关的难度代理量：CoTracker3 输出轨迹的平均可见比例、逐帧光流幅度的中位数、VDA 深度图的逐帧时序方差。
  • 测量：(a) 计算 AJ 与每个难度代理量的 Spearman 相关；(b) 计算在控制住这三个代理量之后，AJ 与人类 motion quality 评分的偏相关。
  • 判据：若偏相关相比原始相关（0.55）下降不超过 0.1，说明 AJ 确实主要在测真实感，论文的主张稳固；若下降到 0.3 以下，说明相当一部分相关性由跟踪难度这个共同因素解释，指标需要按难度做归一化。

这个实验成本极低（只需推理一遍加上统计），却直接决定这套指标能否被当作通用评估器使用。

§ 11 — 最强反例设计 ​

最有力的攻击是指出两个基准上的消融结论互相矛盾，而论文没有解释这个矛盾。IntPhys2 上，只加 DINO 的变体几乎追平完整模型，只加 3D 的变体在 solidity 上跌到 38.46——3D 是负贡献；VideoPhy-2 上，只加 3D 的变体（0.50）反而强于只加 DINO 的变体（0.40）。同一套组件在两个"都测物理真实性"的基准上贡献方向相反，最简单的解释不是"两个基准互补"，而是两个基准测的根本不是同一件事：IntPhys2 是 Unreal Engine 渲染的、语义类别有限的合成场景，DINO 特征在其中可能主要起到"识别出这是哪个刚体、它应该保持什么形状"的作用；VideoPhy-2 是真实文生视频，内容开放，3D 深度线索承担了更多区分度。

设计一个能戳破的实验：构造一批语义上完全正常但 3D 上违反物理的视频（例如把真实视频的某个物体在深度方向上做非物理平移，保持 2D 投影和外观完全不变，或轻微改变透视使物体尺度随深度错配）。这类视频对 DINO 来说毫无异常——物体身份、形状、纹理都对——只有 3D 结构错了。如果 3DSPA 在这批视频上的胜率接近随机，就说明它在 IntPhys2 上的高分主要来自语义捷径，"3D 结构是关键"的核心主张需要大幅收窄。反过来构造"3D 一致但语义荒谬"的视频（物体缓慢变成另一个物体，轨迹与深度全程平滑），可以检验另一半。

另一类可预测的失败：真实但罕见的运动。真实世界里也有看起来违反直觉的片段（体操动作、流体飞溅、快速旋转的物体）。自编码器学到的是训练分布里的"规律性"，罕见但真实的运动同样压不进瓶颈，会被判为不真实。论文的训练数据是 Kubric3D 合成场景加 TAPVid-3D，后者包含 DriveTrack、Panoptic Studio 一类相对受限的场景，可以推断这个分布对极端真实运动的覆盖有限（这是基于训练集构成的推断，论文未做此类测试）。

§ 12 — Follow-up Research Idea ​

驱动动机。 论文自己在 Discussion 里留了一句关键的话：未来想探索这些指标能否用来改进或正则化生成模型的训练。但当前形式做不到——AJ 的计算链条上有 CoTracker3、VDA、DINOv2 三个不可微或未接通梯度的模块，整个指标只能事后打分，无法回流到生成模型。同时 §9 指出的难度混淆意味着，即便强行把它当奖励，模型也可能学会"生成容易跟踪的视频"而非"生成真实的视频"——静态、低运动、高对比度的画面会被系统性奖励。

新的 framing。 与其把真实感做成一个绝对分数，不如做成一个配对的、难度受控的判别问题：给定一段视频，用现成的编辑或重渲染手段生成它的"物理扰动孪生"（同场景、同外观、同运动幅度，只改一处物理量），指标的输出是"原视频比孪生更真实"的置信度。这正是 IntPhys2 四元组设计的思想，但把它从"基准的构造方式"提升为"指标本身的定义方式"。这样定义的指标天然免疫难度混淆，因为比较永远发生在难度匹配的一对视频之间，而且它可以为任意视频自动构造对照，不需要人工标注。

可借鉴的相邻领域工具。 因果推断里的匹配（matching）与合成对照（synthetic control）思想正是为消除这类混淆而生；对比学习里的 hard negative 构造提供了如何生成"只差一个因素"的样本对的工程手段；而 3D 感知的视频编辑（把物体在重建的 3D 场景里平移、缩放后重渲染）近年已经足够可用，可以作为扰动孪生的生成器。

第一个实验。 在 EvalCrafter 那 1849 段视频上，为每段自动生成一个"深度方向非物理平移"的孪生视频（保持 2D 投影尽量不变），把 3DSPA 的输出从绝对 AJ 改成配对 AJ 差值，重新计算与人类 motion quality 评分的 Spearman 相关。同时按 §10 的方法计算配对指标与难度代理量的相关性。如果配对版本的难度相关性显著下降、而与人类评分的相关性持平或上升，就证明了"真实感应当被定义为配对比较而非绝对分数"——这会让这类指标第一次具备当作训练信号使用的资格，因为它不再能被"生成容易跟踪的视频"这条捷径攻破。

ViVa: A Video-Generative Value Model for Robot Reinforcement Learning ​

项内容
arXiv2604.08168
提交日期2026-04-09（v1），2026-06-05 修订至 v2
作者Jindi Lv, Hao Li, Jie Li, Fankun Kong, Yang Wang, Pengfei Yi, Yifei Nie, Xiaofeng Wang, Zheng Zhu, Chaojun Ni, Qiuping Deng, Hengtao Li, Jiancheng Lv, Guan Huang（GigaAI / 四川大学 / 清华）
分类cs.RO, cs.AI
一句话把预训练视频扩散模型改造成价值函数：把本体感受和标量 value 都编码成 latent frame，让模型在预测 K 步后的关节状态的同时输出 value，把「进度判断」接到「对未来的预演」上。

所属教程：物理感知视频生成

版本说明

本文基于 v2（2026-06-05）全文撰写；abs 页 HTML 链接指向的也是 v2。

§ 1 — 研究问题与重要性 ​

VLA 模型靠大规模预训练把「看图执行指令」做通了，但真机部署时的失败集中在另一个地方：长程任务里反馈是延迟的、观测是部分的，机器人在第 3 分钟叠错一道褶皱，要到第 5 分钟才在「衣服没折好」上体现出来。RL 处理这类问题的标准工具是 value function——它给每个状态打一个「离成功还有多远」的分数，advantage 由此算出来，policy 才能被推着改。π0.6∗​ 的 RECAP 流水线把这件事说得很直白：整条 pipeline 的学习效果强烈依赖 value model 的质量。

问题是现在的 value model 几乎清一色建在 VLM 上。VLM 训练在静态图文对上，它擅长回答「画面里有什么」，不擅长回答「这段交互正在把环境推向哪里」。ViVa 的主张是：value 估计本质上是一个预测问题，而视频生成模型正是被显式优化去建模时间演化的那类模型，所以它才是更自然的底座。这件事重要在于，它把「世界模型/视频生成」的用途从「生成动作、生成规划轨迹」挪到了一个此前没人认真做的位置——评判。

§ 2 — 前人工作与不足 ​

论文点名了三条线。GVL 把 value 估计变成对打乱帧做时序排序，让 VLM 零样本回答；TopReward 直接拿 VLM 的 token 概率当零样本 reward；π0.6∗​ 训练一个专门的 VLM value model，用稠密监督做 advantage-conditioned 的策略精修。前两者是 training-free 的，好处是不需要标注，代价是只能在稀疏时刻查询 VLM，缺少把静态帧和任务进度绑定的稠密监督——表 1 里 GVL 在 box packaging 和 paper 上的 Pearson 相关是负的（−0.081、−0.099），TopReward 在 shirt 上只有 0.118，基本等于没信号。

π0.6∗​ 有稠密监督，全局相关性就上来了（0.740 / 0.946 / 0.926），但它的骨干仍是 SigLIP + VLM。论文的批评很具体：这类模型逐帧看语义，不显式建模时序动力学和物理交互，所以在关键事件上的响应「延迟或迟钝」。这不是「前人没想到用视频模型」，而是当时视频生成模型的输出接口是像素，没人清楚怎么让它吐出一个标量；ViVa 解决的正是这个接口问题。

另一条线是视频生成在机器人里的既有用法：世界模型做规划、逆动力学抽动作、goal frame 条件化、视频与动作联合生成、人到机器人的迁移。这些工作都在用视频生成「产生」行为，没有人用它「评价」行为。

§ 3 — 重建作者的思考路径 ​

假设你在 2025 年底手上有一条能跑的 RECAP 流水线，也有一个 VLM value model，然后你去看它在真机 rollout 上的 value 曲线。你会看到一条大体单调上升、但在关键节点几乎不动的线：衣服被抓歪了，曲线不掉；箱子侧板折错了，曲线不掉。你去查 shirt folding 的数值，发现 MS 和 ES 都是负的（−0.266、−0.299）——不是不灵敏，是方向反了。

接着你会问：为什么会反？一个自然的猜想是，VLM 看到的是当前帧的语义内容，而「这一下抓歪了」的信息不在单帧语义里，它在「接下来会发生什么」里。人类判断也是这样：我们说「这一下不行」，其实是在心里往前推了两秒。

于是问题变成：什么模型天生会往前推两秒？答案是视频生成模型。剩下的就是工程：怎么让一个 image-to-video 的 DiT 输出一个 [0,1] 的数。既然它的输入输出统一是 latent frame，那就把标量也做成一个 latent frame——把 value 广播到整帧、把关节状态 repeat-padding 到整帧，放进同一条序列里一起去噪。这条路径不需要改架构，只需要改序列的组织方式。

§ 4 — 核心 Intuition ​

判断「任务进行得好不好」等价于「预演接下来会发生什么」。VLM 只能看当下的截图，视频生成模型被大规模视频语料训成了会外推的模型，所以把 value 塞进它的 latent 序列里、并强制它同时预测 K 步之后的本体感受，就等于让 value 的估计被「对未来身体状态的预期」牵着走。多出来的那个 future proprioception 目标不是装饰：它逼模型内化自己的运动学，而运动学恰好是「刚才那一下是不是失手了」的最直接证据。

§ 5 — 具体方法与完整 Pipeline ​

以 shirt folding 为例，机器人要从筐里拿衣服、摊平、按顺序折袖子和两侧、再纵向和横向对折、最后放回筐，300 秒内完成才算成功。

  • 模态编码：三路相机图像 oti​ 各自过预训练时空 VAE 得到 latent frame zoti​​；本体感受 qt​ 先归一化到 [−1,1]，再把元素重复填满 H′W′C′ 并 reshape 成一帧；标量 value vt​ 直接广播——整帧每个元素都等于同一个归一化数值。
  • 训练序列：[zblank​,zqt​​,zot1​​,zot2​​,zot3​​,zqt+K​​,zvt​​]。前五帧是干净条件（blank 是 causal VAE 要求的占位），后两帧加高斯噪声，denoiser 只学着从干净前缀恢复它们。
  • 推理：只给前五帧，反向扩散生成后两帧。v^t​ 取生成帧所有元素的平均再从 [−1,1] 还原到 [0,1]；q^​t+K​ 把 latent 展平、按原始维度切块、块内取均值再还原。实际只用 1 步 DDIM。
  • 骨干与训练：Wan2.2 视频 DiT，不改核心结构，只做 latent 注入。λprop​=0.5、λval​=1.0、K=50（与 RECAP 默认 advantage 估计视野对齐），batch 192 训 1 个 epoch，8 张 A800。数据是三任务约 20 小时演示数据加两轮 rollout（第一轮每任务 150 成功 + 50 失败，第二轮 100 + 50）。
  • 接入 RECAP：把它替换掉 π0.6∗​ 的 VLM value model，基座策略是 Gigabrain-0，跑两轮 rollout 精修。

一个值得注意的负结果：作者试过让模型同时预测未来的视觉 latent，value 精度反而下降。他们的解释是两个任务难度不匹配——视觉生成要建高维空间结构，value latent 结构极简单，联合优化时容易被视觉重建目标干扰。

§ 6 — 核心数学推导 ​

价值函数。标准定义 Vπ(xt​)=Eπ​[∑k=tT​rk​​xt​]，其中 xt​=(ot​,qt​)。

奖励设计。每条 episode 只有二值成功标签，作者把它铺成逐步 reward：

rt​=⎩⎨⎧​T1​,0,1,​t<Tt=T 且成功t=T 且失败​

累积回报因此是

Gt​={TT−t​,TT−t​+1,​成功失败​

这个设计的用意很清楚：成功轨迹的回报落在 [0,1) 表示归一化进度，失败轨迹被终端惩罚整体平移到 [1,2)。于是在任意时刻，成功和失败之间都有恒定 1.0 的间隔，「进度低」和「要失败了」不再混淆。代价也很清楚——Gt​ 里的进度项是时间的线性函数，见 §9。

Flow matching 目标。沿用 Wan2.2 的形式。取干净 latent z0​、噪声 z1​∼N(0,I)，构造线性路径 zτ​=(1−τ)z0​+τz1​，模型回归常速度 z1​−z0​：

L=λprop​E[∥vθ​(zτq​;τ,c)−(z1​−z0q​)∥22​]+λval​E[∥vθ​(zτv​;τ,c)−(z1​−z0v​)∥22​]

c 是干净条件帧。

评测指标。给关键帧 k 标方向 dk​∈{+1,−1}（里程碑为 +1，执行错误为 −1），取前后 w 帧窗口的均值 Vbefore(k)​,Vafter(k)​：

ERSk​=dk​⋅Vbefore(k)​+ϵVafter(k)​−Vbefore(k)​​

MS/ES 是在里程碑帧/错误帧上的 ERS 均值；把 ERSk​>0 当作「检测到」，就得到 MDR 和 ErrDR。这个指标的 intuition 是：不看 value 的绝对值，只看它在该动的时候有没有朝正确方向动。

§ 7 — 实验设计与结论 ​

问题一：全局相关性够不够？ 表 1 用 Pearson/Spearman 对比四种方法。稀疏采样的 GVL / TopReward 崩掉（负相关或接近零），稠密监督的 π0.6∗​ 和 ViVa 都很高，ViVa 在 shirt（0.984）和 paper（0.952）领先，π0.6∗​ 在 box（0.946 vs 0.868）领先。作者自己指出全局相关不能说明问题：近似均匀的预测会把 advantage 压成零，一样没有 RL 信号。

问题二：事件级响应对不对？ 表 2/3 是全文最有说服力的部分。shirt folding 上 VLM 基线的 MS/ES 是 −0.266/−0.299，方向完全反了，MDR/ErrDR 只有 0.407 / 0.500；ViVa 是 +0.095/+0.012，MDR/ErrDR 达到 0.990 / 1.000。paper roll 上 ViVa 也全面领先（0.039/0.055/0.762/0.778 对 0.023/0.028/0.704/0.667）。但 box packaging 上 ViVa 的 MDR 是 0.733，低于 VLM 的 0.765——论文写「across nearly all metrics」，这个 nearly 有实指。

问题三：换新物体还灵吗？ 在域外的 pants folding 上（50 条，只标里程碑），ViVa 的 Pearson 0.819 / MS 0.037 / MDR 0.643，对比 π0.6∗​ 的 0.740 / 0.016 / 0.397。事件级指标的相对提升远大于全局相关的提升。

问题四：更好的 value 能不能换来更好的策略？ 真机三任务成功率：模仿学习基线 π0.5​ 46.7%、Gigabrain-0 40.0%；RECAP(VLM) 63.3%；RECAP(ViVa) 80.0%（shirt 90 / box 70 / paper 80）。分轮看，ViVa 在 R0→R1 就冲得更快（paper roll 20%→80%，VLM 只到 50%），R1→R2 VLM 基本停滞而 ViVa 还在涨。

问题五：增益来自哪一块？ 三张消融表给出的答案并不一致，这点值得如实说。box 上「只换视频骨干」（VG-only）就把 MS 从 0.013 拉到 0.048、MDR 从 0.765 拉到 0.853，但 ES/ErrDR 反而不如加了状态的完整版；完整 ViVa 的 MS/MDR（0.034/0.733）低于 VG-only，只有 ES/ErrDR 更好。shirt 上 VG-only 把 MS 从 −0.266 翻正到 0.137、MDR 拉满到 1.000，但 ES 仍是负的（−0.026），要加上 future state 才转正。paper roll 上 VG-only 全面差于 VLM 基线（0.016/−0.011/0.651/0.444），只有完整架构才赢。合起来看，视频骨干主要买到里程碑敏感度，future proprioception 主要买到错误敏感度，两者缺一在某些任务上就会输给 VLM。

预训练权重的消融最干净：去掉后 shirt 的 ES 从 0.012 塌到 −0.524，box 的 MDR 从 0.733 掉到 0.523。超参上 λprop​=0.5 和 K=50 都是 U 形最优（K=10 时 shirt 的 ErrDR 直接归零，K=75 时 ES 转负）。效率上 ViVa 训练 4 GPU·days、推理 0.18 s/frame，比 VLM 基线的 6 GPU·days / 0.32 s 更省——主要因为省掉了 SigLIP 视觉编码器。

§ 8 — Take-aways ​

5 句话版：value 估计本质是「预演未来」，所以视频生成模型比静态 VLM 更适合当底座。ViVa 把本体感受和标量 value 都编码成 latent frame 塞进 Wan2.2 的序列，不改架构就让视频 DiT 吐出一个数。奖励设计用「1/T 逐步进度 + 失败终端 +1」把成功与失败拉开恒定 1.0 的间隔。事件级指标（MS/ES/MDR/ErrDR）暴露出 VLM 基线在 shirt folding 上响应方向是反的，而 ViVa 检测率接近满分。接进 RECAP 后真机平均成功率从 63.3% 提到 80.0%。

3 句话版：用预训练视频扩散模型当 value function，靠 latent 注入让它同时预测未来关节状态和当前 value。全局相关性掩盖了 VLM 基线在关键事件上方向反了的事实，事件级指标才看得出差距。真机三任务平均成功率 80% 对 63.3%。

1 句话版：把 value 当成一帧图去生成，用视频模型的时空先验换来对执行错误的敏感度。

§ 9 — 最脆弱的假设 ​

最要命的一条是：监督信号 Gt​ 中的进度项是时间的线性函数，因此「学会 value」在很大程度上可以退化为「学会读时钟」。 成功轨迹的目标值就是 (T−t)/T，一个只会从画面估计「这段任务进行到百分之多少」的模型，不需要任何关于成败的语义，就能拿到极高的 Pearson 相关。

论文自己的数据支持这个担忧：ViVa 在 shirt 上 Pearson 高达 0.984，但同一模型的 MS 只有 0.095、ES 只有 0.012。ERS 是相对变化率，0.012 意味着在标注的错误帧前后，value 的相对跌幅只有约 1%。换句话说，那条曲线绝大部分的方差来自单调的时间趋势，事件响应只是叠在上面的一层极薄的涟漪。ErrDR 能到 1.000 是因为它只判断符号，不判断幅度。

如果这条假设不成立——即高相关主要来自时钟读数而非进度理解——那么核心 claim「grounding value in anticipated dynamics 带来更可靠的 value」就被削弱成「视频骨干读时钟读得更准、顺带在事件上多抖了一下」。论文缺的证据是：一个只回归归一化时间、不含任何成败监督的对照模型能拿到多少 Pearson。作者在 limitation 里只提了没做大规模预训练，没有讨论这一点。

§ 10 — 最小复现实验 ​

一周可做，不需要真机：

  1. 取任一带成功/失败标注的长程操作数据集（如公开的双臂折衣或仿真长程任务），每任务留出 50 条做测试，人工标 5–10 个里程碑帧和错误帧。
  2. 实现三个模型，全部用同一套 Gt​ 监督：(a) VLM 分类头基线；(b) 视频 DiT + value latent（ViVa w/o fut）；(c) 完整 ViVa（加 future proprioception）。骨干可以用最小的开源视频 DiT，分辨率降到 256。
  3. 关键对照：再加 (d) 一个「时钟基线」——同样的视频骨干，但监督目标换成纯归一化时间 t/T，完全不含成败信息。
  4. 测 Pearson/Spearman + MS/ES/MDR/ErrDR。

判据：如果 (d) 的 Pearson 与 (b)(c) 接近而 MS/ES 显著更差，说明全局相关确实主要由时间趋势解释，论文的事件级指标是对的、全局指标应当废弃；如果 (d) 的事件指标也接近 (c)，那 ViVa 的增益就更可疑。

§ 11 — 最强反例设计 ​

站在反对者立场，最有力的攻击是给出一个替代解释：ViVa 的真机增益可能来自 value 的平滑性而非正确性。

RECAP 用 advantage 做条件化，advantage 是 value 的差分。VLM 基线用的是 201 路分类，输出天然是阶梯状、带量化噪声的；ViVa 输出的是一整帧 latent 的均值，等于对 H′W′C′ 个元素做平均，这本身就是一个强力低通滤波器。差分一个带噪信号会放大噪声，差分一个平滑信号不会。所以 RECAP(ViVa) 更快收敛，可能只是因为它的 advantage 信噪比更高，与「视频先验理解了物理」无关。

设计的实验：把 VLM 基线的输出做同等强度的时序平滑（论文在图 6 里对 π0.6∗​ 和 ViVa 都做了 20% 平滑，说明平滑度本身是个已知变量），或者把它的 201 路分类换成回归头，然后重跑两轮 RECAP。如果 VLM 基线的成功率从 63.3% 明显上抬，那么「视频骨干」这个归因就站不住。

另一个可预测的失败场景：任务时长分布很宽或者存在合法的停顿/重试。由于 Gt​ 假设进度匀速推进，一个正确但慢的策略会被系统性地判为「进度落后」，advantage 为负，RL 会把它往「快」的方向推——在需要谨慎的接触密集任务上，这可能主动制造失败。

§ 12 — Follow-up Research Idea ​

驱动它的局限：ViVa 让视频模型输出一个标量，但为了这个标量，它把模型最值钱的能力——生成完整的未来——扔掉了（作者甚至发现联合预测视觉 latent 会损害 value 精度）。这说明「用生成模型做判别」的接口还没找对。

新的 framing：不要让模型预测 value，让它比较。给定当前观测和两个候选动作片段，用同一个视频生成器分别做条件外推，然后用一个轻量的可学习读出头判断哪一条外推更接近成功终止状态。这把 value 学习变成 preference learning，绕开了 Gt​ 这条把进度线性化的监督，也绕开了「时钟读数」的捷径——因为两个候选在同一时刻出发，时间信息被完全对消。

可借鉴的相邻领域：一是 RLHF 里的 Bradley–Terry 偏好建模与 reward model 训练（成对比较对绝对标注的鲁棒性已被反复验证）；二是 model-based RL 里的 MPC/CEM——用生成器做短程 rollout 并排序，而不是回归一个全局 value。

第一个实验：在已有的 rollout 数据上构造成对样本——同一任务、同一时间戳附近、一条最终成功一条最终失败——训练一个成对读出头，指标仍用 MS/ES/MDR/ErrDR，并额外报告「时钟基线」在成对设定下的表现（应当退化到 50%）。如果成对模型在事件级指标上明显超过回归版 ViVa，就说明当前的瓶颈是监督形式而非骨干。

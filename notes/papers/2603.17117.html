MosaicMem: Hybrid Spatial Memory for Controllable Video World Models ​

项内容
arXiv2603.17117
提交日期2026-03-17
作者Wei Yu, Runjia Qian, Yumeng Li, Liquan Wang, Songheng Yin, Sri Siddarth Chakaravarthy P, Dennis Anthony, Yang Ye, Yidi Li, Weiwei Wan, Animesh Garg
分类cs.CV
一句话把空间记忆的基本单元从「点云/高斯」和「整帧」之间取中间态定为 patch，先用现成 3D 估计器把 patch 抬到 3D 做精确定位与定向检索，再交给 DiT 用原生 attention 拼贴回当前视角，该持久的保留、该演化的交给模型 inpaint。

所属教程：世界模型

§ 1 — 研究问题与重要性 ​

视频扩散模型正从「生成几秒钟看起来合理的片段」转向「可探索的世界模拟器」。Genie 3 一类系统展示了目标：实时交互、远超普通模型的持续时长、物体恒常性、视角一致性、干预下稳定的因果关系。这些能力全都压在同一个组件上——空间记忆。

论文的问题很具体：现有两种空间记忆范式各自在一半的场景里有效，在另一半失效，而失效模式恰好互补。显式记忆能保住几何但画不动东西；隐式记忆能画动态但相机会漂。做世界模拟器需要两者同时成立，因此需要一个既不是点云也不是整帧的记忆单元。

§ 2 — 前人工作与不足 ​

显式空间记忆把 2D 观测抬进外部 3D 几何缓存，存储单元是点、体素或 3D Gaussian。GEN3C 维护点云缓存，Spatia 用 visual SLAM 更新记忆，VMem 用 surfel 索引可见性做视图检索。重访时把缓存投影到查询视角，作为条件注入生成器，通常走 ControlNet 分支或通道拼接。优点是几何由专门的 3D 推理保证，减少训练数据偏置。论文点出两个精确的失效点：其一，维护一个包含多个独立运动物体的一致显式缓存本质上很难，因此这一范式最适合静态场景；其二，全局 3D 重建会累积跨视角微小失配，长时程记忆更新变得脆弱。更根本的是，这种设计把视频生成器降格成 inpainting，很难产生丰富的文本驱动动态。

隐式空间记忆把世界状态留在模型的 latent 表征里，存储单元是带位姿的帧，检索通过 DiT 自带的条件机制完成，典型是 token 拼接。Context-as-Memory、RTFM、WorldPack、WorldPlay 都属此列。这条路灵活，能处理动态、外观变化、非刚性因素，且端到端可微。论文给出的批评比通常的说法更尖锐：即使给定完全正确的相机位姿，生成视频的 egomotion 仍然不准，重访时会明显漂移。这是因为视角转换没有被投影强制执行，小位姿误差会累积成空间漂移。另一个问题是冗余，帧级记忆逐帧转化上下文，生成变慢且在有限 context window 下限制持续时长；试图用压缩 patch token 减少上下文的做法又会降低检索保真度，重访时更模糊。

§ 3 — 重建作者的思考路径 ​

先做一次范式的解剖：显式记忆的完整流程可以拆成「几何抬升」加「投影渲染式条件注入」，隐式记忆则是「帧存储」加「attention 式条件注入」。两条流程的前半段和后半段是可以互换的。显式记忆的问题出在后半段——投影渲染把生成器锁死成 inpainting；隐式记忆的问题出在前半段——没有几何，定位不准且冗余。那么取显式的前半段配隐式的后半段，两个问题同时解掉。

接下来是记忆单元的选择。显式用点，隐式用帧，中间还有一个被忽略的粒度：patch。patch 足够小以便逐个抬到 3D 做精确定位，又足够大以便直接作为 DiT 的 token 参与 attention。而且 patch 是独立存储的局部证据，不需要维护一个全局一致的重建，这直接绕开了显式记忆的跨视角失配累积。

这里有一个可以先验证的猜想：预训练视频模型是否已经具备把 context 里的 patch 放到正确时空位置的能力。论文做了这个实验——把 Mosaic Memory 直接塞进未经任何修改的 Wan 2.2，不做任何 finetune，模型仍然能把检索到的记忆投到目标位置并做适度精修。这个训练无关的现象说明思路成立，剩下的是精度问题。

精度问题来自 3D VAE 的高时空压缩，它引入时空歧义并降低 DiT 中 RoPE 坐标的有效分辨率，导致检索到的 patch 对不准生成区域中心。既然已经有深度和相机参数，就可以算出 patch 在目标视角下的精确重投影坐标，然后要么改位置编码，要么改特征本身。两条路都试，最后混合训练。

§ 4 — 核心 Intuition ​

记忆的粒度决定了它能做什么。点云粒度带来几何但锁死了生成自由度，整帧粒度带来自由度但丢了几何。patch 粒度可以两头都要：抬到 3D 就有了可靠的定位与定向检索，塞进 attention 就保留了模型原生的 prompt-following 能力。检索到的 patch 只是参考信号而非硬约束，模型自己决定哪里照抄记忆、哪里按 prompt 生成新的动态。

§ 5 — 具体方法与完整 Pipeline ​

任务是给定一张真实输入图像 I、一组文本 prompt L、一条相机位姿序列 C，生成长时程 rollout。以在一条街上走出去再走回来为例：

  • backbone：Wan 2.2 5B，一个开源 TI2V DiT，用 flow matching 学整段视频的联合分布，向量场额外条件于空间记忆 M。
  • 写入记忆：对每个 patch P，用现成 3D 估计器（Depth Anything V3 或 ViPE）推断深度与相机参数，把 patch 抬到 3D，记下其 3D 时空位置。
  • 检索：走回头路时按 3D 位置定向检索相关 patch。检索可以稠密也可以稀疏，因为视频高度冗余，把同一场景的记忆分散到不同时空位置往往就足以重建整段；而且现代视频生成器天然保留首帧细节，与首帧重叠的区域不需要提供完整记忆，这显著削减了条件 token 数。
  • 对齐：检索到的 patch 通过 warped RoPE 或 warped latent 与查询视角建立几何对应（见 §6）。
  • 条件注入：mosaic patch 被 flatten 后拼接到 token 序列，作为条件参与 DiT 的原生 attention。
  • 相机控制：PRoPE 模块提供帧级运动引导。论文给出三条理由：大幅相机运动或稀疏记忆下 Mosaic Memory 主要提供视觉线索而非精确运动信号；3D VAE 的 4 倍时间压缩使记忆无法捕捉帧间细粒度运动；有了相机控制就能直接复用此前生成的 video latent 而无需重新编码，模块负责把 latent 里残留的旧运动纠正对齐到目标轨迹。
  • 数据：MosaicMem-World。作者指出公开第一人称数据集（Ego4D、DL3DV、EgoVid）以向前导航为主，显式重访罕见，不适合考验记忆。新数据来自四个来源、各数十小时：授权素材搭建的 UE5 场景（含显式重访片段）、商业游戏环境如 Cyberpunk 2077、真实第一人称拍摄、以及从 Sekai 中按相机轨迹挑出重访频率最高的序列。标注按 32 帧分段，Gemini 3 为每段生成两条描述，一条写首帧静态内容（布局、显著物体、空间关系），一条写其余帧的时序动态（相机运动、交互、状态变化）。这种静态加动态的因子化标注支持组合式训练：把连续段的动态描述拼起来就能构造任意长度的训练片段。
  • 训练：AdamW，学习率 1×10−5，250k 步，有效 batch 64，8 张 H100。推理沿用 Wan 默认采样器 50 步。

§ 6 — 核心数学推导 ​

生成过程是概率流 ODE：

dλdXλ​​=uθ​(Xλ​,λ∣I,L,C,M)

记忆对齐的核心是一次标准的反投影再投影。检索到的 patch 关联着源时刻的深度 D 与相机内外参 (Ki​,Ti​)，其原始 RoPE 坐标为 (u,v)，目标时刻 j 的相机为 (Kj​,Tj​)：

(u′,v′)=Π(Kj​Tj​Ti−1​Ki−1​(u,v,D))

其中 Π(⋅) 是透视投影，即齐次坐标的透视除法。链式读法是：Ki−1​(u,v,D) 把像素抬回源相机坐标系的 3D 点，Ti−1​ 转到世界系，Tj​ 转到目标相机系，Kj​ 再投影回像素。

得到 (u′,v′) 之后有两种用法。Warped RoPE 用 (j,u′,v′) 作为该 patch 的 3D RoPE 坐标，并且保留重投影坐标的小数部分、在更高分辨率上采样 RoPE，以尽量保住精度。Warped Latent 反过来不动位置编码，而是用同样的 (u′,v′) 对源 latent 特征做可微双线性 grid sampling，直接把特征搬到对的地方。

相机控制用 PRoPE，把相对相机视锥几何直接注入 self-attention。给定逐帧相机投影矩阵 P~i​∈R4×4，两视图的完整相对关系由射影变换 P~i1​​P~i2​−1​ 编码，通过 GTA 风格的变换 attention 施加：

AttnPRoPE​(Q,K,V)=D⊙Attn(D⊤⊙Q, D−1⊙K, D−1⊙V)

每个 token 使用块对角矩阵 DtPRoPE​=diag(DtProj​,DtRoPE​)，其中 DtProj​=Id/8​⊗P~i(t)​。这个构造的 intuition 是：把相机几何做成作用在 Q/K/V 上的可逆变换，attention 分数自动只依赖两个 token 相机之间的相对射影关系，与全局坐标系选择无关。

视频场景的改动在于时间压缩。VAE 以 s=4 压缩时间，一个 latent 帧索引 ℓ 对应四个原始帧 {4ℓ+k}k=03​，因此单个 latent slice 必须以四个相机矩阵为条件。做法是展开一个子索引 k，用 Dℓ,kProj​=Id/8​⊗P~ℓ,k​，等价于把相机打包成 P~∈RB×L×4×4×4 广播进 Q/K/V 的旋转，attention 算子层面的接口保持不变。

§ 7 — 实验设计与结论 ​

评测用四组互补指标各配专用评测集：FID 与 FVD 看生成质量；RotErr 与 TransErr 看相机精度（位姿由 DA V3 估计）；Dynamic Score 用平均光流幅度在相机运动极小的轨迹上度量物体动态强度；Consistency Score 在标注的对应区域内测 SSIM/PSNR/LPIPS，作为记忆检索准确度。

对显式记忆的对比。 GEN3C、SEVA、VMem、VWM 的 Dynamic Score 在 1.18 到 1.41 之间，MosaicMem 是 2.58。作者的解释是这些方法的非零动态分主要来自相机运动而非物体运动。缺乏动态演化还连带拉低视觉质量，因为生成分布偏离真实分布：显式基线 FVD 在 301 到 372 之间，MosaicMem 是 232.95。相机精度上 MosaicMem 的 RotErr 0.51 度对最好的显式基线 SEVA 1.42 度，作者坦言这部分受益于日益强大的 DA V3。定性结果显示基线无法生成新的运动物体，也无法让已观测物体动起来，而 MosaicMem 能按 prompt 生成组合场景，例如科幻环境里骑马的中世纪骑士。

对隐式记忆的对比。 WorldMem 与 CaM 的 RotErr 分别是 5.87 与 4.65 度，Consistency PSNR 15.34 与 15.78，MosaicMem 是 0.51 度与 23.57。差距接近一个数量级，与论文开头的诊断吻合：隐式记忆即便给对位姿也画不准 egomotion。

消融的层次很清楚。 以 ControlMLP 做相机控制为基线（RotErr 6.51），换成 PRoPE 降到 4.91，只用 MosaicMem 不加 PRoPE 降到 0.79，完整模型 0.51。「MosaicMem 单独」已经远好于「PRoPE 单独」，说明记忆本身携带了大量运动信息；但它仍显著弱于完整模型，作者归因于两点：无法处理 patch 内的细粒度运动，以及大幅相机运动下可能检索不到足够 patch，此时模型失去引导。

两种 warping 各有胜负。 Warped Latent 相机更准（RotErr 0.66 对 0.70，TransErr 0.08 对 0.09），Warped RoPE 画质与检索更好（FID 71.89 对 75.46，Consistency SSIM 0.69 对 0.65）。自回归实验里 Warped RoPE 还暴露一个具体故障：相机运动极慢时，前几帧新观测到的物体会在图像边界附近被反复重新生成。混合训练两种策略得到最终模型，全部指标最优。

长视频与自回归。 每次生成 80 帧片段并写入记忆，用上一段末帧作为下一段首帧，重复拼成 2 分钟导航视频；CaM 在长 rollout 中伪影累积直至崩溃。作者进一步用 Causal Forcing 把双向模型蒸馏成因果架构，并在长时程生成中叠加 Rolling Forcing，得到 Mosaic Forcing，在 640×360 下实现 16 FPS 实时生成。与 RELIC 和 Matrix-Game 2.0 对比，总质量分 81.11 对 79.08 与 75.11，RotErr 0.89 度对 4.99 与 5.32。

记忆可操纵性。 因为 patch 带 3D 时空位置，可以直接删除、复制、拼接、重定位。论文演示了最简单的一种：把两个不同场景注册进同一记忆空间并在空间上连起来，用户可以从中世纪场景走进现代街道再走回去；把记忆翻转后注册到天空，则得到抬头能看见另一条街的超现实连接。

§ 8 — Take-aways ​

5 句话版：空间记忆的两种范式在互补的场景里失效，显式记忆保几何但画不动物体，隐式记忆能画动态但即便给对位姿也会漂移。MosaicMem 把记忆单元定在两者之间的 patch 粒度，用现成 3D 估计器抬升做定位与定向检索，再用 DiT 原生 attention 做条件注入。3D VAE 的时空压缩会破坏对齐精度，用 warped RoPE 改位置编码或 warped latent 改特征来修正，混合训练效果最好。PRoPE 提供帧级相机条件，补上记忆无法表达的帧间细粒度运动。结果是相机精度比隐式基线好近一个数量级、动态强度是显式基线的两倍，并解锁分钟级导航、记忆编辑与 16 FPS 实时自回归。

3 句话版：把空间记忆的基本单元从点或帧改成 patch，就能同时拿到显式记忆的几何定位和隐式记忆的生成自由度。对齐误差来自 VAE 压缩，用重投影坐标改 RoPE 或改 latent 特征来补，两者互补需混合。记忆带 3D 位置因而可被直接编辑，这是帧级记忆做不到的。

1 句话版：记忆的粒度决定了世界模型能不能既记住地形又画出变化。

§ 9 — 最脆弱的假设 ​

最致命的假设是：现成 3D 估计器给出的深度与相机参数足够准确，因而 patch 的 3D 定位可以被信任。整个 pipeline 的前半段完全建立在 Depth Anything V3 或 ViPE 之上，检索靠它、warping 的重投影公式靠它、连评测中的 RotErr 都是用 DA V3 估的位姿算的。

它在实践中可能不成立的机制有两层。第一层是估计器本身的失效域：低纹理墙面、镜面与透明物体、强运动模糊，这些场景下单目深度不可靠，patch 会被抬到错误的 3D 位置，重投影坐标随之错误，而模型没有任何机制察觉这一点——错误的 patch 会被自信地拼到错误的位置。作者的数据清洗步骤删掉了 3D 估计不准或运动模糊过重的视频，这承认了问题存在，但也意味着模型从未在这类数据上训练过，部署时遇到就是分布外。第二层更微妙：论文自己承认相机精度的提升「部分受益于日益强大的 DA V3」。这句话反过来读是，方法的性能上界由外部估计器决定，而评测又用同一个估计器，构成与训练标签同源的度量闭环。

论文提供的证据是各项指标上的大幅领先，以及 Wan 2.2 上训练无关注入的可行性演示。缺的证据是估计器质量与最终性能的对照实验——比如把 DA V3 换成更弱的深度估计器，看性能退化多少。没有这条曲线，就无法区分「patch 粒度记忆这个想法好」与「DA V3 很强」这两种解释各占多少。

§ 10 — 最小复现实验 ​

一周内可做、且不需要 250k 步训练的验证，直接利用论文自己发现的训练无关现象：

  • 取未经修改的 Wan 2.2 或同类 TI2V DiT，实现最简版 Mosaic Memory：单目深度用任意开源模型，从一张源图裁出若干 patch，按给定目标相机位姿计算重投影坐标，把 patch token 拼进 context。
  • 做三组条件：正确重投影坐标、加入受控噪声的坐标（在 (u′,v′) 上加不同幅度的高斯扰动）、随机坐标。
  • 测量生成结果在 patch 对应区域的 PSNR，画出「坐标误差幅度对重建质量」的曲线。
  • 支持论文的结果：曲线在小误差区间平坦、超过某阈值后陡降，说明 patch 定位精度确实是关键变量，且模型有一定容错。反驳的结果：曲线全程平坦，说明模型基本忽略了 patch 的位置信息而只把它当作全局风格线索，那么 warped RoPE 与 warped latent 这两个组件的必要性就要重新评估。

这个实验只需推理，不需训练，且能直接量化论文最核心的假设——几何定位精度到底有多重要。

§ 11 — 最强反例设计 ​

设计一个针对 patch 独立性假设的攻击。MosaicMem 的一大卖点是「存独立局部 patch 而非全局重建，因而避免跨视角失配累积」。但独立性同时意味着 patch 之间没有一致性约束：两个来自不同时刻、深度估计各自有偏的 patch，被拼到同一视角时可能在几何上互相矛盾，比如同一面墙的两半错开、地平线在拼接处断裂。全局重建虽然会累积误差，但它至少强制了一个全局一致的解。

具体实验：构造一条轨迹，让相机绕一个大物体（比如一栋建筑）走大半圈，使得当前视角同时需要来自轨迹起点与轨迹中段的记忆 patch。这两组 patch 的深度估计误差是独立的，且相机基线很长，误差不会相互抵消。可预测的失败是拼接处的几何断裂。若观察到这种断裂，就说明「独立 patch 避免误差累积」这一优势是有代价的：误差不再累积，但变成了不可调和的局部冲突。

论文的评测设计没有覆盖这个情形。MosaicMem-World 强调的是「周期性重访先前 checkpoint」，重访意味着回到相似视角，检索到的 patch 主要来自单一先前时刻，冲突概率低。真正的压力测试是「多源 patch 在同一视角汇合」，这在环绕运动和大范围探索中很常见，但基准里没有专门构造。

一个更温和的替代解释针对动态性指标。Dynamic Score 定义为「相机运动极小的轨迹上的平均光流幅度」，而 MosaicMem 得分 2.58 显著高于显式基线的 1.18 到 1.41。反对者可以主张这部分差距来自 MosaicMem 保留了完整的 prompt-following 能力因而更愿意生成运动，而不是因为它「更好地建模了动态」。区分这两种解释需要一个动态准确性指标而非强度指标——比如给定明确的物体运动 prompt，测量生成运动与指定运动的一致性。论文只报了强度。

§ 12 — Follow-up Research Idea ​

驱动的局限：记忆写入是无差别的。每个 patch 都被抬到 3D 存起来，检索时按空间位置取回。但世界里的内容在持久性上差别巨大：墙和地面应当永久保留，路过的行人不该被写进空间记忆，桌上被移动过的杯子应当以最新状态覆盖旧记忆。当前设计把这三类同等对待，靠模型在生成时自行判断该不该照抄，这既浪费 context 也留下了矛盾记忆的隐患。

新 framing：把空间记忆从「几何索引的缓存」升级为「带持久性先验的场景信念」，每个 patch 除了 3D 位置还携带一个持久性估计，决定它被写入、被覆盖还是被丢弃。这个转变把记忆管理从检索问题变成了信念更新问题。

可借鉴的相邻工具：机器人建图里的 dynamic object filtering 与 occupancy 的贝叶斯更新提供了现成框架——同一空间格点被反复观测到一致内容则置信度上升，观测到不一致则触发更新而非并存。视频领域则有 motion segmentation 可以在写入时就把独立运动的区域标出来。两者结合可以让 patch 的持久性从数据里自动学出来，而不需要人工标注。

第一个实验：不必立刻改架构。先在现有 MosaicMem-World 上做一次测量：把每个 patch 按「是否落在独立运动物体上」二分（用光流残差相对相机运动的偏离来判定），然后比较两种检索策略下的生成质量——全量检索，与只检索静态 patch。若只用静态 patch 的版本在 Consistency Score 上持平甚至更好，同时 Dynamic Score 不降，就直接证明了动态 patch 的写入是纯粹的浪费甚至干扰，持久性过滤有明确收益。若剔除动态 patch 后动态生成质量显著下降，说明模型确实在利用历史动态信息做时序外推，那么问题的形态就不是「过滤」而是「分层存储」，静态几何与动态轨迹应当进入两套记忆并以不同方式检索。

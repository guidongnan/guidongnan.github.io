"PhyWorldBench": A Comprehensive Evaluation of Physical Realism in Text-to-Video Models ​

项内容
arXiv2507.13428
提交日期2025-07-17
作者Jing Gu, Xian Liu, Yu Zeng, Ashwin Nagarajan, Fangrui Zhu, Daniel Hong, Yue Fan, Qianqi Yan, Kaiwen Zhou, Ming-Yu Liu, Xin Eric Wang
分类cs.CV, cs.AI
备注ICLR 2026 oral；35 页、21 图
一句话用 1050 条覆盖 10 类物理现象的 prompt（含刻意违反物理的 Anti-Physics 类）加 Yes/No 双标准人工评测 12 个 T2V 模型，并提出 Context-Aware Prompt 让 MLLM 零样本当物理评审。

所属教程：物理感知视频生成

§ 1 — 研究问题与重要性 ​

视频生成模型的画面已经足够逼真，但它们真的理解物理定律吗？这个问题不能靠 FVD 或 IS 回答——那些指标衡量的是视觉分布距离，对运动是否合理、是否遵守物理毫无判别力，而且在无参考视频时基本失效。

问题的实际重要性在于：一旦有人把这些模型当作"世界模拟器"用于机器人训练、科学可视化或教育，物理错误就不再是审美瑕疵而是错误信息。这篇论文提供的答案很不客气——12 个模型里最好的 Pika 2.0 综合成功率只有 0.262，也就是四分之三以上的生成视频过不了"物体对 + 事件对 + 物理现象对"这三关。

§ 2 — 前人工作与不足 ​

通用 T2V benchmark（VBench、EvalCrafter、T2V-CompBench）覆盖多样性、时序连贯性、组合性，但不针对物理。物理向的 benchmark 已有几个：VideoPhy 与 PhyGenBench 评物理常识，DEVIL 与 VideoPhy-2 评动态真实性，Physics-IQ 测流体与热力学等基本原理，Morpheus 聚焦实验物理。

作者对这些工作的批评落在两处。规模与覆盖：Table 1 的对比里 PhyWorldBench 有 50 个物理类别、1050 条 prompt，而对照的四个 benchmark 分别是 5 类/688 条、27 类/160 条、5 类/396 条、3 类/84 条。评测器的可移植性：PhyGenEval 假设事件有固定顺序，而 PhyWorldBench 的许多场景没有；VideoCon-Physics 是在 VideoPhy 自己的标注上训练的，跨到别的 benchmark 就退化；VideoPhy-2 的评测器同样是在自己的标注上微调的。作者因此把这三个评测器排除在对比之外以避免不公平比较，转而设计一个不需要微调的零样本方案。

还有一个此前没人系统做的维度：没有任何 benchmark 测试模型能否按指令生成反物理内容。这不是猎奇——如果模型只是复现训练数据里的模式，那它在反物理 prompt 上会"合理化"回真实物理；如果它真懂物理，就能在被要求时违反它并保持逻辑自洽。

§ 3 — 重建作者的思考路径 ​

从一个观察出发：模型在真实物理 prompt 上表现好，可能只是因为训练数据本身就遵守物理，模式匹配足以过关。要把"理解"和"记忆"分开，需要一个模式匹配必然失败的测试——反物理场景，因为训练数据里根本没有酒杯里的酒反重力上浮。

第二条线索来自评测本身。人工评测昂贵且不可扩展，MLLM 是自然替代，但已有工作报告 MLLM 评物理真实性不可靠。作者发现了具体原因：MLLM 主要在真实视频上训练，看到不合理内容时倾向于为它编出合理解释，除非被明确告知这是 AI 生成的。这个观察直接导出解法——在 prompt 里显式说明视频是生成的而非真实的。

第三条：Yes/No 二值判断比打分更客观。把评测拆成"物体数量对不对 + 事件有没有出现"（Semantic Adherence）与"关键物理现象是否全部满足"（Physical Commonsense）两组标准，标注者只需回答是否，主观性被压到最低。

§ 4 — 核心 Intuition ​

模型在真实物理上的高分说明不了理解，只有让它在被要求违反物理时也能做到，才能证明它把物理当作可操作的规则而非固定的视觉模式。而让 MLLM 当评审的关键不是换更强的模型，是先告诉它"这段视频是假的，可能有问题"——否则它会用自己的真实世界先验替生成模型圆谎。

§ 5 — 具体方法与完整 Pipeline ​

三级层次结构。 Fundamental Physics 覆盖运动学、相互作用动力学、能量守恒、流体与颗粒动力学、光照与阴影、形变与弹性；Composite Physics 覆盖尺度与比例、刚体动力学、人与动物运动；Anti-Physics 单独一类，含反重力、能量凭空产生/永动、物体穿模与超现实交互、时间逆转、无限复制与分裂五个子类。10 个主类 × 5 子类 × 7 场景 × 3 种 prompt 变体 = 1050 条。

三种 prompt 变体。 Event Prompt 是最简洁的事件描述，测最小输入下的高层理解；Physics-Enhanced Prompt 在其上自然地加入物理后果但不直接写出物理定律；Detailed Narrative Prompt 由 GPT-4o 按固定 query 改写，加入主体描述、动作、场景、可选的镜头语言与光影氛围。

构建流程。 先由物理专家与作者共同定义类别（参考 Fundamentals of Physics 与 Classical Mechanics）；再用 GPT-4o 与 Gemini-1.5-Pro 为每个子类生成 20 条 Event Prompt，由人按多样性与物理代表性选出 7 条；Physics-Enhanced 由标注者手写，Detailed 由 LLM 生成后人工验证；全程有伦理审查。

标准与评测。 每条 prompt 单独标注 Basic Standards（物体、事件）与 Key Standards（若该事件在真实世界发生，应观察到哪些物理现象）。评测在 Amazon Mechanical Turk 上进行，每段视频 3 名独立标注者多数表决，时薪 18 美元。共生成并评测 12600 段视频。

CAP 评测器。 两步 chain-of-thought：第一步让 MLLM 详细描述视频（物体、事件、观察到的物理现象），并在 prompt 里明确写出"这是视频模型生成的，可能低质量、模糊、不一致，尤其可能不遵守真实世界物理"；第二步基于第一步的描述，对物体、事件、以及标准列表里每一条物理现象分别输出 Yes/No，返回 JSON。均匀采样 8 帧。作者强调 CAP 不默认视频有错，只在明确违反类别标准时才判错，并用正确视频的假阳性率验证中立性：SA 从 0.188 变到 0.187，PC 从 0.172 变到 0.186。

§ 6 — 核心数学推导 ​

本文无形式化数学推导，跳过。评测量化仅涉及二值标注 SA,PC∈{0,1} 及其联合满足率的统计。

§ 7 — 实验设计与结论 ​

问题一：现在的模型到底有多差？ 人工评测覆盖 5 个闭源模型（Sora-Turbo、Gen-3、Kling-1.6、Pika 2.0、Luma）与 7 个开源模型（Hunyuan 720p、Open-Sora 2.0、Open-Sora-Plan 1.3、CogVideoX-1.5、Step-video-T2V、Wanx-2.1、LTX-Video）。综合 Both 得分：Pika 2.0 最高 0.262，Sora-Turbo 0.208，Wanx-2.1 0.189（开源最佳），Kling-1.6 0.188，Hunyuan 0.185，Luma 0.184，Step-video 0.173，Open-Sora 0.170，CogVideoX-1.5 0.163，Gen-3 0.130，Open-Sora-Plan 0.075，LTX-Video 0.062。部分开源模型已超过部分闭源模型。

问题二：反物理是否揭示了理解与模仿的差别？ 所有模型的分数都沿 Fundamental → Composite → Anti-Physics 单调下降，且降幅剧烈。Pika 2.0 在 Fundamental 上 Both 为 0.312，在 Anti-Physics 上只有 0.011；Luma 与 LTX-Video 在 Anti-Physics 上的 PC 或 Both 直接是 0.000。更有信息量的是失败方式：给"酒杯里的酒反重力"这样的 prompt，模型生成的是一张几乎静止的画面——它按真实物理"合理化"了指令而不是尝试后失败。附录 M 把这个现象量化为 static-scene rationalization，从 12 个模型各抽 50 个失败案例标注，Pika 34%、Wanx 28%、Sora 24%、Kling 24%，而 Open-Sora 4%、LTX 4%。趋势很清楚：整体质量越高的模型，越倾向于用冻结画面回避难做的物理。弱模型不"合理化"，只是因为它们连语义对齐都做不到，没有机会合理化。

问题三：prompt 工程能救多少？ 用开源模型（闭源模型内部可能有 prompt 改写，无法验证）对比三种 prompt。Physics-Enhanced 普遍最好：Wanx 从 0.175 提到 0.202，Hunyuan 从 0.159 到 0.198，CogVideoX-1.5 从 0.123 到 0.177。而 Detailed（LLM 改写）常常不如 Physics-Enhanced，有时甚至不如 Event（Hunyuan 0.155 < 0.159）。结论是改写提升了清晰度与美感，但没有触及物理；显式写出物理现象则有效，这被作者解读为模型 prompt-following 能力强、而非物理理解能力强。

问题四：哪些场景最难？ 两组专门设计的对照实验各 20 组配对 prompt、12 个模型共 240 段视频。剧烈视觉变化（碰撞、破碎、状态突变）成功率 22.1%，对应的柔化版本 42.1%；Pika 分别是 30% 与 75%。多力/多物体的复杂交互成功率 11.7%，简化版 18.3%；Pika 15% 与 40%。典型失败是"羽毛和石头同时下落，石头快得多"——所有模型都做不对。

问题五：CAP 好用吗？ 以人工标注为真值算 ROC-AUC（随机猜为 50）。GPT-o1 原始 SA 75.4 / PC 61.6，加上 CAP 后 80.3 / 75.1，PC 提升 13.5 个绝对点。消融显示两个组件都有用：去掉 CoT 得 76.3 / 73.6，去掉 Context 得 77.3 / 65.6——去掉 Context 对 PC 的伤害远大于对 SA 的伤害，正好印证"MLLM 不知道视频是假的就会替它圆谎"这个诊断。CAP 在 Qwen-VL-2.0、Gemini-2.0-Flash、GPT-4o 上同样有效（PC 分别从 59.8/60.9/60.1 提到 74.1/74.0/73.9）。作者还诚实报告了两个失败模式：审美偏置（画面漂亮的视频得分偏高）与过度自信（在人类标注者都犹豫的边界情形上给出笃定判断）。Leaderboard 上人工与 CAP 排序几乎一致，唯一分歧是 Kling 的电影感风格让 CAP 高估了它，人工评审因被要求只看物理而把 Sora 排在前面。

附录 G 还给出两条 scaling 观察：同架构下更大的模型更好（Cosmos 14B 优于 7B，CogVideoX-1.5-5B 优于 2B）；采样预算更大也更好（Open-Sora 的采样步数从 50 增到 200 有显著提升）。

§ 8 — Take-aways ​

5 句话版：当前最强的 T2V 模型在物理正确性上的综合成功率不到 27%，开源与闭源差距已不明显；Anti-Physics 类是区分"理解物理"与"记住数据"的关键探针，所有模型在这里几乎全军覆没；失败的主要形态不是画错，而是把难物理场景改写成静止画面来回避，且模型越强这种回避越普遍；显式在 prompt 里写出物理现象能提升表现，而 LLM 做的辞藻润色不能；告诉 MLLM"这是生成视频"能让它的物理判别 AUC 提升十几个点。

3 句话版：视觉保真度的进步没有带来物理理解的进步。反物理测试与静态化回避率这两个指标，比任何真实物理分数更能揭示模型到底学到了什么。MLLM 当评审的瓶颈在先验而非能力，一句上下文说明就能解锁。

1 句话版：模型不是在模拟物理，是在模仿看起来像物理的视频，而且越强的模型越擅长绕开它不会的部分。

§ 9 — 最脆弱的假设 ​

最要命的假设是：人类标注者对"关键物理现象是否出现"的 Yes/No 判断构成可靠的真值。整个 benchmark 的所有结论、以及 CAP 的全部 AUC 数字，都以这批 AMT 标注为地基。

这个假设在实践中很容易松动。判断"羽毛比石头落得慢"在 5 秒、低分辨率、可能带运动模糊的视频里需要相当的时间分辨力；判断"能量损耗是否体现"或"折射是否正确"要求标注者具备物理直觉。论文说明标注 prompt 与标准由计算机科学专业的本科生与研究生完成并经作者复核，但视频评测交给 AMT 众包，每段仅 3 人多数表决。论文没有报告标注者间一致性（Cohen's kappa 或 Fleiss' kappa），这是最该有而缺失的证据。作者自己在附录 D 里承认"人类标注者在边界情形上常表达不确定或分歧"——既然承认了分歧，就更需要量化它。

一个具体的风险：如果 PC 标注的一致性偏低，那么模型之间 0.02 量级的 Both 差距（比如 Wanx-2.1 的 0.189 与 Kling-1.6 的 0.188）就完全落在噪声里，leaderboard 的中段排名不可解释。反过来，Anti-Physics 上接近 0 的分数与 rationalization rate 这类定性趋势足够悬殊，即使标注有噪声也不会翻转——所以论文最强的结论恰恰是最不依赖精细标注的那些。

§ 10 — 最小复现实验 ​

一周内可做，只需 API 与少量算力：

  • 从 PhyWorldBench 公开的 1050 条 prompt 里分层抽样 100 条（Fundamental/Composite/Anti-Physics 按比例），代码与 prompt 已在 GitHub 与 HuggingFace 上开源。
  • 用两个可获取的模型（例如 Wanx-2.1 与 CogVideoX-1.5，均为 Apache-2.0）各生成一遍，共 200 段视频。
  • 自己按 CAP 的两步 prompt 实现评测器，跑三个配置：完整 CAP、去掉 Context 一句、去掉 CoT。
  • 同时找 3 个人对同一批视频做 Yes/No 标注，计算 Fleiss' kappa。
  • 判定：若 CAP 相对无 Context 版本在 PC 上的 AUC 提升复现出接近 10 个点的量级，核心方法主张成立；若 kappa 低于 0.4，则 §9 的脆弱假设被证实，benchmark 的细粒度排名需要打折看待。

§ 11 — 最强反例设计 ​

替代解释攻击：Anti-Physics 上的近零分数可能不是物理理解的缺失，而是安全对齐与 prompt 分布外的产物。商业模型普遍带有内容过滤与 prompt 改写层，遇到"酒反重力上浮"这种在训练分布外的描述，改写器很可能把它规整成一个更常见的场景，模型看到的根本不是原始 prompt。论文自己也承认"闭源模型隐藏了生成过程，无法验证是否做了 prompt 改写"，并因此只在开源模型上做 prompt 类型分析——但 Anti-Physics 的结论却是在全部 12 个模型上得出的。要区分两种解释：在开源模型上直接绕过任何改写层，用原始 Anti-Physics prompt 生成，并与商业 API 结果对比。如果开源模型的 Anti-Physics 分数明显高于闭源，那"模型不懂物理"就要修正为"部署管线把反常识指令过滤掉了"。

可预测的失败场景：这个 benchmark 会随时间迅速失效，而且失效方式很隐蔽。所有 prompt、评测标准与 12600 段生成视频都已公开发布在 HuggingFace 与 GitHub 上。这意味着未来的 T2V 模型完全可能在包含这些内容的语料上训练，或被开发者用这 1050 条 prompt 做定向优化。届时分数会上升，但 static-scene rationalization 这类回避策略未必减少——模型可以学会"在这些特定 prompt 上不要冻结画面"而不真正获得物理理解。benchmark 的第二版需要保留一个私有的 held-out 分片。

§ 12 — Follow-up Research Idea ​

新 framing：把评测目标从"生成的视频是否物理正确"改成"模型的物理知识是否可被条件化调用"，用 Anti-Physics 作为可控性探针而非正确性探针。

驱动局限：当前 benchmark 把 Anti-Physics 当成一道更难的题，得出"分数很低所以模型不懂物理"的结论。但这个推理有缺口——分数低也可能是因为模型的物理先验被硬编码在权重里、无法被文本条件覆写。这两种情况对下游应用的含义完全不同：前者需要更多物理数据，后者需要更强的条件化机制。

可借鉴的相邻工具：LLM 可解释性里的 activation patching 与 concept editing，以及扩散模型中的 classifier-free guidance 强度扫描。这些工具的共同目标是把"模型不能做"与"模型不愿做"分开。

第一个实验：取一个开源模型（Wanx-2.1 或 CogVideoX-1.5），选一组配对 prompt——同一场景的正常物理版与反物理版（如"球落下"与"球向上落"）。扫描 CFG 强度从 1 到 15，记录反物理成功率与视觉质量的曲线。如果反物理成功率随 CFG 增大而单调上升，说明物理知识是可条件化的、只是默认权重下文本条件太弱，那么解法在 guidance 与训练目标而非数据；如果无论 CFG 多大反物理率都贴地，说明重力先验已经烧进了模型的时空动力学，需要架构级干预。进一步可把 static-scene rationalization rate 作为一个独立报告的指标——它衡量的是模型的"逃避倾向"，与正确率正交，而当前所有 T2V benchmark 都没有测量这个维度。

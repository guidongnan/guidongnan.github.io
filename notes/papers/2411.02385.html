How Far is Video Generation from World Model: A Physical Law Perspective ​

项内容
arXiv2411.02385
提交日期2024-11-04（v2 修订于 2025-06-22；abs 页 Comments 写 ICML 2025）
作者Bingyi Kang, Yang Yue, Rui Lu, Zhijie Lin, Yang Zhao, Kaixin Wang, Gao Huang, Jiashi Feng
分类cs.CV, cs.AI
一句话用完全可控的 2D 力学模拟器把视频扩散模型的泛化拆成 ID / OOD / 组合三类后发现：ID 误差随规模一路逼近解析下限，OOD 完全不随规模改善，模型实际是按 color > size > velocity > shape 的优先级去检索最像的训练样本。

所属教程：自回归视频生成

版本与命名

本页依据 v2（2025-06-22）全文撰写。项目主页为 phyworld.github.io，社区常称其为 PhyWorld 基准，与《物理感知视频生成》教程里同名的后训练方法 PhyWorld（2605.19242）不是同一件东西。

§ 1 — 研究问题与重要性 ​

Sora 技术报告把「视频生成模型是 world simulator」当成一个可以靠 scaling 兑现的承诺。这个承诺如果成立，机器人、自动驾驶就可以把仿真器换成生成模型；如果不成立，所有建立在「生成视频 = 可信仿真」之上的下游系统都建在沙子上。

问题在于这个承诺此前从未被真正验证过。用开放域视频去测「模型懂不懂物理」有三个结构性障碍：真实视频里的纹理、非刚体、遮挡都是混淆因子；没有 ground truth 状态，无法算出定量误差；更致命的是预训练数据不透明，你无法排除测试场景已经在训练集里。本文的做法是把这三件事一次性消掉：自建 Box2D 2D 模拟器，用纯色几何体承载单条或两条经典力学定律，从零训练模型，从像素反解出物体位置与速度，于是「模型预测的速度」与「模拟器真值速度」之间就有了一个可以直接相减的标量误差。

§ 2 — 前人工作与不足 ​

**开放域物理评测（VideoPhy、T2VCompBench、VBench 一类）**已经能给出「这段视频看起来物不物理」的打分，但打分依赖人或 VLM 的主观判断，无法区分「碰撞后速度差了 3%」与「碰撞后速度差了 40%」，也就无法画出 scaling 曲线。

**物理推理 benchmark（PHYRE、CLEVRER、Phy-Q）**提供了确定性环境与真值，但它们评的是 agent 能不能解题，而不是生成模型能不能把动力学预测对，评测目标与视频生成的训练目标之间隔着一层。

把物理先验塞进模型的路线（论文点名了 Cao 等 2024 一类工作）在生成质量上有效，但它恰好绕开了本文关心的问题：不加任何人工先验时，模型能从原始观测里自己长出定律吗。

已有的 ID/OOD 泛化理论工作（Schott 等、Balestriero 等）在抽象层面讨论过外推的困难，但没有针对视频生成这一具体归纳偏置给出机制性解释。本文的增量正是机制：不仅报告 OOD 失败，还给出失败的形式（case-based 检索）与检索时的属性优先级。

§ 3 — 重建作者的思考路径 ​

出发点是一个方法论上的洁癖：要判断模型学没学到定律，只能看它在没见过的情形上怎么表现，而「没见过」需要被精确定义。于是第一步是把泛化按训练/测试分布关系切成三类：ID（同分布）、OOD（隐变量落在训练区间之外）、组合泛化（每个概念都见过，但这个组合没见过）。

第二步是找一个能把这三类都精确控制住的实验场。开放域做不到，所以退到 2D：物体是纯色圆和方块，动力学由 Box2D 决定，隐变量就是半径和初速度，训练集在网格上均匀采样，OOD 区间直接写死在网格外面。

第三步是解决「怎么量化」。既然物体是纯色的，就可以用颜色掩码求质心得到位置，再差分得到速度。这里作者做了一件容易被忽略但很关键的事：把 ground truth 视频本身也过一遍这套解析流程，得到的误差 egt​ 就是解析噪声地板，任何模型都不可能低于它。有了地板，「ID 误差 0.012」才有意义。

第四步是 scaling 扫描：数据 30K / 300K / 3M，模型 DiT-S(22.5M) / DiT-B(89.5M) / DiT-L(310M)（组合实验另加 DiT-XL, 456M）。看到 OOD 曲线平坦之后，才有了后面追问机制的第五步。

§ 4 — 核心 Intuition ​

在一个数据可以无限生成、动力学完全确定的世界里，视频扩散模型仍然学不会外推。它在训练分布内能把速度预测到解析精度极限，一旦初速度或半径越出训练区间，误差就跳一个数量级，且加数据加参数都不动。原因是模型没有把 vt+1​=vt​ 抽象成规则，而是在生成时去找像素上最接近的训练样本照抄；照抄时它按 color > size > velocity > shape 的顺序决定保留哪个属性、牺牲哪个属性。

§ 5 — 具体方法与完整 Pipeline ​

模型侧是标准配方：(2+1)D-VAE 做压缩（由 SD1.5-VAE 结构膨胀而来，把编码器末端若干 2D 下采样块换成因果 3D 块，并在预训练后冻结），DiT 做去噪，位置编码用 3D RoPE，训练目标是 v-prediction，AdamW，最大学习率 1×10−4 余弦衰减，batch 256。条件帧的注入方式是把前 c 帧零填充到全长，再加一路二值 mask（前 c 帧为 1），与噪声沿通道维拼接。

走一遍匀速直线运动这个具体例子：

  1. 造数据。Box2D 世界 10×10，步长 0.1 秒，共 32 帧即 3.2 秒，渲染成 128×128。自由度是小球半径与初速度，ID 区间 r∈[0.7,1.5]、v∈[1,4]，在这个二维网格上均匀采样出 30K / 300K / 3M 三档训练集。
  2. 训练。给定前 3 帧（足够反解出速度），预测剩余 29 帧。100K 步，32 张 A100，batch 256；作者验证过训到 300K 步结果相当，说明已收敛。
  3. 测试。ID 测试点从同一网格里采（保证不与训练点重合）；OOD 测试点取 r∈[0.3,0.6]∪[1.5,2.0]、v∈[0,0.8]∪[4.5,6.0]，分「只有 r OOD / 只有 v OOD / 两者都 OOD」三档。
  4. 解析与打分。用颜色像素均值定位球心，丢弃出画的帧，差分得到逐帧速度，与模拟器真值相减取平均。同一流程作用在真值视频上得到误差地板。

组合泛化换到 PHYRE：8 类物体（两个动态灰球、一组固定黑球、固定黑杆、动态杆、一组动态立杆、动态罐、动态立棍），每个任务是一个红球加从 8 类中任选 4 类，共 C84​=70 个模板，每模板 100K 段视频。训练用 6 / 30 / 60 个模板（对应 0.6M / 3M / 6M），留 10 个模板做 out-of-template。因为物体形状不规则、颜色相近，像素解析不可靠，这里放弃速度指标，改用 FVD / SSIM / PSNR / LPIPS 加人工判定的 abnormal ratio（10 名评测员，in-template 120 段、out-of-template 100 段，只凭第一印象判断是否违反物理）。

§ 6 — 核心数学推导 ​

论文把「物理定律发现」形式化如下。设隐状态 z=(z1​,…,zk​)，经典力学给出 z˙=F(z)，离散化为

zt+1​=zt​+δF(zt​),It​=R(zt​)

其中 R(⋅) 是渲染函数。于是「物理连贯性损失」就是给定前 c 帧的条件负对数似然 −logpθ​(Ic+1​,…,IL​∣I1​,…,Ic​)。这个式子的 intuition 在于：只有真正掌握 F，模型才可能对任意初始条件都给出高似然，所以似然本身就是对「懂不懂定律」的一种度量。

实际评测不用似然，而用可解释的速度误差

e=N∣T∣1​i=1∑N​t∈T∑​​vti​−v^ti​​

N 是球数，T 是有效帧集合（排除出画帧；碰撞场景只取碰撞后的帧）。这个指标的关键配套是那条平凡下限：把真值视频喂进同一解析流程得到 egt​，匀速运动 0.0099、碰撞 0.0117、抛体 0.0210；VAE 重建视频的 erecon​ 分别为 0.0105 / 0.0131 / 0.0212，与地板同量级，说明压缩器没有吃掉运动学信息，后续差异可以全部归因到 diffusion 部分。

训练目标沿用 v-prediction：y=1−γt​​ϵ−γt​​V，并在 t=1 时令 γt​=1 以消除零信噪比处的训练-推理 gap。

§ 7 — 实验设计与结论 ​

问题一：scaling 能否带来 ID 泛化？ 能，而且逼近地板。匀速运动上 DiT-S + 30K 的速度误差是 0.022，DiT-L + 3M 降到 0.012，真值解析地板是 0.010。这条曲线单调、干净，是「视频模型可以精确建模已见分布」的强证据。

问题二：scaling 能否带来 OOD 泛化？ 不能。DiT-L + 3M 在匀速运动上的 OOD 误差是 0.427，比它自己的 ID 误差 0.012 高一个数量级以上；DiT-B 在 30K/300K/3M 上的 OOD 误差是 0.433 / 0.328 / 0.358，随数据量的变化是随机游走而非下降。作者又把 DiT-XL 拿到匀速运动 3M 上训，OOD 依旧没有改善，于是放弃在其他场景重复这项开销。附录里对 Stable Video Diffusion 做了微调对照：SVD 的 VAE 重建误差 0.0103 / 0.0107 很小，但微调后的 ID/OOD 是 0.0505 / 0.9081，OOD 同样比 ID 高一个数量级，说明这不是「从零训练」造成的假象。

问题三：OOD 失败是外推问题还是能力问题？ 是外推问题。把训练集中间挖掉一段速度区间，缺口越小模型在缺口内的预测越准；碰撞场景里，落在训练集凸包内部的 OOD 点误差与 ID 相当，落在凸包外部才崩。换句话说模型有插值能力、没有外推能力。

问题四：组合泛化随规模改善吗？ 改善，而且改善的是组合覆盖度而非数据量。DiT-XL 从 6 个模板扩到 60 个模板，out-of-template 的人评 abnormal ratio 从 67% 降到 10%；同样 60 模板下把模型从 DiT-XL 换成 DiT-B，abnormal ratio 回升到 24%。有意思的反向证据是 6 模板模型在 in-template 上的 SSIM/PSNR/LPIPS 最好，因为它的每条样本被看到的次数是 60 模板设置的十倍。

问题五：模型到底在做什么？ 在检索。训练速度限定在 v∈[2.5,4.0]，Set-1 只含从左向右的视频，Set-2 通过水平翻转引入反向运动；在未见过的低速 v∈[1.0,2.5] 上测试时，Set-1 模型只吐正速度，Set-2 模型会让低速球在条件帧之后突然掉头。反向运动在物理上完全错误，但它是「低速」在训练集里最近的邻居。属性优先级则由成对实验确定：训练红球+蓝方，测试时蓝球变蓝方、红方变红球，1400 个测试样例无一例外，得到 color > shape；color vs size 的 202 个样例中尺寸一律被改写而颜色保持不变；逐对比较后合成出 color > size > velocity > shape。附录用 CogVideo 的 VAE 重跑，顺序不变。

§ 8 — Take-aways ​

5 句话版：在一个数据无限、动力学确定的 2D 力学世界里训练视频扩散模型，ID 误差随模型与数据规模单调下降到接近解析噪声地板，OOD 误差却比 ID 高一个数量级且对 scaling 完全不响应；把训练集的空缺区间缩小或让 OOD 点落进训练集凸包内部，误差就回到 ID 水平，说明模型只有插值没有外推；机制上模型在生成时检索像素最近的训练样本，翻转增广这类「欺骗性样本」会直接把它带偏；检索时属性按 color > size > velocity > shape 排序，作者推测这与各属性引起的像素变化幅度有关，并用红环-蓝球的反例说明该顺序可被推翻；组合泛化确实随模板覆盖度提升（abnormal ratio 67% → 10%），但受益于组合多样性而非数据体量。

3 句话版：视频生成模型能把见过的物理拟合到测量精度极限，见不到的一律靠模仿最近的训练样本蒙混。模仿时它按 color > size > velocity > shape 决定牺牲哪个属性，这解释了开放域视频里常见的形状漂移。要让它更「懂物理」，应该扩组合多样性而不是单纯堆数据量。

1 句话版：scaling 能让视频模型精确复现见过的物理，但不足以让它发现物理定律。

§ 9 — 最脆弱的假设 ​

最脆弱的一条是：在纯色几何体的 2D 玩具世界里观察到的泛化机制，可以外推到在互联网视频上预训练的开放域大模型。整篇论文的说服力建立在受控实验之上，而受控恰恰意味着删掉了真实数据里最可能改变结论的东西——纹理、光照、遮挡、多尺度物体，以及最重要的一点：真实视频的隐变量分布是连续且高维的，「OOD」在那里几乎无法定义。作者自己在讨论里承认真实世界的组合空间大到无法覆盖，这既是他们结论的推论，也是他们结论无法被直接验证的原因。

论文为这条假设提供的证据是附录 D：换成 CogVideo 的 VAE，属性优先级不变；微调 SVD，OOD 比 ID 高一个数量级的模式不变。这两条都不弱，但它们仍然是在同一个 2D 测试床上测的，只换了模型，没换世界。缺的证据是：在真实视频（比如落体、抛物、碰撞的实拍片段）上构造一个可定量的 OOD 划分，验证同样的量级差距与同样的属性优先级。这个实验难做，但它才是把结论从「玩具世界成立」推到「视频生成整体成立」的必要一步。

§ 10 — 最小复现实验 ​

一周可做的版本：只复现匀速直线运动这一条。用 Box2D 或 pymunk 在 128×128 上渲染 32 帧视频，半径与初速度在 ID 网格上采 30K 段；用任意开源 latent video diffusion（冻结 VAE，只训一个 DiT-S 规模的去噪器），条件为前 3 帧。

必须先做的一步：把真值视频过一遍你的像素解析流程，记下 egt​。没有这条地板，后面所有误差数字都无法解释。

然后测三件事：(a) ID 误差是否落在 egt​ 的 1.5 倍以内；(b) 把初速度换到 [4.5,6.0]，OOD 误差是否比 ID 高约一个数量级；(c) 训练集加水平翻转增广后，低速条件下是否出现掉头。若 (a)(b) 复现而 (c) 不出现，说明 case-based 现象对增广细节敏感，这本身就是一个值得报告的结果；若三件事都复现，再花剩下的时间做 color vs shape 的成对实验（训练红球+蓝方，测试蓝球与红方各 200 例）。整个流程不需要 32 卡，单卡数天可完成缩水版。

§ 11 — 最强反例设计 ​

最有力的攻击是指出**「OOD 误差不随 scaling 下降」可能是评测协议的产物而非模型的性质**。作者的 OOD 区间是 v∈[0,0.8]∪[4.5,6.0]，而 ID 是 v∈[1,4]；速度越界意味着物体在 32 帧内的位移模式（尤其 v∈[4.5,6.0] 时频繁出画）与训练时完全不同，而解析流程要求「排除出画帧」。高速 OOD 样本的有效帧 ∣T∣ 会显著变少，误差估计的方差随之上升。反对者可以设计这样一个实验：固定 OOD 速度不变，只把画布放大到 256×256 并相应延长视频，使高速球在整段视频里都不出画；如果此时 OOD 误差显著下降并开始随数据量改善，那么原结论的一部分就要归因到「越界样本的观测窗口被截断」，而不是「模型不会外推」。

第二个更具体的攻击针对属性优先级。作者自己在附录 E.3 给了推翻材料：把「方块 vs 圆球」换成「红环 vs 蓝球」后，color > shape 不再成立，红环可以变成红球也可以变成蓝环。这说明所谓优先级排序不是模型的内在属性，而是「哪种改写引起的像素变化更小」的函数。反对者可以据此构造一组新的属性对，使排序变成 shape > color，从而论证 color > size > velocity > shape 这条被广泛引用的结论只在作者选定的渲染参数下成立，不应被当作视频模型的普遍归纳偏置。

可预测的失败条件：任何在 latent 空间上距离度量与人类语义显著不一致的渲染设置（低对比度配色、纹理化背景、非纯色物体），都应该改变优先级顺序。这是一个可证伪的预测。

§ 12 — Follow-up Research Idea ​

驱动这个想法的局限：论文把「模型在检索最近训练样本」当成结论摆在那里，但检索是在什么空间、按什么度量发生的，只有一个「像素变化幅度」的推测（作者明说是 hypothesis）。这意味着我们知道模型会失败，却不知道给定一个新场景它会失败成什么样。

新的 framing：把视频扩散模型显式建模成一个核回归器，即假设 pθ​(⋅∣I1:c​)≈∑j​wj​(I1:c​)δVj​​，其中 Vj​ 是训练样本、wj​ 是某个待辨识的核。这样一来问题就从「模型懂不懂物理」变成「这个核长什么样」，而后者是可以被测量的。

可借鉴的相邻领域工具：influence function 与 datamodel（LLM 数据归因领域已经比较成熟），以及 kernel regression 的经典理论。做法是对每个测试条件用 influence 近似反推出对该次生成贡献最大的训练样本子集，再检验这些样本是否确实在颜色上与测试条件一致、在形状上不一致。

第一个实验：在匀速运动 30K 训练集上训一个小模型，对 200 个 OOD 测试条件各生成一段视频，用 TracIn 一类的梯度相似度估出 top-20 影响样本。若「模型输出速度」能被这 20 个样本的速度加权平均预测到 R2>0.8，就把 case-based 从定性描述升级成了可预测的定量模型；此时属性优先级不再需要靠人工设计成对实验去测，而是可以直接从核的形状读出来。这条路线还能顺带给出一个可操作的推论：想让模型在某个 OOD 区域表现好，需要往训练集里加哪些样本，加多少。

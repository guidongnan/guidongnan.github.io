LINA: Learning INterventions Adaptively for Physical Alignment and Generalization in Diffusion Models ​

项内容
arXiv2512.13290
提交日期2025-12-15
作者Shu Yu, Chaochao Lu（上海人工智能实验室 / 上海创智学院 / 复旦大学）
分类cs.CV, cs.AI, cs.LG
一句话把扩散模型的物理不对齐诊断成"引导信号标定错误"而非知识缺失，用一个轻量模块按 prompt 预测干预强度，在 token embedding 与 visual latent 两级调节引导，并把采样算力前移到因果结构成型的早期去噪步。

所属教程：物理感知视频生成

§ 1 — 研究问题与重要性 ​

扩散模型有两个顽固毛病：物理不对齐，和 OOD 指令跟随失败。前者的典型样例是"红球放在小镜子上"，模型把倒影画到镜面之外；后者的典型样例是 Winoground 的 "a person is close to the water and in the sand"，模型直接把人放进水里。

这篇论文的主张是这两件事是同一个病：模型学到的是对称相关而非有向因果。树和影子在训练时被同时去噪，模型从未被告知"移走树影子就消失，遮住影子树还在"。因果方向缺失导致物理不对齐；因果因子纠缠导致无法把概念重新组合出分布外的场景。

论文的价值不在于又提了一个对齐方法，而在于它先做了一组干预式诊断，把病因从"模型不懂物理"改判为"模型懂但引导没标定好"。这个判断直接决定了正确的修法是调引导而不是重训权重，也决定了修法可以做到零 MLLM 推理开销。

§ 2 — 前人工作与不足 ​

论文把已有的纠错方案按干预位置分成三类，并逐类说明为什么不够。

Prompt engineering / 采样引导。LLM-grounded Diffusion（LMD）把 prompt 解析成 bounding box 布局去引导 attention，其他工作训练 LLM 改写 prompt 或生成负向引导。这类方法在寻找一个预失真的输入 X′，使得有缺陷的映射 F(GX′​)≈GX∗​。对空间布局有效——实验里 LMD 把 Density 从 54.2 拉到 81.5 就是证据——但它只改输入，不碰采样动态，所以对隐式物理定律无能为力，Optics 上 80.5 几乎等于基线 80.4。

MLLM-in-the-loop 精修。PPAD 这类方法在去噪过程中插入外部 MLLM 纠正中间 latent。问题是推理成本高，而且论文用一组实验揭示了更根本的障碍：识别—纠正鸿沟。GPT-5 有时压根认不出多余倒影；即使用 CoT 提示让 Gemini 2.5 Pro 准确定位了错误，交给 Nano Banana 去改，改出来仍然违反物理。表 1 量化了这一点：Nano Banana 与 GPT-image 的纠正成功率只有 2.5%，加 CoT 后升到 45.0% 与 67.5%，仍远不足。

微调与 adapter。偏好对齐、LoRA、轻量 adapter 试图把权重从 θ 改成 θ′。这类方法的前提假设是 θ 里缺知识。论文的诊断否定了这个前提，实验也显示 LoRA 在 Optics/Density 上虽强（95.9/91.3），但在 OOD 上几乎无效（Winoground 57.3，仅比基线 54.4 高 3 点），因为它在过拟合相关性而非修复对称范式。

§ 3 — 重建作者的思考路径 ​

出发点是一个老观察：SOTA 扩散模型生成的图看起来什么都懂，但一到需要多跳推理的物理场景就崩。自然的第一个问题是"它到底是不懂，还是懂了没用上"。要回答这个只能做干预，而干预需要一个能把"prompt 里说了的元素"和"物理定律隐含的元素"分开的表示。

已有的两种结构化表示各缺一半：因果图模型（CGM）有方向但没空间布局，场景图（SG）有空间关系但可以成环、没有因果方向。把两者的节点复用、边集合并，就得到能同时表达 X→YD​→YI​ 层级和空间约束的图。这一步是纯粹的工具搭建，不依赖本文任何结论。

有了图，干预就有了操作对象：把某类元素抠掉重画（masked inpainting），看别的元素会不会跟着变。如果因果真的存在方向，给定原因的视觉状态应该显著提升结果的正确率。这是一个可以立刻做的实验，也是论文实际做的第一件事。

§ 4 — 核心 Intuition ​

扩散模型脑子里其实有物理知识，只是它把 prompt 里的所有词一视同仁地当条件用了，导致表达因果关系的那几个词（"on"、"in"、"hits"）的引导强度远远不够。既然这些词的表示已经和物体、属性的表示解耦，就可以只放大它们，不动模型权重。放大多少因 prompt 而异，所以训一个小模块来预测这个强度。再加上一个观察：因果结构在最初两三步去噪里就定下来了，所以把采样密度前移到那几步。

§ 5 — 具体方法与完整 Pipeline ​

诊断阶段。构建 PAP 数据集：287 条 prompt 模板，分 Optics（100 条，"A [color] [object] on a [mirror_shape] mirror"）、Density（28 条，浮沉 13 + 天平 15）、OOD（159 条，尺寸反转 75 + 不可能容纳 75 + 显式违反物理 9）。用 SD-3.5-large 与 FLUX.1-Krea-dev 各生成 50 张/prompt，共 28700 张，Qwen2.5-VL-72B 做视觉解析器输出 bbox 与点提示，SAM2（Hiera-Large）转成像素级掩码。评测采用几何优先的混合协议：倒影底边不得超出镜面底边 15 像素、浮沉按物体中心在液面高度的相对位置（上 40% 判浮、下 25% 判沉）、天平按两盘底边差 20 像素判倾斜，几何不明确时才回退到 MLLM 文本判断。

五组探针，全部基于掩码 inpainting：

  • (I) P(YI​∣X,YD​) 正向推理：81.1%，与基线 80.4% 无显著差别。给了原因的视觉状态，模型并没有把结果画得更对。
  • (II) P(YD​∣X,YI​) 中介推理：94.9%，基线 94.3%。
  • (III) 给一个与 prompt 冲突的 YI′​（prompt 说红球，倒影是绿的），94.0% 的情况下 YD​ 跟着 prompt 走，只有 0.4% 跟着冲突倒影走。
  • (IV) 去掉 prompt 只给 YD​ 推 YI​：2.2%。
  • (V) 去掉 prompt 只给 YI​ 推 YD​：2.4%。

结论很干净：因果链 X→YD​→YI​ 塌缩成了并行映射 X→YD​、X→YI​，视觉元素之间没有条件依赖。

表示层探针。把关系 token（"on"、"in"、"hits"）替换成无条件 embedding 中同位置的 token，Physical Alignment 从 80.4% 崩到 5.2%，而 Texture Alignment 只从 94.3% 掉到 91.8%。反过来把物体与属性 token 替换掉，Texture Alignment 崩到 3.1%，Physical Alignment 却保住 92.5%——模型照样画出倒影，只是不知道倒影里是什么。这个双向崩塌证明纹理与物理在 prompt embedding 里是解耦的。

时间探针。在 SD-3.5-large 的 28 步官方调度上看中间 latent，PAP-Optics 上 97.8% 的成功样本在最初 2–4 步（即 26→24 步）就能辨认出正确的因果结构，后续步骤主要在精修纹理。

LINA 的两阶段流程，以 "a person is close to the water and in the sand" 为例：

  1. 离线：从 PAP 里挑出基线失败的 hard case，用 MLLM evaluator 驱动的坐标下降搜索找最优 (γ1∗​,γ2∗​)。坐标下降之所以可行，是因为网格搜索显示两个方向的效果基本解耦且单调——γ2​ 管纹理（水还是沙），γ1​ 管空间布局与交互。同一 prompt 跨 100 个随机种子的最优值聚成一簇，说明该修正是 prompt 的结构性属性而非噪声的函数，因而可以训一个确定性映射。
  2. 训 AIM：T5 text encoder 接一个轻量 MLP 回归头，用 L2 损失拟合 (γ1∗​,γ2∗​/γ0​)。
  3. 在线：spaCy 解析出关系 token 掩码 Mrel​，AIM 预测强度，按下节两个公式改造 embedding 与噪声预测，并在放大 shift 的调度上采样。全程不调用 MLLM，不改 backbone 权重。

§ 6 — 核心数学推导 ​

Token embedding 级：因果边标定。 设条件 embedding c=Emb(X)，无条件 embedding u=Emb(∅)，关系 token 掩码 Mrel​：

c′=c+γ1​⋅Mrel​⊙(c−u)

(c−u) 是这条 prompt 在 embedding 空间相对"什么都不说"的语义方向向量，CFG 正是沿这个方向外推。这里只在关系 token 的位置上额外放大它，等于把诊断里的"离散替换"推广成连续的软强度：γ1​=0 退化为原始 embedding，γ1​<0 逼近诊断中的消融实验。

Visual latent 级：对比式因果引导。 把 prompt 里的关系词松弛成通用连词（"on"→"and"）得到中性 prompt Xneutral​，它代表"画出这些物体但不带任何因果依赖"的生成方向。最终噪声预测在标准 CFG 之上再加一项对比：

ϵ~θ​(xt​,t)=ϵθ​(xt​,u,t)+γ0​(ϵθ​(xt​,c′,t)−ϵθ​(xt​,u,t))+γ2​(ϵθ​(xt​,c′,t)−ϵθ​(xt​,cneutral​,t))

第二项是常规 CFG，把生成推离无条件分布；第三项的减数不是"什么都不说"而是"说了物体但不说关系"，所以差值里被滤掉的是通用语义，剩下的正是空间与物理交互那部分信号。这就是"对比"的意义：用一个精心构造的负基线把要放大的分量隔离出来。

AIM 的目标。 L=∑i=1N​∥Φ(Xi​)−(γ1∗​,γ2∗​/γ0​)∥22​。回归 γ2∗​/γ0​ 而非 γ2∗​ 是为了归一化，让回归目标尺度稳定。

因果感知调度。 现代扩散模型用 time-shifting 把均匀时间 τ∈[0,1] 映射为

τs​=1+(s−1)⋅τs⋅τ​

s>1 会把采样点往高噪声端聚集，原本是为高分辨率设计的。论文的做法是进一步放大 s，让更大比例的推理预算落在因果结构成型期。这个改动没有引入新参数，只是重新分配了固定的步数预算。

§ 7 — 实验设计与结论 ​

问题一：SOTA 闭源系统能不能纠正它自己识别出的物理错误？ 在 Dhard​ 测试集上，给编辑模型送入有缺陷的图和纠正指令。Nano Banana 与 GPT-image 的纠正成功率只有 2.5%（第二列分别 25.0 与 22.5）；加 CoT 后升到 45.0/70.5 与 67.5/82.0。LINA 用同一 prompt 同一种子重新生成即达到 96.4 与 86.0。结论：CoT 改善的是诊断环节，不是执行环节，识别—纠正鸿沟真实存在。

问题二：与开源纠错路线相比如何？ 全部在 SD-3.5-large 上做。Optics/Density 上，基线 80.4/54.2，LMD 80.5/81.5，PPAD 91.7/76.2，LoRA 95.9/91.3，LINA 97.4/92.3；换到 FLUX.1 上 LINA 拿 96.8/94.0。三条路线各自的失败模式与 §2 的分析吻合。

问题三：OOD 指令跟随。 Winoground（采用排除歧义样本后的 171 条子集）与 PAP-OOD 上，基线 54.4/69.3，LMD 73.1/75.2，PPAD 62.6/74.1，LoRA 57.3/72.0，LINA 79.5/84.3，LINA on FLUX 83.0/86.1。PPAD 在 Winoground 上（62.6）比基线只高 8 点，LoRA 只高 3 点，两条主流路线在这里都近乎失效。

问题四：能否迁移到视频？ 接到 Wan-2.2-T2V-A14B 上（832×480，16fps，81 帧，评测时降采样到 4fps 喂 Qwen2.5-VL-72B），PAP-Density 与 Winoground 上的时序物理对齐成功率从 29.5% 提到 58.0%。论文同时诚实报告了两个 domain gap：视频模型对动词的敏感度远高于名词，以及 Wan-2.2 偏好写实纹理，被要求画"红球"时常画成番茄或草莓，导致几何类任务的基线分本就偏低。

消融。 去掉 γ1​ 后 Optics/Density/Winoground 变成 85.1/80.5/60.2，OOD 掉得最狠；去掉 γ2​ 变成 81.3/78.0/74.9，物理对齐掉得最狠——两个机制互补而非冗余。把 AIM 换成对所有 prompt 用同一个平均强度（Fixed γ）掉到 90.5/85.2/68.4，证明自适应是必要的；退回标准调度掉到 92.3/88.1/74.3，证明算力前移有效。

标注可靠性。 AIM 的训练标签全部来自 Qwen2.5-VL-72B 的判断，作者在 500 条子集上与 GPT-5、Gemini 2.5 Pro 做一致性检验，原始判断的 Krippendorff α=0.92，加上规则化几何检查后收敛到 α=0.97。

§ 8 — Take-aways ​

5 句话版：扩散模型的物理错误不是知识缺失而是引导标定错误，因为消融关系 token 会让物理对齐从 80.4% 崩到 5.2% 而纹理几乎不动。因果层级 X→YD​→YI​ 在模型内部已塌缩成并行映射，给定原因的视觉状态对结果的正确率毫无帮助。修法是在 embedding 级放大关系 token 的语义方向、在 latent 级用"去关系"的中性 prompt 做对比引导。强度因 prompt 而异且跨种子稳定，所以可以用 T5+MLP 离线学出来，推理时零 MLLM 开销、零权重改动。图像与视频上都验证有效，视频物理对齐从 29.5% 提到 58.0%。

3 句话版：诊断先于方法——用掩码 inpainting 探针把病因定位到引导而非权重。两级干预分别管因果边与空间结构，强度由一个轻量回归器按 prompt 预测。附带发现：因果结构在最初 2–4 步去噪就定型，把算力前移能再涨几个点。

1 句话版：模型知道物理，只是没被问对。

§ 9 — 最脆弱的假设 ​

最致命的一条是：最优干预强度 (γ1∗​,γ2∗​) 是 prompt 的确定性函数，可以由一个不看图像的文本回归器预测。整个在线流程的效率优势——不调 MLLM、不重训——完全依赖这一点。

论文给出的证据是图 8：同一 prompt 在 100 个随机种子下的最优强度聚成紧簇，AIM 的预测落在簇心。这是有力的支持，但覆盖面有限。簇的紧密度是在 PAP 这类高度模板化的 prompt 上测的——"A [color] [object] on a [mirror_shape] mirror" 这种结构，物理关系单一、场景干净、还统一加了灰底影棚光的后缀。一旦 prompt 里出现多个相互竞争的物理关系（既有倒影又有浮沉，还要求某个关系被违反），最优 γ1​ 就不再是单一标量能表达的——你需要对不同关系 token 施加不同强度，而当前公式里 γ1​ 是全局标量、Mrel​ 只是二值掩码。

论文缺的证据是：在关系数量 ≥3 的复合 prompt 上，最优强度的簇是否还紧、AIM 的预测误差如何随关系数增长。PAP 的构造方式（笛卡尔积模板）恰好保证了这类样本几乎不存在。

§ 10 — 最小复现实验 ​

一周内可做，不需要训练 AIM。

  • 数据：自己写 60 条 prompt，分三档——1 个物理关系（"a red ball on a mirror"）、2 个关系（"a red ball on a mirror next to a glass of water"）、3 个及以上关系。每档 20 条。
  • 实现：只实现 γ1​ 那一条（式 1），用 spaCy 抽介词与交互动词做掩码，接在 SD-3.5-large 的 diffusers pipeline 上。γ2​ 与调度改动都先不做。
  • 测量：对每条 prompt，在 γ1​∈{−0.5,0,0.5,1.0,1.5,2.0} 上各生成 20 张（种子 0–19），人工或用一个 VLM 判定物理是否正确，记录每条 prompt 的最优 γ1​ 及其跨种子方差。
  • 判据：若 1 关系档的最优 γ1​ 跨种子标准差小、且 3 关系档明显变大甚至出现双峰，就复现了论文的稳定性结论同时暴露了它的边界——支持"确定性映射"假设在简单 prompt 上成立、在复合 prompt 上失效。若三档方差都小，则假设比论文声称的更强，反而是好消息。

§ 11 — 最强反例设计 ​

替代解释：LINA 的增益可能主要来自"提高了关系词的有效 CFG 强度"这一低阶效应，而与因果结构无关。

注意式 (1) 与式 (2) 合起来做的事，在数学上非常接近"对 prompt 的一个子集施加更高的 guidance scale"。CFG 强度上调本来就会让生成更贴 prompt、更少走向数据先验，代价是多样性下降与过饱和。论文没有报告任何多样性或图像质量指标（FID、CLIP score、人类偏好），也没有报告"对全部 token 统一放大 γ1​"这一对照组。

具体攻击实验：加两个基线。基线 A，把 Mrel​ 换成全 1 掩码（即对所有 token 均匀放大），扫 γ1​ 找最优；基线 B，直接把 γ0​（标准 CFG scale）从推荐的 3.5 扫到 8.0。在 PAP-Optics/Density 上比较三者的最优成功率，同时报告 FID 与 CLIP score。如果基线 A 或 B 能达到接近 97.4 的成功率，那么"关系 token 的定向干预"这一核心 claim 就失去了必要性，LINA 退化为一个自动调 CFG 强度的模块——仍然有用，但因果叙事被替换掉了。

论文对此有一条间接反驳：图 5(a) 显示关系 token 与物体 token 的消融效果是双向解耦的，说明定向确实有信息量。但解耦性只证明"分开调是可能的"，不证明"分开调比统一调更好"。这个对照缺失是论证链上最明显的一环。

§ 12 — Follow-up Research Idea ​

驱动它的局限：LINA 用一个标量强度调节整条 prompt 的关系信号，本质上是在假设"这条 prompt 需要多少额外因果引导"是一个一维量。但 §9 指出，真实场景里不同因果关系需要的修正量不同，甚至方向相反（一个关系要加强、另一个要压制，比如"铁块漂浮"这种要求模型违反自身物理先验的 OOD prompt）。

新的 framing：不要把干预看成"调强度"，而看成在因果图上做调度——决定哪些边在哪一段去噪时间窗内被激活。诊断部分已经证明因果结构在最初 2–4 步定型，那就意味着时间维度上存在结构性的先后顺序：先定空间布局，再定物理交互，最后精修纹理。当前方法把所有干预在全时间轴上恒定施加，浪费了这个结构。

可借鉴的相邻领域工具：因果发现里的"干预调度"（intervention design，即在预算约束下选择干预哪些变量、何时干预以最大化可识别性），以及编译器领域的指令调度——把有依赖关系的操作按拓扑序排到时间槽里。CSG 已经是 DAG，直接可以做拓扑排序。

第一个实验：取 PAP 中包含至少两个因果关系的 prompt（需要新构造，因为现有模板里少见），把 CSG 的边按拓扑深度分层：深度 1 的边（prompt 直接决定的空间关系）只在去噪的前 20% 步施加 γ1​，深度 2 的边（物理导出的隐式关系，如倒影、浮沉）在 20%–50% 步施加。对照组是现有的全程恒定施加。测三个量：物理对齐成功率、纹理对齐成功率、以及分层与恒定两种方案在同一算力下的差距。如果分层调度在多关系 prompt 上显著更好而在单关系 prompt 上持平，就说明"因果结构有时间序"这个观察可以从诊断上升为方法，而不只是一个调整采样密度的理由。

第 0 章 导读：如何使用本教程 ​

0.1 一句话概括本教程 ​

具身智能（Embodied AI） 关心的是"一个身体（机器人）如何在物理世界里感知、决策、行动"；视频生成（Video Generation） 学到的是"世界在时间上如何演化、物体如何运动、动作如何产生后果"。把后者的能力"接"到前者身上，就是本教程的主题——视频生成赋能的具身智能。

核心信念只有一句话：

能"预测/生成未来会发生什么"的模型，天然蕴含了做决策所需的知识。 如果一个视频模型能画出"机械臂把杯子放到架子上"的逼真过程，那么它其实已经"知道"了完成这个任务需要经历哪些中间状态——我们要做的就是把这份"知道"翻译成机器人能执行的动作（action）。

0.2 我们为什么单独写这一篇 ​

视频生成 × 具身智能是 2023 年以来增长最猛的交叉方向之一，到 2025–2026 年已形成一个独立、成体系、有自己的任务/数据/基准/方法论的子领域。它与"世界模型"教程（游戏、驾驶、探索）有重叠，但关注点截然不同：

维度通用/游戏/驾驶世界模型具身智能中的视频生成（本教程）
终极目标画得真、可交互、可漫游让真实机器人把任务做成功
成功判据FVD、可玩性、视觉一致闭环任务成功率（success rate）
"动作"含义键鼠、相机、方向盘末端位姿 / 关节角 / 夹爪 / 力
核心难点长时程一致、实时渲染动作可提取、物理接触、sim-to-real
数据瓶颈互联网视频足够多带动作标注的真机数据极其昂贵

正因为"成功判据是真实机器人的任务成功率"，这个领域发展出许多独有的技术选择：逆动力学模型（IDM）、潜动作（latent action）、稠密对应（dense correspondence）、"要不要真的生成像素"之争、神经轨迹（neural trajectory）数据引擎等等。

第 1 章 基础概念与直觉：为什么"视频生成"能赋能"具身智能" ​

1.1 先厘清两个词 ​

具身智能（Embodied AI）：智能体有一个"身体"（机械臂、双臂、人形、移动底盘），必须通过与物理世界的实际交互（抓、放、推、走）来完成任务。它的输出是动作，它的成败由物理世界裁决。

视频生成（Video Generation）：给定条件（文本、首帧图像等），模型输出一段时间连贯的像素序列。现代视频生成大模型（Sora、Wan、HunyuanVideo、CogVideoX、Cosmos、Veo、Kling 等）在海量互联网视频上训练，学到了物体外观、运动规律、光影、乃至朴素的物理直觉。

把两者连起来的桥梁是一个朴素但深刻的观察：

机器人策略学习最缺的是"数据"与"对物理世界的理解"。而视频恰恰是最廉价、最丰富、且天然编码了动力学的数据形式。视频生成模型在预训练中已经"看过"了海量的"人/物体如何运动、如何交互"，这份先验正是具身智能急需的。

1.2 为什么是"视频"，而不是别的表示 ​

  • 视频天然编码动力学与因果：物体如何被推动、水如何倒出、绳子如何缠绕——这些都写在帧间变化里，无需显式物理引擎。
  • 数据近乎无限且廉价：互联网视频、第一人称人类操作视频（Ego4D、Something-Something）、机器人示范都可用；相比之下，带动作标签的真机数据极其昂贵。
  • 模态统一、跨本体（cross-embodiment）：不同机器人有不同的关节/自由度，动作空间互不兼容；但"图像/视频"是一种与本体无关的统一表示——UniPi 的关键洞见就是"把决策问题重述为图像空间中的视频生成问题，从而统一不同状态/动作空间"。
  • 人类可读、可调试：输出即画面，便于人机理解、可视化失败原因。

代价（也是本领域的核心难点，见第 7 章）：视频是高维、冗余、且不显式携带 3D/物理状态和动作的。要用它驱动机器人，必须解决"如何从像素里把动作抠出来"以及"生成的未来是否物理可行"。

1.3 核心范式总览：视频生成有"五种身份"赋能具身智能 ​

视频生成模型在具身智能里可以扮演五种角色（它们并不互斥，很多系统同时占多个）：

① 生成即规划 / 策略（Generation-as-Policy / Planning） 先用文本/目标图作条件，生成一段"任务应该怎么完成"的未来视频，再从视频里反解出动作执行。视频是"计划"，机器人只是"照着演"。代表：UniPi、AVDC、SuSIE、Video Language Planning、RoboDreamer。

② 预测即表征（Prediction-as-Representation） 不一定真的输出漂亮像素，而是把视频扩散模型内部/预测出的未来特征当作富含动态信息的视觉表征，接一个动作头（policy head）。核心洞见（VPP）：能预测未来的模型，其中间特征同时包含"当前静态信息 + 预测的未来动态"，比只做单帧重建/对比学习的编码器更适合具身任务。代表：GR-1/GR-2、VPP、Seer。

③ 世界模型 / 仿真器（World-Model / Simulator） 学一个动作条件的视频预测器 xt+1​=f(x≤t​,at​)，当作可学习的模拟器，用于：(a) 在"想象"里训练/优化策略（model-based RL、MPC）；(b) 闭环评估一个策略好不好（省去昂贵危险的真机试验）；(c) 反事实推理（"如果这样做会怎样"）。代表：iVideoGPT、IRASim、Ctrl-World、以及 2026 年爆发的一大批"世界-动作模型（WAM）"。

④ 数据引擎（Data Engine） 把视频生成模型当作合成数据的生产者：让它生成大量"机器人做各种任务"的神经轨迹（neural trajectory）视频，再用 IDM 或潜动作模型反解伪动作，得到可训练的"视频-动作"对，从而极大扩增数据、解锁泛化。代表：DreamGen / GR00T-Dreams、GigaWorld、EnerVerse-D、RynnWorld-Teleop。

⑤ 统一 VLA + 世界模型（Unified） 把"预测动作（VLA）"与"预测未来（世界模型）"放进同一个模型联合训练，让二者互相增强：世界模型逼动作模型理解物理，动作模型帮世界模型生成得更准。代表：WorldVLA、UVA（Unified Video Action）、Xiaomi-U0、iFLYTEK-Embodied-Omni。

一句话记忆：视频生成之于具身智能，可以是计划（①）、眼睛/大脑皮层（②）、梦境模拟器（③）、数据工厂（④），或四位一体的统一大脑（⑤）。

1.4 与经典机器人学习的关系（放进大图里） ​

传统机器人策略学习大致三条路，视频生成对每条都有增益：

经典路线局限视频生成如何帮
模仿学习（IL / BC）需要大量真机示范，泛化差用生成的神经轨迹扩增示范（身份④）；用视频预训练表征（身份②）
强化学习（RL）真机试错昂贵、危险、慢在视频世界模型里"想象中"试错（身份③）
VLA（Vision-Language-Action）直接回归动作，缺乏对"后果"的建模用未来预测作密集监督（身份②③⑤）

一个关键区分——VLA vs WAM（世界-动作模型）：

  • VLA：直接学 at​=π(ot​,语言)，把"看→动"端到端拟合。
  • WAM：先（显式或隐式地）建模"如果做动作 a，世界会变成什么样"，再让这个"对后果的预测"服务于动作选择。WAM 把"未来"当作密集监督信号，被认为比 VLA 更 data-efficient、更能泛化（详见 2606.20781《World Action Models: A Survey》）。

1.5 一个贯穿全教程的"灵魂问题" ​

到底要不要真的把像素生成出来？

这是 2025–2026 年本领域最核心的争论，几乎每篇新论文都要表态：

  • 要（渲染未来，rendered future）：像素可解释、可评估、可当仿真器；但慢、贵，实时闭环控制吃不消。
  • 只在隐空间预测（latent future）：不解码像素，只预测未来的 latent/token，快很多，但牺牲可解释性（InternVLA-A1.5、DVG-WM）。
  • 干脆不生成（generation-free at inference）：训练时用"未来"作监督，推理时只出动作，把生成模型的知识"蒸馏"进策略（VPP、GigaWorld-Policy、Fast-WAM、ImageWAM）。

2026 年大量工作本质上是在这个"表达力 vs 速度"的谱系上取不同的折中点，第 7.1 节会专门展开。

1.6 评价一个"视频生成赋能的具身系统"好不好，看这几点 ​

学界（尤其 WAM survey 2606.20781、WorldArena 2602.08971）逐渐收敛出一组正交能力轴：

  1. 任务成功率（Task Success Rate）：终极指标。闭环执行下任务做成没有。
  2. 动作可提取性 / 遵循性（Action-extractability / following）：能否从生成的视频里可靠地得到正确动作；给不同动作能否得到不同且正确的未来。
  3. 物理合理性（Physical plausibility）：接触、碰撞、抓握是否符合物理（尤其接触区）。
  4. 数据效率与泛化（Data efficiency & Generalization）：少量真机数据 + 大量视频，能否泛化到新物体/新场景/新技能/新本体。
  5. 实时性（Real-time）：闭环控制频率、动作延迟（如 EnerVerse-A 单卡 280ms/8步动作块）。
  6. sim-to-real / 作为评估器的可信度：仿真里好用能否迁移真机；当评估器时判决是否可信（admissibility）。

核心矛盾（记住它）："生成得逼真"≠"对具身任务有用"。一个 FVD 很低、看着很美的视频模型，可能对动作响应错误、物理违规，导致机器人失败。这就是为什么本领域的评测（第 6 章）正在从"像不像视频"快速转向"能不能让机器人成功"。

第 2 章 数学原理与关键技术 ​

本章从"如何把决策问题写成视频生成问题"讲起，逐步搭到"如何注入/提取动作""如何学潜动作""如何做世界模型""如何加速"。

2.1 把"决策"重述为"条件视频生成"（奠基性形式化） ​

把机器人任务建模为一个（部分可观测）马尔可夫决策过程 (PO)MDP：状态 st​、动作 at​、观测 ot​（此处即图像帧 xt​）。经典策略直接学 at​=π(o≤t​)。

UniPi 的重述（2302.00111）：把"给定目标求动作序列"改写为"给定目标文本 g，生成一段实现该目标的未来视频"：

x^1:H​∼pθ​(x1:H​∣x0​, g),at​=Πϕ​(x^t​,x^t+1​)

  • 第一步是文本条件视频生成（planner）：从当前帧 x0​ 和文本目标 g 生成"任务完成过程"的帧序列 x^1:H​。
  • 第二步是从相邻帧反解动作：用一个逆动力学模型（Inverse Dynamics Model, IDM） Πϕ​ 把"两帧之间的视觉变化"翻译成动作 at​。

这个"先想象过程、再反解动作"的两段式，是身份①（生成即规划）的数学骨架，被后续 AVDC、SuSIE、RoboDreamer、DreamGen 等大量继承。

为什么这样有用：g（文本/目标图）天然支持组合泛化；x（图像）作为统一表示天然支持跨任务/跨本体；而生成器可从互联网视频学到丰富先验。代价是需要一个准确的 IDM，且生成一整段像素很慢。

2.2 视频生成的三大生成范式（骨干选择） ​

(a) 扩散 / 流匹配（Diffusion / Flow Matching） 前向加噪、反向去噪；以 flow matching / rectified flow 为例，学速度场 vθ​：

L=Et,x0​,x1​​​vθ​(xt​,t;cond)−(x1​−x0​)​2,xt​=(1−t)x0​+tx1​

主流骨干是 DiT（Diffusion Transformer），在 VAE 压缩的视频隐空间上操作。具身领域常直接微调通用底座（Wan、HunyuanVideo、CogVideoX、Stable Video Diffusion、Cosmos）。VPP、DreamGen、EnerVerse、Ctrl-World 都属此类。

(b) 自回归 / 块因果扩散（Autoregressive / Chunk-wise Causal Diffusion） 按帧或按 chunk 因果生成，天然支持"边给动作边预测"的流式闭环。EnerVerse 用块级自回归视频扩散 + 稀疏记忆做长时程；iVideoGPT、WorldVLA 也偏此类。核心技术：因果注意力 + 滚动 KV 缓存。

(c) 离散 token 自回归（Token AR，VideoGPT 式） 先用 VQ tokenizer 把帧变成离散 token，再像语言模型一样预测下一 token。优点是可复用 LLM 基础设施、易与语言/动作 token 混合，因此深受"统一大模型"路线偏爱。代表：iVideoGPT、Moto、WorldVLA、Xiaomi-U0。

2.3 条件信号：目标怎么给（Goal Specification） ​

具身视频生成的"条件"比通用视频生成更丰富：

  • 文本指令（"把红色方块放进碗里"）：最通用，支持组合泛化（UniPi、RoboDreamer、VLP）。
  • 目标图像 / 子目标图（subgoal）：SuSIE 用图像编辑模型生成"下一子目标观测"，比纯文本更精确地锚定空间。
  • 首帧 / 历史帧：几乎所有方法都条件于当前观测 x0​（image-to-video）。
  • 语言 + 手势/轨迹（This&That）：用简单手势指向 + 语言消解歧义。
  • 多视角（EnerVerse、多相机操作）：多路视图缓解运动歧义与 3D grounding。
  • 机器人本体状态 / 动作（见 2.5）：把动作也作为条件，即"动作条件世界模型"。

2.4 从视频里"抠动作"：四种动作提取范式 ​

身份①④都需要"从生成的像素反解出机器人动作"。这是本领域独有的关键技术，主要四类：

  1. 逆动力学模型（Inverse Dynamics Model, IDM）：学 at​=IDM(xt​,xt+1​)，从相邻帧预测动作。需要少量"带动作标签"的真机数据训练 IDM，但生成端可用海量无标注视频。UniPi、DreamGen、Seer 皆用。痛点：IDM 误差会直接传给执行。
  2. 稠密对应 / 光流（Dense Correspondence / Optical Flow）：AVDC 通过帧间稠密对应推出闭式动作，完全无需动作标签；FlowWAM 更进一步把光流本身当作"与视频同格式的动作表示"（逐像素位移），可用无标注视频预训练。
  3. 潜动作模型（Latent Action Model, LAM）：从无标注视频自监督学一套"潜动作词表"（见 2.6），再用少量真机数据把潜动作对齐到真实动作。DreamGen 可用 LAM 或 IDM 二选一。
  4. 目标条件低层策略（Goal-conditioned low-level policy）：不直接反解，而是把生成的未来帧当作"子目标"，训一个低层策略去"够到"这个子目标（SuSIE 的高层出子目标图、低层去实现）。

选型直觉：有一定真机动作数据 → IDM 最直接；完全无动作标签 → 稠密对应/光流或 LAM；想要分层规划 → 子目标 + 低层策略。

2.5 动作注入机制：如何把机器人动作"喂进"视频模型 ​

当视频模型要当动作条件世界模型（身份③⑤）时，需把动作 at​（末端 6-DoF 位姿 / 关节角 / 夹爪 / 速度）注入生成过程。主流方式：

  1. 通道拼接（Concatenation）：动作编码成向量/图，与视频 token 拼接。最常见（iVideoGPT、IRASim）。
  2. AdaLN 调制（Scaling & Shifting）：动作经 MLP 产生 AdaLN 的 γ,β 调制 DiT 特征。
  3. 交叉注意力（Cross-Attention）：动作作为 K/V 注入，适合高层/语义动作。
  4. 动作作为独立 token（Action-as-Token）：在 token AR 里把动作离散成 token，与视觉 token 交错，用统一 Transformer 建模（WorldVLA、Moto、Xiaomi-U0）。这也让"动作预测"和"视频预测"能在同一序列里互相条件。
  5. 视觉化动作（Visualized Action）：把数值动作渲染成图像通道再注入——如 IOI 用前向运动学把末端轨迹渲染成正交投影图注入，让生成器专注学"随机的物理接触"而非重复学"确定的运动学"；FlowWAM 用光流图。这是 2025–2026 的重要趋势。

设计原则：确定性的、可解析的部分（运动学轨迹）宜"渲染成图"显式给出；不确定的、需要学的部分（接触、形变、物理）交给生成器。IOI、PhysisForcing 都体现这一"运动学/物理解耦"哲学。

2.6 潜动作学习（Latent Action Learning）——连接海量无标注视频的桥梁 ​

难点：互联网视频、人类操作视频没有机器人动作标签。潜动作学习从无标注视频对 (xt​,xt+1​) 中自监督地学一个离散/连续潜动作 zt​，使得 xt+1​≈decode(xt​,zt​)。

  • 思想来源：Genie（2402.15391）的 Latent Action Model（LAM）——从视频学离散潜动作，让无动作标注视频也能训可交互世界模型。
  • 机器人侧代表：
    • LAPA（Latent Action Pretraining from Videos, 2410.11758, ICLR'25）：先在海量（含人类）视频上学潜动作、做潜动作预训练，再用少量真机数据把潜动作映射到真实动作，显著提升数据效率与跨本体迁移。
    • Moto（2412.04445）：把视频中的运动压成潜运动 token（latent motion token），作为"机器人操作的桥接语言"，先在视频上做潜运动自回归预训练，再对齐真实动作。
    • AdaWorld（2503.18938, ICML'25）：学可适配的潜动作，快速迁移到新环境。
    • Motus（2512.13030）：统一潜动作世界模型。
  • DreamGen 的实用主义：既然生成器只出视频，就用 LAM 或 IDM 二选一恢复伪动作——潜动作与逆动力学在这里是"殊途同归"的两种动作恢复器。

为什么重要：潜动作是把"海量无标注视频"变成"可训练的具身数据"的关键。它让"用 YouTube 教机器人"从口号变成可行路线。

2.7 把视频模型变成"世界模型/仿真器"的关键技术 ​

要当仿真器（身份③），除动作注入外还需解决长时程稳定与闭环可用：

  • 长时程 rollout 与抗漂移（error accumulation）：训练时看真实历史、推理时看自己生成的带误差历史，误差滚雪球。对策：Diffusion Forcing（对不同帧加独立噪声，学会从"不完美历史"预测）、Self Forcing（on-policy 吃自己生成的历史）、Scheduled Rollout、稀疏记忆（EnerVerse 的 sparse context memory）等。
  • 记忆与持久性：机器人任务常需"记住看不见的东西"（被遮挡的物体、已完成的子步骤）。Mem-World（2606.18960）做持久操作记忆；EnerVerse 用稀疏上下文记忆做长程推理。
  • 多视角 / 4D 一致：单目有运动/深度歧义，多视角视频 + 4D 表示（EnerVerse 的 4DGS、MVISTA-4D）提升 3D grounding 与物理一致。
  • 作为评估器的"自一致性"：SC3-Eval（2606.18610）提出前向-逆向动力学一致、跨视角一致、测试时一致三重约束，把视频基础模型改造成准确的闭环策略评估器（与真机成功率相关性高达 0.929）。

2.8 作为"数据引擎"的关键技术（身份④） ​

把视频模型当数据工厂，流程（以 DreamGen / GR00T-Dreams 为例，4 阶段）：

  • 神经轨迹（Neural Trajectory）：生成器合成的"机器人执行任务"视频 + 反解的伪动作，构成可训练轨迹。
  • 本体适配（embodiment adaptation）：先把通用 I2V 模型微调到目标机器人外观，保证生成的手臂/夹爪逼真且动作可解。
  • 自增强数据闭环：EnerVerse-D 把生成建模 + 4D 高斯泼溅结合成自增强数据闭环，缩小 sim-to-real 差距。
  • Real2Sim2Real：EmbodieDreamer（2507.05198）用生成式世界模型打通真实→仿真→真实闭环。
  • 数字遥操作（Digital Teleoperation）：RynnWorld-Teleop（2607.06558）用手部位姿驱动生成式世界模型合成第一人称视频，产出可迁移到任意机器人的状态-动作轨迹，绕开昂贵真机遥操作。

DreamGen 的里程碑结论：一个人形机器人仅用单一 pick-and-place 任务、单一环境的遥操作数据，借助神经轨迹就能泛化出 22 种新行为、并迁移到未见环境。这把"扩数据"从"雇人遥操作"升级为"让模型做梦"。

2.9 统一 VLA + 世界模型的原理（身份⑤） ​

把动作预测与未来预测放进同一序列/模型联合训练。以 WorldVLA（2506.21539）为例：

  • 世界模型部分：用"动作 + 图像理解"预测未来图像 → 逼模型学环境物理。
  • 动作模型部分：基于图像观测生成后续动作 → 帮助视觉理解，反过来提升世界模型生成质量。
  • 互相增强：论文证明统一模型优于"单独的动作模型"与"单独的世界模型"。
  • 一个坑与解法：自回归连续出动作时，早期动作误差会传播使后续动作恶化；WorldVLA 提出注意力掩码策略（生成当前动作时选择性遮蔽先前动作）显著改善动作块生成。

UVA（Unified Video Action, 2503.00200）则用联合视频-动作隐表示 + 解耦解码，训练时同时学视频与动作、推理时可只走动作分支从而提速——再次呼应 1.5 的"要不要生成像素"主线。

2.10 效率与实时（闭环控制的硬约束） ​

机器人闭环控制需要低延迟、稳定频率。核心手段：

  • 只出动作、不解码像素（推理期 generation-free）：VPP、GigaWorld-Policy、Fast-WAM（85ms 延迟）、ImageWAM（用图像编辑代替视频生成，FLOPs 降到约 1/6）。
  • 动作分块（action chunking）+ 特征复用：EnerVerse-A 复用第一步去噪特征、预测动作块，单张 RTX 4090 约 280ms/8 步动作块。
  • 解耦动力学与合成：DVG-WM（2606.32028）解耦"动力学学习"与"视觉合成"，取得约 3.97× 加速。
  • 潜空间预测替代像素：InternVLA-A1.5（2607.04988）用 foresight token 在冻结视频生成器监督下压缩未来，避免逐帧解码。

"要不要生成像素"本质是"表达力 vs 实时性"的工程权衡，也是区分"能 demo"与"能上真机闭环"的分水岭。

第 3 章 任务体系（Tasks） ​

本章逐一拆解"视频生成赋能具身智能"承载的具体任务：输入/输出、条件信号、评价方式、代表工作。任务可按"用视频生成来干什么"（对应第 1.3 的五种身份）和"在什么本体上干"（操作/导航/人形）两个维度交叉理解。

3.1 按"用途"划分的任务 ​

3.1.1 视频规划 / 视频即策略（Video Planning / Video-as-Policy） ​

  • 定义：给定当前观测 + 目标（文本/图），生成"任务完成过程"的未来视频，再反解动作执行。
  • 输入：x0​（首帧）、g（文本或目标图）；输出：x^1:H​ + 动作 a1:H​。
  • 子任务：单步子目标生成（SuSIE）、整段轨迹生成（UniPi/AVDC）、长时程分层视频规划（Video Language Planning：VLM 出高层文本步骤 + 视频模型出低层视觉计划，交替进行树搜索）、组合泛化视频规划（RoboDreamer）。
  • 评价：任务成功率、计划-执行一致、组合泛化到新指令。

3.1.2 动作条件未来预测（Action-Conditioned Future Prediction） ​

  • 定义：给定历史观测 + 未来动作序列，预测未来视频（可含深度/多视角）。这是身份③⑤的共同内核。
  • 输入：x≤t​、at:t+H​；输出：xt+1:t+H​。
  • 评价：视觉保真（FVD/PSNR/LPIPS）+ 动作遵循（改动作→改未来）+ 长时程稳定。
  • 代表：iVideoGPT、IRASim（交互式真机动作模拟器）、Ctrl-World、WorldVLA。

3.1.3 世界模型作策略学习的"想象环境"（Imagination for Policy Learning） ​

  • 定义：把动作条件视频预测器当可微/可 rollout 的仿真器，在"想象"里做 model-based RL 或 MPC。
  • 评价：想象中训练的策略迁移到真机/真仿真的成功率。
  • 代表：iVideoGPT（可扩展交互世界模型，支持 MBRL）、Dreamer 4（在可扩展世界模型内部训练智能体）。

3.1.4 世界模型作"闭环评估器"（Policy Evaluation / Real-World Simulator） ​

  • 定义：不训练策略，而是评估一个已有策略好不好——在世界模型里让策略跑闭环，估计其真机成功率，省去昂贵/危险的真机试验。
  • 评价核心：世界模型的判决与真机成功率的相关性/排序一致性；以及评估器自身的可信度（admissibility）。
  • 代表：Ctrl-World（可控生成式操作世界模型）、SC3-Eval（自一致→准确评估器，相关性 0.929）、A2World（一套权重既作 simulator 又作 policy）、Interactive World Simulator（2603.08546）、"先验证再信任"的准入阶梯（2607.07196）。

3.1.5 神经轨迹数据合成（Neural Trajectory Data Synthesis） ​

  • 定义：生成大量"机器人做任务"的视频 + 反解伪动作，作为训练数据扩增。
  • 评价：下游策略在真机/仿真上的成功率提升、对新技能/新环境的泛化。
  • 代表：DreamGen / GR00T-Dreams、GigaWorld-0、EnerVerse-D、RynnWorld-Teleop（数字遥操作）、MimicDreamer（2509.22199）。

3.1.6 视频表征预训练（Video Representation Pretraining for Control） ​

  • 定义：用视频（预测）预训练视觉表征，再迁移到下游策略；推理时不一定生成像素。
  • 评价：下游成功率、样本效率、跨任务迁移。
  • 代表：GR-1/GR-2（大规模视频生成式预训练 → 操作）、VPP（用 VDM 内部表征）、Seer（预测式逆动力学）、V-JEPA 2（自监督视频模型→理解/预测/规划）。

3.2 按"本体 / 场景"划分的任务 ​

3.2.1 桌面操作（Table-top Manipulation） ​

最主流的试验场：抓取、放置、开抽屉、堆叠、倒水等。基准以 CALVIN、LIBERO、RoboTwin、Meta-World 为主。几乎所有奠基工作（UniPi、AVDC、SuSIE、VPP、EnerVerse）都在此验证。

3.2.2 灵巧操作与双臂（Dexterous & Bimanual） ​

多指手、双臂协调，动作维度高、接触复杂，对物理合理性要求更高。VPP 报告在复杂真机灵巧任务上成功率提升 31.6%；RoboTwin 2.0（2506.18088）提供强域随机化的双臂基准。

3.2.3 移动操作与导航（Mobile Manipulation & Navigation） ​

机器人要"边走边操作"，动作含底盘移动 + 机械臂。相机位姿本身成为重要动作，与"探索式世界模型"（相机可控视频）技术相通。

3.2.4 人形 / 全身（Humanoid / Whole-body） ​

自由度极高、数据极稀缺，因此最依赖视频先验与数据引擎。GR00T N1（2503.14734）为人形提供开放基础模型；DreamGen 的旗舰验证正是人形机器人的行为泛化。

3.2.5 跨本体 / 通用（Cross-embodiment / Generalist） ​

用"图像/视频"这一本体无关表示，把不同机器人的数据/知识拉通。UniPi 的初衷、LAPA/Moto 的潜动作、Worldscape-MoE（2607.03964）的"异构动作接口"都服务于此。

3.3 任务全景速记 ​

读法：任何一篇论文都可定位为"（用途 × 本体）"的一个或多个格子。例如 DreamGen = 数据合成 × 人形；VPP = 表征预训练 × 灵巧；Ctrl-World = 闭环评估 × 桌面操作。

第 4 章 数据（Data） ​

数据是本领域的命门。核心张力一句话：

带动作标注的真机数据"贵而少"，无动作标注的视频"廉而多"。 视频生成赋能具身智能的一切数据策略，都是围绕这个张力做文章。

4.1 数据的层级与"动作标注 vs 多样性"权衡 ​

数据源视觉/任务多样性动作标注采集成本典型用途
互联网视频（YouTube 等）极高✗（需潜动作/IDM）极低视频预训练、潜动作
人类第一人称操作视频高✗（需手-物先验）低表征、潜动作、跨形态
真机遥操作示范低-中✓（精确动作/本体）极高IDM 训练、微调、对齐
仿真引擎中（可控/可随机化）✓中大规模、可验证、评测
世界模型合成（神经轨迹）高（可提示）伪动作（反解）低（算力换数据）数据扩增、泛化

4.2 真机机器人数据集（带动作，昂贵而珍贵） ​

  • Open X-Embodiment（2310.08864）：跨 20+ 机构、多本体的大规模真机轨迹合集，是"跨本体"研究的底座。
  • DROID（2403.12945）：大规模、多样场景的真机操作数据集。
  • BridgeData V2（2308.12952）：桌面操作，广泛用于 SuSIE 等。
  • RH20T、RoboMIND、AgiBot World：更大规模、更贴近实用的真机数据（人形/双臂/工业场景），2024–2025 陆续开放，支撑数据引擎与大模型训练。
  • 用途：训练 IDM / 潜动作对齐器、微调生成器到目标本体、提供闭环评测的真值。

4.3 人类视频与跨形态数据（无动作，海量） ​

  • Ego4D / Ego-Exo4D：大规模第一人称人类活动视频，蕴含丰富手-物交互先验。
  • Something-Something V2：强调"动作概念"（推、拉、盖）的短视频，利于学动作语义。
  • EPIC-Kitchens：厨房场景第一人称长视频。
  • 价值：VPP、GR-1/2、LAPA 等都强调"混入互联网/人类操作视频"能显著提升未来预测精度与策略泛化——因为人类的手与机器人的夹爪在"如何完成任务"的层面高度相通。

4.4 仿真平台与数据生成器 ​

  • CALVIN（2112.03227）：语言条件长时程桌面操作，标准泛化划分（ABC→D）。
  • LIBERO（2306.03310）：终身学习/多任务操作基准。
  • RoboTwin 2.0（2506.18088）：可扩展数据生成器 + 强域随机化双臂操作基准，2026 年大量 WAM 论文用它报成功率。
  • Meta-World、RoboCasa、ManiSkill：多任务/家庭场景/大规模操作仿真。
  • 价值：提供廉价、可复现、带真值动作的数据与可验证闭环的评测环境。

4.5 专为"视频生成 × 具身"构建的数据/基准 ​

  • DreamGen Bench（随 DreamGen/2505.12705 发布）：视频生成基准，且证明其分数与下游策略成功率强相关——即"视频生成得好，策略也学得好"，为身份④提供了度量抓手。
  • 多视角操作数据（EnerVerse 等）：多相机 + 4D 表示，缓解运动歧义。
  • WorldArena（2602.08971）：统一评测具身世界模型的感知 + 功能效用，含 action-planner 协议与 EWMScore，被 2026 年 WAM 论文广泛当作标准协议（详见第 6 章）。

4.6 "世界模型即数据引擎"范式（数据不再只是输入） ​

到 2025–2026，数据的生产方式发生范式转变——模型自己造数据：

  • DreamGen / GR00T-Dreams（2505.12705, NVIDIA）：神经轨迹 → 伪动作 → 单任务数据泛化出 22 种新行为。
  • GigaWorld-0（2511.19861）：世界模型作数据引擎，系统性赋能具身 AI 的数据规模化。
  • EnerVerse-D：生成建模 + 4DGS 的自增强数据闭环，降 sim-to-real gap。
  • RynnWorld-Teleop（2607.06558）：数字遥操作——手部位姿驱动生成，产出可迁移任意机器人的状态-动作轨迹。
  • EmbodieDreamer（2507.05198）：Real2Sim2Real 闭环。
  • Xiaomi-Robotics-U0（2607.11643）：统一大模型既作具身世界模型，又作可扩展数据引擎。

一句话趋势：数据供给正从"人力采集为主"转向"采集 + 合成双轮驱动"，算力开始能"换"数据。

下面逐个拆解这些奠基工作（按主线分组），每篇统一用"问题 → 思路 → 技术细节 → 结果与意义"四段式讲清楚。

5.1.A 生成即规划系（身份①的源头） ​

UniPi（arXiv:2302.00111, NeurIPS 2023）——"把决策变成拍电影"

  • 问题：不同任务、不同机器人有不同的状态空间和动作空间，很难训一个通用智能体；而且想用互联网视频里的知识，却不知怎么用。
  • 思路：把"求动作序列"重述为"给定文本目标，拍一段任务完成过程的视频"。文本负责"要做什么"，图像作为本体无关的统一表示，视频里则隐含了"该怎么做"。
  • 技术细节：① 一个文本条件视频扩散模型作 planner，从首帧 + 文本生成未来帧序列；为保证长且清晰，用时间超分/层级生成逐级加密帧；② 一个**逆动力学模型（IDM）**从相邻两帧回归出动作；③ 训练 IDM 只需少量带动作数据，而 planner 可吃海量无标注视频。
  • 结果与意义：实现了对"新物体 + 新动作"的组合泛化，一套模型跨多种操作任务；确立了"生成未来 → 反解动作"这一身份①的数学骨架，被后续几乎所有工作继承。

Video Language Planning / VLP（arXiv:2310.10625, 2023）——"VLM 出主意，视频来演"

  • 问题：长时程任务（如"把桌子收拾干净"）既需要高层语义规划（先干嘛后干嘛），又需要低层视觉落地（具体怎么动）。单靠视频模型难做长程决策。
  • 思路：让 VLM 当高层策略 + 价值函数（提出并评估候选文本子步骤），让文本→视频模型当动力学模型（把每个子步骤"演"成视觉未来），二者交替，构成一次树搜索式规划。
  • 技术细节：VLM 生成多个候选高层文本动作 → 视频模型对每个候选 rollout 出视觉结果 → VLM 对结果打分 → 前向搜索出最优长程计划 → 再用目标条件策略/IDM 落到控制。
  • 结果与意义：显著提升多阶段重排等长时程任务成功率；首次把 LLM/VLM 的规划能力与视频动力学缝合，是"分层视频规划"的范式起点（后来 DSWAM 的双系统与之一脉相承）。

AVDC（arXiv:2310.08576, 2023）——"完全不用动作标签也能学策略"

  • 问题：视频策略通常需要动作标签来训 IDM，而动作标注极贵。
  • 思路：只用 RGB 视频、零动作标签。把图像当任务无关表示，用**帧间稠密对应（dense correspondence / 光流）**闭式地反解出动作。
  • 技术细节：先合成"机器人幻想执行任务"的视频；再在相邻帧间算稠密对应，结合深度/刚体假设，闭式求解出物体/末端的位移与旋转即动作；配套一个能在 4 卡一天内训好的高效视频模型。
  • 结果与意义：在桌面操作和导航上验证了"无动作标签学策略"；它是"光流即动作"思想的先驱，直接启发了 2026 年的 FlowWAM。

SuSIE（arXiv:2310.10639, 2023）——"用图像编辑模型想象下一个子目标"

  • 问题：通用机器人要处理机器人数据里没见过的新物体/新场景。
  • 思路：用图像编辑扩散模型当高层规划器，给出"下一步应该看到什么"的子目标图像；再用一个低层目标条件策略去够到这个子目标。
  • 技术细节：把 InstructPix2Pix 在"人类视频 + 机器人回放"上微调，使其"给定当前观测 + 语言指令 → 输出若干步之后的假想子目标观测"；低层策略用机器人数据训成目标图像条件的控制器；每 N 步刷新一次子目标，形成分层闭环。
  • 结果与意义：在 CALVIN 上达到 SOTA，真机泛化超过使用特权信息或大得多算力的基线；**"子目标图像即计划"**成为身份①的重要分支，且巧妙复用了互联网规模的图像编辑先验。

RoboDreamer（arXiv:2404.12377, 2024）——"把语言拆成积木，才能组合出没见过的任务"

  • 问题：文本→视频世界模型只能生成"和训练指令相似"的视频，无法组合出新的"物体×动作"搭配，这对决策是致命的。
  • 思路：因子化（factorize）视频生成——利用语言天然的组合性，把指令解析成一组低层原语（动词、物体、方位…），让多个模型分别条件于这些原语再组合。
  • 技术细节：组合式扩散；把"put the red block on the shelf"拆成原语集合，各自条件生成再融合；还支持多模态目标（语言 + 目标图）。在 RT-X 上训练。
  • 结果与意义：能为未见的目标组合合成视频计划并驱动仿真执行，显著超过整体式（monolithic）基线；把"组合泛化"正式引入生成即规划。

This&That（arXiv:2407.05530, 2024）——"光说不够，用手指一下"

  • 问题：纯语言指定空间目标有歧义（哪个杯子？放哪儿？）。
  • 思路：**语言 + 手势（指点/箭头）**联合控制视频生成，用手势消解"指哪打哪"的空间歧义。
  • 技术细节：视频扩散条件于语言 + 2D 手势点；两阶段"先生成视频计划，再由视频→动作策略执行"。
  • 结果与意义：更少歧义、更高规划成功率；示范了"更丰富的条件接口"对生成即规划的价值。

5.1.B 预测即表征系（身份②的源头） ​

GR-1（arXiv:2312.13139, ICLR 2024）——"先学会预测视频，再学会动"

  • 问题：机器人数据稀缺，如何借力大规模视频？
  • 思路：用大规模视频预测做生成式预训练，再微调成"同时预测未来帧 + 动作"的模型。
  • 技术细节：GPT 式因果 Transformer，先在 Ego4D 等大规模人类视频上做视频预测预训练；再在机器人数据上微调，单模型联合输出"未来图像 + 动作"；视频预测这一辅助目标把动态先验注入表征。
  • 结果与意义：在 CALVIN（尤其泛化划分）与真机上大幅提升，少数据也能行；**"视频生成式预训练 → 操作"**范式的奠基作，身份②的起点。

GR-2（arXiv:2410.06158, 2024）——"把 GR-1 放大"

  • 问题：把 GR-1 的范式规模化到更多任务、更强泛化。
  • 思路：更大规模视频预训练（约 3800 万条视频片段）+ 多任务动作微调。
  • 技术细节：更大的 Transformer、隐空间视频预测 + 动作头、精细数据清洗；覆盖百余种任务与全身操作。
  • 结果与意义：100+ 任务高真机成功率，对未见场景/物体强泛化；证明身份②可随数据/模型规模持续受益。

VidMan（arXiv:2411.09153, NeurIPS 2024）——"榨取视频扩散里的隐式动力学"

  • 问题：如何最有效地把视频扩散模型学到的动力学用于动作？
  • 思路：两阶段"先动力学建模、再动作预测"——先在 Open X-Embodiment 上预训练一个动力学感知的视频扩散，再用逐层适配器抽取其表征做动作头（受双过程理论启发）。
  • 技术细节：视频扩散作"动力学感知"骨干；自注意力/适配器把中间表征引到逆动力学式动作头。
  • 结果与意义：在 CALVIN 上较 GR-1 提升约 11.7%，数据效率强；进一步坐实"视频扩散内部表征富含可用动力学"。

VPP / Video Prediction Policy（arXiv:2412.14803, ICML 2025 Spotlight）——"不必真画出来，用'将画未画'的特征就够了"

  • 问题：传统视觉编码器（单图重建/双图对比）只抓静态信息，忽略具身任务命脉——动态。
  • 思路：视频扩散模型（VDM）的内部表征天然同时包含"当前静态 + 预测的未来动态"；直接把这份预测式表征喂给策略头，学一个"基于预测未来表征的隐式逆动力学"。
  • 技术细节：把视频基础模型在"机器人 + 人类操作"数据上微调；推理时只做一次前向取预测式表征（不做完整去噪、不生成像素）；上面接一个扩散策略头出动作，因而高频、可实时。
  • 结果与意义：CALVIN ABC-D 相对提升 18.6%，真机复杂灵巧任务成功率 +31.6%；是身份②"预测即表征、推理免生成"最典范的作品。

Seer（arXiv:2412.15109, ICLR 2025）——"预测式逆动力学，能随规模变强"

  • 问题：如何把"前向预测"与"逆动力学"统一且可扩展地学？
  • 思路：预测式逆动力学模型（PIDM）——一个端到端 Transformer 同时"预测未来视觉状态（前向）"和"推断达成该状态所需动作（逆向）"，即"先想再动（predict-then-act）"。
  • 技术细节：输入观测 + 语言，联合输出未来帧 + 动作块；大规模预训练后微调，架构与数据双双可扩展。
  • 结果与意义：CALVIN 与真机显著超越 SOTA、且随规模持续提升；把身份②从"辅助预训练"推进到"预测与动作端到端一体"。

5.1.C 潜动作系（打通"无标注视频→可训练动作"的桥梁） ​

LAPA（arXiv:2410.11758, ICLR 2025）——"从没有动作标签的视频里，先学一套'潜动作语言'"

  • 问题：互联网/人类视频没有机器人动作标签，VLA 预训练却需要动作。
  • 思路：潜动作预训练三步走——① 从视频帧间无监督学出离散潜动作；② 让 VLM 在海量（含人类）视频上预测潜动作；③ 用少量真机数据把潜动作映射到真实机器人动作。
  • 技术细节：潜动作量化模型（VQ-VAE 式，对相邻帧变化编码）；潜动作预训练；小样本对齐到真实动作空间。数据用 Something-Something、Ego4D 等。
  • 结果与意义：某些基准上甚至超过用真实动作标签预训练的 OpenVLA，且跨本体、极省数据、能直接从人类视频学；是"用 YouTube 教机器人"的里程碑。

Moto（arXiv:2412.04445, 2024）——"用'潜运动 token'当机器人的中间语言"

  • 问题：如何用一种紧凑表示把"视频预训练"与"动作"桥接起来？
  • 思路：把帧间运动离散成潜运动 token（latent motion token），先在视频上自回归预训练一个"Moto-GPT"预测运动 token，再微调读出动作。
  • 技术细节：潜运动 tokenizer（对帧对做 VQ）；Moto-GPT 视频自回归预训练；协同微调把运动 token 映射到动作。
  • 结果与意义：在 SIMPLER、CALVIN、真机上数据高效且强；提供了"运动 token 作桥接语言"这一优雅抽象。

AdaWorld（arXiv:2503.18938, ICML 2025）——"带潜动作的、能快速适配的世界模型"

  • 问题：世界模型迁移到新环境/新动作空间代价大。
  • 思路：从多样视频自监督学潜动作，据此构建动作条件世界模型，使其几个示范就能快速适配新环境。
  • 技术细节：跨视频的潜动作自编码器；用潜动作预训练世界模型；新环境上只需小幅微调。
  • 结果与意义：迁移高效、规划更优；把"潜动作"从"学策略"扩展到"学可适配的世界模型"。

5.1.D 世界模型 / 仿真器 / 数据引擎系（身份③④的源头） ​

iVideoGPT（arXiv:2405.15223, NeurIPS 2024）——"可扩展、可交互的 VideoGPT 世界模型"

  • 问题：世界模型要可交互（吃动作、出未来 + 奖励）、可扩展（能吃海量异构数据）、且能服务 model-based RL。
  • 思路：用离散 token 自回归统一"观测 + 动作 + 奖励"，配一个压缩式 tokenizer降低 token 数以支持长序列与实时交互。
  • 技术细节：上下文帧稠密 tokenize、未来帧相对上下文做压缩 tokenize（大幅减 token）；GPT 预测下一 token；在 Open X-Embodiment 上预训练，可做视频预测、MBRL、视觉规划三类下游。
  • 结果与意义：在 RoboNet 视频预测、Meta-World MBRL 等上有竞争力；确立了"token-AR 可扩展世界模型"路线，是身份③与"想象中学策略"的重要底座。

IRASim（arXiv:2406.14540, 2024）——"给一条动作轨迹，精确渲染真机会怎么动"

  • 问题：想要一个逼真且动作精确的学习式真机模拟器，用于评估与造数据。
  • 思路：动作条件视频扩散——从初始帧 + 一整条动作轨迹，生成机械臂精确执行该轨迹的高保真视频。
  • 技术细节：Diffusion Transformer，逐帧注入对应动作（frame-level action conditioning）；在 RT-1、Bridge、Language-Table 等大规模真机数据上训练；提出 IRASim 基准专测"轨迹跟随精度"。
  • 结果与意义：视觉逼真 + 轨迹跟随准，可作"真机模拟器"；是身份③里"动作精确 rollout"的代表，直接服务于闭环评估与数据合成。

Cosmos（arXiv:2501.03575, NVIDIA）——"面向 Physical AI 的世界基础模型平台"

  • 问题：Physical AI（机器人/驾驶）需要自带物理直觉、可微调的世界基础模型（WFM）与配套工具链。
  • 思路：提供一整套预训练 WFM + tokenizer + 数据管线，支持动作/控制条件，可微调到各下游。
  • 技术细节：Cosmos-Predict（未来预测）、Cosmos-Transfer（带控制的 Sim2Real 迁移）、Cosmos-Reason（VLM 推理）；连续与离散两种视频 tokenizer；在 1 亿+ 小时视频上训练。
  • 结果与意义：成为大量具身/驾驶工作的通用底座（如被多种 WAM 拿去做骨干）；把"世界模型"从论文推进到工业级平台。

EnerVerse（arXiv:2501.01895, NeurIPS 2025）——"为操作而生的具身未来空间生成器"（身份②③④三合一）

  • 问题：具身预测要长时程 + 3D 落地 + 高效，三者兼得难。
  • 思路：块级自回归视频扩散从指令预测未来"具身空间"，用稀疏上下文记忆做长程推理、**多视角（自由锚视角 FAV）**做 3D 落地、再接策略头出动作。
  • 技术细节：Free Anchor View 多视角表示缓解运动歧义与 3D grounding；稀疏记忆压历史；EnerVerse-D 数据引擎把生成建模 + 4D 高斯泼溅（4DGS）组成自增强数据闭环降 sim-to-real；EnerVerse-A 动作头复用第一步去噪特征、预测动作块，单张 RTX 4090 约 280ms/8 步动作块。
  • 结果与意义：仿真 + 真机双 SOTA 且高效；是同时占身份②③④的集大成者，多视角 + 4D + 数据闭环的思路被后续广泛借鉴（详见 5.5）。

DreamGen / GR00T-Dreams（arXiv:2505.12705, NVIDIA）——"让机器人在梦里学会新技能"（身份④里程碑）

  • 问题：真机数据采集是规模化机器人学习的最大瓶颈，尤其"行为泛化 + 环境泛化"。
  • 思路：神经轨迹（neural trajectory）——用视频世界模型批量"做梦"生成机器人执行各种任务的合成视频，再反解伪动作变成可训练数据。
  • 技术细节：4 阶段——① 把 I2V 生成器（如 Cosmos/WAN 系）微调到目标本体外观；② 用文本提示批量生成"新任务/新环境"的视频；③ 用**潜动作模型（LAM）或逆动力学（IDM）**反解伪动作；④ 用"视频-伪动作"对训练视觉运动策略。配 DreamGen Bench 度量。
  • 结果与意义：人形机器人仅用单一 pick-and-place 任务、单一环境的遥操作数据，就泛化出 22 种新行为并迁移到未见环境；且 DreamGen Bench 证明"视频质量↔策略成功率"强相关。把"扩数据"从'雇人遥操作'升级为'让模型做梦'，详见 5.5。

V-JEPA 2（arXiv:2506.09985, Meta）——"在隐空间预测、零样本规划的世界模型"（身份②③"潜未来"典范）

  • 问题：想要自监督视频表征，既能理解又能用于控制，且不必生成像素。
  • 思路：联合嵌入预测架构（JEPA）——在隐空间预测被遮挡内容（而非像素）；再加动作条件得到可 rollout 的世界模型 V-JEPA 2-AC，做零样本 MPC 规划。
  • 技术细节：100 万+ 小时视频上做掩码隐空间预测预训练；随后用少量机器人数据（Droid）做动作条件微调；在隐空间里做模型预测控制规划；主预训练无需动作/奖励标签。
  • 结果与意义：在新机器人、新实验室零样本完成抓取-放置；视频理解/预测多项 SOTA；是"潜未来派"（不生成像素也能当世界模型）的旗舰，直接呼应 1.5 的灵魂之争。

5.1.E 统一 VLA + 世界模型系（身份⑤的源头） ​

UVA / Unified Video Action Model（arXiv:2503.00200, 2025）——"训练时video+action一起学，推理时可只走动作提速"

  • 问题：联合学视频与动作能互相增强，但视频生成慢，拖累实时控制。
  • 思路：用联合视频-动作隐表示 + 解耦解码——训练时同时学视频与动作，推理时可跳过视频解码只出动作。
  • 技术细节：共享隐空间 + 视频/动作两个解码头；掩码训练；一模可当策略、正/逆动力学、视频生成多用。
  • 结果与意义：多基准 SOTA 且推理快；是身份⑤"联合训练、按需生成"的清晰样板，与 VPP 一样体现"训练时用未来、推理时省"的哲学。

GR00T N1（arXiv:2503.14734, NVIDIA）——"通用人形机器人的开放基础模型"（身份②⑤）

  • 问题：通用人形需要一个能吃异构数据、跨本体的基础模型。
  • 思路：双系统 VLA——System 2（VLM 慢推理）+ System 1（扩散/流匹配动作头快执行）；数据用"金字塔"（网络视频、人类、仿真、真机）。
  • 技术细节：VLM（Eagle 系）+ 流匹配动作头；用潜动作/神经轨迹从视频补数据；强调跨本体。
  • 结果与意义：操作与人形任务强、且开源；是 GR00T-Dreams（DreamGen）的底座，把"视频先验 + 双系统 VLA"整合进人形基础模型。

5.2 身份①：生成即规划 / 策略（2025.06–now） ​

在奠基的"生成未来→反解动作"框架上，2025.06 后的重点是组合/长时程泛化、动作恢复更可靠、推理更快。逐个拆解代表工作：

FlowWAM（arXiv:2607.13017）——"光流就是动作，动作就是光流"

  • 问题：身份①的老大难是"生成整段像素慢 + IDM 反解动作有误差"。数值动作（关节角/位姿）和视频像素格式不兼容，难以用无标注视频统一预训练。
  • 思路：把光流（optical flow）当作"与视频同格式的、原生的动作表示"——光流本身就是逐像素位移，天然编码"东西怎么动"；于是"读出动作"和"注入动作"变成同一件事。
  • 技术细节：模型在与 RGB 同构的光流场上做预测，可先用海量无动作标注视频预训练光流动力学，再对齐到机器人动作；光流既是模型输出（读出的动作），也可作为条件回注（注入的动作），模糊了身份①与身份③的边界。
  • 结果与意义：RoboTwin 成功率 92.94%；把 AVDC 的"稠密对应即动作"推向"光流即统一动作接口"，是 2026 年"绕开 IDM"路线的代表。

ImageWAM（arXiv:2606.19531）——"别拍整段电影，画一张'目标剧照'就够了"

  • 问题：生成一整段视频既慢又贵，但机器人规划其实只需要"知道目标长什么样"。
  • 思路：用图像编辑只建模"当前帧 → 目标帧"的单步变换，而不是逐帧生成整段视频，保留"想象目标→执行"的规划语义却大幅省算力。
  • 技术细节：把世界模型退化为"目标帧变换器"（image-editing 式），只预测关键的目标观测；FLOPs 降到约整段视频生成的 1/6；下游用目标条件策略/IDM 落地。
  • 结果与意义：在"表达力 vs 速度"谱系上取"只生成目标帧"这一折中，是 SuSIE"子目标图像"思想在效率维度的 2026 版延续，直指真机可用。

RoboDreamer 路线的延续与组合泛化

  • 把语言分解为原语、组合生成，仍是应对"未见指令组合"的主力思路；2026 年更多与潜动作/光流动作结合，减少对 IDM 的依赖。

直觉：身份①最大的工程痛点始终是"生成一整段像素太慢 + IDM 误差"。2026 年的解法要么"只生成关键帧/目标帧"（ImageWAM），要么"用与视频同构的动作表示（光流/潜动作）绕开 IDM"（FlowWAM）。

5.3 身份②：预测即表征（2025.06–now） ​

延续 GR-1/2、VPP、Seer 的思路：用"预测未来"这一自监督目标塑造出富含动态的表征，推理时不生成像素、只出动作，兼顾性能与速度。逐个拆解：

InternVLA-A1.5（arXiv:2607.04988）——"把未来压成几颗'预见 token'"

  • 问题：逐帧生成像素太慢，但完全丢掉未来预测又会损失动态先验，如何折中？
  • 思路：用少量 foresight token（预见 token）在冻结的视频生成器监督下压缩未来，动作头只需读这几颗 token 就能出动作。
  • 技术细节：冻结一个预训练视频生成器作"未来老师"，蒸馏出紧凑的 foresight token（隐空间未来摘要）；VLA 主干条件于观测 + 语言 + foresight token 出动作；推理不解码像素。
  • 结果与意义：既保留"预测未来"的动态先验，又避免逐帧解码，是"潜未来派"在 VLA 上的落地；与 V-JEPA 2 同属"隐空间预测"，但更贴近 VLA 动作头。

DVG-WM（arXiv:2606.32028）——"把'学动力学'和'画画'拆开，各干各的"

  • 问题：世界模型把"理解动力学"和"合成漂亮像素"耦在一起，导致又慢又难优化。
  • 思路：解耦动力学学习与视觉合成——控制真正需要的是动力学，像素合成按需再做。
  • 技术细节：一条轻量动力学通路服务动作/控制，一条合成通路按需生成像素（可关掉）；因避免了不必要的像素合成，取得约 3.97× 加速。
  • 结果与意义：清晰诠释"控制不一定要好看"，把算力集中到对动作有用的部分；是身份②③交叉、面向实时的代表。

GigaWorld-Policy（arXiv:2603.17240）/ GigaWorld-Policy-0.5（arXiv:2607.13960）/ Fast-WAM（arXiv:2603.16666）——"训练时用未来，推理时只出动作"

  • 问题：世界模型知识很有用，但推理时生成未来太慢，上不了真机高频闭环。
  • 思路：把"未来预测"当训练期的监督/正则塑造策略，推理期彻底不生成，只前向出动作——相当于把世界模型"蒸馏"进一个纯策略。
  • 技术细节：训练时联合"预测未来 + 预测动作"，推理时砍掉预测未来分支；Fast-WAM 把延迟压到 85ms，直指高频控制；GigaWorld-Policy 系列与 GigaWorld-0 数据引擎（见 5.5）配套，形成"数据引擎 + 策略"闭环。
  • 结果与意义：是身份②"免生成推理"最激进的一派，把"世界模型的知识"与"实时策略的速度"两头通吃。

PhysisForcing（arXiv:2606.28128）——"让预测出的表征不仅像，而且物理对"

  • 问题：预测式表征可能"看着像"但物理错（尤其接触区），会误导动作。
  • 思路：在训练中加入物理强化约束，让预测的未来同时满足像素级与语义级的物理一致。
  • 技术细节：像素级轨迹对齐（预测轨迹与真值逐像素对齐）+ 语义级关系对齐（物体间接触/支撑等关系一致），共同强化接触区物理正确。
  • 结果与意义：提升接触密集任务的物理合理性，让身份②的表征"可信可用"；与 IOI 同属 2026 年"物理正确性"攻坚线。

身份②的精髓："预测未来"只是训练时的脚手架，推理时把脚手架拆掉，只留下被塑造好的表征与动作头。 这也是"要不要生成像素"之争里最务实的一派。

5.4 身份③：世界模型 / 仿真器 / 评估器（WAM 大爆发，2025.06–now） ​

这是 2025–2026 增长最猛的方向，统称世界-动作模型（World Action Model, WAM）。

《World Action Models: A Survey》（arXiv:2606.20781）——这条线的"地图与纲领"

  • 问题：世界模型论文百花齐放，缺乏统一坐标系；且很多"世界模型"其实只是"带动作头的视频生成器"，没真正服务控制。
  • 核心主张：WAM 的本质是"把对未来的预测服务于动作/控制"，而非追求像素好看；趋势是"生成更少的未来、但保留控制所需的部分"。
  • 分类框架：按"要生成什么"分三类——渲染未来 / 潜未来 / 免生成（正好对应 1.5 的灵魂问题）；并梳理动作注入、记忆、评估器可信度等子问题。
  • 意义：为本领域提供了公认的术语与坐标系，被 2026 年大量工作引用作纲领。

下面按其三分法逐个拆解代表系统。

5.4.1 渲染未来（rendered future）——真的把像素画出来 ​

Ctrl-World（arXiv:2510.10125）——"可控的操作世界模型，用来'在梦里考策略'"

  • 问题：真机评估策略昂贵、危险、慢；想在一个可控世界模型里闭环评估。
  • 思路：训一个动作可控的生成式操作世界模型，给定策略动作即可 rollout 出未来，据此估计策略成功率、做 what-if 反事实。
  • 技术细节：动作条件视频生成骨干 + 可控接口，支持"固定场景、改动作"看不同后果；强调闭环 rollout 的稳定性。
  • 结果与意义：把"世界模型作评估器"落到操作任务，是身份③"评估器用途"的代表；与 SC3-Eval、准入阶梯共同构成 2026 年"可信评估"图景。

EMMA（arXiv:2509.22407）——"生成式视觉迁移，让策略跨域也能用"

  • 问题：策略在一种视觉域训练，换外观/光照/背景就崩（视觉域移）。
  • 思路：用深度条件的多视角 DiT 把已采集的演示视频"换皮"成不同前景/背景/光照，再用一个按策略表现动态加权难样本的采样器把这批合成数据喂给 VLA。
  • 技术细节：生成模型当"视觉翻译器"只改外观、几何由深度条件锁住；主要用作数据扩增，也可做推理期域适配。
  • 与本节主线的关系（需注意）：EMMA 不做动作条件的未来渲染——它重画的是"同一段已发生轨迹的另一种外观"，而不是"若执行动作 a 会看到什么"。列在本节只因为它同样真的把像素画了出来；按五身份划分，它更靠近身份④数据引擎。
  • 结果与意义：把视频/图像生成用于"跨域鲁棒"，是身份③④之间的实用桥梁。

A2World（arXiv:2606.29501, ECCV'26）——"一套权重，既是'梦'又是'做'"

  • 问题：simulator（世界模型）与 policy（策略）通常分开训，浪费且不一致。
  • 思路：动作条件世界建模预训练学到可迁移的动力学先验，让同一套权重既能当仿真器（A2World-sim）又能当策略（A2World-policy）。
  • 技术细节：先在动作条件预测任务上预训练动力学；下游既可 rollout 未来（sim），也可直接出动作（policy）；动力学先验跨任务/场景迁移。
  • 结果与意义：优雅统一"预测"与"控制"，且世界模型可当可靠评估器；体现"预测服务控制"的 WAM 精神。

5.4.2 潜未来 / 免生成（见 5.3 已详解，此处点明其身份③属性） ​

  • InternVLA-A1.5（arXiv:2607.04988，foresight token）、DVG-WM（arXiv:2606.32028，解耦加速 3.97×）：在隐空间"预测未来"充当世界模型，但不解码像素——潜未来派的世界模型。
  • ImageWAM（arXiv:2606.19531）、GigaWorld-Policy / Fast-WAM：训练用未来、推理免生成——免生成派的世界模型（详见 5.2 / 5.3）。

5.4.3 动作表示与物理/运动学解耦（2026 的关键方法论） ​

IOI（arXiv:2606.23296）——"运动学我会算，物理你来学"

  • 问题：世界模型既要学"机械臂怎么走"（确定的运动学），又要学"接触时会怎样"（随机的物理），把两者混在一起既浪费又学不好。
  • 思路：解耦运动学（解析先验）与物理（学习动态）——运动学用前向运动学解析算出、渲染成图注入，把生成器的学习容量全部让给"随机的物理接触"。
  • 技术细节：由关节/位姿经前向运动学算末端轨迹，渲染成正交投影图作为条件注入生成器；生成器专注建模接触、形变等随机物理。
  • 结果与意义：RoboTwin SOTA + 零样本 OOD，且可作可靠的策略评估器；是"视觉化动作 + 物理/运动学解耦"最清晰的样板。

PhysisForcing（arXiv:2606.28128）：像素级 + 语义级对齐强化接触物理（详见 5.3），也是身份③世界模型"物理正确"的关键。

FlowWAM（arXiv:2607.13017）：光流统一动作表示（详见 5.2），其光流既是读出的动作也是注入的条件，天然是动作条件世界模型。

Motus（arXiv:2512.13030）——"统一潜动作的世界模型"

  • 问题：不同任务/本体的动作空间不一，难以统一建模世界。
  • 思路：用统一的潜动作作为世界模型的动作接口，让一个世界模型吃各种来源的"潜动作"。
  • 技术细节：潜动作自监督学习（承 Genie/LAPA/AdaWorld 血脉）+ 动作条件世界建模，统一异构动作。
  • 结果与意义：把"潜动作"从策略/预训练推进到"统一世界模型的通用动作接口"，服务跨本体。

5.4.4 作为评估器的可信度（本领域评测前沿，元评测） ​

SC3-Eval（arXiv:2606.18610）——"用'自一致'把视频模型变成靠谱的考官"

  • 问题：想用视频基础模型当"策略考官"（闭环评估），但它可能"看着对、判得错"。
  • 思路：施加三重自一致约束让评估更准——前向-逆向动力学一致、跨视角一致、测试时一致。
  • 技术细节：前向预测的未来与逆动力学反解的动作要自洽；多视角预测要互相一致；测试时自一致校准。
  • 结果与意义：闭环判决与真机成功率相关性高达 0.929；给"世界模型当评估器"提供了可操作的可信度提升手段。

准入阶梯 / Admissibility Ladder L0–L4（arXiv:2607.07196）——"先验证你的梦，再信它的判决"

  • 问题：直接拿世界模型当"测试预言机"很危险——它可能不可信。
  • 思路：提出 L0–L4 五级准入阶梯，世界模型当评估器前必须逐级被认证（借鉴安全关键仿真的 VV&A/SOTIF）。
  • 关键发现：视觉质量排名高的模型，动作遵循反而可能低——即视觉保真不预测闭环判决所依赖的动作鲁棒性。
  • 意义：开启"评估评估器"的元评测方向，是把"在梦里测机器人"做得可信、可标准化的关键一步。

5.4.5 记忆增强 / 长时程 ​

Mem-World（arXiv:2606.18960）——"记住看不见的东西"

  • 问题：长时程操作里，物体被遮挡、子步骤已完成等信息会"忘掉"，导致前后不一致。
  • 思路：给操作世界模型加持久记忆，跨长时程保持物体/状态一致。
  • 技术细节：显式/检索式记忆存储关键状态，rollout 时读回，维持持久性。
  • 结果与意义：提升长任务一致性，是身份③"长时程可用"的关键组件。

MVISTA-4D（arXiv:2602.09878）——"多视角 4D 一致的具身世界"

  • 问题：单目预测有深度/运动歧义，3D 落地差。
  • 思路：**多视角 + 4D（含时间的 3D）**一致建模，缓解歧义、增强物理正确。
  • 技术细节：多相机视频联合建模 + 4D 表示约束跨视角/跨时刻一致。
  • 结果与意义：承接 EnerVerse 多视角 4D 思路，服务接触密集与 3D 依赖任务。

w-EVA（arXiv:2606.09457）——"先设想、再验证、后执行"

  • 问题：直接执行动作缺乏"三思"，易出错。
  • 思路：Envision–Verify–Act 闭环——先用世界模型设想后果，验证可行性，再执行。
  • 技术细节：世界模型 rollout 候选动作后果 → 验证器筛选 → 执行最优；类似"想象中的模型预测控制"。
  • 结果与意义：把世界模型嵌入决策闭环做"安全三思"，呼应 VLP/DSWAM 的规划思路。

Interactive World Simulator（arXiv:2603.08546）——"可交互的真实世界模拟器"

  • 问题：要一个可实时交互、供策略反复试错的通用真实世界模拟器。
  • 思路/意义：延续 UniSim 的"通用真实世界模拟器"愿景，强调可交互 rollout 供具身策略学习与评估。

5.5 身份④：视频生成作数据引擎（2025.06–now） ​

在 DreamGen 打样后，"让模型做梦、把梦变数据"成为规模化机器人学习的新轴。逐个拆解：

DreamGen / GR00T-Dreams（arXiv:2505.12705）——数据引擎的里程碑（详见 5.1.D）

  • 一句话回顾：4 阶段（本体适配→生成神经轨迹→LAM/IDM 反解伪动作→训练策略），单任务数据泛化 22 新行为，配 DreamGen Bench 度量"视频质量↔策略成功率"。它是本节所有工作的范式起点。

GigaWorld-0（arXiv:2511.19861）——"把'做梦造数据'做成系统工程"

  • 问题：DreamGen 证明了可行，但要规模化成生产级数据引擎，需要系统性的数据质量、覆盖度与效率保障。
  • 思路：把世界模型作为系统化的数据引擎，大规模、可控地生成具身训练数据，并与下游策略（GigaWorld-Policy 系列）形成闭环。
  • 技术细节：可控生成覆盖多任务/多场景的神经轨迹；配套动作恢复与质量筛选；与 GigaWorld-Policy（2603.17240）/ 0.5（2607.13960）"数据引擎↔策略"协同（后者训练用未来、推理免生成，见 5.3）。
  • 结果与意义：把"模型造数据"从单点验证推进到"数据引擎 + 策略"的完整闭环，是产业化数据合成的代表。

RynnWorld-Teleop（arXiv:2607.06558）——"数字遥操作：用手比划，模型来演"

  • 问题：真机遥操作采数据又贵又慢，且数据绑定具体机器人。
  • 思路：数字遥操作——用人手位姿驱动生成式世界模型合成第一人称操作视频，产出可迁移到任意机器人的状态-动作轨迹。
  • 技术细节：手部位姿作控制信号→生成式世界模型→第一人称视频→反解状态-动作轨迹；因为在"视频/状态"层面产出，故本体无关、可再映射到不同机器人。
  • 结果与意义：把"采数据"的人力成本从"真机遥操作"降到"对空比划"，且天然跨本体；是数据引擎里"更接地的动作来源"。

EmbodieDreamer（arXiv:2507.05198）——"Real2Sim2Real 闭环"

  • 问题：仿真数据便宜但有 sim-to-real gap，真实数据准但贵。
  • 思路：用生成式世界模型打通 Real→Sim→Real 闭环，让仿真更贴近真实、再回灌真机。
  • 技术细节：从真实数据学世界模型（Real2Sim）→在其中大规模生成/训练→迁移回真机（Sim2Real），迭代缩小差距。
  • 结果与意义：以生成模型为媒介系统性压缩 sim-to-real gap，是数据引擎与仿真的交汇。

MimicDreamer（arXiv:2509.22199）——"用'模仿式梦境'扩增示范"

  • 问题：模仿学习示范太少，覆盖不足。
  • 思路：生成"模仿式梦境"视频扩增示范数据，提升模仿学习的覆盖与泛化。
  • 技术细节：以少量示范为种子，生成风格/场景变体的示范视频 + 反解动作，扩充训练集。
  • 结果与意义：数据引擎在"模仿学习扩增"方向的代表。

关键度量抓手：DreamGen Bench 证明"视频生成质量↔下游策略成功率"强相关——这让"数据引擎好不好"第一次有了可优化的代理指标（详见 6.4）。但也要警惕 7.4 的"伪动作质量天花板"：反解不准，扩增的就是噪声。

5.6 身份⑤：统一 VLA + 世界模型（2025.06–now） ​

把"预测动作"与"预测未来"塞进一个模型联合训练，让二者互相增强，是通往"具身基础模型"的主流路径。逐个拆解：

WorldVLA（arXiv:2506.21539）——"动作模型和世界模型互相当老师"

  • 问题：VLA 只学"看→动"，缺乏对"动作后果"的建模；世界模型只学"预测未来"，不出动作。二者分开都不够。
  • 思路：在一个自回归框架里统一动作与图像的理解与生成——世界模型用"动作+图像"预测未来图像（逼模型懂物理），动作模型基于图像出动作（帮视觉理解，反哺世界模型生成）。
  • 技术细节：把图像与动作都离散成 token，用统一自回归 Transformer 建模；发现自回归连续出动作时误差会传播（早期动作错→后续更错），提出注意力掩码策略——生成当前动作时选择性遮蔽先前动作，显著改善动作块生成。
  • 结果与意义：统一模型优于"单独动作模型"与"单独世界模型"，证明双向增益；注意力掩码是应对自回归动作误差传播的实用技巧。

UVA / Unified Video Action（arXiv:2503.00200）——"联合训练、推理按需生成"（详见 5.1.E）

  • 一句话回顾：联合视频-动作隐表示 + 解耦解码，训练时都学、推理时可只走动作分支提速；身份⑤"省算力"的样板。

Xiaomi-Robotics-U0（arXiv:2607.11643）——"38B 的统一具身合成大模型"

  • 问题：具身智能需要一个像 GPT 那样"大一统"的基础模型，既懂世界又能动、还能造数据。
  • 思路：多模态自回归统一具身合成——一个 38B 模型同时充当具身世界模型与可扩展数据引擎。
  • 技术细节：多模态 token（视觉/语言/动作/状态）统一自回归；规模化到 38B；一模多用（预测未来、出动作、造数据）。
  • 结果与意义：把身份③④⑤压进一个大模型，是"具身基础模型"的规模化尝试，代表工业界"大一统"路线。

iFLYTEK-Embodied-Omni（arXiv:2607.02542）——"脑-小脑一体的 Omni 架构"

  • 问题：高层推理（脑）与低层动作（小脑）常割裂。
  • 思路：把 **VLM（推理）+ 视频生成（想象未来）+ 动作生成（执行）**统一进一个 Omni 架构，形成"脑-小脑"协作。
  • 技术细节：VLM 出意图/子目标→视频生成想象后果→动作生成落地，三模块端到端。
  • 结果与意义：身份⑤中"推理×想象×执行"三位一体的代表。

DSWAM（arXiv:2607.04927）——"快慢双系统的世界-动作模型"

  • 问题：又要快执行、又要会规划，单一系统难兼顾。
  • 思路：双系统——System 1 WAM 快速执行，按需唤起 System 2 VLM 做子任务规划（呼应 Kahneman 快/慢思维）。
  • 技术细节：System 1 是动作条件世界-动作模型高频出动作；遇到需要推理处调用 System 2 VLM 分解子任务；二者协同。
  • 结果与意义：把 VLP 的"高层规划 + 低层执行"升级为"世界模型级双系统"，兼顾实时与长程。

LingBot-VA（arXiv:2601.21998）——"因果世界建模驱动机器人控制"

  • 问题/思路：用因果世界建模（建模"动作→后果"的因果，而非表面相关）来驱动机器人控制，提升对动作的正确响应。

PhyAgentOS（arXiv:2607.16636）——"把 VLA/世界模型/规划器装进一个自演化'操作系统'"

  • 问题：具身系统的各模块（感知、世界模型、规划、执行）如何编排、协同、持续进化？
  • 思路：提出一个自演化"操作系统"，把 VLA、世界模型、规划器作为可组合、可升级的组件统一调度。
  • 技术细节：模块化 + 编排层 + 自演化机制（组件可替换/自改进）。
  • 结果与意义：从"单模型"上升到"系统/OS"视角，指向可持续演化的具身智能体架构。

Worldscape-MoE（arXiv:2607.03964）——"一个世界，多种动作接口"

  • 问题：人体运动、机器人操作、手部控制等异构动作通常各训各的，难统一。
  • 思路：用 MoE 世界模型统一异构动作控制——把不同控制视为"同一世界的不同接口"，由不同专家（expert）承接。
  • 技术细节：混合专家路由不同动作模态到对应专家，共享世界骨干；实现跨控制类型的统一建模。
  • 结果与意义：指向"一个骨干 + 可插拔动作/本体专家"的跨本体大一统（呼应 7.7），是身份⑤面向通用性的代表。

第 6 章 基准与评测（Benchmarks & Metrics） ​

评测是本领域最快演化、也最微妙的部分。核心命题贯穿始终：

"视频生成得好" ≠ "机器人任务做得成"。 因此评测必须回答两个层次的问题：(1) 视频作为"世界的预测"对不对；(2) 这份预测最终能不能让真实机器人成功。

6.1 评测的四个层次（从"像"到"有用"） ​

层次越往右，越贴近"机器人真的成功了吗"，也越是本领域区别于通用视频生成的地方。

6.2 第①层：视频质量指标（必要但远不充分） ​

  • FVD（Fréchet Video Distance）：分布级视频质量，最常用。
  • FID / PSNR / SSIM / LPIPS：帧级质量/重建。
  • VBench（2311.17982）：多维视频生成综合基准。
  • 局限：这些只奖励"视觉真实"，不检验动作响应、物理接触、任务达成。一个 FVD 很低的模型可能对动作响应错误。

6.3 第②层：世界正确性（动作遵循 / 物理 / 一致） ​

  • 动作遵循 / 可控性：固定历史、改变动作，度量输出是否随动作正确改变（动作条件世界模型的核心考题）。
  • 物理合理性：接触、碰撞、抓握是否符合物理，尤其接触区——PhysisForcing、IOI 都专门优化并度量这一点。
  • 多视角 / 4D 一致：跨视图几何是否自洽（MVISTA-4D、EnerVerse 多视角）。
  • 自一致性诊断：SC3-Eval 的前向-逆向动力学一致、跨视角一致、测试时一致，既是训练目标也是评测维度。

6.4 第③层：具身效用（是否"对机器人有用"） ​

这一层直接度量"视频/世界模型对下游具身任务的贡献"。逐个拆解代表基准：

DreamGen Bench（随 arXiv:2505.12705）——"视频质量能预测策略成功率吗？能！"

  • 要解决什么：造数据/预训练用的视频模型五花八门，选哪个？总不能每个都拉去训策略再看真机成功率（太贵）。
  • 怎么做：构建视频生成基准，系统测量"视频生成质量"与"用该视频训出的策略的下游成功率"之间的相关性。
  • 关键结论：二者强相关——于是可以用"视频基准分"作为廉价代理指标，预判一个视频模型对策略的增益，指导数据引擎选型。
  • 意义：第一次把"数据引擎好不好"变成可优化、可预判的量，是身份④能规模化的度量基石。

WorldArena（arXiv:2602.08971）——"具身世界模型的统一竞技场"

  • 要解决什么：世界模型评测各说各话，缺乏"既看预测对不对、又看对控制有没有用"的统一协议。
  • 怎么做：统一评测**感知（视觉/物理正确）+ 功能效用（能否用于规划/控制）**两大类能力，提供 action-planner 协议（把世界模型接到规划器上闭环）与 EWMScore 综合分。
  • 意义：被 2026 年大量 WAM 论文当作标准评测协议，是"具身效用"这一层的事实标准之一。

RoboGaze（arXiv:2606.28385）——"不只打分，还告诉你视频哪一步错了"

  • 要解决什么：一个成功率数字无法解释"失败在哪、为什么"。
  • 怎么做：免训练的多智能体 VLM 框架，对机器人操作视频做结构化、可解释评测，给出 6 维 30 类故障分类（如抓取时机错、路径偏、放置偏差等）。
  • 意义：把评测从"分数"升级为"可解释的诊断报告"，利于定位与改进。

KineBench（arXiv:2607.19876, ECCV'26）——"免 IDM 的闭环具身世界模型评测"

  • 要解决什么：评测世界模型常需一个 IDM 把生成视频反解成动作再闭环，IDM 本身的误差会污染评测。
  • 怎么做：跳过 IDM——用视觉基础模型直接从生成视频抽 6D 末端位姿，放进物理仿真里闭环验证；配 SPARC（平滑度）/ 可操作度等运动学指标。
  • 关键发现：观察到"任务复杂度受限的非线性 scaling"（并非越大越好，复杂任务上收益递减）。
  • 意义：为"闭环具身世界模型评测"提供免 IDM、带运动学解释的新范式。

6.5 第④层：闭环任务成功率（终极判据） ​

  • CALVIN（2112.03227）：语言条件长时程操作，ABC→D 泛化划分（VPP 在此 +18.6%）。
  • LIBERO（2306.03310）：多任务/终身学习操作。
  • RoboTwin 2.0（2506.18088）：强域随机化双臂基准，2026 年 WAM 论文的成功率主战场（FlowWAM 92.94%、IOI SOTA）。
  • RoboChallenge（2510.17950）：大规模真机评测。
  • 真机 + 仿真双报告：EnerVerse、VPP、DreamGen 都强调"仿真好还要真机好"，避免只刷仿真分。

6.6 第⑤层：世界模型作评估器的"可信度"（元评测） ​

当世界模型本身被用作"测试机器人策略的模拟器"时，它自己也需要被评估——这是 2026 年新兴的元评测层：

  • SC3-Eval（2606.18610）：把视频基础模型改造成准确的策略评估器，闭环判决与真机成功率相关性 0.929。
  • 准入阶梯（Admissibility Ladder L0–L4，2607.07196）："先验证梦境、再信任其判决"；关键发现——视觉质量排名 ≠ 动作遵循排名，视觉保真不预测评估所依赖的动作鲁棒性。
  • 无参考物理一致性度量（2606.22363）：指出 FVD 无法反映"世界是否对动作正确响应"，提出基于 DROID-SLAM + SEA-RAFT 的无参考物理一致性指标；用它过滤生成数据后，可把 VLA 任务成功率提升 8%+、缩小 sim-to-real 差距。

第 7 章 核心挑战与研究趋势 ​

7.1 灵魂之争：到底要不要生成像素？（贯穿全领域） ​

这是本领域的头号张力，本质是"表达力/可解释性 vs 速度/实时性"的权衡：

  • 渲染派：像素可当仿真器、可评估、可 debug；代价是慢、贵，难上真机高频闭环（Ctrl-World、A2World、IOI）。
  • 潜未来派：只预测 latent/token，兼顾动态先验与速度（InternVLA-A1.5 的 foresight token、DVG-WM 的解耦）。
  • 免生成派：训练用未来当监督、推理只出动作，把"梦"蒸进策略（VPP、Fast-WAM、GigaWorld-Policy、ImageWAM）。

趋势判断：demo/研究/数据引擎场景偏"渲染派"（要可视化、要造数据）；真机高频闭环控制强烈偏"潜未来/免生成派"。2026 年很多工作干脆"训练时渲染、推理时免生成"两头通吃。

7.2 动作提取与动作表示 ​

  • IDM 误差瓶颈：身份①④依赖 IDM/LAM 反解动作，其误差直接传给执行。趋势是用与视频同构的动作表示（光流 FlowWAM、潜动作 Moto/LAPA、视觉化运动学 IOI）绕开或减轻 IDM。
  • 运动学/物理解耦：把"确定的运动学"解析给出、把"不确定的物理接触"交给生成器（IOI、PhysisForcing），是 2026 年提升物理正确性的关键方法论。

7.3 物理合理性与接触 ​

  • 生成模型擅长"看起来对"，却常在接触、遮挡、精细力交互处违反物理。
  • 对策：接触区显式监督（PhysisForcing）、多视角/4D grounding（EnerVerse、MVISTA-4D）、无参考物理一致性度量与数据过滤（2606.22363）。
  • 这是"sim-to-real"差距的主要来源之一。

7.4 数据：合成的"伪动作"够准吗？ ​

  • 数据引擎（身份④）解锁了规模，但伪动作的质量是天花板：LAM/IDM 反解不准，扩增的数据就是噪声。
  • 趋势：更好的动作恢复器 + 用具身效用指标（DreamGen Bench）筛数据 + 数字遥操作（RynnWorld-Teleop）提供更接地的动作源。

7.5 实时闭环与延迟 ​

  • 真机控制需要稳定的高频闭环。当前代表：Fast-WAM 85ms、EnerVerse-A 单卡 280ms/8 步动作块、DVG-WM 3.97× 加速。
  • 手段：动作分块、特征复用、少步蒸馏、潜空间/免像素预测。

7.6 长时程与误差累积 ​

  • 长任务需要长 rollout，误差滚雪球 + 需要"记住"看不见的东西。
  • 对策：稀疏/持久记忆（EnerVerse、Mem-World）、Diffusion/Self Forcing、分层规划（VLP、DSWAM 的双系统）。

7.7 跨本体与统一大模型 ​

  • 用"图像/视频"这一本体无关表示拉通不同机器人（UniPi 初心）；潜动作（LAPA/Moto）、异构动作接口（Worldscape-MoE）、统一 VLA+WM（WorldVLA、Xiaomi-U0、iFLYTEK-Omni）是主要路径。
  • 趋势：从"每本体一个专用模型"走向"一个骨干 + 可插拔的动作/本体专家"。

7.8 评估器可信度（新兴且关键） ​

  • 用世界模型评估策略能省下昂贵危险的真机试验，但评估器本身可能不可信（视觉好 ≠ 动作准）。
  • 准入阶梯（2607.07196）、SC3-Eval（2606.18610）开启了"评估评估器"的元评测方向，未来会像安全关键仿真的 VV&A/SOTIF 一样标准化。

结语 ​

本教程沿着"原理 → 任务 → 数据 → 方法 → 基准 → 挑战 → 论文"的主线，系统梳理了"视频生成赋能具身智能"这一交叉方向。若把全篇压成几句话带走：

  1. 一个核心信念：能"预测未来"的视频模型，天然蕴含做决策所需的物理与动力学知识；把这份知识翻译成动作，就能赋能机器人。
  2. 五种身份：视频生成之于具身智能，可以是计划（①生成即规划）、表征（②预测即表征）、梦境仿真器（③世界模型/评估器）、数据工厂（④数据引擎）、或统一大脑（⑤VLA+WM）——这是理解任何一篇论文的坐标系。
  3. 一条灵魂主线："要不要真的生成像素"——渲染 / 潜未来 / 免生成，是"表达力 vs 实时性"的连续谱，几乎决定了一个系统能 demo 还是能上真机闭环。
  4. 一个独有命门：数据。带动作标注的真机数据贵而少，无标注视频廉而多；潜动作、IDM、光流、稠密对应、数字遥操作、神经轨迹，都是为跨越这道鸿沟而生。
  5. 一场评测革命：从"像不像视频"走向"能不能让机器人成功"，再到"世界模型当评估器可不可信"——评测正回归具身智能的初心。

未来最值得关注的三条线：

  • 一个骨干 + 可插拔本体/动作专家的跨本体统一大模型（Worldscape-MoE、Xiaomi-U0 路线）；
  • 训练时渲染、推理时免生成两头通吃的实时闭环范式（VPP / Fast-WAM / InternVLA-A1.5 路线）；
  • 可被认证的世界模型评估器（准入阶梯 / SC3-Eval 路线），让"在梦里测机器人"变得可信、可标准化。

与本教程配套阅读的姊妹篇：《动作条件与探索式世界模型》（游戏/驾驶/探索）、《视频生成后训练与强化学习》、《视频生成加速与蒸馏》。四篇合起来，覆盖"视频生成"从基础能力到世界模拟再到具身落地的完整版图。

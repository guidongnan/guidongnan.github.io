SymbOmni: Evolving Agentic Omni Models via Symbolic Concept Learning ​

项内容
arXiv2607.12042
提交日期2026-07-13
作者Jinxiu Liu, Jianru Li, Tanqing Kuang, Xuanming Liu, Kangfu Mei, Yandong Wen, Weiyang Liu
分类cs.CV, cs.LG（ECCV 2026）
一句话把 ComfyUI 工作流的执行轨迹蒸馏成可检索、可组合、可用语言反馈定点修正的符号概念，让视觉生成 agent 不更新任何参数也能跨任务累积经验。

所属教程：智能体视频生成

§ 1 — 研究问题与重要性 ​

视觉生成 agent 每接一个新任务都从零规划：读文档、拼 pipeline、试错、重试，上次调通的方案下次用不上。作者称之为 perpetual novice 问题——系统缺少把经验结构化为可复用知识的机制，因此组合泛化差、知识留存低、推理开销高。企业场景尤其贵：个性化工作流无法靠通用模型覆盖，而把全部文档塞进 context 既昂贵又放大幻觉。目标是让 agent 不做任何梯度微调也能持续变强。

§ 2 — 前人工作与不足 ​

统一多模态模型（GPT-Image-1、BAGEL、Janus 系列）端到端质量强，但知识只以参数形式静态存在，部署后无法累积。工作流自动化（WorkflowLLM、AFlow、ComfyAgent、ComfyGPT）能把目标翻译成可执行 DAG，但架构刚性、领域覆盖有限、存在级联错误传播。通用 agent 框架（AutoGen、ReAct、Reflexion）支持迭代精化，作者点名它们缺乏可靠的错误诊断与恢复机制：语言反馈只作用于当前 episode 的短期记忆，任务结束即丢失。要做长期符号记忆，必须先回答「什么算可复用单元、怎么检索、错了怎么删」，而这需要把工作流形式化成有语法的对象。

§ 3 — 重建作者的思考路径 ​

从既有事实出发：ComfyUI 工作流本身就是序列化成 JSON 的节点 DAG，天然是符号对象。同一批节点组合在不同任务里反复出现，这是模式不是实例。于是把成功的 DAG 抽象成带参数槽的模板、配一句描述用于语义检索，规划就从零生成 JSON 变成在文法里做推导。模板不能靠人写，只能从执行轨迹归纳；归纳需要成功与否的信号，失败时还需知道改哪一条——Reflexion 的语言反馈与 TextGrad 的文本梯度由此接入。

§ 4 — 核心 Intuition ​

先前方法把知识放错了地方：要么在参数里改不动，要么在 context 里用完即丢。SymbOmni 把知识放进一个可增删改的外部符号库，每条是「描述 + 参数化工作流模板 + 已调好的参数 + 历史效用分」。于是规划从生成解退化成组合已验证构件，学习从反向传播梯度变成用语言定位该改哪条概念。

§ 5 — 具体方法与完整 Pipeline ​

以「把红车改成绿车并扩展画布」为例，循环分四相。Transduction 把指令分解为带依赖的子任务，两级级联检索——先按描述 embedding 余弦相似度召回，再按依赖约束过滤，最后按效用分排序，LLM planner（实验用 Gemini 2.5 Flash）据此实例化候选工作流。Execution 逐步调用工具并记录完整轨迹。Induction 由 Evaluation Agent 给二值判定：成功则符号化入库；失败则两个互补验证器分工，硬验证器查语法与流程正确性、软验证器查语义质量，LLM 把两者合成结构化语言损失。Memory Optimization 对比检索到的概念与实际轨迹执行 add / update / delete，失败轨迹存为负概念或参数修正。系统另打包成 ComfyUI-SymbOmni 插件，去掉原 Copilot 的闭源后端依赖。

§ 6 — 核心数学推导 ​

符号概念是四元组 Ck​=(Desck​,SWIk​,Paramsk​,Scorek​)，SWIk​ 是参数化工作流模板。全部概念构成的 Concept Box 被形式化为语言系统 L=(Σ,R)，Σ={Desck​} 是语义基元词表，R={SWIk​} 是合法组合的产生式规则。这是最关键的形式化：规划被重述为在 L 中的一次文法推导，把开放式生成压成受限搜索。检索与失败时的更新分别为

Cret​=Rank∘Filterstruct​∘Retrievesem​(ST,CB),CB←Refine(CB,Replay(τ,∇sym​))

∇sym​ 是「符号梯度」，由链式归因定位到该修改的条目。需说清楚：这里没有任何真实微分，∇ 只是类比记号，可靠性完全由 LLM 的归因能力决定而非由数学性质保证。

§ 7 — 实验设计与结论 ​

符号记忆能否提高成功率？ ComfyBench（200 任务）上 100% pass、86.0% 总 resolve；complex 从 75.0% 升到 83.3%，creative 从 42.5% 升到 67.5%。相同工具配置下换 Nano Banana 后 91.0% vs ComfyMind 84.0%——这条对照关键，它把增益归给概念学习而非底层生成模型。正文声称 GenEval overall 0.98（ComfyMind 0.90、GPT-Image-1 0.84），ReasonEdit 9.190 vs 8.135；需注意 HTML 版表 2 的数值排布与正文不一致，此处以正文为准。

记忆是省钱还是费钱？ 去掉记忆检索后，ReasonEdit 上总 token 从 14,361 涨到 21,727（+33.9%），每例 API 请求从 7.25 涨到 9.85。

学到的是模式还是实例？ 用 147 个社区野生工作流单独建库并完全替换原库，ComfyBench 总 resolve 从 67.0% 升到 75.0%；offline 模式不给任何文档仅靠积累的概念，在 complex 分片上 70.0% 超过有完整文档的 ComfyMind 的 66.7%。另有 63 人 1,197 次盲测，对 Nano Banana 偏好率 59.2%、对 ComfyMind 65.9%。

§ 8 — Take-aways ​

5 句话版：视觉生成 agent 的真问题不是单次质量而是经验无法累积。SymbOmni 把成功轨迹抽象成带参数槽的符号工作流指令存入可编辑的 Concept Box。规划因此从生成退化为文法推导，失败时用语言反馈定位到具体概念修正。全程不更新参数，却把 creative 任务 resolve rate 从 42.5% 提到 67.5%，同时省掉三分之一 token。概念能跨分布迁移：野生工作流学到的概念迁到 benchmark 仍有 +8.0 增益。

3 句话版：把经验形式化为「描述 + 模板 + 参数 + 效用分」的符号概念，用归纳-演绎循环持续扩充。规划变成组合已验证构件，失败由双验证器诊断并做符号级修正。不改参数即可持续学习且省 token。

1 句话版：用可增删改的外部符号工作流库替代参数微调，实现视觉生成 agent 的持续学习。

§ 9 — 最脆弱的假设 ​

整个循环的唯一学习信号来自 Evaluation Agent 的二值判定。它不成立的代价是灾难性的：错误的成功判定会把坏工作流写进 CB，而 CB 又会被检索复用，错误被放大而非稀释。论文在附录 0.H 承认了记忆污染风险，应对是 add/update/delete 与 verbalized backpropagation，但这是机制性论证而非实证证据：全文未报告 judge 与人工标注的一致率，也没做「注入错误概念看能否自愈」的对照。附录 0.G 的一个数字值得警惕——基线检索得分只有 2.9/5.0，合并多域概念后才升到 3.3/5.0，说明喂给 planner 的概念平均质量并不高。此外官方评测同样由 LLM judge 完成，优化目标与评价指标共享同一类判别器，这一自洽性风险论文未讨论。

§ 10 — 最小复现实验 ​

一周内的最小验证不需要整个系统：取 ComfyBench 的 60 个 complex 任务，实现只有「描述 + 模板 + 参数」三元组的极简概念库；用任意 LLM 做 planner，只实现 Transduction 与「成功即入库」的最简 Induction，不实现语言反馈；对照组禁用检索；测量 resolve rate、每例 token 与尝试次数，按任务顺序画学习曲线。判定标准：若开启记忆后 resolve 提升且 token 单调下降，说明符号复用本身就是主要增益来源；若两组曲线重合，则增益更可能来自失败诊断而非记忆检索。

§ 11 — 最强反例设计 ​

最有力的攻击是给出替代解释：增益可能主要来自 prompt 里多了几个高质量 in-context 示例，与「符号」「持续学习」无关。对照是构造静态基线——把演化结束后的 CB 冻结、去掉全部归纳与增删改逻辑、仅保留检索与实例化，作为纯 RAG 系统评测；若它与完整 SymbOmni 接近，自演化这一核心卖点就没被实验支撑。

第二个攻击面是可预测的失败条件：检索基于描述 embedding 相似度，当两个任务描述相近但所需结构截然不同时（如「移除物体」与「移除物体后补全背景纹理」），系统会稳定召回错误概念且因效用分高被排在前面。构造 20 个近义歧义对，预测表现会低于无记忆基线，即负迁移；论文未报告任何负迁移案例。

§ 12 — Follow-up Research Idea ​

驱动局限：概念库只增不减地长，靠 LLM 自己判断该删谁，把知识库的健康托付给一个没有校准的判别器。

新 framing：把 Concept Box 当作需要被主动实验验证的科学假设集合而非被动经验日志。可借鉴主动学习与 bandit：每条概念带后验分布而非标量效用分，系统在低置信度概念上主动安排探针任务，把检索从 exploit-only 变成 explore-exploit。这改变的是知识的认识论地位——从记录变成可证伪假设。

第一个实验：给每条概念维护 Beta 后验、用 Thompson sampling 选概念，每完成 k 个任务挑后验方差最大的概念合成最小任务去测量，对照贪心 Rank。核心观测量不是最终 resolve rate，而是概念效用估计的校准误差随任务数的下降速度，以及注入 10 个人工坏概念后两者的清除时间。

Robust Bimanual Vision-Language-Action Models via Embarrassingly Simple Modality Masking ​

项内容
arXiv2608.22419
提交日期2026-08-23（v1，35 页 / 22 图 / 9 表）
作者Dongzhou Cheng, Ziang Li, Yixiao Zhou, Haojuan Li, Jinghao Zhang, Lei Lei, Minjing Dong, Jie Gui, Jiaqi Wang（上海创智学院、武大、浙大、上交、中科大、港城大、东南大学）
分类cs.RO, cs.CV
一句话训练时按结构化规则随机掩掉「双腕视角 / 语言 / 部分 action query」这三组 token（始终保留 egocentric 视角），不改架构、不加参数、不做机器人预训练，把 query-based 双臂 VLA 在 RoboTwin 2.0 上的平均成功率从 41.0% 抬到 62.7%。

所属教程：视觉语言动作模型 VLA

§ 1 — 研究问题与重要性 ​

Query-based VLA（OpenVLA-OFT、VLA-Adapter 这一路）用一组并行的 learnable query 在单次前向里解码出整段 action chunk，没有自回归解码也没有扩散去噪的迭代，延迟低到可以真的跑双臂实时控制。这是它相对 π0​、RDT 这类 flow/diffusion 方案的全部卖点。

问题是：把它放到双臂任务上，动作会抖。论文观察到的现象是轨迹在接触区附近出现不连续，长程任务尤其严重——Handover Block 这种需要左臂抓、交接、右臂放的任务，VLA-Adapter 基线只有 27% 成功率。作者把这个失败模式和一个可视化现象绑在一起：失败 rollout 里，模型的 attention 会散到与当前动作无关的图像区域上，而不是集中在目标物体和接触点。

为什么这在双臂场景才明显？论文给了一个具体机制：单臂平台上腕部相机基本跟着执行手走，各视角的视觉证据不太竞争；双臂平台上闲置那条臂的腕相机会持续提供高显著度但与当前子步骤无关的画面，构成一种单臂设置里不存在的 cross-view 干扰。

这个问题值得解决的理由是成本结构：如果修复它需要大规模机器人预训练，那 query-based VLA 的效率优势就没了。论文的答案是不需要——只改训练时的 attention mask。

§ 2 — 前人工作与不足 ​

自回归 VLA（RT-2、OpenVLA）把连续动作离散成 language token 逐个预测，量化误差在精细操作上会累积；扩散/流匹配 VLA（Diffusion Policy、π0​、RDT-1B）直接在连续动作空间迭代去噪，精度好但推理成本高，且 π0​ 与 RDT 都依赖百万级跨形态轨迹预训练才能拿到泛化。论文在 RoboTwin 2.0 的 Clean 设定下实测这两个预训练模型分别只有 39.5% 和 30.2%，低于没有做机器人预训练的 VLA-Adapter（41.0%）——这个对比本身就说明预训练规模不是这个 benchmark 上的决定因素。

query-based 路线（ACT 的 DETR 式 decoder、OpenVLA-OFT 的 parallel decoding、VLA-Adapter 的 0.5B 骨干 + bridge attention）拿到了效率，但作者指出它在双臂设置下几乎没被认真研究过。

正则化路线才是最直接的对照。Dropout、layer dropout、attention dropout、以及多模态融合里的 modality dropout 都早就存在。论文的 Table 4(b) 明确把它们跑成 baseline：token dropout 31.8%、modality dropout 24.1%、visual augmentation 22.3%、region augmentation 23.0%，而完整 M3 是 64.0%（三任务平均）。通用 dropout 不够是本文最实的一条实证结论——它把「随便掉点东西」和「按双臂几何结构掉东西」区分开了。

§ 3 — 重建作者的思考路径 ​

站在这篇之前能看到的事实：(a) 双臂 VLA 在长程任务上掉链子；(b) 失败时 attention 图是散的；(c) 部分可观测决策（POMDP）文献里有一条老经验——如果训练时策略永远能看到全部信息，它就学不会区分哪些信息在测试时仍然可靠。

把 (b) 和 (c) 接起来，很自然的猜想是：全视角始终可见的训练方式，让模型有机会去拟合跨视角的偶然相关（比如「闲置臂视野里那块高对比边缘出现时，通常正好该合爪」），这种相关在干净演示里成立，一旦换背景、加干扰物就断掉。于是训练时随机遮住一部分视角，逼它只用稳定证据。

但直接随机 dropout 会踩到双臂特有的坑，作者显然是试过才写出三条 guideline：

  • 如果把 egocentric 全局视角也掩掉，只剩腕相机，很多任务里放置目标根本不在腕视野内，任务变得不可解——消融给出 37.0% vs 64.0%。
  • 如果左右腕独立掩，只掩一个时模型仍可用剩下那个腕视角去和 ego 做显著度匹配，捷径没被切断——消融给出 32.7%。
  • 如果把 action query 全掩，任务不可解；掩太狠也会掉（ratio 0.9 时 43.7%）。

于是三条规则的形状就被逼出来了：ego 恒可见、双腕联合掩、query 只掩子集且至少留一个。

§ 4 — 核心 Intuition ​

多视角双臂 VLA 学到的不是「哪个视角在这一刻可靠」，而是「所有视角一起出现时的联合模式」，其中混着大量只在干净演示里成立的巧合相关。把双腕视角作为一个整体随机拿掉、同时永远保留 egocentric 这个稳定的全局参照系，就等于在训练里反复问模型一个问题：只靠全局帧你能不能把任务几何算出来。能算出来之后，腕视角就只在提供非冗余的局部信息时才被使用，而不是被无差别地融合进来。

§ 5 — 具体方法与完整 Pipeline ​

以 Handover Block（左臂抓红块 → 交接 → 右臂放到蓝垫）为例走一遍。

输入：三路 RGB（egocentric Vego、左腕 VL、右腕 VR）、语言指令 token T、Nq​ 个 learnable action query Q，外加本体感觉。骨干是 Prismatic VLM（Qwen2.5-0.5B 语言模型 + DINOv2/SigLIP 混合视觉编码器），action expert 沿用 VLA-Adapter 的逐层 bridge attention。

训练时的 M3 采样：每个训练 step 采三个伯努利变量——uv​ 决定这一步左右腕视角是否一起被掩，uℓ​ 决定语言整体是否被掩，uq​∈{0,1}Nq​ 逐元素采样并强制 ∥uq​∥1​≥1。ego 的 token 恒为可见。由此拼出可见性指示向量 m，再构造一个方阵加性 mask：只有当行列两端 token 都可见时才允许 attend，否则置 −∞。这个 mask 与原有 causal mask 逐元素相加后进 scaled dot-product attention。

query rescaling：被保留的 query embedding 乘 1/(1−pq​)，保持期望能量不变，作用等价于 query 维度上的 inverted dropout。

损失：完全不变，还是对 masked 输入下预测出的 action chunk 做 ℓ1​ 回归。

推理时：mask 全部关掉，三路视角与完整 query 一起进模型，架构、参数量、延迟与基线完全一致。也就是说 M3 的全部代价只发生在训练阶段。

训练配置：AdamW，lr 2e−4，10k steps，5k 处 MultiStep 衰减 ×0.1，LoRA rank 64，global batch 48（4 张 H100，每卡 12），action chunk 25 步；评测在单张 RTX 4090 上。

§ 6 — 核心数学推导 ​

M3 的形式化只有三步，但每一步都对应一条工程决策。

第一步是可见性向量。设 Sego​,Swrist​,Slang​,Sq​ 是四组 token 的下标集合，则

mi​=⎩⎨⎧​1,uv​,uℓ​,uq​(i′),​i∈Sego​,i∈Swrist​,i∈Slang​,i∈Sq​.​

注意 Swrist​ 共用同一个 uv​，这就是 guideline 2「双腕联合掩」的全部数学内容——左右腕不是两个独立开关，而是一个。

第二步是把「掩」翻译成 attention。一个被掩的 token 既不该看别人也不该被别人看到，所以需要同时屏蔽行和列：

M~xy​={0,−∞,​mx​=1 且 my​=1,otherwise.​

Attn=softmax(d​QK⊤​+Mc​+M~)V

其中 Mc​ 是原有的 causal mask。这种写法的好处是 embedding 一个都不动，掩码纯粹作用在注意力权重上，因此不需要为「缺失模态」准备任何占位符或专门的 embedding。

第三步是 query rescaling：对可见的 query，q~​i​=1−pq​1​qi​。这是标准 inverted dropout 的期望保持技巧，作用是让训练与推理（不掩）时的特征尺度一致。

训练目标不变：LM3​(θ)=∥gθ​(VtM3​,TtM3​,QtM3​)−A^t​∥1​。整套方法没有新增任何可学习参数，这是「embarrassingly simple」这个标题的字面含义。

§ 7 — 实验设计与结论 ​

问题一：结构化掩码在干净分布内有用吗？ 设计：RoboTwin 2.0 选 10 个双臂任务（按平均步数分短/中/长程，62–592 步不等），每任务 50 条干净演示训练、100 个 held-out 干净场景评测。答案：整体 41.0% → 62.7%（+21.7）。增益集中在长程：长程平均 33.7% → 61.0%，Handover Block 27% → 74%。同表里 RDT 30.2、π0​ 39.5、ACT 25.9、DP 25.5，都低于 M3。

问题二：能不能扛分布迁移？ 设计：Clean2Rand——同样用干净演示训练，但在换背景、换光照、加干扰物的随机场景上评测。答案：3.7% → 15.1%（+11.4），是所有方法里最高的，但绝对值仍然很低。作者对此的表述值得原样引用：目标是缩小这个 gap 而不是关闭它。Block Rank Size 在所有方法上都是 0，作者归因于该任务需要细粒度尺寸关系推理。

问题三：真机上成立吗？ 设计：Agilex Cobot 三个 800 步以上的长程任务（瓶子丢弃含臂间交接、碗堆叠上架、蔬菜装盘并居中），每任务 50 条演示；三轮重复，每轮 16 次 clean + 8 次 OOD，且每轮对应试次使用相同的场景布局（含干扰物摆放）。答案：clean 44.4% → 69.4%，OOD 12.5% → 61.1%。OOD 上基线的崩塌幅度远大于 M3。

问题四：换骨干还成立吗？ 把 M3 搬到 OpenVLA-OFT（7B、parallel decoding、双向 attention，与 VLA-Adapter 结构不同），Clean 设定下 32.2% → 53.5%（+21.3）。

问题五：增益来自哪个部件？ 组件消融（三任务平均）：无掩 23.7，仅语言 29.0，仅视觉 34.0，仅 query 33.3，视觉+语言 36.7，视觉+query 60.3，全量 64.0。结论很清楚：主增益来自视觉掩码与 query 掩码的耦合，语言掩码只贡献最后 3.7 个点。视角级消融：掩 ego 37.0、掩单腕 32.7、掩双腕 64.0。query 比例：0.1 最优（64.0），0.9 掉到 43.7。

§ 8 — Take-aways ​

5 句话版：query-based VLA 在双臂任务上的失败常伴随 attention 扩散到无关区域；作者假设根因是训练时全视角始终可见，模型因此学到跨视角的偶然相关；M3 在训练时按三条双臂专用规则随机掩模态（ego 恒留、双腕联合掩、query 掩子集），推理时完全关闭；RoboTwin 2.0 上 Clean 41.0→62.7、Clean2Rand 3.7→15.1，真机 clean +25.0、OOD +48.6，换到 OpenVLA-OFT 骨干仍 +21.3；通用 token dropout / modality dropout / 视觉增广在同一协议下只有 31.8/24.1/22.3，说明起作用的是结构而不是「随机丢东西」这个动作本身。

3 句话版：把双腕视角当成一个整体随机掩掉、同时永远保留 egocentric 作为稳定参照，能逼双臂 VLA 学会「什么时候腕视角才真的有用」。这是纯训练期干预，零额外参数、零推理开销。主增益来自视觉掩码 × query 掩码的耦合，单独任何一项都不够。

1 句话版：双臂 VLA 的多视角融合是靠不住的捷径，训练时按几何结构结构化地关掉它，比加任何模块都便宜有效。

§ 9 — 最脆弱的假设 ​

最要命的一条是：egocentric 视角是一个稳定可靠的全局空间参照。整套 M3 建立在「掩腕视角、留 ego」的不对称上，guideline 1 的消融（掩 ego 37.0 vs 掩双腕 64.0）恰恰证明了这种不对称有多陡——一旦把参照系搞错，方法的收益立刻反号。

这个假设在实践中很容易不成立。移动操作平台上 ego 相机装在会动的躯干或头上；人形机器人做 whole-body 动作时 ego 视角本身在剧烈变化；很多产线工位根本没有第三人称相机，只有腕相机。论文的两个平台（RoboTwin 2.0 仿真、Agilex Cobot 真机）都是固定底座 + 固定第三人称相机的桌面构型，ego 的「稳定」是平台给的，不是方法保证的。

论文为此提供的证据是消融和 attention 可视化，缺的证据是：没有在 ego 视角本身受扰（相机移动、ego 被遮挡）的条件下测过。此外 Appendix B.1 的 attention-misalignment 分析是post-hoc 统计相关——它证明的是「不连续轨迹伴随更高的 prompt-无关注意力质量」，不是「注意力扩散导致了失败」。因果方向在论文里没有被实验隔离，作者的措辞（"consistent with"、"may"）也相当克制。

还有一个口径问题需要读者自己注意：仿真结果按 RoboTwin 官方协议报的是单次运行，没有多 seed、没有误差棒。100 个 episode 上的二项标准差约 5 个百分点，所以像 Stack Blocks Two 的 +5、Block Rank Size 的 +14 这类小增益，单看一次运行是读不出显著性的；真正扛得住噪声的是 +21.7 这种量级的总体差距和 Handover Block 的 +47。

§ 10 — 最小复现实验 ​

一周，不需要真机，也不需要跑满 10 个任务。

  1. 拿 VLA-Adapter 官方 pro 配置 + RoboTwin 2.0 的三个任务（Place Phone Stand / Place Shoe / Handover Block，正好是论文消融用的三个），各 50 条干净演示，10k step。这是 23.7% 的基线。
  2. 在 attention 里加上 §6 那个加性 mask，只做视觉部分：分别跑「掩双腕」「掩单腕」「掩 ego」三档。
  3. 加上 query 掩码（ratio 0.1）与 rescaling，跑「V+Q」。
  4. 每档跑 3 个 seed，每 seed 100 个 held-out 场景，报均值与标准差。

判据：若「掩双腕 + query」在三 seed 上的均值显著高于「掩单腕 + query」，则 guideline 2 成立；若三档差异落在 seed 方差里，说明论文的单次运行结果不可靠。这一步的成本是论文全量实验的约 1/10，却能验证它最核心的一条结构主张。

§ 11 — 最强反例设计 ​

论文缺一个关键对照组：永久去掉腕视角的 ego-only 策略。

Table 3(a) 有「掩 ego」，有「掩单腕」，有「掩双腕」，唯独没有「训练和推理都只用 ego，一路腕视角都不给」。这个缺口很致命，因为它对应一个完全不同的替代解释：也许在 RoboTwin 2.0 这十个任务上，腕视角本来就是净有害的（闲置臂的干扰 > 局部细节的收益），M3 的增益不是来自「结构化部分可观测训练」，而只是来自「把有害输入的权重压下去」。如果 ego-only 策略本身就能打到 55–60%，那 M3 相对 62.7% 的边际贡献就小得多，而「学会何时使用腕视角」这个叙事也就没有实验支撑。

配套的第二个攻击点是数据规模。M3 只在每任务 50 条演示的极小样本区间被验证过，而 dropout 类正则化的典型行为是收益随数据量单调衰减。把演示数扫成 50 / 150 / 500，若 M3 与基线的差距在 500 条时收敛到个位数，那结论应该改写成「小样本双臂微调的有效正则化」，而不是关于多视角融合本质的论断。

第三点是平凡基线缺位。RoboTwin 2.0 的 Click Bell 在多个方法上都能到 80–98%，这类任务应该报「静止不动 / 重复上一动作 / 输出训练集动作均值」的得分，否则读者无法判断 84% 与 97% 之间的差距有多少是真本事。论文没有报这组数字。相对地，Clean2Rand 那一栏（DP 全 0、Adapter 3.7）反倒是可信的——分数低到不可能被平凡策略刷出来。

§ 12 — Follow-up Research Idea ​

驱动局限：M3 的掩码分布是手工设计且固定的（三条 guideline + 一组固定的伯努利概率），它编码的是作者对双臂几何的先验。换一个形态（人形、移动底盘、多指手、加触觉），这套先验就得重新猜一遍，而猜错的代价在 Table 3(a) 里已经量化过了（37.0 vs 64.0）。

新 framing：不要把可见性当超参，把它当成一个可学习的、与策略对抗的信息瓶颈。相邻领域现成的工具是特征归因里的 learned masking（把 mask 参数化成一个可微的伯努利/Concrete 分布），以及 information bottleneck 里对每路输入的率约束——目标从「按人写的规则掩」变成「在总信息预算 β 下，自动分配每路视角/每个 query 的可用带宽，使策略损失最小」。这样掩码分布会随任务阶段变化：接触前多给 ego，接触中多给腕。

第一个实验：在 VLA-Adapter 上把 uv​,uℓ​,uq​ 换成 Concrete 分布的可学参数，加一项对期望可见率的 KL 惩罚，在 Place Phone Stand / Place Shoe / Handover Block 上训练，然后画出学到的 pv​(t) 随 rollout 时间的曲线。判据有两条：(1) 学到的策略是否自动复现「ego 恒留、双腕同掩」这两条人工 guideline——若复现，说明这些规则是任务结构的必然产物而非作者的运气；(2) 学到的可见率是否随接触阶段变化——若变化，说明固定概率的 M3 还有明确的剩余空间，且这个空间可以在不加推理开销的前提下拿到。

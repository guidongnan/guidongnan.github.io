DeforM: Reasoning-Guided Physics-Aware Video Generation via Spatial-Temporal Masking ​

项内容
arXiv2607.18664
提交日期2026-07-21
作者Yunyi Li, Yu Qiao, Yaohui Wang, Xinyuan Chen
分类cs.CV
一句话先用 VLM 推理出提示中会发生形变的物体、经开放词表检测器落成时空掩码，再把掩码分别以「放大掩码内 cross-attention query」（免训练）或「向 self-attention 的 K/V 与 cross-attention 的 Q 注入学习到的偏移」（训练）的方式，把模型注意力钉在物理关键区域上。

所属教程：物理感知视频生成

说明

本文为 arXiv v1（2026-07-21），上海人工智能实验室。项目页 nemosunny.github.io/DeforM-ProjectPage。基座为 Wan2.2-TI2V-5B。

§ 1 — 研究问题与重要性 ​

刚体运动可以用显式轨迹或公式描述：抛物线、碰撞后的速度、绕轴旋转。形变动力学不行——熔化、挤压、断裂、拉伸、切片都是高维变换，写不成一条轨迹，也没有几个参数能概括。这正是当前物理感知视频生成里被绕开的一块。

作者给出的诊断很具体，也是全文的起点：模型缺的不是「物理知识」，而是知道该把物理用在哪里。他们可视化了关键词 melting 的 cross-attention 图，发现注意力信号弥散在整帧上，于是无关区域稀释了模型的注意力，熔化效果被画到了不该熔化的地方。这是一个语义-空间鸿沟——文本里的物理指令与图像里的具体像素之间没有建立绑定。

问题的价值在于：形变几乎覆盖了日常物理里最难仿真的那一半（软体、流变、破碎）。如果生成模型能可靠地演这些，它作为世界模型的适用面会显著扩大；而如果只能演刚体碰撞和自由落体，它在具身场景里的用处相当有限。

§ 2 — 前人工作与不足 ​

作者按「物理信息从哪来」把前人分成三类，批评是逐类给出的。

仿真器路线（PhysGen、PhysMotion、WonderPlay）：物理正确性有保证，但需要显式场景重建和复杂资产构建，流水线长、效率低，扩展到多样真实环境很受限。

数据驱动/奖励路线（WISA、PISA、Force Prompting 学物理先验；PhysRVG、PhysHPO 用强化学习）：不需要重建，但受制于物理数据多样性有限，且依赖精心设计的奖励函数，容易 reward hacking。

VLM 引导路线（VLIPP、PhyRPR）：用 VLM 规划物体轨迹，training-free 地引导生成。这一路最接近本文，但作者指出其结构性限制——依赖轨迹框或简单公式，就必然只能覆盖刚体运动（碰撞、自由落体），因为形变根本无法被一串 bounding box 的位移表达。

第四条隐含批评针对生成模型本身：它们主要在做视觉模式合成，缺乏理解复杂场景物理动态所需的显式推理能力。这解释了「为什么 X 一直没被考虑」——不是没人想做形变，而是在 VLM 推理能力成熟之前，没有廉价手段把「哪块区域会形变」这个知识注入生成过程。

§ 3 — 重建作者的思考路径 ​

从已有观察出发。第一个观察来自 VLIPP 一路的成功与边界：VLM 确实能为生成提供有用的物理先验，但它输出的形式（轨迹框）限定了能表达什么。第二个观察来自扩散模型可解释性文献：cross-attention 图是文本 token 与空间位置绑定关系的直接读数，且这个绑定是可以被干预的（prompt-to-prompt 一类工作已经证明改 attention 就能改内容）。

把两者接起来：如果 VLM 的输出不再是「物体走什么轨迹」，而只是「哪个物体、哪块区域会发生形变」，那么它就绕开了「形变无法参数化」的死结——因为位置是低维的，形变本身不需要被描述，只要交给生成模型在正确的地方去发挥。

接下来是一个实验驱动的分叉。作者先做了最轻的干预：只放大掩码内 cross-attention 的 query 幅度，不动任何权重。如果这就能改善物理一致性，那么「注意力弥散是主因」这个诊断就被验证了。他们观察到确实有效（attention 图重新聚焦，蜡烛在边界内正确熔化），于是这个 training-free 版本被保留下来作为机制分析工具。但它有一个明确的天花板：如果基座模型内部根本没有某类形变的表示，放大注意力只会放大伪影。这就自然导出了训练版本——不是放大已有的注意力，而是把掩码编码成高维特征注入进去，让模型学出新的局部物理关联。

§ 4 — 核心 Intuition ​

形变没法写成公式或轨迹，但「哪里会形变」可以。模型失败的原因不是不知道熔化是什么，而是不知道该把熔化用在哪块像素上——cross-attention 对关键词 melting 的响应弥散在整帧，于是生成能力被无关区域稀释。把注意力钉在物理关键区域上，物理一致性就跟着回来了；这一点用一行 training-free 的 query 缩放就能验证，而要突破基座知识的上限，则需要把掩码作为可学习特征注入。

§ 5 — 具体方法与完整 Pipeline ​

以「蜡烛熔化」为例：

  1. DeforM-Reason（推理与接地）：Qwen2.5-VL-7B 读入首帧与文本提示，推理出最可能发生形变的目标物体 Otarget​（这里是蜡烛本体而非烛台或背景）。接着 LLMDet（开放词表检测器）做空间接地。训练与推理在这一步的行为不同：训练时用真值视频序列，检测器在全部 T 帧上定位目标，得到精确的框序列 {Bi​}i=1T​；推理时未来帧不存在，检测器只在首帧得到 B1​，再由 VLM 按提示描述的形变做时间外推，规划出 {Bi​}i=2T​。框内置 1 得到二值掩码 M∈{0,1}T×H×W，下采样对齐到 latent 形状 (T′,H′,W′)。
  2. DeforM-Free（免训练）：把掩码展平插值成与 latent 序列长度 S=T′×H′×W′ 对齐的 M^，在 cross-attention 里按 Q~​j​=Qj​⋅[1+M^j​(α−1)] 缩放掩码内 token 的 query，α=1.4。不改任何预训练权重。
  3. DeforM-Injection（训练版）：Dense Mask Modulator Fϕ​ 用一串 3D 卷积把二值掩码编码成三路解耦调制流 Δkself​,Δvself​,Δqcross​，最后的线性层零初始化以保证训练稳定、不破坏基座能力。self-attention 的 K/V 与 cross-attention 的 Q 分别加上对应偏移。分工是明确的：cross-attention 的 Q 决定「掩码区域向文本索取多少物理信息」，self-attention 的 K/V 决定「掩码区域内部的时空一致性」。
  4. 训练目标：在标准 flow matching 损失之外加一个区域敏感损失，Ltotal​=(1−λmask​)Lflow​+λmask​Lmask​，λmask​=0.3。同时优化 modulator 与骨干上的 LoRA（rank 256），batch 64，LoRA lr 1×10−6、modulator lr 2×10−6。
  5. 数据：从 WISA-80K 的 melting 与 deformation 子集出发，用 Qwen2.5-VL-7B 按文本-视频对齐、形变显著性、视觉质量三个维度 1–5 打分（每秒采 3 帧），任一维度 ≤2 的送人工复核并剔除。最终 6,322 条高质量样本，约 6k 训练、320 评测（其中随机 160 条用于物理一致性评测）。

§ 6 — 核心数学推导 ​

基座的 flow matching。 视频经编码器映为 latent z0​=E(x)，采用 Optimal Transport 路径

zt​=(1−t)z0​+tz1​,z1​∼N(0,I),

模型回归真值速度 ut​=z1​−z0​：

L(θ)=Ez0​,z1​,t,c​​vθ​(zt​,t,c)−(z1​−z0​)​2.

推理是从 t=1 积分到 t=0 的 ODE 求解。

query 缩放为什么能放大注意力。 DeforM-Free 的核心是式 (5)：

Q~​j​=Qj​⋅[1+M^j​(α−1)],α>1.

注意 attention 分数是 Softmax(Q~​K⊤/d​)V，且 softmax 沿文本 token 维归一化。因此把某个空间位置 j 的 query 整体乘以 α，等价于把该位置的 logits 向量整体乘以 α，也就是把该位置的注意力分布降温（temperature 从 1 变成 1/α）。效果是该位置对它本来就最相关的那个文本 token（这里是 melting）的权重被锐化，对其余 token 的权重被压低。这解释了为什么一个纯乘法就能「重新聚焦」：它不是凭空增加注意力总量（softmax 归一化后总量恒为 1），而是让掩码内位置的语义选择变得更果断，同时掩码外位置保持原样。α=1.4 是一个温和的降温，作者称是为了在引导精度与生成质量之间取平衡——过大的 α 会把分布压成 one-hot，反而破坏多 token 的语义组合。

注入版的加性形式。 式 (6) 是纯加性偏移

Kself′​=Kself​+Δkself​,Vself′​=Vself​+Δvself​,Qcross′​=Qcross​+Δqcross​,

三者均由 Fϕ​(M) 产生。与乘法缩放的区别在表达能力：乘法只能改变已有分布的锐度，加法可以引入原本不存在的方向，因此有可能超出基座知识的上限——这正是作者从 Free 走向 Injection 的理由。零初始化最后一层保证训练初期 Δ≈0，模型从基座行为出发平滑演化。

§ 7 — 实验设计与结论 ​

评测设计：视觉质量用 VBench，但剔除 subject consistency 与 background consistency——理由是形变过程中前景物体本来就要发生剧烈结构变化并可能影响背景，这两项天然被压低。保留六项：temporal flickering、motion smoothness、dynamic degree、aesthetic quality、imaging quality 与 quality score。物理一致性用 Qwen3-VL-32B 按 1–5 分打三个维度：PC（整段视频的物理常识）、SA（是否遵循文本指令）、LDF（局部形变的准确性与真实感），Physical Score 取三者算术平均。

问题一：相对开源 SOTA 如何？ 表 1：CogVideoX1.5-I2V 98.25 / 98.84 / 48.32 / 45.68 / 65.92 / 71.40，PC 4.07 / SA 3.62 / LDF 3.24 / 3.64；Hunyuan-I2V 99.30 / 99.54 / 27.74 / 46.15 / 64.80 / 67.50，3.86 / 3.34 / 3.01 / 3.40；Wan2.2-I2V-14B 97.42 / 98.34 / 46.07 / 46.61 / 67.47 / 71.18，4.28 / 3.91 / 3.65 / 3.95；MAGI-1 99.09 / 99.41 / 28.03 / 45.97 / 63.79 / 67.26，3.93 / 3.39 / 3.01 / 3.44；DeforM-Injection 97.24 / 98.40 / 54.74 / 46.61 / 68.84 / 73.17，PC 4.59 / SA 4.46 / LDF 4.16 / 4.40。

需要如实指出：DeforM 的 temporal flickering 是全表最低（97.24），motion smoothness 也只排倒数第二（98.40，仅高于 Wan2.2-14B 的 98.34）。作者的解释是 Hunyuan-I2V 与 MAGI-1 这类高平滑度模型倾向于生成近乎静止的画面（dynamic degree 只有 27.74 与 28.03），这个解释与数据一致且合理，但它同时意味着 dynamic degree 与 flickering/smoothness 在本设定下是强负相关的，单看某一项没有意义。另外 aesthetic quality 一项 DeforM 的 46.61 与 Wan2.2-I2V-14B 完全相同，并非优势。

问题二：各组件贡献多少？ 表 2：Vanilla Wan2.2（5B 基座）98.12 / 98.85 / 42.61 / 46.28 / 67.40 / 70.65，物理分 3.97 / 3.31 / 3.19 / 3.49；SFT（同数据、无掩码）97.71 / 98.54 / 44.77 / 45.99 / 67.65 / 70.93，4.19 / 3.69 / 3.41 / 3.76；W/O DeforM-Reason（掩码替换为随机时空掩码）97.70 / 98.62 / 47.58 / 45.60 / 67.52 / 71.40，4.22 / 3.79 / 3.45 / 3.82；DeforM-Free 97.21 / 98.27 / 51.57 / 46.47 / 66.41 / 71.99，4.28 / 3.86 / 3.53 / 3.89；DeforM-Injection 97.24 / 98.40 / 54.74 / 46.61 / 68.84 / 73.17，4.59 / 4.46 / 4.16 / 4.40。

这张表里有两条重要信息，作者只强调了其中一条。强调的一条是：DeforM-Free 在完全不训练的情况下（Physical Score 3.89）超过了 SFT（3.76），支持「注意力锚定是关键」的核心观察。未被强调的一条是：随机掩码已经拿到 3.82，与 DeforM-Free 的 3.89 只差 0.07。论文没有说明「W/O DeforM-Reason」是在 Free 还是 Injection 之上做的消融；按表格排序（位于 SFT 与 DeforM-Free 之间）更像是前者，若如此，则 VLM 推理相对随机掩码的边际贡献只有 0.07 分——也就是说增益的绝大部分来自「存在一个局部掩码去锚定注意力」这件事本身，而不是掩码画得准不准。若该行实际是 Injection 的消融（4.40→3.82），结论则相反。这个歧义足以影响对方法核心主张的判断，论文应当写清楚。

问题三：cross 与 self 各管什么？ 表 3：DeforM-Cross 97.37 / 98.43 / 53.23 / 46.42 / 67.74 / 72.64，4.42 / 4.01 / 3.83 / 4.09；DeforM-Self 97.68 / 98.62 / 53.16 / 46.50 / 68.21 / 72.83，4.22 / 3.73 / 3.33 / 3.76；完整 4.59 / 4.46 / 4.16 / 4.40。分工与作者描述一致：cross 主要拉 SA 与 PC（语义与物理常识），self 主要拉时序平滑与成像质量。但两点值得指出：DeforM-Self 的 Physical Score 3.76 与 SFT 完全相同，且 LDF 3.33 反而低于 SFT 的 3.41，说明单独注入 self-attention 对物理一致性几乎没有贡献；而两者合并后从 4.09/3.76 跳到 4.40，是明显的超加性。论文没有解释这个超加性从何而来。

用户研究：10 名参与者，与四个基线做物理一致性对比，作者称在所有维度显著领先（表 4 的具体数值在 HTML 中未渲染，此处不复述）。

§ 8 — Take-aways ​

5 句话版：形变动力学无法用轨迹或公式参数化，因此 VLIPP 一类 VLM 引导方法被结构性地限制在刚体上。DeforM 的转向是让 VLM 只回答「哪里会形变」而不回答「怎么形变」，把高维形变留给生成模型自己发挥。诊断依据是 cross-attention 对物理关键词的响应弥散全帧，导致生成能力被无关区域稀释。免训练版只用一个 query 缩放（α=1.4）就把注意力重新聚焦，并在物理分上超过同数据 SFT，验证了诊断；训练版用零初始化的 Dense Mask Modulator 向 self-attention 的 K/V 与 cross-attention 的 Q 注入偏移，配区域敏感损失。最终在 dynamic degree（54.74）与三项物理分（4.59/4.46/4.16）上全面领先，代价是 temporal flickering 全表最低。

3 句话版：把「物理该用在哪」和「物理怎么演」拆开，前者交给 VLM 与检测器，后者留给生成模型。免训练的注意力锚定就能超过 SFT，说明瓶颈是空间绑定而非物理知识。训练版进一步突破基座上限，但消融显示随机掩码已能拿到接近的物理分。

1 句话版：模型不是不懂熔化，是不知道该熔化哪儿——把注意力钉在那块像素上就行。

§ 9 — 最脆弱的假设 ​

最要命的假设是：推理阶段 VLM 对未来帧 bounding box 的时间外推，其质量足以替代训练阶段用真值视频检测出的框序列。

这条不成立的话，训练与推理之间就存在系统性分布偏移，而所有报告的推理期指标都建立在这个偏移之上。风险很具体。训练时 {Bi​}i=1T​ 来自真值视频上的逐帧检测——这是oracle 级的空间接地，框会随着物体真实的熔化、塌陷、断裂而收缩或分裂。推理时只有 B1​ 是检测出来的，B2​ 到 BT​ 全部由 VLM 「按提示描述的预期形变」想象出来。这正是本文一开始批评 VLIPP 的地方——用 bounding box 序列去描述形变——只不过 DeforM 把它降级成了「粗略的区域提示」而非「精确的运动规划」。

问题在于形变恰恰是最难用框外推的：熔化时物体高度下降、宽度扩散，断裂时一个框要变成两个，切片时目标一分为二。VLM 在没有中间视觉反馈的情况下逐帧规划这些，误差会沿时间累积。作者自己在 Limitations 里承认「DeforM 受 DeforM-Reason 定位精度限制，复杂场景下可能产生次优的时空掩码」，但全文没有任何实验量化这个偏移的大小——没有报告推理期外推框与真值框的 IoU，也没有做「推理时也用真值框」的 oracle 上界对照。这个对照成本极低（评测集有真值视频），却是判断方法能走多远的关键数字。

一个反向的证据线索是：随机掩码消融只掉 0.07 分（若该行确为 Free 的消融）。这既可以读成「方法对掩码质量鲁棒」（好消息），也可以读成「掩码精度本来就不重要，VLM 推理这一环是可有可无的」（对贡献主张不利）。两种读法都指向同一个必须补的实验。

§ 10 — 最小复现实验 ​

一周内可做，只需推理不需训练：

  • 数据：从 WISA-80K 的 melting/deformation 子集取 100 条评测样本（有真值视频）。
  • 实现：跑 DeforM-Free（基座 Wan2.2-TI2V-5B + Qwen2.5-VL-7B + LLMDet，全部开源），四种掩码条件——(a) 论文的推理期 VLM 外推框；(b) oracle：真值视频上逐帧检测的框；(c) 首帧框静态复制到所有帧；(d) 位置随机、面积匹配的框。
  • 测量：每种条件下的 Physical Score（用同一个开源 VLM 判分器）与 dynamic degree；同时报告 (a) 与 (b) 的逐帧框 IoU。
  • 判据：如果 (b) 明显高于 (a)，说明时间外推是当前的主要瓶颈，方法的天花板取决于 VLM 的形变预测能力；如果 (a)≈(b)≈(c)≈(d)，说明真正起作用的只是「有一个局部区域被降温」这件事，与掩码内容无关——这会大幅改写对 DeforM-Reason 贡献的评价。(c) 这一条尤其便宜且有力：它把 VLM 的时间规划完全去掉，只保留首帧接地。

§ 11 — 最强反例设计 ​

替代解释一：增益主要来自 6k 条领域内数据的 LoRA 微调，注意力锚定只是锦上添花。 论文在这一点上做得比多数同类工作好——表 2 有 SFT 行（同数据、无掩码）作为对照，3.49→3.76 是数据带来的，3.76→4.40 是掩码机制带来的。这个对照是有效的，替代解释一因此基本被排除。但仍有残余问题：所有基线（Hunyuan-I2V、CogVideoX1.5、Wan2.2-14B、MAGI-1）都是零样本评测，没有在这 6k 条数据上微调过，所以表 1 的对比同时包含了「领域适配」与「方法」两个因素，不能单独归因给后者。

替代解释二：物理评分器与被评对象共享偏置。 PC/SA/LDF 全部由 Qwen3-VL-32B 打分，而数据清洗用的是 Qwen2.5-VL-7B、推理模块也是 Qwen2.5-VL-7B。虽然评判器与推理器不是同一个模型，但同族模型的视觉偏好高度相关。更关键的是 LDF（局部形变保真度）这个维度是本文自定义的，且是本文优势最大的一项（4.16 vs 次优 3.65）——一个专门为「局部区域被强化」而设计的指标，自然会偏向一个「专门强化局部区域」的方法。用户研究（10 人）是必要的补充，但样本量小且表 4 数值未在 HTML 中渲染，无法核验。一个干净的检验是换一个完全不同族的评判器（如 InternVL 或 GPT 系）重跑排序，看 LDF 的优势幅度是否稳定。

可预测的失败场景：多物体同时形变，或形变物体与非形变物体在框内重叠。 掩码是轴对齐 bounding box 的并集，不是实例分割。切一个放在盘子上的番茄，框内必然包含盘子的一部分；而 query 缩放是对框内全部 token 施加的，因此盘子也会被「降温」到更强烈地响应 slicing 这个关键词。方法在这类场景下会可预测地把形变泄漏到相邻物体上。论文的定性图（图 4、图 5）全部是单主体特写场景，没有展示多物体或杂乱桌面。这既是一个具体的攻击点，也解释了为什么随机掩码消融的差距那么小——在单主体特写里，随机框有很高概率也覆盖到主体。

一处需要指出的表内异常：表 3 中 DeforM-Self 单独使用时 Physical Score 3.76 与 SFT 完全相等、LDF 3.33 还低于 SFT 的 3.41，而 Cross 单独是 4.09，两者合并却达到 4.40。若 self 注入独立贡献为零，合并后不应超过 Cross 太多。这个超加性可能来自训练配置差异（三个变体是否用同一 LoRA 预算与同样步数，论文未说明），也可能是真实的协同效应，但论文没有提供区分依据。

§ 12 — Follow-up Research Idea ​

驱动局限：DeforM 把物理先验压缩成一个二值、轴对齐、时间上由 VLM 想象的掩码。这个表示恰好卡在两个极端之间：它比轨迹框更适合形变（不需要描述怎么变），但又比真正的形变描述贫乏得多（无法表达往哪个方向塌、以多快速率、材料多硬）。结果是方法只能说「在这里发生物理」，说不出「发生什么物理」。

新 framing：把引导信号从「空间掩码」换成材料场——为每个像素预测一组连续的材料参数（杨氏模量、屈服应力、黏度、各向异性方向），由 VLM 从图像与文本联合推断，然后作为稠密条件注入生成过程。这不是「加一个模块」，而是把引导的语言从几何换成本构关系，从而与连续介质力学、可微仿真、以及材料属性估计这几个相邻领域直接对接。它同时解决了 §11 指出的失败模式：材料场天然是逐像素的，盘子与番茄会拿到不同的参数，泄漏问题自动消失。

可借鉴的相邻工具：可微 MPM 仿真（提供材料参数到形变的正演映射，可用来合成带真值参数的训练数据）；单图材料估计与 intrinsic decomposition（已有从外观反推粗糙度、金属度的成熟做法，可迁移到力学参数）；以及 ControlNet 式稠密条件注入，用来承载多通道材料场而不破坏基座。

第一个实验：不需要真实材料标注——先用 MPM 仿真渲染一批带精确材料参数的形变视频（同一物体、同一动作，只改杨氏模量与黏度），训练一个轻量的材料场条件分支，验证「改变输入的材料参数能否单调地改变生成视频的形变幅度」。这是一个可以完全在仿真里闭环的可控性测试，成本远低于端到端评测。如果单调性成立，再用 VLM 从真实图像预测材料场接上去，与 DeforM 的二值掩码在同一套 PC/SA/LDF 指标上比较；如果单调性不成立，说明生成模型对连续物理参数根本不敏感，那么二值掩码这种粗粒度引导反而是当前阶段的正确选择——这个负结果本身也很有价值。

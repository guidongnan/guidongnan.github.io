PhysAlign: Physics-Coherent Image-to-Video Generation through Feature and 3D Representation Alignment ​

项内容
arXiv2603.13770
提交日期2026-03-14
作者Zhexiao Xiong, Yizhi Song, Liu He, Wei Xiong, Yu Yuan, Feng Qiao, Nathan Jacobs
分类cs.CV
一句话用 Blender 刚体仿真造 3K 条带深度与物理参数标注的合成视频，把 DiT 中间层的时空 Gram 关系矩阵对齐到 V-JEPA2、再加一个四项监督的深度头，LoRA 微调 Wan2.2 后推理时把所有辅助分支全部丢掉。

所属教程：物理感知视频生成

§ 1 — 研究问题与重要性 ​

论文把"物理连贯"拆成两个可操作的维度，这个拆法本身值得记下来：通用物理律（一致的重力加速度、合理的碰撞、动量守恒的轨迹）与 3D 感知保真度（正确的遮挡序关系、物体相对相机运动时的尺寸变化）。前者关于动力学，后者关于几何与透视——它们经常被混在"物理合理性"这个笼统词下，但失败模式完全不同：一段球以匀速穿过桌面的视频违反的是几何，一段球落地后弹得比落下时还高的视频违反的是动力学。

问题的核心矛盾论文说得很清楚：当前 VDM 都在大规模视频上训练，因而只隐式学到物理连贯；而显式的物理线索——深度、力、质量、物体状态——是最强的监督信号，却几乎不存在于真实视频语料中。你不可能从 YouTube 视频里读出球的质量是多少牛的力把它推出去。这就是整篇论文的立足点。

§ 2 — 前人工作与不足 ​

论文没有按"物理在生成前还是生成后"这种常见的二分法归类，而是按物理知识注入生成流水线的位置分成三类，这个分类比时间序更有信息量：

输入空间。用 MPM 一类外部仿真器先算出物理上合理的轨迹或场景状态，再作为条件送进生成器（PhysGen3D、Phys4DGen、PhysGaussian、PhysMotion、PhysDreamer、AutoVFX、SeeU、PhysCtrl）。可控性显式，代价是要求用户为每个场景手工设计物理规则，跨环境、跨物理体制都不泛化。

潜空间。把物理直接嵌进生成模型的表示或运动结构中（PhysDiff、PhysAnimator、NewtonGen、WonderPlay、MotionModes、VLIPP）。好处是由生成模型自己维持合理动力学而不依赖预计算仿真。

输出空间。生成后用外部评估器（LLM/VLM）判物理一致性再精修或重排（GPT4Motion、PhyT2V、PhyWorldBench 及相关自精修流水线）。因为物理推理是从数据里隐式学的，一旦遇到物理上更困难或分布外的场景，鲁棒性急剧下降。

本文属于第二类，但它对前作的批评落在一个很具体的技术点上：现有的表示对齐（REPA 一系）做的是逐 token 的绝对值匹配，而绝对值匹配对生成先验的干扰太大；且它们普遍用图像编码器（DINO 一类）当 teacher，静态图像编码器结构性地缺少时序上下文，无法提供关于运动因果的监督。

§ 3 — 重建作者的思考路径 ​

论文之前已存在三条独立线索。其一，REPA 证明把扩散模型的中间表示对齐到预训练视觉编码器能显著加速收敛并提升质量——这是一个已被反复验证的免费午餐。其二，VideoREPA 已经把关系式蒸馏（对齐 token 之间的关系而非 token 本身）引入视频生成的物理学习，并指出刚性 token 匹配会破坏生成先验。其三，V-JEPA2 这类视频原生自监督模型的表示按其训练目标就编码了"未来如何演化"，与图像编码器有本质区别。

把三条拼起来的推理是：既然要注入的是运动因果而不是语义身份，teacher 就必须是视频原生的；既然要保住生成多样性，对齐目标就应当是关系结构而非绝对值。这一步之后剩下的问题是数据——关系蒸馏需要的是含丰富碰撞与遮挡的视频，而真实语料里这类片段稀疏且无标注。于是 Blender 出场：它能以低成本生成任意多的刚体碰撞序列，且深度图是免费的（渲染管线本来就有 z-buffer），而深度恰好直接对应第二个维度"3D 感知保真度"。两个维度、两路监督，数据瓶颈同时被解开。

§ 4 — 核心 Intuition ​

大视频模型其实已经"见过"足够多的物理，缺的不是知识而是把知识调出来的结构性催化剂。要调出来，得对齐关系而不是数值——把 DiT 中间层里"这一帧的这个位置与那一帧的那个位置有多相似"这张关系图，对齐到一个视频原生 teacher 的同一张图上，因为物体轨迹恰恰就写在这张跨帧相似度图里。再加一路显式深度监督管住透视与遮挡，而深度这种标注在真实视频里拿不到、在仿真器里唾手可得。

§ 5 — 具体方法与完整 Pipeline ​

以"一个篮球被斜向推出、落地弹起并撞到一个立方体"为例：

  1. 数据生成。在 Blender 上搭刚体仿真，为每个物体采样类型（篮球/足球/网球/保龄球，以及立方体、圆柱、圆锥、二十面体等原始刚体）、真实量级的质量与尺寸、不同摩擦的表面材质、初始高度、施加力的大小与发射角（方向在 0°–360° 均匀采样）、参与交互的物体数（训练场景 3–7 个）以及可选的横向运动。渲染 90 帧、512×512，同时导出对齐的 RGB 与深度，外加物理元数据（质量、球直径、力的牛顿值、起始高度米数、施力点像素坐标）与自动生成的自然语言描述。总计 3K 条训练视频。
  2. Physical Relation Alignment。取 DiT 中间块的隐状态 H(b)，经轻量 MLP 投影 ϕ(b) 到 teacher 维度；把投影后的 token reshape 成 5D 张量，用无参数的三线性插值直接插到 V-JEPA2 的时空网格 (tg​,hg​,wg​)——刻意避开参数化卷积下采样，理由是后者会引入结构偏置、扭曲细粒度几何。然后在学生与 teacher 上分别计算跨全部时空 token 的余弦相似度矩阵（Gram 矩阵），用带 margin 的 L1 惩罚对齐。
  3. 3D Geometry Injection。从 DiT 中间若干块（如 12、16、20、24）取隐状态，线性投影后 reshape 成空间特征图，与最终视频潜变量拼接，过一个轻量 3D 卷积深度头预测深度潜变量。监督由四项组成：潜空间 L2、尺度-平移不变的像素级损失、空间梯度匹配的结构损失、时序梯度匹配的时间损失。
  4. 训练与推理。骨干 Wan2.2-I2V-14B，LoRA rank 32，插在 DiT 的 q,k,v,o 与 ffn.0/ffn.2 上；高噪声与低噪声两个 expert 分开训练，时间步区间分别为 [0,0.358] 与 [0.358,1]；AdamW，恒定 lr 10−4，wd 0.01，bfloat16；4×H100 约 24 小时收敛。每个训练样本 49 帧，首帧作为 I2V 条件；因 V-JEPA2 的时序 tubelet 为 2，奇数长度的 49 帧在送 teacher 前截断为 48。对齐只施加在 DiT block 16，权重 0.25、margin 0.1，teacher 输入按等比缩放到高 160。深度头用多尺度结构，64 隐藏通道、3 层。推理时 teacher 与深度头全部丢弃，只跑冻结骨干 + LoRA，采样方案与原 flow-matching 模型完全一致，显存与耗时与普通 Wan2.2+LoRA 无异。

评测数据两套：Blender 合成测试集；以及从 WISA-80K 中挑 200 条覆盖碰撞、滚动、弹跳等常见物理律、且与训练数据表征相近的真实视频，取首帧构成 WISA-Test，用于测合成到真实的迁移。

§ 6 — 核心数学推导 ​

关系对齐。标准 REPA 的目标是逐 token 的相似度

LREPA​=−E[N1​n=1∑N​sim(E∗[n], W(Et​[n]))]

它要求学生的第 n 个 token 在数值上贴近 teacher 的第 n 个 token。本文改为对齐关系矩阵：把学生与 teacher 的特征沿时空维展平为 s,t∈RB×Nv​×D（Nv​=tg​hg​wg​），计算

Gi,j​=∥si​∥2​∥sj​∥2​⟨si​,sj​⟩​

这一步是整个方法的关键，值得说清它为什么与物理有关。G 的对角块（同一帧内的 token 对）编码的是帧内空间布局；非对角块（跨帧的 token 对）编码的是"第 t 帧位置 i 的内容与第 t+k 帧位置 j 的内容有多像"——一个物体的运动轨迹在 G 里就表现为一条高相似度的对角带，带的斜率就是速度，带的弯曲就是加速度。所以对齐 G 等价于对齐轨迹的形状，而不对齐外观。

损失用带 margin 的 L1：

LPhys(b)​=Nv2​1​i=1∑Nv​​j=1∑Nv​​max(0, ​[GS(b)​]i,j​−[GT​]i,j​​−m)

m=0.1 的作用是给出一个容差带：只有当关系差异超过 m 才受罚。这既避免了刚性匹配对生成多样性的挤压，也隐含地把监督集中在差异大的那些 token 对上——通常正是运动区域，因为静态背景的关系矩阵本来就容易匹配。

深度四项损失。Llatent​ 在压缩潜空间做 L2，提供稳定的全局梯度；Lpixel​ 用尺度-平移不变（SI）度量，对每帧最优地解出 (sb,t​,tb,t​) 后再算 L2，从而把绝对尺度模糊性剥离，只惩罚相对结构；Lst​ 匹配空间前向差分 ∂x​D^,∂y​D^，保住边界锐度、防止过平滑；Ltemp​ 匹配时序差分 Δt​Db,t​:=Db,t+1​−Db,t​ 的 L1，抑制闪烁并强制深度演化的连续性。四项加权求和为 L3D​，总目标 L=LFM​+λPhys​LPhys​+λ3D​L3D​。

评测指标 PIS。这是理解本文实验结论的关键，也是最需要警惕的地方。用 SAM2 分割运动物体、取质心序列、算逐帧速度与加速度，得到某个物理决定量 C 的均值 Cμ​ 与标准差 Cσ​，则

PIS=(1+∣Cμ​∣+ϵCσ​​)−1

括号里那一项就是变异系数。所以 PIS 本质上是"C 有多接近常数"的度量，取值域 (0,1]，在 Cσ​=0 时取到最大值 1。论文对此的物理论证是：在针孔相机下 2D 轨迹是 3D 运动的确定性投影，u˙=zf​(x˙−zx​z˙) 等关系表明，对标准抛体运动（ax​=0、ay​=−g），加速度的常值性与符号结构在投影后按比例保持，因此 2D 空间的加速度平滑性与符号一致性可作为 3D 物理正确性的可靠代理。这个论证在单段自由飞行的前提下成立，但它的边界条件在下文 §9 会成为最大的问题。

§ 7 — 实验设计与结论 ​

问题一：合成数据能不能教会物理？ 在 Blender 测试集上比较 CogVideoX-5B、HunyuanVideo-I2V、Wan2.2 与本方法的 PIS 与 VBench-I2V。论文称 PhysAlign 在全部 PIS 维度（加速度、速度、尺寸变化一致性）上最优。需要如实说明：表 1 的行名与列名在 HTML 转换中全部丢失，只剩 5 行 × 5 列数值；且表 1 与消融表 6 的首列与末列完全相同（末列为 0.632 / 0.648 / 0.746 / 0.798 / 0.641），由此可推断末列即完整模型、行对应五类物理场景。WISA 侧的表 2 / 表 7 / 表 10 也共享同一末列（0.604 / 0.611 / 0.775 / 0.739 / 0.451），且该列在全部五行上都高于同表其他列。此外表 1 的 caption 明确写的是 "acceleration metrics"，而正文声称覆盖速度与尺寸变化——速度与尺寸的表并未出现在正文中。因此本文只引用可确认的部分，不复述被截断的数值归属。

问题二：VBench 上是否有代价？ 在配对主体测试集上（表 3，八列依次为 i2v_subject、i2v_background、subj_consis.、bkg_consis.、motion_smooth.、dynamic_degree、aesthetic、imaging）：CogVideoX-5B 0.816 / 0.870 / 0.772 / 0.876 / 0.985 / 0.540 / 0.406 / 0.636；Hunyuan I2V 0.842 / 0.891 / 0.814 / 0.912 / 0.993 / 0.340 / 0.453 / 0.635；Wan2.2 I2V 0.879 / 0.910 / 0.826 / 0.922 / 0.978 / 0.676 / 0.411 / 0.516；本方法 0.911 / 0.928 / 0.886 / 0.955 / 0.996 / 0.730 / 0.467 / 0.655；真实参考视频 0.931 / 0.985 / 0.913 / 0.971 / 0.996 / 0.820 / 0.460 / 0.673。这组数字很有说服力：本方法在每一项上都优于所有基线，且在多数项上接近真实参考视频。dynamic_degree 0.730 低于参考的 0.820 但高于所有基线，说明它不是靠"生成更静的视频"取胜——这一点对 §9 的质疑是一个部分反驳。

问题三：合成到真实迁移成立吗？ WISA-Test（表 4）：Wan2.2 I2V 0.963 / 0.969 / 0.925 / 0.936 / 0.988 / 0.607 / 0.451 / 0.624；本方法 0.975 / 0.981 / 0.934 / 0.951 / 0.995 / 0.635 / 0.458 / 0.643。增益整体变小但方向一致，i2v_subject 与 i2v_background 的提升最明显，作者归因于 3D 几何约束防止了结构畸变。

问题四：在第三方物理 benchmark 上呢？ PhysicsIQ 总分（表 5）：CogVideoX-5B 32.3、Wan2.2 29.6、Wan2.2 I2V+LoRA 34.5、本方法 38.1。收益主要来自固体力学类别，与训练数据聚焦刚体一致，作者也坦承扩展到更复杂物理体制是未来工作。这里有一处值得注意的异常：Wan2.2（29.6）低于 CogVideoX-5B（32.3），而 Wan2.2 在 VBench 各项上全面强于 CogVideoX——说明 PhysicsIQ 与通用视频质量之间的相关性很弱，这本身是支持"物理需要专门优化"这一论点的证据，但论文没有指出。

问题五：两路对齐各自贡献多少？ 表 6/7 的消融（FA = feature alignment、3D-A = 3D alignment）同样丢失了行列名。可确认的定性结论是作者的文字描述：去掉特征级对齐会导致运动连贯性明显退化（速度不规则、加速度模式不一致、物体身份稳定性下降）；去掉 3D 几何对齐会削弱深度感知与尺度一致性，表现为错误的尺寸变化。

问题六：合成数据真的比真实数据划算吗？ 附录 B.1 用同样的 LoRA 在真实的 WISA 数据上训练作为对照。表 9（WISA-Test 的 VBench）：Train on WISA 0.965 / 0.971 / 0.927 / 0.944 / 0.991 / 0.612 / 0.452 / 0.627；DINOv3 变体 0.972 / 0.978 / 0.928 / 0.944 / 0.993 / 0.617 / 0.455 / 0.633；本方法 0.975 / 0.981 / 0.934 / 0.951 / 0.995 / 0.635 / 0.458 / 0.643。两个结论：3K 合成数据优于在真实 WISA 上训练；把 V-JEPA2 换成 DINOv3 后一致变差，且差距在运动与物理相关指标上更明显——这是对"teacher 必须是视频原生"这一设计选择最直接的支持。附录称合成数据量比 WISA 少 "10×"，但 WISA-80K 名义上有 8 万条，3K 对 8 万是约 27 倍，这个倍数的口径论文未说明。

问题七：人类怎么看？ 用户研究（表 8）按 1–4 分评 Motion Physics Quality / Identity Physics Quality / Overall Video Quality，四列数值为 1.671 / 1.543 / 2.557 / 3.236、1.757 / 1.679 / 2.536 / 3.343、1.771 / 1.607 / 2.643 / 3.286。列名同样丢失，按与表 3 一致的方法顺序推断为 CogVideoX-5B、Hunyuan I2V、Wan2.2、本方法，则本方法在三项上均最高且领先约 0.65–0.8 分。

§ 8 — Take-aways ​

5 句话版：物理连贯需要显式的深度、力、质量监督，而真实视频语料里没有这些标注。PhysAlign 用 Blender 刚体仿真造 3K 条带完整物理与深度标注的合成视频来补这个缺口。方法上把 DiT 中间层的时空 Gram 关系矩阵对齐到视频原生 teacher V-JEPA2（用带 margin 的 L1 而非刚性 token 匹配以保住生成多样性），并用四项损失监督一个辅助深度头。推理时全部辅助分支被丢弃，开销与普通 Wan2.2+LoRA 完全一致。3K 合成片段的效果超过在真实 WISA 上训练，PhysicsIQ 从 29.6 提到 38.1，换用图像 teacher（DINOv3）则一致变差。

3 句话版：物体轨迹写在跨帧的 token 相似度矩阵里，所以对齐关系比对齐数值更贴近物理。真实视频没有物理标注，仿真器有，而且深度是免费的。大模型已经有物理先验，3K 条干净数据足以把它催化出来。

1 句话版：用抽象的 Blender 小球教大视频模型做物理，靠的是对齐"谁跟谁像"的结构而不是"长什么样"的数值。

§ 9 — 最脆弱的假设 ​

最脆弱的一条是：PIS 是物理合理性的有效度量。全文关于"物理连贯"的核心量化证据（表 1、2、6、7、10 五张表）全部由它给出，若它不成立，这些表就只剩 VBench 与 PhysicsIQ 两组间接证据。

它在实践中很可能不成立，原因就在定义本身。PIS=(1+Cσ​/(∣Cμ​∣+ϵ))−1 是变异系数的单调递减变换，因此它奖励的是 C 的低方差。这带来两个直接后果。第一，退化解：一段完全静止的视频，其质心序列恒定，Cσ​=0，PIS 取到理论最大值 1。同理，一段以完美匀速直线滑行、既不受重力也不发生碰撞的视频，加速度恒为 0，Cσ​=0，PIS 同样接近 1——而这恰恰是物理上错误的（球应该落下）。也就是说 PIS 无法区分"遵守了物理"和"什么也没发生"，它只能检出"加速度忽大忽小"这一类抖动型违规。第二，碰撞失效：论文的物理论证明确建立在抛体运动"ax​=0、ay​=−g 常值"的前提上，而训练与评测数据的核心卖点恰恰是碰撞——碰撞的定义就是加速度在某一瞬间发生冲激式突变。在含碰撞的片段上，真实物理会产生高 Cσ​，因而真实视频的 PIS 反而会低于一段平滑穿模的假视频。

论文提供的证据是那组投影关系推导，它证明的是"3D 的常值加速度在 2D 投影后仍保持常值性与符号结构"，即 PIS 高 ⇐ 物理正确（在单段自由飞行下）。但评测需要的是反方向：PIS 高 ⇒ 物理正确。论文没有论证这个方向，而上面两个反例说明它不成立。

缺的证据非常具体且极易补：在真实视频（WISA-Test 的原始片段）上计算 PIS，作为参照上界。表 3 里作者已经为 VBench 报告了 "Reference Video" 这一行，说明他们理解参照的重要性；PIS 的表里却恰恰没有这一行。

§ 10 — 最小复现实验 ​

不训练任何模型，只做 PIS 的效度检验，一周可完成：

  • 数据：WISA-Test 的 200 条真实视频（含碰撞、滚动、弹跳）。
  • 实现：按 §5.2 复现 PIS——SAM2 分割主运动物体、取质心、算逐帧速度与加速度、代入公式。另构造三组人工对照：(A) 把真实视频的首帧复制 49 遍得到的完全静止片段；(B) 把首帧物体以恒定像素速度平移合成的匀速直线片段（物理上错误，因为忽略了重力）；(C) 真实视频本身。
  • 测量：三组的 PIS 分布（均值与四分位），以及 (C) 中含碰撞子集与不含碰撞子集的 PIS 差异。
  • 判据：若 PIS(A)≈PIS(B)>PIS(C)，PIS 作为物理合理性度量被证伪，§9 成立，本文所有 PIS 表格的结论需降级为"运动平滑性"结论；若 PIS(C) 最高，PIS 有效，质疑消解。若 (C) 内部含碰撞子集的 PIS 显著低于不含碰撞子集，则说明 PIS 在本文最关心的场景类型上恰好失效。

§ 11 — 最强反例设计 ​

除了 PIS 本身，还有一个针对归因的替代解释值得设计实验去检验：PhysAlign 的增益可能主要来自领域简化而非物理学习。

3K 条 Blender 视频的共同特征是：单一纯色地面、无杂乱背景、光照均匀、3–7 个几何简单的刚体、无变形无流体。在这样的数据上做 LoRA 微调，最自然的效果是让模型输出更"干净"——更少的背景抖动、更少的纹理闪烁、更少的物体形变。而 VBench 的 subj_consis.、bkg_consis.、motion_smooth. 三项天然奖励这种干净，i2v_subject 与 i2v_background 也会因为模型更倾向于保守地保留首帧内容而上升。换句话说，表 3/4 中的大部分增益可以用"LoRA 把模型拉向低方差、高保守性的输出模式"解释，完全不需要引入"内化了物理律"。

设计一个能分开二者的实验：构造一个物理反事实测试集。取同一首帧（一个球悬在空中），生成两组条件——prompt A 描述"球下落"，prompt B 描述"球向上飞"。物理上只有 A 是自由演化的正确答案，B 需要外力。度量模型在两组条件下生成的质心竖直位移的符号与大小。真正学到重力的模型应当表现出不对称：A 方向的下落加速度稳定接近某个常值，B 方向要么被拒绝执行、要么执行后立刻回落。而只是变干净了的模型会对称地服从两条 prompt。这个实验不需要任何新数据（首帧可以从合成集里直接取），也不依赖 PIS，且能直接反驳或支持"3K 合成片段催化出了物理先验"这一核心主张。

第二个可预测的失效条件由论文自己的 PhysicsIQ 分析给出：增益集中在固体力学类别。可以预期在流体、软体、热效应、光学（折射、镜面）这些类别上本方法与基线无差异甚至更差——因为 Blender 刚体仿真的分布与这些体制完全不重叠，而 LoRA 微调会把模型往刚体方向拉。分类别报告 PhysicsIQ 就能验证，论文只给了总分 38.1。

§ 12 — Follow-up Research Idea ​

(a) 驱动局限：本文的对齐目标是匹配 teacher 的关系矩阵——让学生的 GS​ 靠近 GT​。但 V-JEPA2 的 GT​ 本身也只是一个近似：teacher 在真实视频上训练，它对物理的理解同样是隐式的、有偏的，且没有任何机制保证 GT​ 在物理违规处与在物理正确处有可分的结构。于是学生最好的结果是"像 teacher 一样看视频"，而不是"物理正确"。这是所有蒸馏式方法的天花板，且它与本文自己发现的现象吻合：合成到真实的增益（表 4）明显小于合成域内的增益。

(b) 可借鉴的相邻领域：JEPA 与能量模型体系里的预测误差/惊奇度概念，以及本文自己引用却未使用的 LikePhys（ICLR 2026，通过似然偏好评估视频扩散模型的直觉物理理解）。这两者共同指向一个不同的信号源：teacher 最有价值的输出不是它的表示，而是它的预测失败——V-JEPA2 的训练目标就是从过去预测被遮蔽的未来，因此它的预测残差在物理反常处会系统性升高。物理违规恰恰住在 teacher 预测不出来的地方。

(c) 第一个实验：把对齐目标从"匹配表示"改为"匹配可预测性"。具体做法：对生成视频，用冻结的 V-JEPA2 predictor 在给定前 k 帧的条件下预测后续帧的表示，得到逐时空位置的残差场 ri​；同样在真实视频上算出残差场的参考分布。训练目标改为最小化生成视频残差场与真实残差场在分布上的差异（例如按位置的分位数匹配），而不是最小化表示差异。第一个验证实验很小：不训练任何东西，先检查残差场是否具备判别力——在 WISA-Test 的真实视频与四个基线模型的生成视频上分别计算残差场统计量，看它与人类的 Motion Physics Quality 打分（表 8 已有）的秩相关能否超过 PIS 与该打分的秩相关。

这个重构的意义在于换了监督的方向：从"让学生的表示像 teacher"变成"让学生生成 teacher 觉得不意外的视频"，后者是一个可以在没有配对真值、没有物理标注的真实视频上直接计算的量，因而不再受合成数据分布的束缚。它同时给出了一个不依赖变异系数的物理度量，绕开 §9 的全部问题——一段静止视频对 predictor 而言毫无意外，但它的残差分布与真实运动视频的残差分布截然不同，因此不会像 PIS 那样得到满分。

DrivingWorld: Constructing World Model for Autonomous Driving via Video GPT ​

项内容
arXiv2412.19505
提交日期2024-12-27
作者Xiaotao Hu, Mingkai Jia, Xiaoyang Guo, Qian Zhang, Xiao-xiao Long, Wei Yin（arXiv v3 署名，共 6 位；v1 另列 Junyuan Deng 与 Ping Tan，v3 已移除）
分类cs.CV
一句话把 GPT 的一维 next-token 拆成「先跨帧融合预测下一状态、再在帧内自回归出每个 token」的时空解耦结构，配合随机 token dropout 与位姿注意力加权，做出 40 秒以上可控的驾驶视频。

所属教程：世界模型

§ 1 — 研究问题与重要性 ​

自动驾驶最难的部分是长尾：事故、极端天气、罕见交通参与者行为，这些场景恰恰最难收集到足够的标注数据。世界模型给出的解法是从海量无标注视频里学出环境动力学，然后在想象中推演。要让这条路走通，模型必须能生成足够长且受控的未来——只能预测 2 到 4 秒的模型，对规划几乎没有价值。

这篇论文要解决的是一个很具体的技术问题：把 GPT 那套 next-token prediction 搬到驾驶视频上时，为什么效果会崩，以及怎么修。它的答案不是换成 diffusion，而是重新设计自回归的展开顺序。

§ 2 — 前人工作与不足 ​

GAIA-1 是第一个把 GPT 框架从语言扩展到驾驶视频的工作：把 4D 时序相关的帧摊平成 1D token 序列，用 next-token prediction 生成未来。作者对它的批评很精确——经典 GPT 是为 1D 上下文设计的，本身不具备建模视频所需空间与时间动力学的结构；结果是画质低、伪影明显。此外 GAIA-1 参数量与计算量都很大，且计算开销随条件帧数增长。

diffusion 这一侧，Drive-WM、Vista、GenAD 视觉质量更好，但作者指出其固有问题是可控性：扩散过程每一步注入的随机性使得对具体属性的严格控制变得困难。Vista 的最长片段是 15 秒 / 150 帧，Drive-WM 是 8 秒 / 16 帧，DriveDreamer 是 4 秒 / 48 帧——都远达不到规划需要的时长。

tokenizer 一侧的缺口更值得注意。VQVAE、VQGAN、MoVQ、ViT-VQGAN、VAR、LlamaGen 这一整条线全是单图处理的，编码时每帧独立、不含任何时间信息。作者的诊断是：单图 tokenizer 产生的 embedding 天然不时序一致，这会让下游世界模型的训练目标本身就是抖动的。这个点在此前的驾驶世界模型工作里几乎没被当作瓶颈处理。

§ 3 — 重建作者的思考路径 ​

从当时已有的事实出发。第一，把 T 帧图像各自展成 H×W 个 token 再首尾相接，序列长度是 T×H×W，attention 的显存与算力随之平方增长；本文的配置是每帧 512 个图像 token 加 2 个位姿 token、15 帧条件，序列已有 7,710 个 token，这个量级下朴素 GPT-2 结构在 15 帧时直接 OOM。第二，语言里 token 之间是同质的，但视频里「同一帧内相邻 patch」和「相邻帧同一位置」是两种完全不同的依赖关系，把它们塞进同一个 causal mask 里显然浪费了结构先验。

于是自然的想法是把两种依赖拆开：时间维度上，每个 token 只看历史帧中同一空间位置的 token；帧内维度上，让所有模态的 token 互相看（双向），先算出「下一帧应该是什么样」的特征。可这样一来，下一帧的所有 token 就是被并行预测的，会丢掉 LlamaGen 那条线证明过的「自回归逐 token 生成画质更好」的收益。补救办法是再加一层帧内自回归模块，在已经得到的下一状态特征上逐 token 精修。

至于漂移，这是自回归的老问题：训练时喂 ground truth，推理时喂自己的输出，分布不匹配导致误差滚雪球。语言模型里的对应处理是 scheduled sampling 或加噪，这里作者选了最简单的随机 token 替换。

§ 4 — 核心 Intuition ​

视频的自回归不该是「一条一维长队」，而应该是「先跨帧走一步，再在帧内走一圈」。跨帧那一步只需要每个位置看自己的历史，代价是线性的；帧内那一圈才需要逐 token 自回归来保画质，而它只在一帧的长度上展开。把这两件事分开，长序列的算力问题和逐 token 的画质收益就能同时拿到。至于长时漂移，训练时主动把条件里的一部分 token 换成随机 token，模型就被迫学会在带噪历史上继续预测。

§ 5 — 具体方法与完整 Pipeline ​

以一段城市道路的 15 帧历史为起点：

  • 输入：前视图像序列 {It​}t=1T​（256×512）、自车朝向 {θt​} 与位置 {(xt​,yt​)}。
  • 时序感知图像 tokenizer：在 LlamaGen 版 VQGAN 的量化层前后各插入一个沿时间维的 self-attention。量化前的时序注意力让同一空间位置跨帧的特征互相看到，从而产生时序一致的 code；量化后的时序注意力在 decoder 侧继续维持一致性。tokenizer 70M 参数，codebook 16,384，每帧 512 个 token。训练分两阶段：先用 OpenImages + COCO 的 600 万单帧图像学空间，再用 YouTubeDV + NuPlan 的 900 万段 15 帧视频学时序；损失为 charbonnier + LPIPS + codebook，权重 3 : 1 : 1；32 张 4090，两阶段各 500K 步，约 7 天。
  • 位姿 tokenizer：用相邻帧相对位姿而非全局位姿——全局位姿的绝对数值随序列增长而变大，归一化困难、鲁棒性差。朝向离散成 α 类，X 与 Y 轴分别离散成 β 与 γ 个箱。每个状态因此是 512 + 2 = 514 个 token。
  • 世界模型（1B 参数）：由 temporal-multimodal fusion module 与 internal-state autoregressive module 组成。前者交替堆叠 N 层：temporal layer 用 causal mask，每个 token 只看自己和历史帧同位置的 token；multimodal layer 在同一帧内用双向 mask，让图像 token 与位姿 token 充分交互。后者把融合特征 h˚T​ 与已生成的前缀 token embedding 相加，在 causal mask 下逐 token 生成 r^T+1​。训练时同时施加帧级和帧内两级 teacher forcing。
  • 抗漂移与控制：随机 masking（RMS）——每个 token 有 50% 概率被替换为该帧内的另一个随机 token，整个条件序列以 30% 概率触发这一 dropout。balanced attention——由于每帧 512 个图像 token 只对 2 个位姿 token，位姿信号会被淹没，因此在 softmax 之前手工给朝向与位置 token 的 attention 权重分别加上常数 0.4 与 0.2。另加 QK-norm 与 2D rotary 位置编码稳定训练。
  • 输出与放大：位姿 token 反量化得 Δθ^,(Δx^,Δy^​)；图像 token 查 codebook 后经时序感知 decoder 还原。附录里再 fine-tune 一个 SVD 把 256×512 精修到 512×1024，训练时用 15% 的 token 替换来模拟生成分布。
  • 数据与算力：世界模型在 3,456 小时人类驾驶数据上训练（120 小时来自公开 NuPlan，3,336 小时为私有数据，采自北京、南京、合肥、天津，约 2/3 城区、1/3 高速与乡道，全部为白天晴天）；64 张 A100，450K 迭代，batch 64，12 天。

§ 6 — 核心数学推导 ​

时序感知量化。 单图 VQ 的 code 由 argmink​∥lookup(Z,k)−ft(i,j)​∥2​ 给出，每帧独立。本文改成先经过沿时间维的注意力 H(⋅)：

qt(i,j)​=argk∈[K]min​​lookup(Z,k)−H(f1(i,j)​,…,fT(i,j)​)[t]​2​.

直觉是：决定第 t 帧某个位置该用哪个 code 的，不该只是这一帧的局部特征，而应是这个位置在整段时间里的轨迹。这样相邻帧才不会因为微小像素扰动跳到完全不同的 codebook 条目上。

位姿离散化。

ϕt​=⌊θmax​−θmin​Δθt​−θmin​​α⌋,vt​=⌊xmax​−xmin​Δxt​−xmin​​β⌋⋅γ+⌊ymax​−ymin​Δyt​−ymin​​γ⌋.

位置用 β⋅γ 的二维网格展平成单个 token，好处是位置只占一个 token 位；代价是词表变大且相邻格子在 token id 上未必相邻。

时空解耦的两层注意力。 时间层

h~ti​=Fa​(h1i​,…,hti​),i∈[1,H×W+2],

注意上标 i 固定——每个 token 只与历史帧中相同序号的 token 交互，复杂度从 O((THW)2) 降到 O(T2) 每位置。多模态层

h˚t​=Fb​(h~t​)

在帧内双向融合。帧内自回归则是

r^T+1i​=G(Emb([sos])+h˚T1​,Emb(r^T+11​)+h˚T1​,…),

即把「下一状态的预测特征」当成一个逐位置的偏置加到自回归输入上。总损失是两级 teacher forcing 下的交叉熵：

LWM​=−t=1∑T+1​j=1∑H×W+2​logP(r^tj​∣r<t​,rt1​,…,rtj−1​).

§ 7 — 实验设计与结论 ​

问题一：这套结构比朴素 GPT 好多少？ 在 12 小时 NuPlan 子集上从零训 50K 步的对照实验里，GPT-2 结构的 FVD10/25/40 是 2976.97 / 3505.22 / 4017.15，本文结构是 445.22 / 574.57 / 637.60。显存方面 GPT-2 从 5 帧的 31.6 GB 增到 10 帧的 77.6 GB，15 帧直接 OOM；本文从 21.9 GB 增到 45.9 GB。这是全文最干净的一组对比。

问题二：时序感知 tokenizer 值不值？ NuPlan 256×512 上 VQGAN 的 FVD12/FID/PSNR/LPIPS 为 156.58 / 8.46 / 21.52 / 0.2602，LlamaGen 为 57.78 / 5.99 / 22.31 / 0.2054，LlamaGen 在驾驶数据上微调后为 20.33 / 5.19 / 22.71 / 0.1909，本文的时序感知版本为 14.66 / 4.29 / 23.82 / 0.1828，四项全胜。注意 fine-tune 已经贡献了大部分 FVD 收益（57.78→20.33），时序注意力再贡献一截（→14.66）。

问题三：和 SOTA 比如何？ NuScenes 是零样本（未在训练集中），FID 7.4 / FVD 90.9，与 Vista 的 6.9 / 89.4 基本持平，优于 Drive-WM 的 15.8 / 122.7 与 GenAD 的 15.4 / 184.0。去掉私有数据只用 NuPlan 时降到 16.4 / 174.4——这条对比很诚实，也说明 3,336 小时私有数据贡献巨大。最大时长上 DrivingWorld 报 40 秒 / 400 帧，Vista 15 秒 / 150 帧。作者强调多数对手基于在数十亿图像上预训练过的 SVD，而本文是从零训练。

问题四：抗漂移策略有效吗？ 去掉随机 masking 后 FVD10/25/40 从 445.22 / 574.57 / 637.60 升到 449.40 / 595.49 / 662.60。定量提升不大（作者称跨场景 4% 到 32%），但 Figure 3 的定性结果显示不加 masking 时第 10 帧之后内容会剧烈漂移。这里存在一个张力：定性崩溃与定量小幅退化不太匹配，FVD 可能不是刻画漂移的好指标。

其他消融。 帧内自回归模块去掉后（改为并行预测全部 token），NuScenes FVD40 从 933.13 涨到 1601.36。条件帧数 5→25 单调变好（NuPlan FVD40 679.05→580.10）。模型规模 10M / 100M / 1B 单调变好。

关于长视频时长，论文内部标注不完全一致：§4.2 称条件 15 帧可生成 640 帧、在 10 Hz 下对应 64 秒，而 Figure 4 的说明写的是 640 帧 @5Hz 即 128 秒。摘要给出的稳妥 claim 是「超过 40 秒，是 SOTA 驾驶世界模型的 2 倍以上」。

§ 8 — Take-aways ​

5 句话版。 论文指出经典 GPT 的 1D next-token 展开与视频的时空结构不匹配，改为「跨帧的 next-state prediction + 帧内的 next-token prediction」两段式。tokenizer 侧在 VQGAN 量化层前后各插一个时间维 self-attention，使离散 code 本身具备时序一致性，四项重建指标全面领先微调后的 LlamaGen。长时漂移用随机 token dropout 抑制，位姿控制被淹没的问题用在 softmax 前给位姿 token 加常数注意力权重解决。在 3,456 小时数据上训练的 1B 模型可生成 40 秒以上视频，NuScenes 零样本 FID 7.4 / FVD 90.9 与 Vista 持平。结构上相对 GPT-2 的收益极大（FVD40 4017→638）且显存增长从平方降为可控。

3 句话版。 把视频自回归拆成「先跨帧、再帧内」两级，同时拿到长序列的可扩展性与逐 token 生成的画质。用时序注意力改造 VQ tokenizer，让离散 code 从源头上时序一致。随机 token dropout 与位姿注意力加权分别解决漂移与可控性。

1 句话版。 视频 GPT 的问题不在 GPT，而在展开顺序。

§ 9 — 最脆弱的假设 ​

最脆弱的是 temporal layer 里「每个 token 只与历史帧中相同空间位置的 token 交互」这一假设。它成立的前提是场景在帧间的位移足够小，使得同一像素位置在相邻帧仍对应同一物理内容。

在驾驶场景里这个前提常常不成立：高速行驶时画面边缘的光流极大，转弯时整幅图像横向平移，近处切入的车辆会在几帧内扫过大片区域。一旦位移超过一个 token 的空间跨度（256×512 压到 512 个 token，每个 token 覆盖 16×16 像素），时间注意力看到的「历史同位置」就是完全无关的内容。模型能否补偿，只能依赖帧内的 multimodal layer 与堆叠深度间接实现。

论文提供的间接证据是最终 FVD 好、以及条件帧数越多越好；缺失的证据是按自车速度或光流幅度分层的误差分析。私有数据全部采集于白天晴天，且约 1/3 是高速与乡道——恰恰是高速段最能暴露这个假设，但论文没有单独报告高速场景的指标。

§ 10 — 最小复现实验 ​

不需要 3,456 小时数据和 64 张 A100，一周内可做：

  1. 用公开 NuPlan 抽 12 小时视频（与论文消融设定一致），训一个 100M 级模型 50K 步，复现「本文结构 vs GPT-2」这一组对比即可，作者报告约需 32 GPU·小时量级。
  2. 关键测量：把测试片段按自车平均速度分成三档（低速 <5 m/s、中速、高速 >15 m/s），分别报告 FVD10/25/40。
  3. 判据：如果高速档的 FVD 相对低速档的劣化幅度明显大于 diffusion 基线（比如同样测一个 SVD fine-tune 版本）的对应劣化，就支持「同位置时间注意力在大位移下失效」这一诊断；如果三档劣化幅度相当，则该假设并非瓶颈。
  4. 低成本补充：把 temporal layer 的注意力从「同位置」放宽到「3×3 邻域同位置」，只加这一处改动，看高速档 FVD 是否显著下降。这是对论文核心设计的直接压力测试。

§ 11 — 最强反例设计 ​

替代解释攻击。 论文把 NuScenes 上与 Vista 持平归因于结构设计，但同时承认没有私有数据时 FID 从 7.4 掉到 16.4、FVD 从 90.9 掉到 174.4。也就是说 3,336 小时私有数据带来的增益，量级上远超所有结构消融的总和。反对者可以主张：这篇论文真正证明的是「够大的驾驶专用数据能让从零训练的自回归模型追平基于 SVD 微调的 diffusion」，而时空解耦只是让这个数据规模在算力上变得可行的工程手段，不是性能来源。要驳倒这一点，需要在相同数据量下对比时空解耦结构与同参数量的 diffusion，论文没有做。

可预测失败的场景。 全部私有数据为白天晴天，NuPlan 也以晴好天气为主。可以预期在夜间、雨雪、隧道出入口这类低信噪比或剧烈曝光变化的场景下，时序感知 tokenizer 的 code 一致性假设会崩——因为它依赖的正是「同一位置跨帧特征平滑」。构造一个仅含夜间与雨天片段的测试集，若 FVD 劣化远超 diffusion 基线，则说明这套方法的鲁棒性边界比论文呈现的窄得多。

§ 12 — Follow-up Research Idea ​

驱动局限。 balanced attention 这个设计暴露了一个更深的问题：为了让 2 个位姿 token 不被 512 个图像 token 淹没，作者不得不在 softmax 前手工加 0.4 和 0.2 两个常数。这是一个纯粹的补丁——它说明「把异构模态塞进同一个 token 序列并指望注意力自己分配带宽」这个前提本身有缺陷，而且这个缺陷会随着模态增多（作者在 future work 里明确说要加多视角、更多模态）而急剧恶化。

新的 framing。 不要让动作与观测竞争同一份 attention 预算，而是把动作提升为控制展开过程本身的算子：借鉴神经 ODE / 条件流场里「控制信号决定演化算子」的思路，让位姿不作为序列中的 token，而是参数化 temporal layer 的注意力核——即根据自车运动量直接预测「历史帧中哪个空间位置对应当前位置」的位移场，用它去 warp temporal attention 的取值位置。这同时解决了 §9 指出的大位移失配问题与 §12 开头的带宽竞争问题，是同一个改动的两个副产品。

第一个实验。 在 12 小时 NuPlan 消融设定下，把 temporal layer 改成「位姿条件的可变形时间注意力」：由 (Δx,Δy,Δθ) 经一个两层 MLP 预测每个 token 位置的历史采样偏移，用双线性插值取历史特征，其余结构与超参完全不变，并移除 balanced attention 的手工常数。评估两件事：(a) 高速片段的 FVD40 是否优于原结构；(b) 给定人为指定的转向轨迹时，生成视频的实际相机运动与指定值的一致性（可用 GLOMAP 之类做位姿反解后算误差）。如果 (b) 在没有任何手工加权的情况下达到甚至超过 balanced attention 的水平，就说明动作应当以算子而非 token 的形式进入世界模型，这对所有「多模态交错序列」类驾驶世界模型都是一个结构性的更正。

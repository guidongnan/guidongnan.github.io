Learning Plug-and-play Memory for Guiding Video Diffusion Models ​

项内容
arXiv2511.19229
提交日期2025-11-24
作者Selena Song, Ziming Xu, Zijun Zhang, Kun Zhou, Jiaxian Guo, Lianhui Qin, Biwei Huang
分类cs.CV, cs.AI
一句话冻住视频 DiT，只训练一个 150M 的记忆编码器，把检索到的参考视频经高/低通滤波拆成「动态」与「外观」两路 memory token 插进自注意力层，用 10K 样本换来物理一致性提升。

所属教程：物理感知视频生成

版本说明

arXiv abs 页提供的 HTML 全文为 v2（2025-11-27），本文以 v2 正文为准。v2 的 HTML 中表 2（PhyGenBench 主表）、表 3（VBench 主表）的数值单元格未成功渲染，因此下文只引用作者的文字结论，不编造这两张表的具体数字；消融表 4/5/6 的数值完整可读，均如实引用。

§ 1 — 研究问题与重要性 ​

DiT 架构的视频生成模型在画质和时序连贯性上已经很好，但仍会犯基本的物理错误：物体穿墙、液体向上流、碰撞后双方毫发无损。这类失败反映的不是渲染能力不足，而是模型缺少显式的世界知识。

现有的解决路线基本都是训练侧的。一条是继续堆模型容量和数据，指望模型从足够多样的场景里隐式内化物理规律；另一条是往训练目标里加约束或监督。两条路都昂贵，而且都面临同一个覆盖问题——真实世界的知识空间太大，靠参数记忆很难覆盖全。

论文问的是另一个问题：能不能不改动扩散骨干，只给它接一个外挂记忆？这个 framing 直接对应 LLM 里的 in-context memory 与 RAG——当参数记忆不够时，把知识放进上下文，而不是塞进权重。如果这条路走得通，收益是明显的：训练成本降到一个轻量模块，且同一套记忆可以插到不同骨干上。

§ 2 — 前人工作与不足 ​

论文用一张对比表把相关工作分成三类，评价维度是「是否即插即用 / 是否可学 / 是否同时提供高低频特征 / 训练数据量与可训练参数量」。

多模态 RAG 类：RAGME 检索参考视频提升运动真实感，但仍需对扩散模型做微调，且训练数据规模 10M；MotionRAG 用运动适配器与注入适配器，1M 数据、800M 可训练参数，且没有显式的解耦；VideoRAG 即插即用但记忆不可学，缺乏跨域适应能力。

扩散记忆类：Corgi 缓存记忆引导生成但不可即插即用；VMem 用 surfel 索引的视图记忆，即插即用但不可学；MALT 与 WorldMem 可学且高低频兼备，但都需要改动骨干（MALT 用了 1B 数据、440M 参数；WorldMem 85K 数据）。

上下文压缩类：LoViC 可学、高低频兼备，但需要 1.6M 数据、2.3B 可训练参数，且要改骨干。

归纳起来，前人的困境是一个二选一：要么即插即用但记忆是固定的、不可学（VideoRAG、VMem），要么可学但需要动骨干、训练成本高（MALT、LoViC、MotionRAG）。本文声称同时拿到两边：即插即用、可学、高低频兼备，只要 10K 数据和 150M 可训练参数。

至于为什么此前没人做「冻结骨干 + 可学记忆编码器」，可以推断原因是：不改骨干意味着记忆必须在 DiT 已有的表示空间里说话，而没人验证过 DiT 的隐状态是否真的可以被外部向量有效地干预。本文的 §3 就是为了先补上这个验证。

§ 3 — 重建作者的思考路径 ​

出发点是 LLM 里的两条成熟经验。第一，in-context memory 与 RAG 说明：把知识放进上下文比塞进权重更便宜、更可控。第二，steering vector / representation engineering 说明：Transformer 的隐状态可以被一个方向向量加性地干预，从而改变行为倾向（如 contrastive activation addition）。

把这两条搬到视频 DiT 上，第一个必须验证的问题是：DiT 到底能不能被隐状态干预？做法很直接——对某个物理概念（重力、碰撞）构造正负样本对（物理描述 prompt vs 空 prompt），记录所有层所有去噪步的 cross-attention value，取差作为 steering vector，推理时加回去。

做这个实验时会自然遇到第二个问题：视频特征里同时混着外观和运动，一个笼统的 steering vector 会把两者一起改，副作用大。这时频域分解是一个已有的、成本极低的候选工具——图像翻译、风格迁移、身份保持（ConsisID）等工作都观察到低频承载全局结构与身份、高频承载细节与快速变化。于是把 steering vector 序列做 FFT、分别低通与高通，看两者各自改变了什么。

论文报告的观察是：低通引导保住了全局结构和物体身份，高通引导让轨迹更符合重力与惯性。这个观察一旦成立，剩下的就是工程化——把「手工构造 steering vector」换成「一个可学的编码器，把检索到的参考视频压成 memory token」。作者还给出了从训练无关走向训练的理由：直接优化 cross-attention 激活会干扰 text–video 对齐，且训练无关的干预会引入噪声和偶发失真。

§ 4 — 核心 Intuition ​

视频 DiT 的隐状态是可以被外部向量加性操纵的，而在嵌入空间里做一次简单的高/低通滤波，就能把「这东西长什么样」和「它怎么动」这两类信息分开。于是外挂记忆不需要是一个笼统的「参考视频摘要」，而可以是两路各司其职的 token：低频那路负责别把物体画歪，高频那路负责让它按物理规律动。骨干不动，只学怎么把参考视频压成这两路 token。

§ 5 — 具体方法与完整 Pipeline ​

以 prompt「一个人往茶杯里倒水」为例走一遍。

检索。 记忆库是 OpenVidHD-0.4M 的带 caption 视频。所有 caption 用 GTE-v1.5 编码成稠密向量、FAISS 建索引。输入 prompt 编码后按内积相似度取 top-5 参考视频（全文实验统一用 5 条）。

编码。 每条参考视频先经生成模型自己的 VAE 得到视觉特征图，再进记忆编码器。编码器是两个堆叠的 3D 卷积块，每块的顺序是：3D 卷积 → 频域滤波模块 → BatchNorm → ReLU → 3D 最大池化。频域模块对特征张量 x∈RC×D×H×W 做三维 FFT，用低通掩码与高通掩码分别把另一侧频段的幅值压到 0.2（不是置零），逆 FFT 后加残差回原特征。卷积结束后展平空间维、沿时间轴做自适应平均池化得到定长 token 序列，再线性投影到共享的记忆嵌入空间。最后对低频与高频两路 token 施加参数共享的多头自注意力做聚合，两路输出在 token 维拼接。

注入。 得到的 memory token 在冻结 DiT 的每一个自注意力层之前追加到隐状态序列上，作为 Q/K/V 一起参与标准多头自注意力；注意力算完后丢弃记忆位置的输出，只保留更新后的视频 token 送进 MLP 与后续层，下一个注意力块之前再重新注入同一套 memory token。5 条参考视频约产生 1,000 个 memory token，而原始序列约 30,000 个 token，所以额外注意力开销有限。

训练。 只更新记忆编码器（约 150M 参数），DiT 全程冻结，目标就是标准的带记忆条件的噪声预测损失。训练集是 OpenVidHD-0.4M 中的 10K 子集，剩余 430K 只用来建检索索引。两个骨干：Wan2.1-T2V-1.3B（lr 1×10−5，1,500 步）与 Wan2.2-TI2V-5B（lr 5×10−5，1,200 步），batch size 4、梯度累积 16、8 张 A100。得到的模型分别记为 DiT-Mem-1.3B 与 DiT-Mem-5B。

推理。 同样的检索→编码→注入。记忆库中所有视频的 token 嵌入可以预先算好存进数据库，推理时直接取用，作者称额外延迟可忽略。

§ 6 — 核心数学推导 ​

背景：扩散目标。 DiT 的训练目标是标准的噪声预测

L=Et,x0​,ϵ,c​[∥ϵ−ϵθ​(xt​,t,c)∥22​]

其中 xt​ 是被高斯噪声污染到第 t 步的潜 token，c 是文本条件。本文只是把条件从 c 扩成 (c,Xmem​)：

Ldenoise​=Ext​,ϵ​[∥ϵ−ϵθ​(xt​,t,c,Xmem​)∥22​]

关键在于梯度只流向产生 Xmem​ 的编码器，θ 不动。

Steering vector（仅用于 §3 的探索性实验）。 对第 t 个去噪步、第 ℓ 层，取正负样本的 cross-attention value 向量在样本 j 与空间位置 k 上的均值之差：

st,ℓ​=Ej,k​[Vt,ℓ,kpos​(j)]−Ej,k​[Vt,ℓ,kneg​(j)]

直觉：正样本用「描述了物理规律」的 prompt 生成，负样本用空 prompt，两者的平均激活之差就近似指向「更遵守物理」的方向。推理时按尺度加回去：

Vt,ℓ,k​←Vt,ℓ,k​+αs~t,ℓ​

α 控制强度。一个重要的工程细节：干预只在早期和中期去噪步施加，跳过最后三分之一，因为后期步决定细粒度视觉质量，强行干预会损伤画质。

频域分解。 对特征做三维 FFT x^=F(D,H,W)​(x)，然后

x^low​=x^⊙Mlow​,x^high​=x^⊙Mhigh​

xlow​=F−1(x^low​)+x,xhigh​=F−1(x^high​)+x

面向不熟悉的读者补一句：FFT 把信号从「每个位置/时刻的值」换成「每种变化快慢的成分强度」。空间与时间上变化慢的成分（低频）对应大块的颜色、形状、身份；变化快的成分（高频）对应边缘、纹理和快速运动。掩码不是硬置零而是把被抑制频段的幅值缩到 0.2，加上残差连接，这两个设计都是为了稳定训练——完全滤掉一侧会让梯度信息丢失过多。

共享注意力聚合。

xattnlow​=SAϕ​(xmemlow​),xattnhigh​=SAϕ​(xmemhigh​)

注意两路用的是同一组参数 ϕ。这既省参数，也强制两路在同一空间里被聚合——消融显示这一点很重要（见 §7）。

§ 7 — 实验设计与结论 ​

DiT 的隐状态到底能不能被干预？ §3 的探索实验在 Wan2.1 I2V-14B 上做，prompt 是「机械爪在白色投影幕前握住一个黄色马克杯，下方有一块混凝土砖，机械爪松手，静态镜头」。基线的结果是杯子向上飘（违反重力）；加高通引导后杯子自然下落，轨迹合物理但背景出现噪声；加低通引导后杯子突然下落且有不真实的转折，同时把源视频里的新物体引了进来。三个结果同时支持了「可干预」和「高/低频分工」两个结论，也暴露了训练无关干预的副作用——这正是转向可学编码器的动机。

记忆能不能改善物理一致性？ 在 PhyGenBench（160 条 prompt、27 条物理定律、力学/光学/热学/材料四个域，GPT-4o 作为 MLLM judge）上，作者报告两个骨干加上 DiT-Mem 后在全部四个物理域都有一致提升：1.3B 版本超过所有开源基线和若干商业系统，达到与更大的 Wan2.2 TI2V-5B 相当的水平；5B 版本进一步取得多数维度的最好成绩。作者特别指出光学与热学上的提升最明显。（该表数值在 HTML 中未渲染，此处只引作者文字结论。）

会不会牺牲画质？ 在 VBench 上按低层（Color、Appearance Style、Object Class）与高层（Subject Consistency、Human Action、Spatial Relationship、Multiple Objects）分组评估。作者的结论是：subject consistency 与骨干持平、appearance style 基本保留，说明记忆模块没有破坏视觉美感；小骨干上 object class 有轻微退化，但在 5B 上消失。在 OpenVidHD 测试集（100 条与训练/检索均不重叠的片段）上，表 5 的数值可读：Wan2.1 的 FVD 为 1479.10，加上记忆后降到 1354.22（作为参照，CogVideoX-5B 为 1420.56，VideoCrafter2 为 1842.92）；同表其余三列的列名在 HTML 中丢失，作者文字称 CLIP 与 Action 略有提升、motion 幅度保持竞争力。

高频和低频真的分工吗？ 表 4 是控制实验（Wan2.1+Ours 为完整模型）：只用低通时 Object Class 从 64.63 升到 67.63、Subject Consistency 从 96.29 升到 96.67，即在外观类指标上更强；只用高通时 Spatial Relationship 从 71.35 升到 73.03、Multiple Objects 从 61.00 升到 75.13，即在语义/动态类指标上更强，但 Color 从 88.96 掉到 80.03。这确实验证了两路的互补性。需要如实指出的是：在这张表的多个单项上，完整模型并不是最优的——它在 Multi-Obj 上明显低于 HPF-only，在 Obj. Class 上低于 LPF-only。可以推断完整模型是在两类目标之间取折中而非同时取上界，但论文没有讨论这一点。

每个组件贡献多少？ 表 6 在 PhyGenBench 上逐步加模块（列名未渲染，末列为平均）：基线 Wan2.1-T2V-1.3B 平均 0.47；只加 3D 卷积升到 0.50，但定性图显示这一变体出现严重结构幻觉（画面里凭空多出一个悬浮的杯子）；再加高通滤波修好了结构问题、运动更自然，平均 0.49，代价是人和手的细节被模糊；再加低通把外观信息补回来，平均 0.50；用独立注意力（SPA）到 0.51；改成共享注意力（SA，即完整模型）到 0.54，是最大的单步提升。这条消融链的价值在于它给出了因果叙事而不只是数字：3D 卷积提取时空特征但会幻觉、高通修结构但丢细节、低通补细节但会把参考物体的外观带进来、共享注意力让两路交互从而在「增强运动」与「不过度注入参考外观」之间取得平衡。

记忆库要多大？ 附录的记忆规模研究显示，记忆越大越好（完整 430K 最佳），但缩到二十分之一时性能仍然很强。作者归因于编码器的判别能力。

§ 8 — Take-aways ​

5 句话版：视频 DiT 缺的是世界知识而不是渲染能力，本文用外挂记忆而不是继续训练骨干来补。前置实验证明 DiT 的隐状态可以被 steering vector 加性干预，且在嵌入空间做一次高/低通滤波就能把外观信息与动力学信息分开——低频管「长什么样」，高频管「怎么动」。据此设计的 DiT-Mem 用 3D CNN + 高低通滤波 + 共享自注意力把检索到的参考视频压成约 1,000 个 memory token，插进冻结 DiT 的每个自注意力层。只训练 150M 参数、只用 10K 样本，就在 PhyGenBench 的四个物理域上一致提升，且不损伤 VBench 上的画质、FVD 从 1479 降到 1354。消融显示共享注意力是最关键的一步，因为它让两路频段互相约束，避免把参考视频的物体外观直接搬进生成结果。

3 句话版：把 LLM 的 in-context memory 搬到视频扩散上，关键是先证明 DiT 的隐状态可被干预、再用频域滤波把外观与动力学解耦。DiT-Mem 冻结骨干、只学一个 150M 的记忆编码器，用 10K 数据换来物理一致性提升。高低频两路必须共享注意力做交互，否则要么幻觉结构、要么把参考视频的外观照搬过来。

1 句话版：给视频扩散模型接一个可学的、频域解耦的外挂记忆，冻住骨干也能让物体按重力落下。

§ 9 — 最脆弱的假设 ​

最脆弱的假设是：频域的高低通分解与「物理动力学 / 外观」这组语义划分是对齐的。

整个方法的结构性设计——两路滤波、两路 token、分别归因——全部建立在这条上。如果它不成立，DiT-Mem 就退化成一个普通的双分支特征提取器，「高频负责物理」的解释只是事后叙事。

它在实践中可能不成立的理由很具体。频率描述的是信号变化的快慢，而不是语义类别。一个缓慢的物理过程——水面缓缓上升、物体在斜面上匀速滑动、热传导——在时间维上就是低频信号；反过来，高频的时空成分同样包含纹理噪声和压缩伪影。所以「高通 = 物理」在慢动力学上可预测地失效。论文的探索性实验只用了重力和碰撞这类快速事件，恰好落在高频有利的一侧。

论文为此提供的证据是表 4 的控制实验：HPF-only 在 Spatial Relationship 与 Multiple Objects 上更强、LPF-only 在 Object Class 上更强。但这两个指标属于 VBench 的语义类，不是直接的物理指标；用它们支持「高频编码物理」是间接的。缺的证据是：在 PhyGenBench 上按物理域（力学 / 光学 / 热学 / 材料）拆开做 HPF-only vs LPF-only 的对比。热学与材料变化通常是慢过程，如果在这两个域上高通并不占优，假设就要打折。作者自己提到 5B 模型「在光学和热学上提升最明显」，这与「高频管物理」的叙事其实存在张力（属于推断，论文未讨论）。

§ 10 — 最小复现实验 ​

一周内可做、不需要训练记忆编码器的验证，目标是直接检验频段与物理语义的对齐关系。

数据与实现：取任一开源视频 DiT（Wan2.1-T2V-1.3B 即可，单卡可跑）。按论文 §3 的方法构造 steering vector：挑选 8 个物理概念，分成两组——快过程组（自由落体、碰撞反弹、绳索绷断、飞溅）与慢过程组（融化、热膨胀、液面上升、缓慢弯曲）。每个概念各生成 20 对正负样本（物理描述 prompt vs 空 prompt），记录 cross-attention value，按论文公式求差。

测量：对每个概念分别用低通与高通滤波后的 steering vector 做干预，α 扫 3 个档位，每档生成 20 条视频，用一个固定的 VLM judge（或人工两两比较）评「该物理过程是否被正确呈现」的胜率。

判据：若快过程组高通显著优于低通，而慢过程组两者持平甚至低通更优，则「频率 ≈ 物理」的假设只在快动力学上成立，论文的结构性主张需要限定适用范围；若两组都表现为高通更优，假设得到独立支持，且比论文用 VBench 语义指标的间接证据强得多。这个实验只需要推理，不需要训练。

§ 11 — 最强反例设计 ​

替代解释路线：DiT-Mem 的收益主要来自检索本身，而不是频域解耦或可学编码器。

论文的记忆库是 OpenVidHD-0.4M，训练集是其中的 10K 子集，检索索引用剩余 430K；PhyGenBench 的 prompt 描述的是常见物理现象，与这类真实视频库高度重合。也就是说，检索到的 top-5 参考视频很可能就是同类物理现象的真实录像。那么一个几乎不需要学习的基线就能构成威胁：把 5 条检索视频的 VAE 潜特征直接做时间平均池化成同样数量的 token 注入（不做任何 FFT、不做注意力、不训练任何参数），或者做一次简单的线性投影后注入并只训练这个投影矩阵（参数量比 150M 小两个数量级）。如果这个朴素基线就能拿到大部分 PhyGenBench 提升，那么「频域解耦」的贡献就被证伪为叙事而非机制。

第二类可预测失败：反事实与罕见物理。检索的前提是记忆库里有对应的现象。构造一批记忆库中不可能出现的 prompt——月球重力下的球体反弹、超流体爬壁、真空中的羽毛与铁球同时落地——在这些 prompt 上，检索会返回语义上「最像」但物理上错误的视频（普通地球重力的反弹），记忆注入应当把生成结果推向错误的方向。若实验证实 DiT-Mem 在这类 prompt 上劣于未加记忆的骨干，那么这个方法学到的不是「物理知识」，而是「检索到的样例的模仿」，它对世界模型这一目标的贡献要重新评估。论文的记忆规模研究显示缩到 1/20 仍然很强，这一现象也可以被这个替代解释覆盖（属于推断）。

§ 12 — Follow-up Research Idea ​

驱动局限：本文的记忆是按语义检索、按频段切分的。检索用的是 caption 的文本相似度，切分用的是与语义无关的频率。两者都不涉及「这段参考视频到底体现了哪条物理规律」。于是记忆是样例式的，不是规律式的——它能告诉模型「倒水看起来像这样」，不能告诉模型「液体在容器内的自由表面保持水平」。这直接导致 §11 里的反事实失败模式，也解释了为什么记忆库越大越好（覆盖率驱动）。

新的 framing：把记忆的组织单位从「视频片段」换成「不变量」。具体地，不去检索相似视频，而是维护一组可执行的物理约束检查器（自由表面水平、动量守恒、接触不穿透、阴影方向与光源一致），每条约束由一个轻量的可微判别器实现，输入是 DiT 中间层解码出的粗糙场景状态，输出是违背程度。生成时不是注入 token，而是注入梯度——把违背程度对潜变量求导，作为额外的引导项加进去。这与 classifier guidance 是同一套数学，但被引导的目标从类别标签换成了物理不变量，而记忆库从「视频集合」变成了「约束集合」，规模从 43 万降到几十条，且天然支持反事实（把重力常数换成月球值，约束检查器自动适配）。

可借鉴的相邻工具：物理信息神经网络（PINN）里把 PDE 残差当损失的做法；程序合成 / 神经符号里用可执行谓词做验证的框架；以及扩散模型里的 classifier guidance 与 universal guidance（用任意可微目标在采样时纠偏）。

第一个实验：只做一条约束——「液体自由表面在静止时保持水平」。用一个小的分割网络从 DiT 的中间潜变量解码出液面掩码，用掩码的主轴方向与水平方向的夹角作为违背度，在采样的中后期把它的梯度加进去。在 PhyGenBench 的液体子集上与 DiT-Mem 对比，同时在一个反事实集合（倾斜的容器、旋转参考系）上对比。判据：如果单条约束就能在液体子集上追平检索记忆，且在反事实集合上明显超过它，那么「规律式记忆」这条路线比「样例式记忆」更值得投入；如果解码器本身在中间潜变量上不可靠，说明瓶颈在于中间表示的可读性，这本身也是一个有价值的负结果，指向先做 DiT 中间层的可探测性研究。

Past- and Future-Informed KV Cache Policy with Salience Estimation in Autoregressive Video Diffusion ​

项内容
arXiv2601.21896
提交日期2026-01-29
作者Hanmo Chen, Chenghao Xu, Xu Yang, Xuan Chen, Cheng Deng
分类cs.CV
一句话用双向 teacher 的注意力算出「兼顾过去与未来」的 token salience 作监督，蒸馏出一个只挂在最后一层的轻量 MLP，让因果 AR 视频模型在推理时按 salience 淘汰 KV Cache 而非 FIFO。

所属教程：自回归视频生成

版本说明

本文基于 arXiv v3（2026-02-04 修订）全文撰写；v1 提交于 2026-01-29。HTML 中带有 ICML 模板标记，代码以匿名仓库形式发布，推测投稿时处于双盲评审阶段。

§ 1 — 研究问题与重要性 ​

实时 AR 视频扩散（Self Forcing、LongLive 一系）靠 KV Cache 撑住上下文，但缓存容量是固定的，满了就得扔。现在扔的方式几乎清一色是 FIFO——最老的先走。这个策略隐含一个假设：token 的价值随时间单调衰减。对视频来说这个假设很脆弱：一个被遮挡的主体、一个会重新入画的物体，它们的 KV 恰恰是最该留住的，却因为「老」被最先淘汰。结果是长视频里主体身份漂移、背景不断重写。

把 FIFO 换成「按重要性淘汰」看起来是显然的，但在因果 AR 模型里有个硬障碍：判断一个历史 token 重要与否，取决于它对未来帧的贡献，而因果模型在生成时看不到未来。本文要解决的就是这个信息不对称。这件事的价值是双向的——缓存变小既省显存又提吞吐，同时留下的是真正有用的 token，长时程一致性反而更好。

§ 2 — 前人工作与不足 ​

AR 视频扩散这条线上，Ca2-VDM 与 Diffusion Forcing 打下 teacher-forcing / 部分加噪的基础，CausVid 用 DMD 从双向 DiT teacher 蒸馏出少步 AR 生成器，Self Forcing 用 self-rollout 对齐训练与推理，LongLive 借 StreamingLLM 的思路加入 frame sink 并把训练拉长到更长序列，Reward Forcing 给 DMD 加奖励函数。这些工作全部聚焦在误差累积与训练-推理错配，把 KV Cache 当成一个容量固定、FIFO 维护的黑箱，没人问过「该留哪些」。

LLM 那边这个问题已经研究得很透：H2O 保留累积注意力高的 token，SnapKV 用观察窗口利用时间局部性，PyramidKV 按层递减预算，CAKE 做层敏感度自适应级联淘汰，Ada-KV 做头级预算分配，RazorAttention 用 retrieval head 指导压缩。本文明确指出这些方法不能直接搬：扩散是多步去噪，注意力模式在不同 timestep 上并不一致，而且 AR 视频扩散只在最后一步 t0​ 保留 KV，与 LLM 的逐 token 单次前向根本不同。

视频侧已有的尝试（论文引 Xiang et al., 2025；Yi et al., 2025）做语义级或 prompt 级的稀疏 KV 检索，但推理时要付额外算力。更关键的批评是「近视」：它们只根据已有的局部邻居来评估重要性，无法评估一个 token 对尚未生成内容的潜在影响。这解释了为什么「未来相关性」长期没被考虑——在因果架构里它根本不可观测，除非引入一个能看见全序列的外部信息源。

§ 3 — 重建作者的思考路径 ​

第一步是承认因果模型自己评不了未来价值，于是去找一个能看见未来的模型。DMD 训练流程里现成就摆着一个：那个提供监督的双向 DiT teacher（Wan2.1-14B）。它的 self-attention 同时建模前后依赖，把一整段视频喂进去，注意力矩阵里就写着「哪个 token 被后面的帧反复查询」。这个信号在因果学生那里拿不到，但可以蒸馏。

第二步是怎么从注意力矩阵里读出重要性。沿用 H2O 的做法，对 query 维取 max 得到每个 key 的最强响应。作者做了个直接的检查：把最大响应对应的 key 索引与 token 索引均匀分成 7×7 统计一遍（图 3a），发现分布强烈集中在对角线上——self-attention 压倒性地关注帧内或时间上非常近的信息。这意味着朴素的全局 max 会系统性偏袒局部 token，恰好把跨帧的长程关联压下去，而后者才是时序一致性的来源。这个观察逼出了第三步：把注意力矩阵按块拆成下三角（过去）、对角（当前）、上三角（未来）三部分分别取 max 再平均，强行给三个方向等权。

第四步是成本。如果每一层都算 salience 再选 top-k，开销会吃掉压缩带来的收益。作者测了 Wan2.1-14B 各层在 t0​ 时刻 top-k 集合与最后一层的重叠率（图 3b），发现层间共识很强，于是只在最后一层挂一个头。最后一步是这个头的形态：既然 Q/K/V 已经过了几十层、上下文信息高度饱和，salience 又只用于排序，那就没必要再堆 attention 或卷积，一个两层 MLP 就够——这个判断后来被消融反证支持。

§ 4 — 核心 Intuition ​

因果 AR 模型不知道哪些历史 token 会在未来被用到，但双向 teacher 知道，而 teacher 本来就在 DMD 流程里。于是把「这个 token 未来还有没有用」变成一个可蒸馏的标量回归任务：teacher 用全序列注意力算出兼顾过去/当前/未来三个方向的 salience，学生用一个只看 Q/K/V 的小 MLP 去拟合它。推理时按预测分数淘汰缓存，被遮挡但会重现的主体因此能留在 cache 里，而 FIFO 一定会把它扔掉。

§ 5 — 具体方法与完整 Pipeline ​

以生成一段 30 秒、832×480、16 fps 的视频为例。模型骨干是 Wan2.1-T2V-1.3B，一个 latent 帧 = 1560 个 token，推理时 KV Cache 固定为 4680 个 token（正好 3 帧）。

  1. 算 teacher 的 salience（仅训练期）：real score network 对当前 chunk 做全双向 attention，得到 P=softmax(QK⊤/D​)。按块长 LB​=4680 把 P 拆成下三角/对角/上三角，各自对 query 维取 max、对 12 个 head 取平均，再按 token 所处位置平均 2 或 3 个分量，得到监督信号 sreal​。
  2. 学生预测：把学生最后一层的 Q,K,V（各 1×12×4680×128）先把 head 维并进特征维得到 1536，再沿特征维拼成 4608，送进 S-MLP（4608 → SiLU → 1024 → 12），最后对 12 维取平均得到每个 token 的标量分数。
  3. 训练：SmoothL1 损失对齐两者，与 DMD 损失一起优化。因为开了 gradient checkpointing，原地改写 KV Cache 会导致重算时缓存状态不一致、梯度出错，所以作者不搬 KV，而是维护一个与缓存同步滚动的 top-k 索引表 Is​，把 Select(KV;Is​) 塞进去噪式子里。训练分两段：先 500 步不淘汰，再 2500 步开淘汰，共 3000 步、16 张 H200、约两天。
  4. 推理：缓存从空开始，逐 chunk 生成；每生成完一个 chunk 就拿到它的 KV 与预测分数，一旦缓存超容量，就把新旧分数拼在一起取 top-k 保留、其余淘汰，下一个 chunk 在更新后的缓存上继续。整个过程只多了一次小 MLP 前向。

§ 6 — 核心数学推导 ​

AR 视频扩散把联合分布因子化为 p(x1:N)=∏i=1N​p(xi∣x<i)，Self Forcing 的一步去噪写作 xtj−1​i​=Ψ(Gθ​(xtj​i​,tj​,KV),tj−1​)，其中 Ψ 是重新加噪的前向过程。本文唯一改动的是把 KV 换成 Select(KV;Is​)，即所有变化都发生在「喂哪些 KV」这一处，模型结构与去噪流程本身不动。

salience 的定义是全文的核心。设块边界 ℓ(i)=⌊i/LB​⌋⋅LB​、h(i)=ℓ(i)+LB​，对某个 key 位置 j，把所有 query 位置 i 分成三类：Ilow​(j)={i∣j<ℓ(i)}（j 落在 query 所在块之前，即 j 被未来的 query 使用）、Idiag​(j)（同块内）、Iup​(j)={i∣j≥h(i)}（j 被更早的 query 使用）。三个分量各自取 max 再对 head 平均：

lowb,j​=N1​n∑​(i∈Ilow​(j)max​Pb,n,i,j​)

diag 与 up 同理。最终分数按位置分段平均：

sb,j​=⎩⎨⎧​2diagb,j​+lowb,j​​,3upb,j​+diagb,j​+lowb,j​​,2diagb,j​+upb,j​​,​0≤j<LB​LB​≤j<L−LB​L−LB​≤j<L​

这个分段写法值得拆开看。取 max 而非求和，是为了捕捉「最强的一次被引用」，避免被大量弱引用稀释；分三块再等权平均，是为了对抗前面观测到的对角线偏置——如果直接对全局取 max，几乎所有 token 的分数都会由同帧内的邻居决定，跨帧引用被淹没。分段是边界处理：序列首块没有更早的 query，末块没有更晚的 query，相应分量不存在，只能平均剩下的两项。这里有一个隐含的归一化问题：三项各自取 max 后直接平均，等价于假设过去/当前/未来三种引用在同一量纲上可比，但对角块的注意力质量本来就远高于另外两块，等权平均实际上是在放大跨块引用的相对权重。论文没有讨论这一点（此处为基于证据的推断）。

蒸馏损失是 LS​=SmoothL1(Sϕ​([Q,K,V]),sreal​)。选 SmoothL1 而非 MSE 的合理解释是 salience 分布长尾（少数 token 分数极高），L2 会被离群值主导，而分数最终只用于排序，绝对值精度并不重要。

§ 7 — 实验设计与结论 ​

问题一：短视频上会不会掉质量？ 在单张 H100 上按 VBench 官方 prompt 生成 5 秒视频。PaFu-KV 吞吐 23.6 FPS，高于 LongLive 的 20.7 与 Self Forcing 的 17.0；Total 85.12 为全表最高，Quality 88.56 也是最高。但这里必须指出论文表述与表格的落差：Semantic 只有 71.36，而 Self Forcing 是 81.28、LongLive 76.47、Wan2.1-1.3B 80.09。也就是说 Total 的提升完全由 Quality 拉动，语义遵循度相对自己的训练基座掉了约 10 分。正文的写法是「Total 高于 Self Forcing 与 LongLive，Semantic 高于 Rolling Forcing」——两个比较对象被分开选取，回避了这个下降。

问题二：长视频上一致性是否真的更好？ 按 VBench-Long 官方 prompt 生成 30 秒视频。PaFu-KV 的 subject consistency 93.91、background consistency 94.14、imaging quality 71.23 三项最优，quality drift 0.29 优于绝大多数基线。同样需要如实标注两处：motion smoothness 98.14 在全表中仅高于 CausVid 的 98.09，作者承认为「轻微退化」；quality drift 上 Rolling Forcing 的 0.01 明显更好，而表头把 drift 标成 ↑（drift 是成像质量的绝对差，应当越低越好），属于表格标注错误。

问题三：每个设计选择值多少？ 消融全部在 VBench-Long 上做。把 SEH 换成 1D 卷积（kernel 3）或 MHA，参数更多但全面变差（Conv 的 subject 85.47、MHA 88.65，对比完整模型 93.91），作者据此论证「复杂结构无益」。把 salience 计算换成全局 max，subject 掉到 87.65；换成全局 average，直接崩到 78.87 且 motion smoothness 只有 76.94——这是分块设计最强的证据。去掉 frame sink 仅轻微下降（93.12/93.09/0.44），作者自己承认它不是主要增益来源。

问题四：缓存能压到多小？ 4680 之上（9360、6240）与完整模型「相当」，4680 之下断崖：3120 时 subject 85.26、motion 82.11，1560 时 74.48/79.44。这个断崖恰好落在「少于三帧 latent」处。诚实地说，9360 在 subject（94.12）、imaging（71.89）、drift（0.25）三项上都优于 4680，6240 在 background、motion、aesthetic 三项上优于 4680——所以 4680 是效率取舍点，不是质量最优点。

作者的自我披露：附录 E 明确承认，尽管方法减小了 KV Cache，实际显存节省相当有限，原因是 FlashAttention 已把注意力显存从 O(N2) 降到约 O(N)，再压缓存边际收益很小；要真正省显存得减参数量。这与摘要里「reducing memory footprint at inference time」的措辞存在张力，实际兑现的主要是吞吐。

§ 8 — Take-aways ​

5 句话版：AR 视频扩散普遍用 FIFO 维护 KV Cache，隐含「越老越没用」的假设，与遮挡-重现这类场景直接冲突；判断历史 token 的未来价值在因果模型里不可观测，但 DMD 流程里的双向 teacher 恰好可以观测，于是可以蒸馏；作者进一步发现 self-attention 有强对角线偏置，朴素 max 会淹没跨帧引用，因此把注意力按块拆成过去/当前/未来三分量等权聚合；由于层间 top-k 高度重叠，只需在最后一层挂一个两层 MLP，开销可忽略；在 VBench/VBench-Long 上吞吐 23.6 FPS、长视频主体与背景一致性最优，但语义分相对 Self Forcing 明显下降，显存节省被作者自己承认有限。

3 句话版：把「哪些 KV 该留」从启发式变成可学习的标量回归，监督信号取自 DMD 流程里现成的双向 teacher。关键设计是按块拆分注意力以抵消对角线偏置，以及只在最后一层预测以保住效率。长时程一致性与吞吐都有提升，代价是语义遵循度下降且显存收益有限。

1 句话版：用双向 teacher 教因果学生「哪些历史 token 未来还用得上」，据此淘汰 KV Cache。

§ 9 — 最脆弱的假设 ​

最脆弱的是：teacher 在完整真实序列上算出的 attention-max，等价于「该 token 对学生未来生成的价值」。这是一条跨模型、跨任务的迁移假设，中间隔了三重缺口。其一，teacher 是 14B 双向模型，学生是 1.3B 因果模型，两者的注意力分配模式没有理由一致——论文测的层间重叠是在 teacher 内部测的，不是 teacher 与学生之间。其二，attention 权重高不等于对输出贡献大，这一点在 LLM 可解释性文献里早有争议，本文直接沿用 H2O 的前提未作检验。其三，sreal​ 是在 teacher 看到完整 chunk 的条件下算的，而学生在推理时面对的是自己生成的、带累积误差的历史；分布一旦漂移，蒸馏出的分数就可能系统性错判。

如果这条假设不成立，方法的核心贡献（「past- and future-informed」这个卖点）就退化成「一个学出来的、恰好比 FIFO 好一点的启发式」。论文提供的证据是间接的：分块 vs 全局 max/avg 的消融差距巨大，说明这个特定的聚合方式很重要。但缺的是最关键的一环——没有任何实验直接验证「被 SEH 判为高 salience 的 token 确实在后续帧被高频引用」，哪怕在 teacher 上做一次相关性分析也好。

§ 10 — 最小复现实验 ​

一周内可做，不需要复现 DMD 训练。取 Self Forcing 或 LongLive 的公开权重与 Wan2.1-14B teacher，只做离线验证而非训练。

  • 数据：VBench-Long 官方 prompt 里取 30 条，每条用现成模型生成 30 秒视频，保留全部 latent。
  • 实现：在 teacher 上对生成结果做一次全双向前向，按论文式 (4)(5) 算出每个 token 的三分量 salience；同时记录该 token 在后续每一帧被 query 的最大注意力权重（这是「未来真实被用到的程度」的直接度量）。
  • 测量：两者的 Spearman 相关；再与朴素全局 max、与「token 年龄」（FIFO 的隐式分数）各算一次相关。
  • 判据：若分块 salience 与「未来实际被引用度」的相关显著高于全局 max，且明显高于年龄，则 §9 的核心假设得到支持；若三者相关接近，则增益更可能来自训练本身而非 salience 的信息含量。

这个实验的好处是完全绕开了 3000 步 × 16 卡 H200 的训练成本，只需推理。

§ 11 — 最强反例设计 ​

最有力的攻击是指出一个缺失的对照：论文全部主实验把 PaFu-KV 与 Self Forcing / LongLive / Rolling Forcing 的公开权重比较，而 PaFu-KV 自己额外做了 3000 步 DMD + streaming long tuning 训练，且第二阶段的 2500 步是在「缓存被淘汰」的条件下训练的。表格里没有一行是「同样的 3000 步训练、同样的 4680 缓存、但用 FIFO 淘汰」。缺了这一行，就无法区分增益来自 salience 排序，还是来自「模型被额外训练了 2500 步去适应一个只有 3 帧的短缓存」。后者本身就是一种强正则——模型被迫学会不依赖远端历史，主体/背景一致性自然会涨。

第二条替代解释来自 Table 1：Semantic 从 81.28（Self Forcing）掉到 71.36，而 Quality 从 85.07 涨到 88.56。这个方向性组合与「模型变得更保守、更倾向输出平滑稳定但语义偏离的内容」完全一致，也与长视频里 motion smoothness 反而略降、consistency 大涨的模式互相印证。一个坚持这个读法的反对者会说：PaFu-KV 买到的是「稳定」，卖掉的是「跟随 prompt」，而 VBench Total 的加权方式恰好让这笔交易看起来划算。

第三，SEH 架构消融也有替代解释：Conv 与 MHA 参数更多却大幅变差，比起「复杂结构无益」，更简单的解释是它们在同样的 3000 步预算下没训收敛。论文没有报这两个变体的训练损失曲线，无法排除。

可预测会失败的场景：本方法的 salience 由 teacher 在 5 秒窗口内算出，LB​ 就是一个 chunk。对于跨越远超单窗口的依赖（例如一个角色离场 20 秒后再回来），teacher 自己也看不到那么远，监督信号里根本不含这段关系，因此 PaFu-KV 在这类场景上不应比 FIFO 更好。

§ 12 — Follow-up Research Idea ​

驱动局限：salience 目前是一个静态标量——训练完之后，一个 token 的分数与「接下来要生成什么」无关。但缓存该留什么，本质上取决于未来的意图：镜头要拉回起点，就该留住早期背景；要跟随一个新入场的主体，早期背景就是负担。把它压成一个与查询无关的标量，天然丢掉了这个条件性。

新 framing：把 KV Cache 管理重新表述为条件化的检索问题而非固定排序问题——不是「哪些 token 重要」，而是「给定下一个 chunk 的 prompt / 动作条件，哪些 token 与之相关」。这与 LongLive 的 KV re-caching 处理 prompt 切换的动机是同一件事的两半：re-caching 承认缓存里的语义会过期，但它的应对是全量重算；条件化检索则让缓存按需重排。

可借鉴的相邻工具：LLM 的 retrieval head 与 RazorAttention 已经在做「哪些头负责回看」，而记忆增强模型里的可微检索（以及 Ada-KV 的头级预算分配）提供了把预算分配变成学习目标的现成机制。更激进一点，可以把它当成 amortized inference：训一个小网络直接从「下一段 prompt embedding + 缓存摘要」预测保留掩码。

第一个实验：在同一 Wan2.1-1.3B 骨干上，把 SEH 的输入从 [Q,K,V] 扩展为 [Q,K,V,cnext​]（下一 chunk 的文本条件），训练目标不变仍是蒸馏 teacher salience，但 teacher 侧的分数改为「只统计来自下一 chunk 的 query 的最大注意力」，即把监督从「全局重要」收窄为「对下一步有用」。评测选 VBench-Long 里带明确场景切换的 prompt 子集，测两个东西：一是 prompt 切换后 3 秒内的语义遵循度（正好针对 §7 暴露的 Semantic 下降），二是同样缓存预算下的主体一致性。若条件化版本能在不牺牲一致性的前提下把 Semantic 拉回 Self Forcing 水平，就说明当前方法的语义损失来自「排序与意图无关」而非缓存变小本身。

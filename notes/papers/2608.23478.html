Act with Intent: Distilling Behavior Intent for Vision-Language-Action Models ​

项内容
arXiv2608.23478
提交日期2026-08-24（v1，本文按 v1 全文撰写）
作者Sangoh Lee, Sangwoo Mo, Wook-Shin Han（POSTECH GSAI / IME）
分类cs.RO, cs.AI, cs.CV
一句话让一个冻结的物理常识 VLM 在事后看着执行视频读出"这段行为要达成什么局部目标"，把它的多模态隐状态蒸馏进 VLA 动作解码器的中间层，并用注意力瓶颈强制后续解码必须经过这个意图状态。

所属教程：视觉语言动作模型 VLA

§ 1 — 研究问题与重要性 ​

VLA 的视觉语言骨干这几年被喂得很饱，动作解码器却几乎全靠 behavior cloning 训练。BC 告诉解码器"在这个观测和指令下，演示者发出了哪条电机指令"，但它从来没有告诉解码器这条指令是为了达成什么。论文把这句话说得很精确：监督信号规定了 which motor command was demonstrated，而 the local objective served by the behavior under the instruction 始终是隐式的。

为什么这个区分不是文字游戏？因为操作任务里存在两个方向的多对多。同一个阶段性动作（比如"合拢手指"）在不同任务下服务于完全不同的目标；同一个目标（"把茄子放进篮子"）又可以由差异很大的轨迹实现。解码器如果只学到 context → action 的映射，它就没有任何内部变量去表示"我现在这一段是在干什么"，于是在需要跨阶段保持一致的长程任务上会散架。

论文给出的证据是直接的：在 SimplerEnv-Bridge 上，GR00T-N1.7 的平均成功率从 64.3% 提到 84.7%；在 RoboCasa Kitchen 的 24 个任务上，受控的 GR00T-N1.7 基线从 64.1% 提到 70.3%；真机四个任务平均从 62.0% 提到 68.7%。更值得看的是最后一条：真机上的增益集中在长程任务，Drawer Storage 与 Cross-Bin Stacking 分别 +10.7 与 +7.3 pp，而两个短任务只有 +4.0 与 +4.7 pp。

§ 2 — 前人工作与不足 ​

未来监督这条线已经很拥挤。有人生成未来帧或 subgoal 图像（UniPi 一类、SuSIE 一类），有人预测未来潜观测或世界-动作表示（FLARE 走的是解码器中间层表示对齐），有人用光流、point track、visual trace、affordance chain 描述运动如何展开，还有 ECoT 这类把具身推理链写成文本再监督。这些方法确实证明了"动作之外的中间监督有用"，但论文的批评点很准：它们把解码器的接口定义成某一个具体的未来实现，而不是这些实现共享的语义目标。未来帧是"可能发生什么的某个采样"，不是"即将到来的行为的目标"。

潜在计划这条线（Play-LMP 从 play 数据学连续 plan，LADS 学语言正则化的离散 plan）离本文最近，但它们的 latent 是与策略联合训练出来的重构码：这个 latent 之所以有意义，是因为它能重构轨迹。INDI 蒸馏的是一个固定教师对行为的语义解读，教师不参与策略优化，因此 latent 的语义不会为了让策略更好优化而漂移。

论文没有停在口头区分上。在同一个固定 evaluation run 上（该 run 的动作-only 基线是 61.5%），它跑了四个对照：只加视觉/文本 grounding 得 60.0%，只加一个没有任何目标的"自由 latent"得 57.0%——两者都低于基线；换成未来视觉监督得 68.0%；只做教师意图对齐得 76.0%。也就是说，"多给容量"和"给未来目标"都复现不出这个效果。

§ 3 — 重建作者的思考路径 ​

抛开本文的贡献，2026 年初一个研究者手里已有的东西是：(a) 表示对齐在生成模型（REPA）和 VLA 解码器（FLARE）里都被证明能提升下游质量；(b) 未来帧监督的方差很大，因为给定当前状态有很多合法未来；(c) 物理常识后训练的 VLM（Cosmos-Reason 这条线）能对机器人视频做出相当靠谱的行为解读。

把这三条摆在一起，一个自然的问题是：既然未来帧的歧义来自"事前有很多可能"，那能不能换到事后去取监督？训练时我们手上有整段执行视频，事后回看时"这一段在干什么"的歧义远小于事前预测"接下来会发生什么"。这就构造出一个天然的师生不对称：教师拿到 privileged hindsight（执行视频 + 粗动作摘要），学生只有标准 VLA 输入，学生要做的是从贫信息输入里恢复富信息教师形成的那个抽象。

下一个问题是蒸馏什么。让教师输出一句话再让学生对齐这句话，会把多模态信息压成语言瓶颈。所以取教师处理多模态证据时的中间层隐状态，而不是它生成回答之后的表示——论文后来专门做了这个对照（B.6 的 evidence-side vs generated-response 目标）。

最后一个问题最关键：怎么保证学生真的用这个恢复出来的状态，而不是把它当成一个挂在旁边、梯度上好看但推理时被绕开的辅助头。答案就是注意力瓶颈加错配 hinge：一半的更新里切断非意图行到 VLA context 的直连，逼信息过意图这道闸；再用一个 margin loss 要求"配对的意图"比"batch 内错配的意图"给出更低的下游损失。

§ 4 — 核心 Intuition ​

事前预测未来是个高熵问题，事后解读行为是个低熵问题。INDI 把监督搬到事后：让一个能看完整段执行的冻结 VLM 说清"这段行为服务的局部目标"，再要求部署时只能看到当前帧的策略在解码器中层把这个目标恢复出来。目标是所有合法实现共享的那一层，所以它比任何一帧未来都稳定；而注意力瓶颈保证了它不是装饰——后续所有动作预测的上下文必须从它身上流过。

§ 5 — 具体方法与完整 Pipeline ​

以 SimplerEnv-Bridge 的 "put eggplant in basket" 为例，走一遍。

训练侧（教师）。 取一段 H 步的演示片段 Wt​，构造多模态证据 Et​=(ot​,ℓ,cA​(Wt​),vidt:t+H​)：当前观测、指令、这段动作的粗文本摘要 cA​、以及这段的执行视频。冻结的 Cosmos-Reason2-8B 在一个 functional-intent prompt 下处理 Et​ 并生成一段目的陈述（token 跨度 St​）。同一次自回归前向里缓存两段隐状态：从中间层在 Et​ 上取意图目标 It⋆​（KI​=8 个槽），从末层在 St​ 上取文本目的目标 Rt⋆​（KR​=8）；视觉结果目标 Vt⋆​ 则来自另一个冻结视觉编码器（Cosmos-Reason2-2B）对端点观测 ot+H​ 的编码（每路相机 KV​=16）。选中间层的理由是：再往上教师就开始为语言生成特化了，多模态接地会流失。

训练侧（学生）。 预训练 VLA 的视觉语言模块 Fvlm​ 冻结，产生 context token Bt​。flow-matching 动作解码器被扩成五组行：本体感觉 Qt​、加噪动作 Atλ​、自条件的视觉/文本 grounding 行 ZtV,λ​、ZtR,λ​、以及 KI​ 个可学习的干净意图 query QI。在解码器 50% 深度处读出意图 query 的上下文化状态，投影到教师特征空间做余弦对齐。

信息流控制。 意图行只看 Qt​、Bt​ 和彼此；grounding 行看意图行和彼此；动作行看意图行和 grounding 行。一个二值门 α∼Bernoulli(0.5) 控制非意图行能否直连 Bt​，α=0 的更新迫使上下文必须经过意图 query。grounding 行的干净目标在部署时拿不到，所以先做一次 no-grad 前向预测出 ZˉtG​，detach 后在采样到的 flow 时刻重新加噪回填。

部署。 α=1，教师、缓存目标、对齐投影、错配分支全部移除。GR00T-N1.7 从 3.46B 涨到 3.50B 参数，单次策略查询 56.1 ms → 61.5 ms；π0.5​ 是 3.62B → 3.64B、24.4 → 29.7 ms。

训练规模。 Bridge 用 LeRobot 转换版 BridgeData V2（53,192 episode，1,893,026 帧，5 Hz），训 20,000 步、全局 batch 1,536；RoboCasa 训 60,000 步、batch 480。全部在单节点 3 张 NVIDIA B200（每张 183 GB）上完成。

§ 6 — 核心数学推导 ​

目标是让解码器建模

(At​,Vt​,Rt​)∼pθ​(At​,Vt​,Rt​∣Bt​,qt​,It​),

其中 It​ 是中间层恢复出的意图状态，而标准 BC 只建模 pθ​(At​∣Bt​,qt​)。

动作流保留原 VLA 的 flow matching 目标。给定噪声 ϵA​ 与 flow 时刻 λ，令 Atλ​=(1−λ)ϵA​+λAt​、uA​=At​−ϵA​，则

LA​=Eλ,ϵA​​[∥u^A​−uA​∥22​].

直觉上这是在学"从纯噪声走向真实动作块的直线速度场"，比逐步去噪的 DDPM 采样更省步数。

意图恢复用带 stop-gradient 的余弦对齐：

LI​=KI​1​k=1∑KI​​[1−cos(PI​(HI,t,kLtap​​), sg(It,k⋆​))].

用余弦而不是 L2 是有后果的：它只约束方向，不约束尺度。论文附录里的诊断量正好落在这个几何上——角预算定义为 L2 归一化后的目标离其均值方向的平均余弦距离，衡量"可供余弦目标利用的样本相关方向变化有多少"。三个教师的角预算是 0.0027 / 0.0098 / 0.0327，对应下游 54.5% / 73.5% / 85.5%。角预算 0.0027 意味着一个近乎常数的预测就能满足大部分对齐项，损失可以降下去而学不到任何东西。

grounding 流用 REPA 式表示对齐，对 G∈{V,R}：

LG​=Eλ,ϵG​​[KG​1​k∑​(1−cos(PG​(HG,t,kLout​,λ​),sg(Gt,k⋆​)))].

错配 hinge 是"意图必须被用上"的形式化。设 Dright​、Dswap​ 分别是用匹配意图与 batch 内循环平移后的意图继续解码得到的下游损失，

Lmis​=max(0, m+Dright​−Dswap​),m=0.05.

它只在 α=0 的更新上施加，并且 donor 表示被 detach，梯度不回流到被借用的样本。总目标

L=LA​+λI​LI​+λV​LV​+λR​LR​+λmis​Lmis​,

取 λI​=λV​=λR​=0.5、λmis​=0.1。

§ 7 — 实验设计与结论 ​

问题一：意图监督能不能提升现成 VLA？ SimplerEnv-Bridge 上 GR00T-N1.7 从 64.3% 到 84.7%，π0.5​ 从 52.3% 到 58.8%；RoboCasa（每任务 100 条演示）GR00T-N1.7 从 64.1% 到 70.3%，π0.5​ 从 34.9% 到 41.4%。一个漂亮的数据效率结论：100 条演示训出的 INDI（70.3%）与官方用 3,000 条演示训的 GR00T-N1.7 checkpoint（70.8%）只差 0.5 pp。

这里必须如实标注一个口径问题。Bridge 的 +20.4 pp 里，EP-Basket 一项就贡献了 36.0% → 96.0% 的 +60 pp；论文自己写明"扣掉 EP-Basket，剩下三项平均只提升 7.1 pp"。而且基线在这一项上本身异常低——同表里 SpatialVLA 在 EP-Basket 上是 100.0%。所以更保守的读法是：INDI 修好了 GR00T-N1.7 在某个任务上的一个病态失败，同时在其余任务上给了 5–12 pp 的稳定增益。这两件事的性质不同，头条数字把它们混在了一起。

问题二：增益来自"意图"还是来自别的东西？ 固定 run 的对照（基线 61.5%）：只加 grounding 60.0、自由 latent 57.0、未来监督 68.0、只做意图对齐 76.0、完整 85.5。容量和未来目标都不足以解释。机制消融同样清楚：去掉上下文瓶颈 85.5 → 70.0，去掉 Lmis​ → 74.0，两个都去掉 → 65.5。注意 65.5 仍高于 61.5，说明单纯的表示对齐本身有点用，但"强制使用"才是主要来源。

问题三：恢复出的 latent 真的像意图吗？ 三类证据。表示层面，意图按行为目标分离、按早/中/晚执行阶段组织；可读性上，从恢复意图解码出的目标物体 F1 是 0.693、动词 F1 0.432，而从最终文本 grounding 解码只有 0.314 / 0.195（oracle 教师目标是 0.998 / 1.000）——语义瓶颈确实落在意图这一层。因果层面，闭环干预：注入同目标内容保留 84.5% 成功率，跨目标降到 45.2%，高斯扰动降到 1.0%；强制早期阶段内容降到 7.3%、晚期 5.5%，并产生"靠近但不抓""空夹爪去放置"这类阶段一致的错误行为。

问题四：真机成立吗？ SO-101 leader-follower 遥操作平台（5-DoF 臂 + 1-DoF 夹爪），四个任务各 50 次试验。ID clean 71.0 → 76.0，held-out 物体 62.0 → 68.0，distractor 53.0 → 62.0。分阶段看，Cross-Bin Stacking 两者在取回并摆正第一块方块前几乎不可分（96.0 / 96.0），差距出现在转向第二块之后（74.0 → 80.0）；Drawer Storage 则从抓取阶段就拉开（50.0 → 70.0）并一路保持到关抽屉（24.0 → 36.0）。论文没有把两者硬说成同一个机制，这点是诚实的。

缺失的平凡基线。 全文没有报告"不动"或"重放一条固定轨迹"的成功率。SimplerEnv 这类任务上 no-op 大概率为 0，同表里 OpenVLA 的 1.0% 平均可以当作事实上的地板，所以这个缺口在仿真里危害不大；但真机四个任务、每个 50 次试验的绝对数字（尤其 Threading 基线已到 92.0%）没有任何平凡策略参照，读者无法判断 ID clean 上 +5.0 pp 的实际难度。

§ 8 — Take-aways ​

五句话版。 BC 只监督"演示了哪条动作"，未来监督只监督"某个具体的未来实现"，两者都没有监督"这段行为的目标"。INDI 让冻结教师 VLM 在事后看着执行视频读出这个局部目标，取其中间层多模态隐状态作为蒸馏目标。学生 VLA 在动作解码器 50% 深度处用 8 个意图 query 恢复它，并通过注意力瓶颈与错配 hinge 被迫真的使用它。SimplerEnv-Bridge 64.3 → 84.7、RoboCasa 64.1 → 70.3、真机 62.0 → 68.7，部署时教师全部移除、推理只多 5 ms。整个方法的语义上限由教师决定：换成没有具身接地的纯文本 LLM 教师，性能反而掉到基线以下。

三句话版。 把"事前预测未来"换成"事后解读行为"，用冻结的物理常识 VLM 当 hindsight 教师。把它的多模态隐状态蒸馏进 VLA 解码器中层，并用注意力瓶颈强制下游解码必须经过这个状态。增益在长程、多阶段任务上最明显，但头条的 +20.4 pp 有四分之三来自单个任务。

一句话版。 让 VLA 的动作解码器内部长出一个"我这一段在干什么"的变量，办法是把一个能回看执行视频的 VLM 的理解蒸馏进去，并从结构上断掉绕过它的路。

§ 9 — 最脆弱的假设 ​

假设：教师 VLM 对物理行为的理解足够好，好到它的中间层表示能构成一个有用的意图目标。

这个假设一旦不成立，方法不是"退化到基线"，而是跌破基线。论文自己的教师置换实验给出了最锋利的证据：保持学生、数据、优化预算、评测 run 全部不变，只换教师缓存，Qwen3.5-9B 得 54.5%——比 61.5% 的动作-only 基线还低 7 pp；Qwen3-VL-8B-Instruct 得 73.5%；由 Qwen3-VL 经物理 AI 后训练得到的 Cosmos-Reason2-8B 得 85.5%。目标几何解释了原因：Qwen3.5 的角预算只有 0.0027，episode 内变化占比 30.8%，也就是说它的目标基本只编码"这是哪个 episode"，而不编码"现在到哪一步了"。

实践中这为什么会不成立？因为具身后训练的教师目前是稀缺品。换一个形态（双臂、灵巧手、移动底盘）、换一个领域（工业装配、手术），Cosmos-Reason2 是否还能读出正确的局部目标，没有任何证据。论文提供了一个可在训练前测量的前置诊断（角预算、有效秩、episode 内方差占比），这很有价值；但它坦承因果解释只在 Qwen3-VL–Cosmos 这一对上成立，三个教师不足以支撑一条预测律。

更根本的是论文自己在 Appendix D 写下的那句话：框架没有"意图是错的"这个概念，也没有任何机制在执行与意图矛盾时去修正目标。教师说错了，学生就忠实地学错。加上意图只从成功的演示的单个窗口里读取，而失败与纠错的片段恰恰是把目标说得最明白的那些数据——这个上限是结构性的，不是调参能推开的。

§ 10 — 最小复现实验 ​

一周内可做，且不需要复现完整训练。

  1. 先只跑教师诊断（半天，无需训练策略）。 取 BridgeData V2 的一个子集（论文用 17,288 个有效样本，取 3–5k 足够），用两个教师各缓存一次 I⋆：一个具身后训练的 VLM 和一个同规模的纯文本 LLM。计算三个统计量：角预算（L2 归一化后离均值方向的平均余弦距离）、居中后分布的有效秩、episode 内方差占比。判据：如果纯文本教师的角预算不比具身教师低一个数量级，论文的核心诊断就不成立，后面的实验不必做。
  2. 再做单一 suite 的小规模训练（3–4 天）。 用一个公开 VLA checkpoint，只加 KI​=8 个意图 query 与 LI​（不加 grounding、不加 Lmis​），tap 在 50% 深度，其余超参与匹配基线完全一致，各训 3 个种子。
  3. 加机制（1 天）。 在最好的种子上补上下文瓶颈（α∼Bernoulli(0.5)）。判据：论文预测这一步带来的增益比 LI​ 本身还大（85.5 vs 70.0 的差就是它）。若加瓶颈后不升反降，说明"强制使用"的收益是骨干特异的。
  4. 零意图干预（1 小时）。 把对齐层的 8 个意图状态全置零、其余输入不动。若成功率不显著下降，说明你的 latent 只是个装饰，训练配置有问题。

支持结论的最低标准：匹配基线之上稳定 +5 pp（3 个种子），且置零干预造成明显下降。

§ 11 — 最强反例设计 ​

替代解释：起作用的不是"语义意图"，而是"任何一个能分辨执行阶段的非退化对齐目标"。

论文的教师几何表恰好同时支持这个反解释：角预算与 episode 内方差占比随下游成功率单调上升，而这两个量完全不涉及语义——它们只描述"目标向量是否随执行时刻变化"。一个不含任何行为理解的目标，只要满足同样的几何，理论上也能提供同等的阶段性归纳偏置。

攻击实验。 构造一个语义空白但几何匹配的对照目标：取执行片段的视频特征，过一个固定的随机投影，再做逐维仿射校准，使其角预算、有效秩与 episode 内方差占比都对齐到 Cosmos 教师的 0.0327 / 3.4 / 0.723。其余一切不变，训练同样的学生。

  • 若成功率仍显著高于动作-only 基线并接近 85.5%，那么"behavior-level intent"这个 framing 就被证伪了：真正起作用的是一个随阶段变化的稠密辅助目标，教师的物理常识只是生成这种目标的一条便利路径。
  • 若明显低于 85.5%，论文的 claim 就被强化到了它现在还没有的程度。

第二条攻击线：头条数字的稳健性。 表 6(a)、表 10、表 17 里，EP-Basket 一项的摆幅分别是 30→100、100→46、16→100，全部消融结论的方向都由这一项决定。要求作者报告"扣掉 EP-Basket 后的三任务平均"作为主表指标；按论文自己给出的 7.1 pp，完整方法相对基线的稳健增益会从 +20.4 缩到个位数，与未来监督的差距也会大幅收窄。

可预测的失败场景。 论文的部署策略在每次查询恢复一个确定性的意图并立即消费。在目标真正歧义的时刻（刚抓起物体、下一步既可以放进抽屉也可以递给人），正确行为是保持一个分布；确定性恢复只能挑一个，且没有任何机制在下一帧改主意。相位强制实验里 7.3% / 5.5% 的成功率说明这个状态对行为的支配力极强——支配力越强，选错时的代价越大。双臂、多目标共存、人机协作场景应当能可预测地触发这个失败。

§ 12 — Follow-up Research Idea ​

把意图从"内部状态"改造成"双向接口"，并让它由执行结果来校验。

(a) 驱动这个想法的局限。 论文限制节写得很清楚：意图是被恢复的而不是被选择的；策略不能持有目标上的分布，不能跨 rollout 维持一个意图，也不能接受"你应该在试图做 X"这样的纠正。干预实验证明这个状态是可寻址的（同目标注入保 84.5%），但策略自己从不使用这个句柄。同时，意图只从成功片段里读，而失败与纠错片段才最直白地陈述目标。

(b) 可借鉴的相邻工具。 目标条件 RL 里的 hindsight relabeling 提供了现成的框架：把"这段实际达成了什么"（achieved objective）与"这段试图达成什么"（intended objective）分开标注。语言模型侧的 verifier / self-consistency 提供了另一半：让一个判别器根据后续观测判断意图是否被兑现，把不匹配变成训练信号而不是噪声。两者合起来正好补上论文缺的那件事——意图的可证伪性。

(c) 第一个实验长什么样。 在 RoboCasa 上收集 INDI 自己产生的失败 rollout（这些数据现在被丢弃）。对每个失败片段，让教师标两个目标：intended（结合指令与前序状态）与 achieved（只看实际结果）。训练学生同时恢复两者，并加一个一致性头预测二者是否吻合。三个可测量的结果：其一，跨目标干预下的保留率能否从 45.2% 提升（说明意图空间被撑开而不是被记忆）；其二，一致性头能否在闭环中提前若干步预测失败，从而给出一个不依赖任务成功标签的在线中止信号；其三，在测试时注入正确的 intended 意图能否救回失败 rollout——如果能，意图就真正成了人或规划器可用的接口，而不只是一个训练期的正则项。

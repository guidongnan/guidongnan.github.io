CausalMotion: Structured Physical Reasoning as Keyframe and Trajectory Guidance for Training-Free Video Generation ​

项内容
arXiv2606.14317
提交日期2026-06-12
作者Sihan Zhuang, Xinyuan Chen, Tianfan Xue, Yaohui Wang（上海人工智能实验室 / 上科大 / 港中文）
分类cs.CV
一句话让 VLM 把 prompt 拆成一串因果连贯的关键帧加物体级 bbox 轨迹，时间对齐后作为软约束注入 LTX-Video 的 latent 更新，不训练任何参数就提升物理合理性。

所属教程：物理感知视频生成

§ 1 — 研究问题与重要性 ​

扩散视频模型的画质和短程时序一致性已经很好，但长程、多阶段的物理过程仍然崩。论文举的失败模式很具体：冰淇淋从固态直接跳到一摊液体，中间所有软化阶段被跳过；物体从一个位置闪现到另一个位置；杯里的咖啡液面涨到杯沿之外。作者引用的一个更极端的例子是 Runway Gen 3 在"燃烧的火柴伸进水里"时生成了一根蜡烛被点燃——画面完全真实，物理完全不可能。

原因不难理解：视频扩散模型从数据里学到的是统计相关性，因果结构与物理约束从未被显式建模；而带有丰富物理交互且有结构化因果标注的数据本来就稀缺。与此同时，多模态大模型通过链式思考已经能把复杂事件拆成因果步骤，能推理"斜面上的水滴会沿最陡路径下流"——但它们生成不了时序连贯的像素。这就是一个典型的能力错配：会推理的不会画，会画的不会推理。CausalMotion 想在不重训生成模型的前提下把两者接起来。

§ 2 — 前人工作与不足 ​

物理一致视频生成有两条既有路线。基于仿真器（PhysGen、PhysGen3D、NewtonGen、WonderPlay、PhysMotion）先估计场景属性再显式模拟动力学，物理上站得住，但依赖刚体这类简化假设，且建模与计算开销大，很难扩展到开放世界。不用仿真器的又分两支：训练侧对齐（PISA、Force Prompting、NewtonRewards、PhysRVG）通过损失、奖励或强化学习注入物理先验，需要大规模训练和精心设计的监督，性能与约束质量强耦合；基础模型引导（VLIPP、Think Before You Diffuse、VideoREPA、ProPhy、PhyRPR）用视觉-语言或视频基础模型提供结构化引导，通常注入的是运动属性这类高层先验。

VLM 侧的相关工作里，最接近的是 VChain——它证明了 VLM 能产出物理上合理的中间状态。CausalMotion 相对它的差异在于：VChain 提供的是关键状态，而 CausalMotion 额外引入了物体级的稠密轨迹，并把它做成 latent 空间的局部更新。不过这个"额外"到底值多少，实验部分给出的答案并不像论文正文说的那么乐观（见 §7 与 §11）。

§ 3 — 重建作者的思考路径 ​

只用当时已有的观察。第一，长程物理失败的典型形态是"中间状态缺失"而不是"单帧画得不好"——冰淇淋跳过软化、火焰跳过引燃，说明模型缺的是事件的时间分解，不是纹理。第二，链式思考已经被反复验证能让大模型把复杂事件拆成有序的因果步骤，且 gpt-image 一类的模型可以在给定上一张图和一条修改指令时保持视觉一致地生成下一张图——也就是说"自回归地生成一串关键状态图"在工程上是现成的。第三，LTX-Video 这类骨干原生支持在用户指定的时间索引上做多关键帧条件化。

把三条接起来：既然模型缺的是事件分解，而 VLM 会分解、图像模型会画单帧、视频模型会插值，那就让 VLM 分解、图像模型画关键帧、视频模型做关键帧之间的填充。剩下的问题是关键帧之间的运动仍然是自由的，于是再让 VLM 预测一组稀疏的物体状态（位置、尺度、速度、接触关系），插值成稠密轨迹，作为 latent 更新的软约束压住帧间运动。

§ 4 — 核心 Intuition ​

视频扩散模型不缺画面能力，缺的是"这件事分几步发生"的显式结构。所以不要试图教模型物理，而是把物理推理外包给 VLM，让它输出两种中间表示——因果关键帧（回答"分几步"）与物体 bbox 轨迹（回答"每步之间怎么动"），再把这两种表示分别接到骨干的关键帧条件接口和 latent 更新上。推理与生成一旦解耦，就不需要任何训练。

§ 5 — 具体方法与完整 Pipeline ​

以 prompt"一支蜡笔般脆弱的瓷盘被高速掷向坚固的木桌并撞击"为例：

  1. 视觉思维链生成关键帧：VLM 先做一次全局场景理解，推断出 consequence（最可能的最终状态：盘子碎裂）。这条全局因果约束会锚定后续所有关键帧。然后从初态出发，生成第一段文本描述 txt0​ 与对应图像 img0​（用 gpt-image 系列文生图模型）；此后每一步以 imgi−1​、txti−1​ 与 consequence 为条件，预测下一条关键变化指令 txti​ 并生成 imgi​，直到覆盖 consequence 蕴含的所有状态转移。输出是一条 Chain of Visual Thoughts and Captions。
  2. 物理状态与轨迹规划：用分割模型（SAM / Grounding DINO / T-Rex2 一类）在 img0​ 上定位 VLM 指认的关键物体，得到初始 bbox。VLM 随后作为高层物理状态规划器，输入是场景描述（指明主导物理律，如重力、动量守恒、流体）、img0​ 与初始 bbox，输出稀疏时刻上的物理状态向量。
  3. 时间对齐：关键帧与轨迹是在两套不同的表示空间里独立产生的，需要绑定。用一个保序的贪心分配，把每个关键帧指派到 IoU 最大的轨迹时刻。
  4. 轨迹引导的 latent 更新：把逐帧 bbox 按骨干的时间下采样结构编码进 latent 时序空间；从每个关键帧的 latent 里用高斯软掩码裁出物体外观锚点；用"上一时刻的局部传播 + 前后两个相邻关键帧的锚点"三路加权混合出动态参考外观；最后在每个去噪步对轨迹位置做局部 latent 混合。
  5. 实现：骨干是 LTX-Video，关键帧在 tk​ 处以固定强度 λ=0.9 条件化；VLM 用 Qwen2.5-VL-72B；分辨率 720×480、30 FPS、121 帧（约 4 秒）；VLM 只预测 13 个稀疏时刻，插值到 121 帧。

注意 §3.5 写的是 gpt-image-1，§4.1 写的是 gpt-image-1.5，两处不一致，本文按实验节的表述理解。

§ 6 — 核心数学推导 ​

sτj​i​=[xτj​i​, yτj​i​, wτj​i​, hτj​i​, vx,τj​i​, vy,τj​i​, cτj​i​]

bti​={线性插值bτj​i​+vτj​i​Δt+21​ai(Δt)2​匀速运动加速运动​

这就是最朴素的匀加速运动学，Δt=t−τj​。它的意义不在于精确——13 个稀疏点之间用二次多项式补，对自由落体是准的，对碰撞后的反弹只是分段近似——而在于给出一条处处可导且不跳变的位置先验，避免朴素线性插值把抛物线拉成折线。

latent 更新是一次带高斯软掩码的局部混合。掩码 Mi,τ​(x,y)=exp(−∥x−ci,τ​∥2/(2σ2)) 以轨迹中心 ci,τ​ 为中心，更新为

用软掩码而非硬替换是关键：αs​ 控制引导强度，掩码外的区域完全不动，因此全局生成分布被保留，只在物体所在的局部把外观往参考锚点上拉。参考外观 Pi,τref​=wa−​P(−)+wp​P(prev)+wa+​P(+) 按 τ 相对相邻关键帧的时间位置自适应加权，避免固定锚点造成的外观跳变。

§ 7 — 实验设计与结论 ​

问题一：物理理解有没有提升？ 在 PhyGenBench 上用 PhyGenEval 协议评四类现象（力学、光学、热学、材料）。CausalMotion 平均 0.65（消融表给出 0.654），LTX-Video-T2V 基线 0.39，相对提升 67%。其他基线：CogVideoX-T2V-5B 0.45、OpenSora 0.44、CogVideoX-I2V-5B 0.52、SVD-XT 0.52。相对 VLIPP，论文声称力学高 0.06、热学高 0.08（VLIPP 与 PhyGDPO 的行在 HTML 抓取中被截断，此处只引用正文明确给出的差值）。

问题二：物理约束会不会牺牲画质？ VBench 质量分 82.52%，高于 LTX-Video 的 80.57%、VChain 的 78.49% 与 Wan2.1-T2V-1.3B 的 76.21%。评测只用了与 VChain 相同的 20 条 prompt。

问题三：每个模块贡献多少？ 这是全文信息量最大也最需要如实转述的一组。PhyGenBench 上的消融（力学/光学/热学/材料/平均）：完整模型 0.608 / 0.713 / 0.678 / 0.608 / 0.654；去掉关键帧推理 0.425 / 0.600 / 0.467 / 0.358 / 0.471；去掉轨迹物理状态 0.583 / 0.700 / 0.689 / 0.592 / 0.642；去掉 latent 轨迹引导 0.594 / 0.680 / 0.678 / 0.625 / 0.645。

也就是说：关键帧推理贡献 0.654−0.471=0.183，而两个轨迹相关模块各自只贡献 0.012 与 0.009。热学的最优值出现在去掉轨迹物理状态时，材料的最优值出现在去掉 latent 引导时。论文对此的解释是：这两类现象以外观渐变为主、几乎没有空间位移，轨迹约束反而是多余的限制——这个解释合理，但它同时意味着方法的两个"物理"模块只在有明显位移的场景里有边际效果。

问题四：VLM 打分怎么说？ 用 Gemini 2.5 Flash 作评委评物理合理性 / 时序一致性 / 语义对齐。表 2 的行是：LTX-Video 2.53 / 3.89 / 1.68 / 总分 2.70；去掉关键帧推理 2.60 / 4.65 / 2.35 / 3.20；去掉轨迹物理状态 3.05 / 3.65 / 3.40 / 3.37；去掉 latent 引导 3.20 / 3.90 / 3.45 / 3.55；CausalMotion 3.10 / 3.95 / 3.70。

这里有两处必须指出。其一，正文与表格不一致：正文写"时序一致性 3.89 → 4.58、语义对齐 1.68 → 4.00"，但表中完整模型对应的两个数是 3.95 与 3.70；总分 2.70 → 3.58 则与表一致。其二，正文"我们的方法在所有维度上显著优于所有模型"在自家消融面前不成立——去掉关键帧推理的变体时序一致性 4.65 高于完整模型的 3.95，去掉 latent 引导的变体物理合理性 3.20 高于完整模型的 3.10。以表为准。

代价：每条视频约 448 秒，其中关键帧生成 271 秒（GPT-Image-1.5 API）、轨迹规划 69 秒（Qwen2.5-VL-72B API）、LTX-Video 推理 108 秒（单张 A800）。所谓"training-free"是真的不训练，但推理成本是骨干本身的 4 倍以上，且大部分花在闭源 API 上。

附录 A 还给了一个诚实的自查：关键帧与轨迹的 bbox IoU 随时间衰减，且跨 prompt 方差明显，失败主要出现在长程或复杂交互场景。

§ 8 — Take-aways ​

5 句话版：CausalMotion 把物理推理外包给 VLM，产出因果关键帧与物体 bbox 轨迹两种结构化中间表示，再作为软约束接进 LTX-Video 的关键帧条件接口与 latent 局部更新，全程不训练任何参数。PhyGenBench 平均分从 0.39 提到 0.65，VBench 质量分同时略有上升，说明物理约束没有以画质为代价。但消融显示 0.183 的增益来自关键帧推理、只有 0.012 与 0.009 来自两个轨迹模块，热学与材料两类现象上去掉轨迹约束反而更好。VLM 评委表里完整模型在时序一致性与物理合理性两项上都被自己的消融变体超过，正文的部分数字也与表格对不上。推理成本 448 秒/条，其中 340 秒花在闭源 API 上。

3 句话版：让 VLM 拆事件、图像模型画关键帧、视频模型做插值，把长程物理生成降级成一串关键帧条件化问题，PhyGenBench 0.39→0.65。真正起作用的几乎全是关键帧那一步，轨迹与 latent 引导的边际贡献在 0.01 量级。代价是 448 秒推理和对闭源图像 API 的强依赖。

1 句话版：训练无关的物理生成，本质是把 T2V 变成了 VLM 规划 + 关键帧插值。

§ 9 — 最脆弱的假设 ​

最脆弱的一条是：VLM 在图像坐标系里预测的 bbox 轨迹，与另一路独立生成的关键帧，处在同一套空间与时间参数化下。

论文附录 A 自己承认这两个模块"在坐标系与时间参数化上都没有显式对齐"，唯一的桥梁是式 4 那个基于 IoU 的贪心指派。这个假设一旦不成立，后果是直接的：式 9 的 latent 更新会把从关键帧裁出的外观锚点 Pref 粘到轨迹指定的错误位置上，产生比不加引导更糟的结果——物体在错的地方长出来，或者同一物体出现两次。

作者提供的证据是逐帧 IoU 统计：整体均值"相对较高"，但明确指出 IoU 随时间衰减，且逐 prompt 的均值分布方差明显，失败集中在长程与强交互场景。这恰恰是方法宣称最擅长的场景。缺的证据是：没有报告 IoU 的具体数值或分位，也没有做"IoU 低于某阈值时性能如何"的分层分析——如果做了，很可能会发现增益集中在对齐良好的那部分样本上。

这个脆弱性与 §7 的消融结论是自洽的：正因为轨迹与关键帧对不齐，轨迹相关的两个模块才只能贡献 0.01 量级的增益。也就是说，论文自己的数据已经在暗示这个假设在实践中经常不成立。

§ 10 — 最小复现实验 ​

一周内可做，且不需要复现完整系统：

  • 数据：PhyGenBench 的力学子集（位移最明显、最能体现轨迹引导的价值），约 40–50 条 prompt。
  • 实现：三条管线。(A) 裸 LTX-Video 文生视频；(B) 只做关键帧——用任意可用的图文模型自回归生成 4–6 张关键帧，直接送 LTX-Video 的多关键帧接口，不做任何轨迹规划、不做任何 latent 更新；(C) 完整 CausalMotion。(B) 是关键，它对应"同时去掉两个轨迹模块"，而论文只分别去掉了其中一个。
  • 测量：PhyGenEval 分数、VBench 质量分、以及每条的 API 调用成本与墙钟时间。
  • 判据：如果 (B) 的分数落在 0.63 以上（即距离完整模型 0.654 不足 0.03），那么"结构化物理状态 + 轨迹引导"这一贡献在定量上不成立，方法应重新表述为"VLM 驱动的关键帧规划 + 关键帧插值"；如果 (B) 明显低于 (A) 与 (C) 的中点，则两个轨迹模块存在协同效应，论文的分项消融低估了它们——这一点论文没有测过。

§ 11 — 最强反例设计 ​

替代解释：CausalMotion 的提升不是"把物理推理注入了生成"，而是"把一个困难的 T2V 任务降级成了一串简单的关键帧插值任务"。

论文自己的表 1 给出了这个解释所需的全部证据：在 PhyGenBench 上，T2V 基线普遍在 0.39–0.45（LTX-Video-T2V 0.39、CogVideoX-T2V-5B 0.45、OpenSora 0.44），而 I2V 基线普遍在 0.52（CogVideoX-I2V-5B 0.52、SVD-XT 0.52）。仅仅给模型一张正确的起始图像，分数就跳 0.1 以上。CausalMotion 做的事情是给了 4–6 张由 GPT-Image-1.5 画出的、已经把物理结果画对了的图像，然后让 LTX-Video 在它们之间插值。在这个视角下，物理正确性的来源是文生图模型，不是任何"结构化推理"或"轨迹约束"——而文生图模型的物理常识本来就来自它自己的训练数据，与本文方法无关。

消融数据完全支持这一解释：去掉关键帧推理，平均分从 0.654 崩到 0.471；去掉两个轨迹模块，只掉到 0.642 / 0.645。约 95% 的增益归属于关键帧那一步。

反例实验：设计一个 "Keyframe-Only Oracle" 对照——用完全相同的关键帧生成流程，但把关键帧的时间索引改成均匀分布（不做基于 IoU 的时间对齐），且完全关闭 latent 引导。如果它仍能拿到 0.63+，则时间对齐与轨迹引导都被证伪。再加一个更严格的对照：把 CausalMotion 的关键帧换成由人手工挑选的真实照片序列（同一物理过程的实拍分解图），送进同一条插值管线。若分数进一步上升，则说明整个方法的上限由关键帧质量单独决定，"物理推理"只是关键帧生成的一个副产品。

方法会可预测失败的场景：论文附录 D 已经点名——物体基本静止、只有外观变化的过程（金属氧化、颜色渐变）。可以补一类论文没测的：多物体同时运动且互相遮挡的场景，此时基于单一 bbox 的高斯软掩码会互相覆盖，式 9 的局部更新会把两个物体的外观锚点混在一起。

§ 12 — Follow-up Research Idea ​

把单向的"推理→生成"管线改成闭环：让同一个 VLM 既当规划器，也当观测器。

(a) 驱动它的局限：当前架构里 VLM 只在生成之前说话，之后再不参与。它预测的物理状态是否真的在生成结果里实现，没有任何人检查——这正是关键帧与轨迹对不齐（§9）却无人察觉的原因，也是两个轨迹模块只能贡献 0.01 的原因。同时，448 秒的推理预算里有 340 秒花在了一次性的 API 调用上，这笔预算如果用来做迭代反而可能更值。

(b) 可借鉴的相邻领域：控制论里的观测器-控制器分离原理——先从输出估计状态，再基于状态误差施加控制；以及程序合成中的 execute-and-repair 循环（生成候选、执行、读回错误、定向修补），它与 best-of-N 的关键区别是修补是有方向的。

(c) 第一个实验长什么样：在 PhyGenBench 力学子集上做两轮闭环。第一轮照现有流程生成视频；然后把生成结果重新送给 VLM，让它在同一套物理状态向量的格式下读出实际发生的 s^τj​i​；计算与规划值的偏差 ∥s^−s∥，用它同时做两件事——修正 bbox 轨迹，以及自适应调整式 9 的引导强度 αs​（偏差大的时刻加强、偏差小的时刻放松）；第二轮重生成。对照组是同等 API 预算的 best-of-N（生成两条选一条）。如果闭环显著优于 best-of-N，就说明"读回状态"这一步提供了 best-of-N 拿不到的方向信息，VLM 在视频生成里的正确定位是控制回路的一部分而非一次性的前端规划器；如果两者持平，则说明 VLM 读视频物理状态的精度还不足以构成有效反馈，这个负结果同样有价值——它会把研究焦点推向"视频到物理状态的读取器"这个独立问题上。

STEAR: Layer-Aware Spatiotemporal Evidence Intervention for Hallucination Mitigation in Video Large Language Models ​

项内容
arXiv2604.03045
提交日期2026-04-03
作者Linfeng Fan, Yuan Tian, Ziwei Li, Zhiwu Lu
分类cs.CV, cs.MM
commentsPreprint
一句话只在 token 熵超过 0.85 的高风险解码步触发：从中间层 cross-attention 选出 top-10% 关键 patch，一份证据同时用于中间层 FFN 重注入（补空间 grounding）和从触发层分叉的时间扰动反事实分支（证伪时序推断），全程只编码一次视频。

所属教程：长视频理解

本页依据 arxiv.org/e-print/2604.03045 的 TeX 源码（单文件 sample-sigconf-authordraft.tex，58,172 字节）撰写。

§ 1 — 研究问题与重要性 ​

视频里的幻觉比图像里更难缠。图像幻觉主要是"编造不存在的物体"，视频还多两层：把事件顺序说反、把跨帧因果关系接错。这三种错误的产生位置不同，但现有的缓解方法把它们当成同一件事——一条全局共享的纠正规则，在解码时对所有 token 一视同仁地施加。

作者的切入点是一个结构性观察：解码器各层的功能不同。中间层在做视觉证据与演化中的 token 状态之间的对齐，深层则被语言组合和高层推理主导。把解码器当成一个整体来干预，等于对两类完全不同的失败施加同一种药。论文因此把幻觉重新表述为跨层时空证据错配：要么中间层没把局部证据接稳，要么深层在错误的时序假设下继续往下推。

这个 framing 的价值在于它给出了一个可测的诊断量。如果不同层确实分工不同，那么"在哪一层干预"就应该有一个可以画出曲线的最优点，而不是一个信仰。论文的图 2(b) 正是这条曲线。

§ 2 — 前人工作与不足 ​

推理期缓解这一大类包含外部核验（Woodpecker）、检索增强、注意力矫正、记忆增强（MemVR）与对比解码（VCD）。作者对最近的两个视频专用方法给了具体批评：TriCD 需要多条编码通路、辅助的显著性或运动估计器、以及依赖外部工具的扰动设计；VERHallu 上评测的 KFP 类方法说明"围绕关键帧重分配注意力"能在不重训的前提下提升事件级事实性。

作者对整条线的概括是：记忆类方法能补回视觉支撑，但不明确建模"解码器的哪一层最适合修复 grounding"；解码类方法能压语言先验，但通常作用在最终输出分布上，或者作用在全局修改过的视图上。

层级证据路由这条线（PlaM、CLAA 等机制可解释性工作）已经给出了层功能分化的证据：早层分离信号、中层对齐多模态证据、后层语言主导。作者说这个视角"在多数幻觉缓解方法里仍被低估"。这句话是本文最直接的 novelty 声明，也是全文的立足点。

§ 3 — 重建作者的思考路径 ​

第一步是接受机制可解释性已有的结论：解码器层是分工的。这不是本文的发现，作者也没这样宣称，他引的是 PlaM 一线的工作。

第二步是问一个前人没问的问题：既然层是分工的，那对比解码的负分支该从哪一层分叉？ 标准 VCD 的做法是把扰动后的输入从头前向一遍，这意味着两件事——贵（视频要编码两次），以及负分支的扰动会经过所有层，包括那些与 grounding 无关的层。如果只从中间某层分叉，成本降一半，且干预更定向。

第三步是问：正分支和负分支应该共享同一份证据假设吗？ 标准对比解码的负视图是全局加噪，与正分支想强调的东西没有关系。而如果先选出"当前 token 依赖的那几块 patch"，再让正分支去补它、负分支去毁它，对比解码就从"通用分布校准"变成了"针对这条证据假设的证伪测试"。这一步是本文真正的构造性想法。

第四步是效率约束：幻觉是稀疏的，只集中在少数 token 上。所以用 token 熵做触发器，只在高风险步激活。

§ 4 — 核心 Intuition ​

幻觉不是一个均匀的解码失败，而是"证据在错误的层被丢掉"。修复必须发生在证据仍在被读取的中间层，而不是语言先验已经接管的深层。更进一步：同一份 token 条件下的关键证据应当既被正分支修复，又被负分支破坏——只有这样，对比解码才是在测试"这个预测是否真的依赖这份证据"，而不是在做一次泛泛的分布扰动。

§ 5 — 具体方法与完整 Pipeline ​

层级诊断（前置分析）。对 token t 和层 l，用模型自己的最终 LayerNorm 与 LM head 重投影出每层的 token 分布 pt(l)​=softmax(Wlm​LN(ht(l)​))，不引入任何辅助分类器。定义两个量：

G(l)=Et​[i∈Et​∑​At,i(l)​],D(l)=Et​[cos(pt(l)​,pt,∅(l)​)],

其中 Et​ 是基准标注投影到 patch token 空间后的证据区域（不是模型自选的 top-attention patch，这一点作者特意强调），pt,∅(l)​ 是同一解码状态在视觉输入被遮蔽时的分布。图 2(a) 的结论是 grounding 分数在中间层达峰，语言主导度在中间层最低、在后层回升。这个遮蔽前向只用于诊断，不参与推理。

触发。在预设中间层集合 Lm​ 内取归一化熵的最大值 ut​=maxl∈Lm​​U(pt(l)​)，超过 τ 则触发；同时取 l∗=argmaxl∈Lm​​U(pt(l)​) 作为负分支的分叉层。实现里 Lm​ 是第 5–16 层，τ=0.85。

关键证据选择 KES。在 l∗ 周围的小邻域上对 cross-attention 取平均 at​=∣N(l∗)∣1​∑l∈N(l∗)​At(l)​，取 top-r 比例的 patch，实现里 r=10%。作者明确写了"我们不主张 cross-attention 是完美的归因信号，在 STEAR 里它是一个路由信号"。

中间层重注入。把选中的 patch 经骨干原有视觉投影 Wv​ 变成键值记忆 Mt​，以当前隐状态为 query 做一次小规模检索得到 rt(l)​，再沿 FFN 通路注入 h~t(l)​=ht(l)​+λrt(l)​，风格上跟随 MemVR 的 FFN retracing。作者强调这一步是 training-free：Wv​ 复用骨干原有投影，其余张量在推理时现场构造。

patch 级时序反事实。对同一批 It​ 只扰动时间维，两种模式：时序打乱 zi,1:T−​=Shuffle(zi,1:T​) 破坏顺序信息；时序均质化 zi,τ−​=(1−γ)zi,τ​+γzˉi​ 压掉时间变化。扰动作用在视频编码之后的 visual-token 空间，所以骨干的时间槽结构与位置支架保持完好。负分支从 l∗ 之后的原解码器继续跑，最终 logits 为

ot​=(1+α)ot+​−αot−​.

实现里 γ=0.80、α=0.75。

一个具体例子（论文图 5 的时序案例）：视频里的人先遛狗、然后停下、最后才去摸那只黑狗。baseline 依赖了后面那个更显著的动作，答成"摸黑狗"。STEAR 在这个高熵 token 上触发，KES 选出与该 token 相关的 patch，正分支把它们重新注入中间层，负分支把这些 patch 的时间顺序打乱后从触发层往下跑；由于"摸黑狗"这个答案在时序被破坏后依然高概率（它只依赖某一帧的外观），它被减掉，正确答案"遛狗"浮出来。

§ 6 — 核心数学推导 ​

本文没有定理，但对比解码那一步的形式值得掰开看。ot​=(1+α)ot+​−αot−​ 在 softmax 之前做线性外推，等价于在概率空间上取

p(yt​)∝p+(yt​)(p−(yt​)p+(yt​)​)α,

也就是用"正负分支的似然比"给正分支的分布做重加权。α 控制重加权强度。这个形式与 VCD、DoLa 一脉相承，本文的差别不在公式而在 ot−​ 的来源：VCD 的负分支来自全局加噪的输入，本文的负分支来自只被时序扰动的那 10% 关键 patch，并且从 l∗ 之后才开始分叉。

这个差别的直接后果是：负分支只跑了 L−l∗ 层而不是全部 L 层，且不重新编码视频。触发层被限定在第 5–16 层，而主流 7B 语言底座的层数在三十左右（论文未给出具体层数，此处为推测），所以负分支的额外前向大致在全模型的一半以下。效率表里 1.89 倍延迟（相对无干预 baseline）与这个估算方向一致。

触发条件的归一化熵 U(p)=−log∣V∣1​∑j​pj​logpj​ 除以 log∣V∣ 把值域压到 [0,1]。τ=0.85 是一个相当高的门槛——归一化熵 0.85 意味着分布接近词表上的均匀分布，模型几乎完全不知道下一个 token 是什么。

§ 7 — 实验设计与结论 ​

协议：四个基准（EventHallusion 事件级幻觉、VidHalluc 时序幻觉、NExT-QA 因果/时序/描述推理、MVBench 通用视频理解），三个骨干（LLaVA-Video-7B、InternVL2.5-8B、Qwen2.5-VL-7B），四个对比方法（VCD、MemVR、TCD、DINO-HEAL）。

主表（tab:main_overall）。LLaVA-Video-7B：EventHallusion 46.70→54.77、VidHalluc 63.07→65.81、NExT-QA 58.43→61.88、MVBench 41.28→41.74，均值 52.37→56.05。InternVL2.5-8B：均值 70.40→74.10，四项中三项第一（EventHallusion 上 VCD 的 73.84 高于 STEAR 的 72.37）。Qwen2.5-VL-7B：均值 65.97→68.44，四项全第一。值得记下的是 baseline 方法在 MVBench 上普遍掉分（LLaVA-Video 上 VCD -2.36、TCD -3.81），而 STEAR 是 +0.46——但 0.46 这个量级本身很小。

细粒度表（tab:fine_grained_llava）。EventHallusion 的 Misleading 子集从 43.13 跳到 73.53，是全文最大的单点提升；同时 Entire 子集 STEAR 是 42.11，输给 TCD 的 47.36，Mix 子集 52.33 输给 baseline 的 58.55。也就是说 EventHallusion 总分 54.77 几乎全部来自 Misleading 一个子集，另外两个子集是退步的。论文正文只讨论了 Misleading 那一条。

效率表（tab:efficiency）：VCD 需要 2 次编码、2.42× 延迟、1.13× 显存、EventHallusion 40.17；TCD 是 2 次、2.25×、1.13×、51.62；STEAR 是 1 次、1.89×、1.01×、54.77。表里没有写测量所用的 GPU 型号、batch size、视频长度或帧数，只给了相对倍数。

核心消融（tab:ablation_core，LLaVA-Video-7B）。这张表是全文最重要也最具自我拆台效果的一张：

  • 完整 STEAR：EventHallusion 54.77、VidHalluc(ACH-BQA) 44.14，相对 baseline +7.34 / +3.12；
  • 去掉不确定性触发（对所有 token 施加）：48.41 / 41.91，掉 6.36；
  • 去掉中间层重注入：50.61 / 43.50；
  • 去掉时序反事实解码：47.92 / 41.37，几乎回到 baseline；
  • 干预深度：早层 49.63 / 42.16，中层 52.57 / 43.85，后层 47.19 / 41.12；
  • 反事实构造：patch 级 shuffle 单独 54.01 / 44.10，均质化单独 51.34 / 44.02，帧级扰动 52.57 / 43.86，整视频扰动 50.12 / 42.51；
  • 证据选择：把 KES 换成随机 patch，54.03 / 43.86；换成帧级选择，53.79 / 43.62；正负分支各用独立选择器，52.08 / 43.89。

最后那一行需要盯着看：随机选 patch 拿到了 54.03，完整 KES 是 54.77，差 0.74。而 KES 正是论文摘要和标题里的核心模块。

表间不一致：主表里 LLaVA-Video-7B 的 EventHallusion baseline 是 46.70，消融表里同一个 baseline 是 47.43。论文没有说明这两个数为何不同。

§ 8 — Take-aways ​

5 句话版：STEAR 把 Video-LLM 幻觉重述为跨层时空证据错配，用模型自身重投影出的逐层分布做诊断，确认 grounding 在中间层达峰、语言主导度在后层回升。方法只在归一化熵超过 0.85 的高风险 token 上触发，从第 5–16 层的 cross-attention 邻域选出 top-10% 关键 patch，一份证据同时用于中间层 FFN 重注入和 patch 级时序反事实的负分支。负分支从触发层往下分叉，视频只编码一次，实测 1.89× 延迟、1.01× 显存，优于 VCD 的 2.42×/1.13×。三个骨干上均值分别提升 3.68、3.70、2.47，最大单点是 EventHallusion 的 Misleading 子集 43.13→73.53。但消融显示随机选 patch 只比完整 KES 差 0.74，核心模块的边际贡献很小。

3 句话版：干预要选对层、选对时机、并让正负分支共享同一份证据假设——这是本文的三条主张，前两条被消融支持（中层 52.57 vs 后层 47.19；去掉触发器掉 6.36），第三条几乎没被支持（随机 patch 54.03 vs KES 54.77）。真正撑起增益的是"时序反事实解码"这一个模块，去掉它就回到 baseline。单编码设计带来的效率优势是实打实的。

1 句话版：只在模型自己都拿不准的那几个 token 上，把它依赖的证据修一遍、再毁一遍，看预测扛不扛得住。

§ 9 — 最脆弱的假设 ​

最脆弱的假设是：KES 选出的 patch 确实是当前 token 所依赖的证据。

整个框架的叙事都建立在这一点上——"同一份 token 条件下的证据假设同时驱动正负分支"是标题、摘要、引言、方法节反复强调的核心。可论文自己的消融把它证伪了大半：把 KES 换成随机 patch，EventHallusion 从 54.77 掉到 54.03（-0.74），VidHalluc 从 44.14 掉到 43.86（-0.28）。相对 baseline 的总增益是 +7.34，其中随机 patch 就贡献了 +6.60。也就是说 KES 这个模块只解释了总增益的 10%，而且这 0.74 没有任何置信区间——论文全篇单次运行，没有多种子、没有误差棒。

为什么随机 patch 也能工作？一个合理的推断（论文未讨论）：负分支的作用可能主要来自"时序结构被破坏"这个事实本身，而不是"哪些 patch 被破坏"。只要打乱足够多的 patch 的时间顺序，那些只依赖单帧外观的答案就会保持高概率并被减掉——这个机制对 patch 的选择并不敏感。如果这个解释成立，那么本文的贡献应该重新表述为"patch 级时序反事实解码优于帧级和整视频扰动"（54.01 / 52.57 / 50.12，这个梯度是清楚的），而"层感知的关键证据选择"这条主线是多余的。

论文其实给了一条自救线索：独立选择器变体（52.08）比随机 patch（54.03）更差。作者据此论证"共享证据假设"的价值。但这个对比也可以反过来读——两个不同的选择器会让正负分支互相打架，而随机选一次、正负共用，反而没有这个问题。共享性有价值，选得准不准没价值。

§ 10 — 最小复现实验 ​

不需要复现完整框架，一周内可完成。

  1. 重跑 KES vs 随机的对比并加误差棒（三天，最关键）。在 LLaVA-Video-7B 上实现两个变体：完整 KES 与随机 top-10% patch。各跑 5 个随机种子（随机 patch 的种子、以及 EventHallusion 上的评测顺序），报均值与标准差。
  2. 把 KES 换成更差的选择器（一天）。加一个 anti-KES 变体：选 cross-attention 最低的 10% patch。若它的分数仍在 53–55 之间，那么证据选择这条通路就完全不起作用。
  3. 拆掉正分支只留负分支（一天）。论文有 "w/o middle-layer reinjection"（50.61），但没有"只有反事实、且反事实用随机 patch"这一格。补上它。
  4. 补效率的绝对量（一天）。在写明 GPU 型号、帧数、batch size 的前提下，报 STEAR 与 baseline 的绝对延迟（秒/样本）与峰值显存（GiB），而不是相对倍数。

判据：若第 1 步中 KES 与随机的差值（0.74）落在两者标准差之内，本文的核心模块无效；若第 2 步的 anti-KES 也在 53 以上，则 cross-attention 路由信号完全无关。

§ 11 — 最强反例设计 ​

替代解释攻击：本文的全部增益可以用"patch 级时序扰动的对比解码"单独解释，与层感知无关。构造对照实验——把触发层固定为一个常数（比如永远第 10 层），把 KES 换成随机，其余不变。若这个"无层感知、无证据选择"的退化版在四个基准上与完整 STEAR 差距小于 1 个点，那么标题里的 "Layer-Aware" 和方法节里的 KES 都失去了实证支撑。论文自己的消融表已经把这个反例做到了一半（随机 patch 54.03）。

可预测的失败场景：低熵幻觉。 STEAR 只在归一化熵超过 0.85 的 token 上触发。但最危险的幻觉恰恰是自信的幻觉——模型在语言先验的强驱动下，以极低的熵输出一个视频里不存在的物体（"厨房里有一台冰箱"这类常识补全，模型几乎不会犹豫）。这类 token 的熵远低于 0.85，STEAR 永远不会激活。构造一批"高置信度幻觉"测试样本（选取 baseline 输出中 top-1 概率大于 0.9 且被人工判定为幻觉的 token），测 STEAR 在其上的触发率与纠正率。可以预期触发率接近 0。

指标敏感性攻击。 MVBench 上 STEAR 的增益是 +0.46（41.28→41.74），四个子任务分别 +1.17 / +0.40 / +0.50 / +0.50。这个量级在单次运行、无置信区间的条件下与噪声不可区分。而论文用它论证"幻觉缓解没有牺牲通用理解"——这个结论需要的恰恰是一个非劣性检验，而不是一个小正数。审稿人可以要求作者报出 MVBench 各子任务的题目数与二项分布下的标准误，并给出多种子下的方差；在这些数字缺失的前提下，+0.46 无法支持任何关于"没有退化"的断言。

§ 12 — Follow-up Research Idea ​

驱动局限：本文（以及 VCD、MemVR、TCD、DINO-HEAL 整条线）都在推理期修补，且都以"某个内部信号能定位问题"为前提——注意力、熵、层深。而消融显示这些内部信号的定位能力比想象中弱得多（随机 patch 几乎一样好）。更根本的问题是：这些方法都没有关于"什么时候不该干预"的模型，只有一个手工阈值。

可借鉴的相邻工具：因果推断里的干预效应异质性估计（heterogeneous treatment effect，如 causal forest）。它解决的正是"同一种处理对不同个体效果不同，如何预测谁会受益"这个问题。

新的 framing：把"是否干预"从阈值规则变成一个学出来的处理效应预测器。具体做法是先在一批带幻觉标注的数据上，对每个解码步都跑一次"施加 STEAR"与"不施加"，记录该步的答案是否由错变对、由对变错、或不变——这就得到了逐 token 的个体处理效应标签。然后训练一个轻量预测器（输入是当前步的多层熵、注意力集中度、token 类型等），预测处理效应的符号与大小，只在预期为正时干预。这与本文的差别是根本的：本文假设"熵高 = 该干预"，新 framing 直接测量"干预了会不会变好"。

第一个实验：在 LLaVA-Video-7B 和 EventHallusion 上，对 1000 个解码步做双臂记录（干预/不干预），统计处理效应的分布。第一个要看的数字是负效应的比例——有多少步是"干预之后反而答错了"。若这个比例超过 30%，那么当前所有基于固定阈值的干预方法都在做一件亏本买卖的正负相抵，而效应预测器的上限空间就是这一部分。这个实验同时能解释本文"去掉触发器就掉 6.36"的现象：那 6.36 很可能就是被无差别干预打坏的那些原本正确的 token。

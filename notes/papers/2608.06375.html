ω-0: A Latent Predictive World Action Model for Concurrent Humanoid Loco-Manipulation ​

项内容
arXiv2608.06375
提交日期2026-08-06（v2: 2026-08-09）
作者Zhe Li, Zhenzhe Zhang, Yangyang Wei, Wenjie Zhang, Xichen Yuan, Peiyuan Zhi, Gen Li, Xinying Guo, Fengjie Gao, Jianfei Yang, Shanghang Zhang
分类cs.RO
一句话把「预测未来」从像素级视频生成降级成 V-JEPA 式的未来 embedding 预测，只作为辅助监督注入动作分支，动作分支直接扩散出 SONIC 控制器能吃的 66 维全身 action latent，于是人形机器人可以边走边操作而不必把任务拆成导航段和操作段。

所属教程：从视频生成到世界动作模型

§ 1 — 研究问题与重要性 ​

论文开篇给的三个例子很具体：擦一张大桌子要一边迈步一边前倾还要保持抹布贴着桌面；拖地要在移动底盘的同时控制一根长杆工具；从冰箱取物或把衣服放进滚筒下舱要同时完成伸手、弯腰、维持平衡和手部交互。这些任务不是「若干独立技能的长序列」，而是下肢、躯干、手臂、手在整个过程中互相适配的 concurrent loco-manipulation。

现有系统面对这个设定有一个结构性缺口。绝大多数 VLA 围绕 arm-centric 操作设计，输出末端或手臂动作；mobile manipulation 用轮式底盘扩展工作空间，但底盘和手臂仍是分开的功能模块；人形 VLA 虽有进展，却普遍依赖「先走到位、再站定操作」的分解。这类分解在站定操作时够用，一旦稳定执行依赖同时迈步、调躯干、伸手、维持接触，它就成为限制。论文由此主张：全身协调应当被直接学出来，而不是从分开设计的模块里间接涌现。

§ 2 — 前人工作与不足 ​

论文把最相关的对手锁定在 humanoid WAM 上，并给出两条精确批评。

DiT4DiT 用一个 video DiT 和一个 action DiT 联合建模，但它的人形动作接口仍然是上下半身解耦设计；MotionWAM 把动作生成条件在视频世界模型的中间去噪特征上，并预测统一的全身运动 token。两者共同的选择是让视频动力学充当动作预测的核心中间表示。论文指出这在真实人形上代价很高：视觉观测本身有噪声，会被机器人自身躯体或手持工具遮挡，并在移动过程中不断变视角；当动作生成强依赖一条预测出来的视频轨迹时，这条轨迹的时间不一致会被放大成执行上的突变、迟疑和全身失稳。更关键的一条：提升像素级视频保真度并不必然改善控制，因为实时人形执行需要的只是「对选下一个全身动作有用的紧凑未来信息」。

在 VLA 一侧，Ψ-0 用 AMO 作为下层控制器、高层策略主要预测上肢与手部动作，结构上仍与全身控制解耦；OpenHLM 表明直接暴露完整人形动作空间对长时程 loco-manipulation 有益；WholeBodyVLA 从无动作标注的第一人称视频学习并引入面向 loco-manipulation 的 RL 定位策略。论文对这条线的判断是：它们集中在「观测到动作」的直接学习或执行接口改良上，未来视觉建模在人形全身动作生成里仍然缺席。

§ 3 — 重建作者的思考路径 ​

只用这篇之前已有的东西推：SONIC 已经把人形全身运动跟踪扩到大规模运动语料，并对外提供一个可在真机执行的控制器接口——这意味着存在一个现成的、真机可执行的全身动作潜空间。FAST tokenizer 已经证明连续动作可以离散化成 token 喂给自回归 VLM。V-JEPA 已经证明「预测未来 embedding」这个 reconstruction-free 目标能学到有用的表征，不必回到像素。

把这三件事摆在一起，设计几乎是被逼出来的。既然控制器已经定义了动作空间，策略要做的就是输出这个空间里的 latent，而不是自己再造一套关节指令。既然真机人形数据昂贵而人类视频与公开动作数据充足，那么把人类动作在仿真里用同一个控制器 replay 一遍，就能把它们翻译进这个 latent 空间——跟踪不了的直接丢掉。既然像素保真度与控制质量不对齐，未来预测就该退回 embedding 空间，只当辅助监督，不当主通路。

§ 4 — 核心 Intuition ​

未来预测对控制的价值在于提供任务进度和场景演化的线索，而不在于画面好看。所以把它压缩成「预测未来观测的 embedding」这条轻量目标，让 motion query 通过 cross-attention 去读 video query，把预期的未来注入动作表示，然后由 action DiT 直接去噪出控制器兼容的全身 action latent。这样既保留了世界建模的收益，又不需要大视频生成器，也不需要推理期把视频反演成动作。

§ 5 — 具体方法与完整 Pipeline ​

拿任务 6「Mop the floor」走一遍。输入是语言指令 ℓ、当前视觉观测 otv​、机器人本体状态 st​（47 维：身体关节位置、灵巧手关节位置、由 IMU 四元数转成的连续 6D 躯干旋转；IMU 的线加速度与角速度被丢弃）。输出是长度 H=25 的全身 action latent chunk（66 维 = 64 维 SONIC 全身动作 latent + 左右手各一个 [0,1] 的抓握标量）。

  1. Stage 1，全身动作 VLM 预训练。先在统一 SMPL 表示上训一个 whole-body FAST tokenizer，把连续全身轨迹编码成离散 token；再把 Qwen3-VL-2B-Instruct 微调成动作 VLM，输入序列是 x=[ev​,otv​,ℓ]，其中 ev​ 是区分第一/第三人称的可学习 view token，训练目标是自回归预测动作 token。数据来自 ARCTIC、Xperience-10M、Motion-X 的合并与人工过滤。
  2. Stage 2，人到人形的 action-latent 预训练。公开数据没有机器人 proprioceptive state 和控制器 latent，于是用 SONIC 在仿真里批量 replay 这些运动轨迹，记录对应的机器人状态与全身 action latent；SONIC 跟踪不了的（Motion-X 里大量武术类高动态动作）被丢弃。未来视觉 ground truth 由冻结的 Wan encoder 提取。
  3. 联合预测器。prefix 条件 p=[fvlm​,fℓ​,rv​,ftv​] 由 VLM 特征、T5 文本特征、view token 和 V-JEPA 视觉特征拼成。两组可学习 query：motion query 数量与动作 chunk 对齐，video query 对应未来视觉 latent token。三类 token 用不同 RoPE——prefix 视觉 token 用 2D，future video query 用 3D，action query 用 1D 时间 RoPE。
  4. Stage 3，真机微调 + RTC。在 2220 条真实轨迹（11 个任务，每任务约 200 条演示）上微调，V-JEPA、Wan encoder 与 VLM 全程冻结。训练时随机采一个前缀长度 M∈[0,8]，把噪声动作序列的前 M 帧替换成干净 latent，只对非前缀部分算损失。
  5. 部署。SONIC 作下层控制器，单次前向约 0.14 秒（>7 Hz），预测长度 25 的 chunk 但只执行前 K=8 步就重新取图；上一次预测中未执行的部分作为下一次去噪的前缀初始化，并对 chunk 边界做线性 overlap blending。未来视觉分支在部署时不参与实时控制，只在需要可视化时才接一个额外的视频解码器。

§ 6 — 核心数学推导 ​

tokenizer 用 L1 重建约束：Ltok​=∥a^t:t+H​−at:t+H​∥1​。VLM 用标准 next-token 损失 Lvlm​=−∑i=1N​logpθ​(ci​∣c<i​,ℓ,otv​,ev​)。

真正体现设计意图的是双 query 的注意力拓扑。两组 query 先各自自注意力，再分别 cross-attend 到 prefix：qˉ​m​=CrossAttnm​(q~​m​,p~​)，qˉ​v​=CrossAttnv​(q~​v​,p~​)，然后是关键的一步单向连接：

hm​=CrossAttnmv​(qˉ​m​,qˉ​v​),hv​=qˉ​v​

motion query 读 video query，反向不通。这条不对称正是「未来预测是辅助信号而非主通路」的形式化：视觉分支永远不接受来自动作分支的梯度回流去迎合动作，只被自己的目标 Lvideo​=∥hv​−yt+1:t+Kv​∥22​ 约束，其中 yv=EWan​(ot+1:t+Kv​)。

动作分支用 x0​-prediction 而非噪声预测：zτ​=αˉτ​​z0​+1−αˉτ​​ϵ，z^0​=Dθ​(zτ​,τ∣cdit​)，Laction​=∥z^0​−z0​∥22​。Stage 2 总目标 Lstage2​=Laction​+λvideo​Lvideo​；Stage 3 把动作项换成只在非前缀区间计算的 LRTC​=∥z^0M+1:H​−z0M+1:H​∥22​。干净前缀在这里的作用是时间锚点：它让相邻 chunk 不再是从独立高斯噪声各自采样出的两段，从而消掉接缝处的高频跳变。部署时再叠一层线性混合 ajblend​=(1−αj​)ajprev​+αj​ajnext​，αj​=O+1j+1​。

归一化上论文分了两套：64 维控制器 latent 用均值方差归一化，机器人状态与两维手部指令用 min-max，理由是后者的取值边界本身带语义（1 全握、0 全开）。

§ 7 — 实验设计与结论 ​

评测怎么定的？11 个真实家务任务，每个任务每个方法跑 10 次独立试验，三个指标：success rate（全部目标完成才算成功）、score（把任务拆成子任务，完成一个记一分，全套上限 41 分）、task progress（首次失败前走完的有序子任务比例）。所有方法都是单一多任务策略，不训练任务专属策略。

主结果（SR / Score / Progress）：ACT 8.2 / 10.6 / 32.4，Diffusion Policy 15.5 / 14.8 / 40.6；VLA 一档 π-0.5 为 27.3 / 20.9 / 52.8，InternVLA-M1 为 31.8 / 21.8 / 55.6，EgoVLA 为 25.5 / 18.6 / 49.1，GR00T-N1.7 为 22.7 / 19.7 / 49.8；人形与 WAM 一档 Ψ-0 为 44.5 / 23.6 / 59.6，Fast-WAM 为 37.1 / 22.3 / 57.8，DiT4DiT 为 43.6 / 23.1 / 61.0。ω-0 的两个变体分别是 79.1 / 35.8 / 88.7（Ego）与 81.8 / 36.7 / 90.3（Omni，在 5 个 locomotion 重的任务上改用第三人称观测）。

消融最能说明问题（同样是 SR / Score / Progress，满配 Ego 为 79.1 / 35.8 / 88.7）：去掉机器人状态掉到 60.9 / 29.8 / 75.6，去掉 video query 掉到 64.5 / 30.6 / 77.9，去掉 VLM prefix 为 66.4 / 31.7 / 79.8，去掉训练期 RTC 为 71.8 / 33.4 / 84.1。也就是说，未来视觉 latent 预测这一支贡献了约 14.6 个百分点的成功率，量级仅次于本体状态。

一个反直觉的结论值得单拎出来。论文比较了用 Wan encoder 还是 V-JEPA 编码当前帧：用 Wan 时输入输出处在同一 latent 空间，离线未来 latent 预测更准，但真机成功率只有 63.6。作者的解释是 Wan 为时间连续视频设计，部署时每步只有单帧，编出来的表示对动作生成信息量不足，机器人因此表现得过于静止和迟疑。论文据此得出：离线未来 latent 重建准确度本身不足以预测控制性能。

数据侧：ω-HOME 收了 40.3 小时、4827 条 episode、24 个任务、30 Hz，含第一人称 RGB、第三人称 RGB-D、全身 SMPL 运动、机器人状态与 action latent。为避免任务泄漏，Stage-2 预训练池里排除了 11 个下游评测任务，剩余轨迹与公开人类数据混合；加入后 Ego 从 79.1 升到 80.4、Omni 从 81.8 升到 82.4。三个训练阶段都在 8 张 H100 上完成。

§ 8 — Take-aways ​

5 句版：真实人形边走边操作的瓶颈不在动作解码器容量，而在把任务拆成导航段和操作段的结构性分解；ω-0 直接输出 SONIC 控制器兼容的 66 维全身 action latent，绕过了上下半身接口分裂；未来预测被降级成 V-JEPA 式的 embedding 预测并通过单向 cross-attention 注入动作分支，训练时有效、推理时可整支关掉；公开人类动作数据靠控制器仿真 replay 被翻译进机器人可执行的 latent 空间，跟踪不了的直接过滤；消融显示未来视觉分支值约 14.6 个点成功率，而离线 latent 重建更准的 Wan 变体在真机上反而更差。

3 句版：世界模型对控制的价值可以只保留「未来的紧凑表示」，不必保留像素。ω-0 让 action DiT 直接对着控制器的 latent 空间去噪，用未来 embedding 预测当辅助监督，用训练期 RTC 解决 receding-horizon 的接缝问题。11 个真实家务任务、单一多任务策略、8 张 H100，成功率从最强基线的 44.5 提到 81.8。

1 句版：预测未来是为了选下一个动作，不是为了画下一帧。

§ 9 — 最脆弱的假设 ​

整套设计押在一个前提上：SONIC 的 action latent 空间是一个充分且稳定的动作接口——全身行为可以被 64 维控制器 latent 加两个手部标量完整指定，并且凡是控制器跟踪不了的运动都可以安全地从训练数据里删掉。

这个前提一旦不成立，代价是整条数据管线的方向性偏置。论文明说 Motion-X 里大量高动态动作因 SONIC 无法可靠执行而被过滤，这意味着训练分布是被控制器的能力边界裁剪出来的：策略永远学不到控制器跟踪不了的行为，而且这种缺失在评测里看不见，因为评测任务同样是用 SONIC 遥操作采集的。论文没有给出被过滤掉的比例，也没有报告过滤前后的动作分布差异，这一块证据是缺的。

第二层风险在于 latent 的语义稳定性。策略输出的是控制器的中间表示而非物理量，一旦控制器换版本或换本体，这 64 维的含义就变了，上层模型的全部权重随之作废。论文展示的 cross-object 与 cross-scene 泛化都发生在同一台 G1 加同一个 SONIC 上，没有跨控制器的证据。可以推断（论文未显式声明）：ω-0 学到的是「在这个控制器的可达行为流形上做条件生成」，这与「学到全身运动本身」是两件事。

§ 10 — 最小复现实验 ​

只验证论文里最可迁移、也最容易被忽略的那条结论：离线未来预测精度与下游控制性能不同向。

  • 数据：任意公开操作数据集（LIBERO 或 RoboTwin 一类的仿真套件即可），不需要人形硬件。
  • 实现：搭一个最小 WAM——冻结视觉编码器 + 若干 video query 预测未来 latent + 一个小 action head。同一架构训两版，唯一差异是当前帧编码器：一版用视频 VAE 编码器（与未来 latent 同空间），一版用单帧自监督编码器（V-JEPA 或 DINOv2）。
  • 测量：两条曲线同时记——未来 latent 预测的 MSE，以及仿真 rollout 成功率。关键是看二者在训练过程中的相关性。
  • 判据：若同空间那版 MSE 显著更低但成功率不更高甚至更低，就复现了论文的观察，说明「未来预测更准」不能作为 WAM 的选型依据；若两者同向上升，则论文的解释（单帧输入下视频编码器信息量不足）不成立，需要另找原因。

§ 11 — 最强反例设计 ​

攻击点一：统计功效。 每任务 10 次试验、11 个任务共 110 次。在 p≈0.8 附近，110 次试验的标准误约 3.8 个百分点。Ego 79.1 与 Omni 81.8 的差距折合约 3 次成功，落在噪声里；表 3 中加入 ω-HOME 预训练带来的 79.1→80.4 与 81.8→82.4 更是 1 次和 0.7 次试验的量级。论文没有报告置信区间或多 seed 重复。最有力的检验是把试验数提到每任务 30 次并给出区间：可预测的结果是 w/o video query 的 14.6 点差距稳稳存活，而 Ego/Omni 差距与 ω-HOME 预训练收益大概率被吸收掉——那样的话论文关于「omni-view 设计有效」和「ω-HOME 作为预训练数据必要」这两条结论就失去了证据支撑。

攻击点二：混淆变量。 论文写明所有基线都「在我们的真实数据上训练或微调，并在同一协议下评测」，但 ω-0 额外享有 Stage-1 的全身动作 token VLM 预训练与 Stage-2 的人类数据 SONIC replay 预训练，基线没有对应处理。于是 79.1 与 43.6（DiT4DiT）之间的差距至少有三个可能来源：latent 预测式的架构、多阶段预训练带来的额外数据、以及输出空间与 SONIC 对齐带来的执行优势。要拆开这个结的实验是：拿 DiT4DiT 或 Fast-WAM 的动作头改成同样输出 SONIC latent，并给它同一份 Stage-2 replay 数据，再比。如果差距大幅收窄，那么论文的核心增益应当归因于接口对齐与数据管线，而不是「latent predictive」这个建模范式。

§ 12 — Follow-up Research Idea ​

驱动局限：SONIC 的跟踪失败被当成噪声丢弃。但跟踪失败是有信息的——它精确标出了控制器能力的边界在哪里，而这条边界恰好就是下一步该扩张的地方。当前管线把这个信号当垃圾扔了。

新 framing：把「过滤器」翻转成「课程」，让控制器与策略共同演化。具体说，replay 时不只记录成功轨迹，还记录每条被拒轨迹的跟踪误差；误差刚超阈值的那一带（near-miss band）不是物理不可行，而是控制器暂时不会——它们构成一个自然生成的、随能力增长而自动推进的训练前沿。控制器在这一带上做定向微调，被收回的运动再回流进策略的预训练池，如此循环。这样 action latent 空间的覆盖范围不再是外生给定的常数，而是一个被主动扩张的对象。

可借鉴的邻域工具：自动课程生成里的 goal 难度自适应（把「刚好学得会」形式化为成功率区间）；robust control 里 region of attraction 的估计与扩张，正好对应「控制器可靠跟踪的运动集合」这个同构概念；主动学习里按信息增益而非按置信度采样的判据，用来决定先修哪一类失败。

第一个实验：先做度量而非建模——按运动类别统计 Motion-X 与 Xperience-10M 在 SONIC replay 下的丢弃率与跟踪误差分布，画出误差直方图，确认是否存在一个可分离的 near-miss 带（如果误差分布是连续单峰，这个 idea 的前提就不成立，这本身也是有价值的阴性结果）。若存在，只在这一带上微调控制器，重新 replay，测两件事：被收回运动的比例，以及用扩充后数据重训的策略在原 11 个下游任务上的成功率变化。关键对照是「同样数据量、但随机补充而非定向补充」，用来排除单纯的数据量效应。

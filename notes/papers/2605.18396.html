NEWTON: Agentic Planning for Physically Grounded Video Generation ​

项内容
arXiv2605.18396
提交日期2026-05-18
作者Yuxiang Feng, Juncheng Wang, Chao Xu, Yijie Qian, Huihan Wang, Wenlong Hou, Yang Liu, Baigui Sun, Yong Liu, Shujun Wang
分类cs.CV
一句话把视频生成降级成 agent 工具箱里的一个动作：一个用 Flow-GRPO 在线训练的 planner 调度关键帧生成 / Python 物理计算 / prompt 精化三种工具，再由 verifier 打分驱动最多五轮重规划，生成器全程冻结。

所属教程：物理感知视频生成

版本说明

本文基于 v2 全文（v1 提交 2026-05-18，v2 修订 2026-05-19）。frontmatter 日期用 v1 提交日。

§ 1 — 研究问题与重要性 ​

视频生成模型的画面质量已经逼近实拍，但物理仍然系统性地错。在 VideoPhy-2 上，最好的模型的 joint accuracy（语义遵从 SA≥4 且物理常识 PC≥4 同时满足）只有 32.6%，守恒律违反率接近 40%。球不接触也会变速、下落物体无视重力、碰撞不守动量——这些不是偶发瑕疵，而是跨力学、光学、热学、材料几乎全域的失败。

本文的诊断很锋利：根因不是容量不足，而是规格不足（specification bottleneck）。DiT 类生成器的全部指导都从 conditioning 进入，而文本 prompt 是对物理世界的有损压缩。「一个球从桌沿滚下」这句话省略了质量、摩擦系数、桌高、初速度、下方地面材质，而这些参数共同决定轨迹。生成器只能从一句话里幻觉出一组自洽的取值——这是一个病态问题，产物必然是视觉合理而物理不自洽的动态。

从这个诊断出发，作者推出物理 conditioning 必须同时满足的三条性质：充分性（覆盖足以确定动力学的物理维度）、动态性（随场景自适应，不同场景需要不同的物理规格）、可验证性（能检查输出是否遵守目标物理，不对就纠正）。这个三元组本身就是本文最有价值的产出之一：它把「视频物理不对」这个模糊抱怨，转成了一个可以逐条检查的设计规范。

§ 2 — 前人工作与不足 ​

第一条路线是把仿真器当先验。PhysMotion 用可微 MPM 推进粗糙的 3D Gaussian 物体再用 T2I 精修帧；PhysCtrl 在 550K 条覆盖弹性 / 沙 / 塑性 / 刚体四类材料的仿真轨迹上训练生成式物理网络；PhysChoreo 进一步做单图的部件级材质场重建，驱动一个可时序指令化的可编辑仿真器。这类方法的连续介质力学行为确实强，但锁死在一个固定的仿真器族，不会因场景切换而换工具——它们满足充分性，不满足动态性。NewtonGen 走的是另一个极端，把线性物理约束的 Neural ODE 加残差 MLP 嵌进生成器，对单物体连续运动很优雅，但按构造就难处理碰撞与多体交互。

第二条路线是改生成器让它内化物理。VideoREPA 从自监督视频基础模型蒸馏 token 级关系；WISA 把物理拆成文本 / 定性 / 定量三层信号，经 Mixture-of-Physical-Experts 注意力块注入，配 WISA-80K 数据集；ProPhy 用两阶段 Mixture-of-Physics-Experts 加 VLM 蒸馏精修块做区域级各向异性对齐；PhyGDPO 用奖励后训练平移隐式先验。这些都是 one-shot 的：训完就固定，没有逐样本验证，不满足可验证性。ControlNet 式的固定模态条件（深度、身份）同理，不能跨物理域自适应。测试时搜索（如 Video-T1）虽然有反馈，但只在生成器内部搜索，无法调用外部知识。

最接近本文的是 CECT（Chain of Event-Centric Causal Thought），用 LLM 推理一串物理合理的事件链去条件化扩散模型。作者明确划出三点差异：（i）CECT 输出的是加料后的文本事件链，NEWTON 挥舞的是异构工具库，输出的是 prompt 本身承载不了的显式物理信号；（ii）CECT 只规划一次，NEWTON 用 VideoPhy-2-AutoEval 闭环验证并最多重规划五轮；（iii）CECT 依赖通用 LLM 的冻结推理，NEWTON 的 planner 在活的循环里 on-policy 训练。

§ 3 — 重建作者的思考路径 ​

沿着这篇论文之前已有的事实往前走，路径其实相当自然。第一步观察：扩模型和加数据没有关掉物理这个缺口（多篇工作已记录这一点）。第二步：既然容量不是瓶颈，那问题就在输入端——DiT 的所有指导都经由 conditioning 进入，而 conditioning 的上限就是生成质量的上限。第三步：人类已经花了几个世纪把物理写成了结构化定律，给定参数就能完全确定轨迹；而现在的生成器却在从无标注视频里重新发现牛顿定律，既低效又受训练覆盖面所限。第四步顺理成章：不要重训生成器，去把 conditioning 变富——给它物理正确的关键帧、定量约束和精确 prompt，它现有的容量就够把物理渲染对。

剩下的问题只有一个：怎么为一个给定 prompt 自动获取并组织「对的物理知识」。这要求系统能推理场景缺哪些物理量、能访问异构外部来源去补齐、还能根据评估反馈迭代。这三样能力——自适应推理、异构工具使用、闭环纠错——恰好就是自主 agent 的定义。同期 AgentFlow 已经证明 planner–executor–verifier–generator 这套栈用 on-policy 的 Flow-GRPO 训练，能在文本推理任务上显著超过冻结编排，并且报告了离线 SFT 在 agentic 场景反而比冻结基线掉 19% 平均精度。把这条经验搬到视频生成上，NEWTON 的形态就确定了。

§ 4 — 核心 Intuition ​

文本 prompt 是物理世界的有损压缩，生成器被迫幻觉那些从未被指定的参数。与其扩大模型去猜得更准，不如在生成之前先把参数算出来、画出来、写清楚。视频生成因此从系统的输出，降级为 planner 工具箱里的一个动作；planner 学的不是物理本身，而是「这个场景缺哪块物理、该调哪个工具去补」，再由一个 verifier 打分告诉它补对了没有。

§ 5 — 具体方法与完整 Pipeline ​

系统由三个角色构成，只有 Planner 可训练，工具库、视频生成器、Verifier 全部冻结。

  • Planner：一个 VLM（实现用 Qwen3.5-9B）。在第 t 轮读取记忆状态 Mt​（原始 prompt、此前所有工具调用与输出、verifier 反馈），输出结构化动作 at​∼πθ​(at​∣q,Mt​)，指定调用哪些工具、参数是什么。动作空间很松：可以调任意工具子集、可以触发视频生成、也可以整轮跳过。
  • Executor：派发工具调用与冻结生成器。触发生成时，把累积的工具输出按生成器接口喂进去——精化后的 prompt 作为文本，关键帧作为图像。框架对生成器不可知。
  • Verifier：多模态评估模型，对每条视频打 SA 与 PC 两个标量分，写回记忆。

三种工具正对规格瓶颈的三个互补维度。关键帧生成用 T2I 模型在指定时间位置产图，planner 为每张关键帧单独写 prompt 编码期望的物理状态（例如中间帧写「球处于抛物线顶点」），这相当于给轨迹施加时序边界条件，把生成器的插值锁在物理自洽的状态之间。Python 计算提供沙箱环境算抛体轨迹、动量守恒、转动动力学，数值结果进入记忆并指导后续的关键帧 prompt。Prompt Refiner做自然语言层面的补写，补上原 caption 缺的材质属性与场景约束。

举一个论文里的真实例子：「把一瓶啤酒倒进杯子直到倒满」。所有基线的液面高度都固定不动，NEWTON 渲染出渐进上升的液面与堆积的泡沫。另一例「小刀在木头上刻出一道槽」，NEWTON 产生逐渐加深的凹槽与堆积的木屑，基线连材料去除都没启动。

系统跑固定 T 轮，形式化为有限时域 MDP：记忆确定性更新 Mt+1​=fmem​(Mt​,at​,et​)，不是每轮都必须出视频（早期轮可以只做计算和 prompt 精化），最终返回所有轮里 verifier 分最高的那条视频。记忆里不存视频本身，只存标量分数以控制上下文长度。

§ 6 — 核心数学推导 ​

生成器侧是标准 flow matching。给定噪声 ϵ 与干净 latent z 的插值 zt​=(1−t)ϵ+tz，模型学速度场：

Lflow​=Et,z,ϵ​∥uθ​(zt​,t;C)−(z−ϵ)∥22​

其中 C 是 conditioning 上下文。这一式的意义在于点破全文的立论：生成器的一切可控性都从 C 进入，生成质量被 conditioning 质量所界定。NEWTON 完全不动 θ，只改 C。

Planner 侧用 Flow-GRPO，一种面向稀疏奖励多轮 agent 的 on-policy 算法：把单个 trajectory 级奖励广播到每一轮，把多轮 credit assignment 化为可处理的单轮更新。对每个 prompt q 采 G 条并行 rollout {τi​}，每条执行完整 T 轮再给奖励，优势做组内归一化：

Ai​=std({R(τk​)}k=1G​)R(τi​)−mean({R(τk​)}k=1G​)​

组内归一化的直觉是：不需要学一个价值函数，只需要知道这条 rollout 比同一 prompt 下的同伴好多少。策略用裁剪代理目标更新：

J(θ)=E[G1​i∑​T1​t∑​∣ait​∣1​j∑​min{ρi,jt​Ai​, clip(ρi,jt​,1−ϵ,1+ϵ)Ai​}]−βDKL​(πθ​∥πref​)

ρi,jt​ 是 token 级重要性比。奖励是三项之和 R(τ)=Rquality​+Rkf​+Rcompute​：Rquality​ 是所有出视频轮次里最大 SA 与 PC 的分档函数（不是二值通过/失败，中间档奖励部分正确，比如高 SA 配中等 PC），这是为了在「两项同时高分极其罕见」的域里把优势信号变稠密；Rkf​ 是使用新生成关键帧且语义遵从过阈值时的固定奖励；Rcompute​ 要求 trajectory 里含有效物理计算（函数与参数都对）且 quality 奖励为正——这个合取是为了防止用空洞计算刷奖励。任何一轮格式或长度违规触发固定负奖励。

§ 7 — 实验设计与结论 ​

主问题：agentic 编排能否在不动生成器的前提下同时提升 PC 与 SA？ 在 VideoPhy-2（590 caption、197 个物理动作，Hard 子集 180 条，针对守恒律、多体碰撞、铰接动力学）上，NEWTON 挂在 LTX-Video-2B 上把 Joint 从 21.36% 提到 29.66%，Hard-Joint 从 4.44% 提到 12.22%（2.75×）。关键对照是 VideoREPA 与 WISA：VideoREPA 的 PC 最高（84.4% / Hard 86.1%），但 SA 崩到 7% 以下，Joint 反而低于 LTX 基线；WISA 是同样模式的弱化版。NEWTON 是表中唯一同时提升 PC 与 SA 的方法——这条对照比绝对数值更有说服力，因为它揭示了「只优化物理」的方法在偷偷牺牲语义遵从。

跨基准泛化？ 同一个训好的 planner 不重训直接上 PhyGenBench（160 prompt，力学 / 光学 / 热学 / 材料），平均从 0.510 升到 0.560，超过最强开源生成器 Wan2.2-TI2V-5B 的 0.544，而骨干小 2.5 倍。但增益分布极不均匀：光学 +0.067、材料 +0.092、热学 +0.044，力学基本没变（−0.008）。这是一个诚实但值得注意的结果：三种工具里最「物理」的那个（Python 抛体 / 动量计算）本该在力学上最有效。

训练策略消融最关键。 同一个 Qwen3.5-9B planner，Frozen（只提示）已经拿到 Joint 28.14 / Hard-Joint 8.89，Offline SFT 28.81 / 10.56，Flow-GRPO 29.66 / 12.22。也就是说相对 LTX 基线 21.36 的总增益 8.30 点里，6.78 点来自 agentic 脚手架本身（工具 + 五轮 best-of-T 选择），只有 1.52 点来自 on-policy 训练；在 Hard 子集上 RL 的边际贡献大一些（8.89 → 12.22）。论文的说法「Flow-GRPO 把 SFT 相对 Frozen 的增益翻了一倍」在字面上成立，但翻倍的是一个小量。

其余消融。 Planner 规模 2B/4B/9B 的 Hard-Joint，正文写「单调上升 7.22% → 9.44% → 12.22%」，但表 3 的 4B 行实际是 5.00，且 4B 的 Hard-PC（72.22）也低于 2B（74.44）——正文与表格不一致，按表格读则规模效应并非单调。轮数 T∈{2,3,5} 各自单独训练，Hard-Joint 4.44 → 10.00 → 12.22，但 T=3 的全集 PC（82.88）略高于 T=5（82.71）。生成器骨干替换在 100 条子集上做（为控 Veo-3.1 API 成本）：LTX Joint +8.4，Veo-3.1 从 30.74 提到 37.41（+6.7），说明增益叠加在更强骨干上而不是替代它。人类偏好研究用 197 个 prompt、20 名志愿者、双盲双问强制选择，结论方向与自动指标一致（原文只给图，未给数值）。

§ 8 — Take-aways ​

5 句话版。 视频生成的物理失败源于规格不足而非容量不足，文本 prompt 是物理世界的有损压缩。任何物理 conditioning 必须同时满足充分性、动态性、可验证性，而现有方法一个都没同时满足。NEWTON 把视频生成降级为 planner 工具箱里的一个动作，用关键帧 / Python 计算 / prompt 精化构造富 conditioning，用 verifier 闭环最多重规划五轮。planner 是唯一可训练组件，用 Flow-GRPO 在活循环里 on-policy 训练，分档奖励加工具使用 bonus 让稀疏信号变稠密。在两个冻结生成器上 VideoPhy-2 的 Joint 都显著提升，且是表中唯一不牺牲 SA 换 PC 的方法。

3 句话版。 与其重训生成器学物理，不如在生成前把物理参数算好、画好、写清楚。一个 on-policy 训练的 planner 学会按场景调度物理工具，verifier 闭环负责纠错。代价是每条视频要跑到五轮生成，且系统直接优化的正是评测所用的那个 judge。

1 句话版。 物理一致性可以被工程化为 agentic 规划，而不必等待它从规模中涌现。

§ 9 — 最脆弱的假设 ​

最致命的一条：verifier 与主评测指标是同一个模型。NEWTON 的闭环打分器是 VideoPhy-2-AutoEval，训练奖励 Rquality​ 由它的 SA/PC 决定，最终输出是「所有轮里 verifier 分最高的那条」；而 VideoPhy-2 主表上报的 PC / SA / Joint 正是同一个 AutoEval 打的分。这意味着系统在测试时对目标指标做了 T=5 次的 best-of-N 选择，并且 planner 被显式训练去最大化这个指标。若 AutoEval 与真实物理正确性之间存在任何可被利用的偏差（这类 VLM judge 已被多篇工作记录有系统性偏好），NEWTON 报告的增益中就有一部分是对 judge 的过拟合而非物理的改进，且这部分无法从主表中分离。

论文为此提供了两条辩护证据，强度不同。较强的一条是 PhyGenBench 跨基准迁移：换了 prompt 集、换了官方 VLM 评分协议，平均仍从 0.510 涨到 0.560——说明不全是 judge 过拟合。但增益只有 +0.05，且力学域为 −0.008。较弱的一条是 197 prompt / 20 人的偏好研究，原文只给了柱状图不给数值，无法核验幅度。真正缺失的对照是：用一个与 AutoEval 无关的 verifier 训练一遍 planner，再在 AutoEval 上评测，或者反过来。没有这个交叉，「优化了物理」与「优化了打分器」在证据上无法区分。

§ 10 — 最小复现实验 ​

一周可做，不需要复现 RL 训练。目标是量化「agentic 脚手架 vs. best-of-N 采样」的分解——这是论文没做但最该做的对照。

  • 数据：VideoPhy-2 测试集里随机 100 条 caption（覆盖 Hard 与非 Hard）。
  • 生成器：LTX-Video-2B（开源、2B，单卡可跑）。
  • 三个臂，每臂对每条 caption 产 5 条视频，全部用 VideoPhy-2-AutoEval 打分并取最高分那条：（A）朴素 best-of-5：同一原始 prompt 用 5 个不同随机种子；（B）prompt-only agent：冻结的 Qwen 类 VLM 每轮只做 prompt 精化 + 读上一轮分数，5 轮；（C）完整冻结 NEWTON：三种工具全开，5 轮，planner 不训练（对应论文的 Frozen 行）。
  • 测量：三臂的 PC / SA / Joint；额外用一个与 AutoEval 无关的第二打分器（例如 PhyGenBench 官方协议或一个未微调的开源 VLM）复评同一批视频。
  • 判定：若 (C) 相对 (A) 的 Joint 增益在第二打分器上保留大半，则「工具构造的 conditioning 确实有物理价值」得到支持；若 (A) 就吃掉了大部分增益，或增益在第二打分器上蒸发，则论文的核心贡献要重新归因到 best-of-N 与 judge 过拟合。

§ 11 — 最强反例设计 ​

站在反对者立场，最有力的攻击是给出一个完整的替代解释：NEWTON 的增益 = best-of-5 采样 + 关键帧作为 I2V 条件的构图收益 + 对 AutoEval 的适配，物理计算工具的贡献接近零。

支撑这个解释的证据全部来自论文自己。第一，Frozen planner（完全没训练）已经吃掉总增益的 82%（21.36 → 28.14，总共到 29.66），说明主体来自架构而非学习。第二，PhyGenBench 上力学域是唯一没有改善的域（−0.008），而力学恰恰是 Python 计算工具唯一真正能算的域（抛体轨迹、动量守恒、转动动力学）；改善集中在光学（+0.067）与材料（+0.092），这两个域最可能由 prompt 精化与关键帧的外观收益驱动，而不是由数值计算驱动。第三，论文没有做工具级消融——没有「去掉 Python 计算」「去掉关键帧」「去掉 prompt 精化」的三条对照，因此无法反驳「三个工具里真正起作用的只有最不物理的那个」。第四，正文关于 planner 规模单调性的陈述与表 3 的 4B 行（Hard-Joint 5.00 而非正文的 9.44）矛盾，弱化了「更强的规划器学到更好的物理调度」这一叙事。

一个可预测的失败场景：给 NEWTON 一个关键帧无法编码的物理任务，例如「杯中的水在 30 秒内因蒸发缓慢下降 2 毫米」或「金属棒受热后长度变化」。这类任务的正确性藏在微小的连续量里，关键帧图像分辨不出，Python 能算出数值但生成器无法把「2 毫米」渲成可辨的像素差异。预测 NEWTON 在这类子集上的增益接近零，而 verifier 仍可能给出高分——这恰好同时证伪「工具补齐了充分性」和「AutoEval 可靠」。

§ 12 — Follow-up Research Idea ​

驱动局限：本文的 verifier 只输出两个标量，planner 只能靠「分低了」这一位信息去猜哪里错了；作者在 limitations 里也承认这一点。更深的问题是，整个系统假设物理知识可以被预先注入 conditioning，一次性把轨迹钉死；但真实物理是连续的因果链，中途的一次接触就会让此前所有规格作废。

新 framing：把 NEWTON 从「生成前规格化」改成**「生成中断言化」——不是在开头构造富 conditioning，而是让 planner 把 prompt 编译成一组带时间戳的可验证物理断言**（例如 t=1.2s 时杯中液面高度 ≥ 初始的 1.6 倍；碰撞前后总动量偏差 <5%），然后在扩散采样的中途逐段解码、逐段核验断言、只对违约的时间片重采样。

可借鉴的相邻领域工具：程序合成里的 CEGIS（counterexample-guided inductive synthesis）与运行时验证（runtime verification）。断言不满足时返回的不是一个标量，而是一个反例时间片，这正是 CEGIS 循环需要的信号形式；把它作为下一轮 planner 的输入，就把「分低了」升级成「第 1.2 秒液面没升」。

第一个实验：在 VideoPhy-2 的液体子集上，人工写 50 条带时间戳的断言，用现成的视觉估计器（液面高度可用分割 + 像素行统计近似）实现断言检查器。对比三条：整段重采样（现 NEWTON）、时间片重采样无断言（随机选片）、断言引导的时间片重采样。若第三条在相同生成预算下 Joint 更高，且断言违约率与 AutoEval 的 PC 相关性显著，则说明「稠密的、可定位的验证信号」值得取代标量 verifier——同时也顺带得到一个不依赖 VLM judge 的物理度量，正面回应 §9 的循环性问题。
